## 1. 使命(Mission)

源头事实(automath,已 codex 实证): 只能通过有限二元窗口观测动力系统时,被迫出现的结构是——无连续 1 的二进制词→数量 `F_{m+2}`(Fibonacci)→特征方程 `x²=x+1`(黄金比 φ)→golden-mean shift→fold/fiber/defect→Window6 edge-flux 有限计数(`Φ_R=1/12`,`P(leave U_R)=8/9`)→571 Green/Kirchhoff 证书(`τ(G_E)=123336=2³·3³·571`,mod-571 spectral collision)。这些在 automath repo 里有 Lean(0 axiom)finite certificate,是 **principled forced**,不是事后拟合。

本管线的研究使命是把这套被迫结构变成两类可审计产物:

- **Track A(downward / 生物消费)**: 把"有限窗口边界响应塌缩"这个**方法**喂给生物跨层残差(codon→蛋白丰度,即 bio_reality 的 `B*_Q6`/`P_Q=T+S+H+U`)。把"一堆 absorber 相加"重写成"base + 小参数边界响应函数 + 系数映射机制(wobble seam/tRNA 相位/核糖体逃逸)",每系数要独立证书。
- **Track B(upward / BEDC 消费)**: 把 automath 里**被迫且已 Lean 证书化**的窗口组合学(Fibonacci/x²=x+1/Window6 edge-flux/571 Green)重构成 BEDC NameCert(0-axiom forced),让 BEDC 体系能消费接受。

## 2. 铁律红线(决定什么进、什么不进)

科学宪章继承 BEDC/bio_reality + 加一条 numerology 防线:

1. **principled-vs-numerology gate(本域核心)**: 只有"被迫 + 有独立证书"的对象才进 NameCert/实验。源头是有限计数/动力学/Lean 证书强迫出来的→进;事后凑 φ 幂/素数拟合某个常数→挡在审计门外。
2. **independent certificate vs numerical tuning**: 每个系数/常数必须有**独立来源证书**(edge-flux/Green/Lean/生物机制),不允许只因拟合度提升入选。这正是源对话自己担心的("检查 q₃ 是否有独立证书,避免数值微调")。
3. **α 数值拟合先挡门外**: 用户提的 `D_{6,α}^* = 47+φ⁻⁷-(1/2)φ⁻¹⁷+(8/9)φ⁻²⁷`(凑 α≈1/137)**当前不在 automath repo、缺独立证书**=numerology 风险。**不进 BEDC、不当已证**,只作 `needs_formal_definition`/`numerical_tuning_risk` 假设,先在 automath 侧给 formal definition + 过对抗审计才够格升级。
4. **常数不跨域硬搬到生物**: `φ⁻¹⁰`(local return step)、`571`(prime gate)、`Z₆`(相位门)、`Φ_R=1/12`、`8/9` 是二元窗口/Window6 特有,**不能直接命名进 codon 生物**(DNA 4 字母/3-窗口,没先验理由)。生物侧只借**方法**,小参数 ε/ρ 必须从生物数据估。
5. **0-axiom 纯度**: 进 BEDC 的 NameCert 不得引入 numerology 当公理;只重构有 Lean 证书的被迫对象。
6. 继承: 禁编造、禁 over-claim、负面结果显式记录、数据/证书不足诚实返回 `needs_data`/`needs_certificate`、有接触≠进最小字典。
7. **域边界**: BEDC(`papers/bedc`)+ automath 是 **Loning 的域**。Track B 往 BEDC NameCert 写 = 动 Loning 论文体系,**需与 Loning 协调或经用户授权**;本管线自身路径 `tools/fibonacci_reality/*` + `papers/fibonacci_reality/*` 隔离,BEDC 写入走显式 bridge,不擅动 `papers/bedc` 现有章节。
