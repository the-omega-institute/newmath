\subsection{Translation-conditioned RNA half-life and decay-factor RBP occupancy}\label{subsec:bioreality-q6-rna-half-life-rbp-bridge}
\origin{ai}

\paragraph{Finite row surface.}
This record concerns a finite matched RNA panel in which each row carries a synonymous residual coordinate label after amino-acid quotienting, a same-row translation readout, an RNA half-life readout, a measured local occupancy readout for a prespecified decay-factor RNA-binding protein, and matched controls for composition, transcript state, and experimental batch. The coordinate contrast is the high-coordinate versus low-coordinate label within synonymous coding windows, not a protein-level or phenotype-level quantity. The biological question is whether a coordinate-associated RNA half-life residual can be read as a bounded cross-layer RBP bridge only when it is accompanied by the specified local RBP occupancy pattern and perturbation-rescue behavior.

The available RBP-binding finite run for the associated binding surface is the record $b225890251c2$. It contains $900$ total peak rows and reports $3$ cross-RBP concordant cases, with runtime $223.648043$ seconds. These numbers support only a finite binding-surface contact: they show that a row-level RBP-binding comparison has been instantiated, but they do not by themselves supply RNA half-life, same-window target-RBP loss, wild-type rescue, or binding-defective rescue rows. A second translation-layer finite run, $0c2bbfd3e2d9$, supplies an mTOR translation readout surface with $n=6494$ rows and runtime $9.469$ seconds. That translation fact is useful here only as a reminder that translation readouts must be attached as row data before promotion to a translation-conditioned RNA-stability claim; it is not evidence for the RBP bridge in this chapter.

\paragraph{Admissible statistic.}
Let each matched row $i$ contain a coordinate label $q_i$, a translation readout $T_i$, an RNA half-life readout $H_i$, a local occupancy readout $O_i$ for the prespecified decay-factor RBP, and a control vector $Z_i$. The control vector includes transcription rate, local RNA structure, motif density, GC and dinucleotide composition, codon-pair context, splice or isoform state, transcript abundance, amino-acid composition, batch, and the mandatory translation readout. A positive bridge is permitted only when a finite contrast has the following shape:
$$
\begin{aligned}
&\Delta_H(q \mid T,Z) \ne 0,\\
&\Delta_O(q \mid T,Z) \ne 0,\\
&\Delta_H(q \mid T,Z,\mathrm{target\ RBP\ loss}) \approx 0,\\
&\Delta_H(q \mid T,Z,\mathrm{wild\ type\ rescue}) \approx \Delta_H(q \mid T,Z),\\
&\Delta_H(q \mid T,Z,\mathrm{binding\ defective\ rescue}) \approx 0.
\end{aligned}
$$
The same pattern must fail for non-target controls. The point of this definition is not to infer a general RNA-decay law from codon geometry; it is to require that the finite coordinate contrast, the measured occupancy contrast, the loss condition, and the rescue condition all occur on the same externally grounded panel.

\paragraph{Null row interpretation.}
Under the matched null, high-coordinate and low-coordinate synonymous labels are exchangeable for RNA half-life after conditioning on transcription rate, local RNA structure, motif density, GC and dinucleotide composition, codon-pair context, isoform state, transcript abundance, batch, amino-acid composition, and same-row translation readout. If half-life differs but local measured RBP occupancy is unchanged, the row supports at most a finite RNA-stability association. If occupancy differs but target-RBP loss does not collapse the half-life contrast, the row supports at most a binding association. If loss collapses the effect but wild-type rescue fails to restore it, or if a binding-defective or non-target rescue restores it, the row does not support the claimed RBP bridge.

\paragraph{Readback from the finite runs.}
The $900$-peak RBP-binding run with $3$ cross-RBP concordant cases is compatible with a bounded binding contact, but it is below the required evidence surface for this RNA half-life bridge. The present finite data do not include the complete same-organism, same-window panel joining $q_i$, $T_i$, $H_i$, $O_i$, target-RBP loss, wild-type rescue, binding-defective rescue, non-target controls, and the declared control vector $Z_i$. The mTOR translation run with $6494$ rows demonstrates that translation readout data can be represented as finite rows in this project, but those rows are not a substitute for the required RNA half-life and RBP perturbation-rescue rows in this chapter.

\paragraph{Local boundary.}
The claim therefore remains a sharply bounded cross-layer relation: it may discuss only the finite conditions under which a synonymous residual coordinate, a translation-conditioned RNA half-life readout, and a prespecified decay-factor RBP occupancy-and-rescue pattern cohere on matched rows. It does not license translation realization from RNA half-life alone. It does not license protein output, folding, physical admissibility, biological function, phenotype, adaptation, causation, mechanism, or universality. Any such statement would require its own layer-matched contact and its own finite statistic. In particular, codon-window geometry, coordinate notation, RBP peak presence, and workflow eligibility are not biological mechanisms; they become relevant only when joined to measured row-level contacts that satisfy the loss and rescue tests above.
