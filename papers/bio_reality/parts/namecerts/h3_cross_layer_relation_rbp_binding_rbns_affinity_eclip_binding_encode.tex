\subsection{Translation-conditioned RBP occupancy as a bounded RNA half-life bridge}\label{sec:bioreality-rbp-binding-rbns-eclip-encode}\origin{ai}

\paragraph{Finite carrier.}
This record concerns a finite matched panel whose rows are coding-transcript or CDS windows equipped with a $B^{\ast}_{Q6}$ synonymous residual coordinate label, an amino-acid quotient, a same-row translation readout when available, an RNA half-life readout, a measured local occupancy surface for a prespecified decay-factor RNA-binding protein, and matched controls. The intended biological object is not an unconstrained RBP enrichment statement. It is the narrower situation in which high-coordinate and low-coordinate synonymous residual labels are compared only after amino-acid identity, transcription rate, transcript abundance, splice or isoform state, local RNA structure, motif density, GC and dinucleotide composition, codon-pair context, batch, and the translation readout have been accounted for. The finite run for the RBP-binding evidence surface is recorded as experiment $\mathrm{b225890251c2}$, with $900$ total peak rows, $3$ cross-RBP concordant rows, and runtime $223.648043$ seconds. These numbers fix the available evidence scale: the present table is a small finite contact with detectable cross-RBP concordance, not a general RNA-decay law.

\paragraph{Readout separation.}
The row schema keeps three finite objects distinct. First, the coordinate object labels synonymous residual windows after the amino-acid quotient. Second, the RBP object records whether a measured target decay-factor RBP occupancy signal is present, absent, or reduced at the editable RNA window. Third, the RNA-stability object records translation-readout-conditioned RNA half-life residuals after transcriptional and abundance controls. The comparison may be summarized by a bounded statistic of the form
$$
\begin{aligned}
\Delta_H &= H_{\mathrm{high}\ Q6}-H_{\mathrm{low}\ Q6},\\
\Delta_O &= O_{\mathrm{target\ RBP,present}}-O_{\mathrm{target\ RBP,reduced}},\\
B_{\mathrm{RBP}} &= \mathbf{1}\{\Delta_H\neq 0,\ \Delta_O\neq 0,\ \Delta_H\ \text{collapses under target-RBP loss}\}.
\end{aligned}
$$
Here $H$ denotes the controlled RNA half-life residual and $O$ denotes measured local occupancy of the prespecified decay-factor RBP. The indicator is only a bookkeeping form for the finite panel. It does not assert causation unless the perturbation and rescue rows are actually present.

\paragraph{Translation conditioning.}
Translation information is mandatory but not sufficient. A linked translation-readout run in the same evidence ledger, experiment $\mathrm{0c2bbfd3e2d9}$, contains $6494$ rows from the Thoreen mTOR translation source and ran in $9.469$ seconds. That run demonstrates the scale of an available translation surface, but it is not by itself the RBP-decay panel required here. The RBP bridge requires a same-row join: the same transcript or CDS window must carry the coordinate label, the translation readout, matched mRNA abundance control, RNA half-life value, local RBP occupancy, and the loss/rescue control state. Without that join, a translation table and an RBP peak table remain separate finite contacts.

\paragraph{Support condition.}
A positive bridge is licensed only by the following finite pattern. High-coordinate and low-coordinate synonymous residual labels remain distinguishable for RNA half-life after the declared controls; the local occupancy of the prespecified decay-factor RBP changes at the same editable window; the coordinate effect is experimentally decoupled from occupancy so that the coordinate is not merely a proxy for motif density or structure; target-RBP loss collapses the RNA half-life effect; wild-type target-RBP rescue returns it; and binding-defective or non-target rescue fails to restore it. In finite-row language, the admissible readback has the shape
$$
\begin{aligned}
& H(q_{\mathrm{high}},T,Z)-H(q_{\mathrm{low}},T,Z)\neq 0,\\
& O_{\mathrm{target}}(q_{\mathrm{high}})-O_{\mathrm{target}}(q_{\mathrm{low}})\neq 0,\\
& \Delta_H^{\mathrm{loss}}\approx 0,\\
& \Delta_H^{\mathrm{wildtype\ rescue}}\approx \Delta_H^{\mathrm{baseline}},\\
& \Delta_H^{\mathrm{binding\ defective\ rescue}}\approx 0,\qquad
  \Delta_H^{\mathrm{non\ target\ rescue}}\approx 0.
\end{aligned}
$$
The control vector $Z$ includes transcription rate, local RNA structure, motif density, GC and dinucleotide composition, codon-pair context, splice or isoform state, transcript abundance, amino-acid composition, same-row translation readout, batch, rank sufficiency, and simpler baseline models. The observed RBP-binding finite run supplies $900$ peak rows and $3$ cross-RBP concordant rows; those values can support only the occupancy side of this design unless the half-life and perturbation rows are joined to them.

\paragraph{Null model.}
The matched null exchanges high-coordinate and low-coordinate labels after all declared controls. Under that null, the label should not predict translation-conditioned RNA half-life. If half-life differs but measured local target-RBP occupancy is unchanged, the result is an RNA-stability association rather than an RBP bridge. If occupancy differs but target-RBP loss does not collapse the effect, the result is an occupancy association rather than a decay mechanism. If loss collapses the effect but wild-type rescue fails, the perturbation is not specifically assigned to the target RBP. If wild-type rescue succeeds but binding-defective or non-target rescue also succeeds, the bridge is not target-binding specific.

\paragraph{Local exclusion boundary.}
This section does not claim that $B^{\ast}_{Q6}$ geometry is observed biological evidence by itself. It also does not claim protein output, protein folding, structural order, physical admissibility, biological function, phenotype, adaptation, mechanism, causation, or universality. RNA half-life alone does not realize translation; translation readout alone does not realize RNA decay; RBP occupancy alone does not realize a decay-factor mechanism. Each stronger layer requires its own matched contact and finite statistic. The present record is therefore a bounded cross-layer candidate: it may become an RBP-mediated RNA half-life bridge only when the same finite rows contain coordinate labels, translation conditioning, RNA half-life, measured local target-RBP occupancy, target-RBP loss, wild-type rescue, and binding-defective or non-target rescue failure.
