\subsection{Translation-Bounded RNA Decay Bridge for Terminal-Motif Stability Rows}
\label{sec:bioreality-q6-rna-decay-rbp-terminal-motif-stability}

\paragraph{Finite carrier.}
This BioReality record concerns a finite matched RNA/CDS window panel in which each row carries a synonymous residual-coordinate label $B^*_{Q6}$, a same-row translation readout when available, an RNA half-life readout, a matched mRNA-abundance control, and, when experimentally attached, prespecified decay-factor RBP occupancy and perturbation-control columns.  The terminal-motif stability run identified by \texttt{h3.cross\_layer\_relation.protein\_degron\_stability.degron\_terminal\_motif\_stability\_voutsinos2026} supplies the local protein-window census used by this chapter: $5303$ C-terminal windows over $5303$ proteins, computed in run \texttt{1a932ef5684e} with deterministic runtime $40.3029$ seconds.  These numbers fix the finite row universe for the terminal-window side of the record; they do not by themselves supply the RNA half-life, translation, or RBP perturbation matrix required for a positive bridge.

\paragraph{Layer distinction.}
The row type is deliberately not a protein-output claim.  A coordinate contrast between high-coordinate and low-coordinate synonymous RNA windows may be evaluated only after amino-acid composition, local sequence, GC and dinucleotide composition, codon-pair context, splice or isoform state, transcript abundance, batch, and local RNA-structure controls have been represented on the same finite table.  The intended finite readout is the following bounded comparison:
$$
\begin{aligned}
\Delta_H
&= H(\hbox{high }B^*_{Q6}\mid Z, T, A) - H(\hbox{low }B^*_{Q6}\mid Z, T, A),\\
Z
&= \hbox{composition, codon-pair, isoform, abundance, batch, and local-structure controls},\\
T
&= \hbox{same-row translation readout},\\
A
&= \hbox{matched mRNA abundance control}.
\end{aligned}
$$
Here $H$ denotes the RNA half-life statistic declared for the panel, not protein abundance or protein stability.  If the translation column is absent, the table can still support a bounded RNA-stability association, but it cannot be promoted to a cross-layer relation.  If the translation column is present but the RBP columns are missing, the table can at most report whether the residual coordinate remains associated with RNA half-life after translation and mRNA controls; it still does not identify an RNA-decay mechanism.

\paragraph{RBP bridge criterion.}
A positive bridge requires an additional finite pattern involving measured decay-factor RBP occupancy.  The high-coordinate versus low-coordinate contrast must track occupied versus unoccupied local windows after coordinate/occupancy decoupling, collapse when the target RBP is lost, and return under wild-type rescue while failing under binding-defective or non-target controls.  In row notation, the permitted claim has the form
$$
\begin{aligned}
B^*_{Q6} &\longrightarrow O_{\mathrm{RBP}} \longrightarrow H,\\
\hbox{loss}(\mathrm{RBP}) &: \Delta_H \approx 0,\\
\hbox{rescue}(\mathrm{RBP}_{\mathrm{wt}}) &: \Delta_H \hbox{ returns},\\
\hbox{rescue}(\mathrm{RBP}_{\mathrm{bind-def}}) &: \Delta_H \hbox{ remains absent}.
\end{aligned}
$$
The arrows in this display are finite-row dependencies to be tested on the joined panel, not a free-standing causal theorem.  The bridge fails if coordinate labels remain predictive only when measured occupancy is absent, unchanged, or confounded with coordinate state.  It also fails if the target-RBP loss does not erase the half-life effect, or if wild-type rescue does not separate from binding-defective and non-target controls.

\paragraph{Cross-record calibration.}
The same finite-row discipline is visible in the neighboring BioReality records carried in the verified payload.  The protein thermal-stability comparison \texttt{h3.cross\_layer\_relation.protein\_thermal\_stability.scd\_charge\_patterning\_thermal\_stability\_meltome\_human} records $6961$ rows with a deterministic runtime bucket of $70.0$ seconds in run \texttt{8873440304f9}; the ubiquitylation acidic-microenvironment comparison \texttt{h3.cross\_layer\_relation.ubiquitylation\_occupancy.ub\_occupancy\_acidic\_microenvironment\_steger2024} records $10410$ sites over $2883$ proteins with $2000$ actual permutations in run \texttt{0b96a8e4da3c}.  These two records are not evidence for the RNA-decay bridge, but they anchor the paper's treatment of biological contacts as finite row tables with declared statistics and layer-specific limits.  The present terminal-motif record therefore remains numerically grounded at $5303$ terminal windows, while its RNA-decay interpretation remains conditional on the missing same-row RNA, translation, abundance, occupancy, and perturbation columns.

\paragraph{Null interpretation.}
The null state is local and finite: after transcription-rate control, local RNA-structure control, motif-density control, GC and dinucleotide control, codon-pair control, splice or isoform control, transcript-abundance control, amino-acid-composition control, batch control, and the same-row translation-readout boundary, high-coordinate and low-coordinate labels are exchangeable with respect to RNA half-life.  A nonzero terminal-window count does not weaken this null; it only says that the finite protein-side coordinate census exists.  The terminal-motif run supplies $n_{\mathrm{cterm}}=5303$ and $n_{\mathrm{proteins}}=5303$, while the decisive RNA-decay rows have not yet been joined.

\paragraph{Local cannot-claim boundary.}
This chapter does not infer translation, protein output, folded structure, physical admissibility, biological function, phenotype, adaptation, causation, mechanism, or universality from RNA half-life alone.  Matched mRNA abundance is only a transcription-layer control.  Ribosome profiling or translation efficiency is only a same-row translation boundary when the row join is actually present.  RNA half-life is only an RNA-stability readout unless the measured decay-factor RBP occupancy and perturbation/rescue columns pass the finite bridge criterion above.  The $B^*_{Q6}$ coordinate is therefore a bounded descriptor until the required empirical columns are attached on the same finite rows; it becomes a bounded cross-layer bridge only after the translation, mRNA, occupancy, decoupling, loss, rescue, and control conditions all pass on that joined table.
