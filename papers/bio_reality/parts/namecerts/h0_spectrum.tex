\subsection{Window-six spectral contact for the standard-code table}
\label{subsec:h0-spectrum-window-six-standard-code}

\paragraph{Finite display.}
The record uses the six-coordinate codon cube as its finite display: each codon is read as a six-bit window, while the observed labels are supplied by the curated standard-code table. This separates the coordinate calculation from the biological labeling act. The coordinate side can form local faces, corners, closures, and spectra; the label side says only that a codon is assigned an amino-acid or stop label in the curated standard code. In the verified row, the distinguished boundary set $R$ has cardinality $13$ and is exactly
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The same row identifies this set as a punctured-cube pattern with face-vector $(13,16,4)$. Thus the finite evidence is not merely a count: it records a particular thirteen-codon subset, sixteen one-dimensional adjacencies, and four local two-dimensional faces inside the window-six cube.

The spectrum calculation attaches a numerical shape invariant to the same finite coordinate packet. The verified values are

These numbers are useful because they summarize the finite window geometry without converting that geometry into a claim about translation, folding, physical chemistry, function, mechanism, or universality.

\paragraph{Shape rarity under finite nulls.}
The shape row compares the observed coordinate pattern with sampled alternatives. In $N=2000$ trials, with seed $42$, the exact shape match count is $1$, giving $p_{\mathrm{exact}}=0.0005$. The high-overlap count at Jaccard threshold $0.9$ is $25$, giving $p_{J\geq 0.9}=0.0125$. The sampling record also reports $57377$ distinct-sample attempts and $55377$ duplicate retries. A separate amino-acid-class-preserving null, also at $N=2000$ and seed $42$, reports observed $M$-size $20$, exact-match count $0$, lower-tail count $7$, class-preserving exact-shape value $0.0$, and lower-tail value $0.0035$. These rows say that the local coordinate shape is uncommon under the tested finite randomizations; they do not say that the shape is a biochemical cause.

The module audit reports $R\_\mathrm{size}=13$, assigned count $13$, no extra module codons, no missing codons from the modules, and no unassigned codons. This is the strongest finite bookkeeping point in the packet: every codon in the local boundary set is accounted for by a named module, and every named module codon lies inside the same thirteen-codon boundary set.

\paragraph{Local biological meaning.}
The supported biological reading is narrow. The curated standard-code contact allows codon-to-label readback and local split checks at the code layer. It does not observe ribosomal realization, protein folding, structural order, physical admissibility, organismal function, or a universal mechanism. Amino-acid label sequences therefore remain label sequences in this chapter. They are not folded structures, not function measurements, and not evidence that the window-six geometry is itself a biological law. A higher-layer statement would require a separate contact designed for that higher layer.

\paragraph{Boundary verdict.}
The finite evidence supports a local window-six boundary pattern for the standard-code label table: the set $R$ is a thirteen-codon punctured-cube pattern with face-vector $(13,16,4)$, its module accounting is complete, the spectral row is numerically stable at $\lambda_M=0.6752479308830213$ and $\lambda_R=0.4758352843197002$, and the finite null comparisons make the observed shape rare under the tested randomizations. The verdict is therefore code-layer readiness only. The result is a coordinate-and-label finding about the curated standard-code table, not an assertion about translation, folding, physical admissibility, function, mechanism, or universality.
