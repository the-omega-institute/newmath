\subsection{Window-Six Codon Spectrum and Local Boundary Readback}\label{sec:bioreality-h0-spectrum}\origin{ai}

\paragraph{Finite coordinate record.} The record indexed by \texttt{h0.spectrum} concerns the standard-code codon table viewed through the six-bit codon cube $Q_6$. The finite carrier is not a biochemical mechanism; it is a display in which codons are placed in a window-six coordinate system, local faces and corners can be inspected, and curated codon labels can be read at the code layer. The operative distinctions are the six-bit codon display, a local tile face, singleton label corners, and three-point label classes. The internal data used here are coordinate, closure, spectrum, and relation data, with readback supplied by a curated standard genetic-code table.

\paragraph{Boundary row.} The punctured local boundary set $R$ has cardinality $13$. The verified row gives the complete codon list
$R=\{\texttt{AAA},\texttt{AGA},\texttt{AGG},\texttt{AUA},\texttt{CUA},\texttt{CUC},\texttt{CUG},\texttt{CUU},\texttt{UAA},\texttt{UAG},\texttt{UCA},\texttt{UGA},\texttt{UUA}\}$.
The same finite row verifies the punctured-cube face count vector $(13,16,4)$. Thus the boundary being discussed is a concrete thirteen-codon object, not an informal drawing of a codon table. The relation row separates the observed codon-label contact from any wider biological assertion: the contact can test code readback and local codon-tile label splits, but it does not test translation realization, structural order, physical admissibility, or function realization.

\paragraph{Shape significance row.} The finite null run for the $M$-shape comparison used $N=2000$ samples with seed $42$. It required $57377$ distinct sample attempts and recorded $55377$ duplicate retries. Exactly one sample matched the observed shape, giving $p_{\mathrm{exact}}=0.0005$. Twenty-five samples had Jaccard similarity at least $0.9$, giving $p_{\mathrm{Jaccard}\ge 0.9}=0.0125$. The row therefore supports a local shape anomaly relative to that sampling regime, but the inference remains at the coordinate-and-label level. A rare local shape is not a statement about protein folding, biological function, physical admissibility, or evolutionary necessity.

\paragraph{Amino-acid-class preserving null row.} A second null calculation preserved amino-acid class information. In that run, again with $N=2000$ and seed $42$, the observed $M$ size was $20$. The exact match count was $0$, so the reported exact-shape probability was $0.0$. The lower-tail count at or below the observed $M$ size was $7$, giving $p_{\mathrm{lower\ tail}}=0.0035$. This strengthens the finite-row evidence that the window-six local structure is not an ordinary draw under that constrained null model. It still does not promote a codon-label table into a physical structure observation.

\paragraph{Leave-one-code-out row.} The leave-one-code-out test evaluated $23$ code tables and $63$ total targets. Its baseline hit rate was $0.19821739130434785$. The hit rate in $M\setminus T$ was $0.9365079365079365$, and the hit rate in $M\setminus T$ plus the boundary was $0.9841269841269841$. The reported hit rate above baseline was also $0.9841269841269841$. By family, the hit rates above baseline were $0.8333333333333334$ for alternative yeast, $1.0$ for bacterial or plastid codes, $1.0$ for candidate other codes, $1.0$ for mitochondrial codes, and $1.0$ for nuclear ciliate codes. These figures make the local codon-label boundary useful for code-layer prediction across the finite evaluation table, while remaining silent about the machinery that realizes translation in cells.

The recovery rate above threshold is also $1.0$. The module classification row accounts for all $13$ codons of $R$: $\texttt{agr}=\{\texttt{AGA},\texttt{AGG}\}$, $\texttt{ar\_lys}=\{\texttt{AAA}\}$, $\texttt{cun}=\{\texttt{CUA},\texttt{CUC},\texttt{CUG},\texttt{CUU}\}$, $\texttt{ile\_met}=\{\texttt{AUA}\}$, $\texttt{ssn}=\{\texttt{UCA},\texttt{UUA}\}$, and $\texttt{stop\_trp}=\{\texttt{UAA},\texttt{UAG},\texttt{UGA}\}$. \paragraph{Scope of the claim.} The verified content is therefore a finite code-read statement: in a six-bit codon display, the standard-code label table exhibits a thirteen-codon punctured boundary with the spectral, null-model, and leave-one-out behavior listed above. The external contact is the curated standard-code table, and its role is only to attach codons to amino-acid or stop labels. No translation process, folded protein structure, physical admissibility condition, functional phenotype, biochemical mechanism, or universal biological principle follows from this row unless an additional contact explicitly supplies that higher-layer evidence.
