\paragraph{Local boundary conclusion.}
The supported conclusion is deliberately narrow.  The standard-code table supplies codon-to-label contact, and the window-six coordinate system exposes a rare local tile whose spectrum, punctured-cube face vector, module partition, and leave-one-out behavior are all recorded by finite rows.  This supports a code-read statement: curated labels on the six-bit codon cube contain a stable local boundary pattern with $R$ as the $13$-codon punctured-cube residual set and with spectral radius $0.6752479308830213$ on the marked side.
