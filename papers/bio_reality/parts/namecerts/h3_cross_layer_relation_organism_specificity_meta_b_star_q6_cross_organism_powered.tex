\paragraph{Domain comparison.}

\paragraph{Local verdict.}
The finite evidence supports the following precise statement.  Organism-specific $B^*_{Q6}$ summaries can be assembled and compared against domain, GC3, tRNA-pool-size proxy, and proteome-size proxy on a $12$-row complete panel inside a $16$-row metadata table.  The computed correlations and permutation tests are descriptive and bounded: $M^{QTP}$ fraction versus GC3 has $r=-0.3062616500469447$ with two-sided permutation value $0.35264735264735264$; versus log proteome size has $r=-0.033628115789504955$ with value $0.913086913086913$; versus log tRNA-gene count has $r=0.06029405206037823$ with value $0.8621378621378621$; and the domain comparison has right-tail value $0.4155844155844156$.  The dominant-coordinate table has Cramer's $V=0.6258327785172862$ but permutation value $0.5814185814185814$.  Consequently the chapter records a real finite meta-surface and a real negative boundary: the data exhibit cross-organism heterogeneity, but they do not establish a causal axis, a phylogenetically corrected conclusion, a universal domain rule, or a mechanism.

\paragraph{No-promotion boundary.}
No translation, folding, physical admissibility, function, mechanism, phenotype, or universal biological claim follows from this meta-table alone.  The measured-TE rows are condition-specific ribosome-profiling translation-efficiency readouts with matched mRNA controls; the modeled-tAI and tRNA-copy rows are bounded proxy surfaces; the $M^{QTP}$ fraction and dominant-coordinate labels are statistical projections.
