\subsection{Translation-conditioned RNA half-life and decay-factor occupancy at a Q6 residual coordinate}
\label{sec:bioreality-q6-rna-half-life-rbp-bridge}

\paragraph{Finite carrier.}
The finite object considered here is a matched transcript/CDS table whose rows carry four kinds of labels at once: a $B^*_{Q6}$ synonymous residual coordinate after amino-acid quotienting, a same-row translation readout, an RNA half-life readout, and an externally prespecified decay-factor RNA-binding-protein occupancy readout at the editable RNA window.  The row is not a protein-acetylation row merely because the claim identifier belongs to the protein-acetylation ledger; in this record the relevant biological question is whether a codon-residual coordinate can be connected to RNA persistence only through a measured RBP bridge.  The finite Hansen-linked assay memory contributes a bounded comparison surface with $n = 6288$ rows and $5921$ distinct stoichiometric labels, computed in run $4c330420a1bf$ with runtime $8.456$ seconds.  That surface is useful as a nearby post-translational occupancy example, but it is not by itself the RNA half-life panel required for the present bridge.

\paragraph{Row variables and null comparison.}
For a row $r$ write $q(r)$ for the high- or low-coordinate synonymous residual label, $T(r)$ for the translation readout, $H(r)$ for the RNA half-life readout, $O(r)$ for measured local occupancy of the prespecified decay-factor RBP, and $C(r)$ for the matched control block.  The control block contains transcription rate, local RNA structure, motif density, GC and dinucleotide composition, codon-pair context, splice or isoform state, transcript abundance, batch, amino-acid composition, and the same-row translation boundary.  The local null is exchangeability of high- and low-coordinate labels for RNA half-life after these controls:
$$
\begin{aligned}
  H(r) \perp q(r) \mid T(r), O(r), C(r).
\end{aligned}
$$
A positive coordinate-associated half-life contrast is therefore not enough.  The contrast must follow measured occupancy of the chosen decay factor, disappear when the target RBP is lost, return under wild-type rescue, and fail to return under binding-defective or non-target controls.

\paragraph{Why the RBP bridge is stricter than an RNA-stability association.}
The RBP contact ledger contains a separate finite RBP-binding benchmark with $900$ total peak rows and $3$ cross-RBP-concordant outcomes in run $b225890251c2$; that fact confirms that RBP rows can be represented as finite occupancy surfaces, but it does not supply the same-window occupancy, perturbation, and rescue rows for this Q6 half-life claim.  Likewise, the translation ledger contains a same-layer translation surface with $n = 6494$ rows in run $0c2bbfd3e2d9$, and the N-terminal-acetylation ledger records $657$ rows, $426$ NatA-class rows, and an AUROC of $0.942081$ in run $f452e76f6363$.  These finite facts anchor nearby biological readout types, but none of them licenses the RBP-decay mechanism demanded here.  They show that the repository has finite row disciplines for translation, RBP binding, and acetylation occupancy; they do not collapse those disciplines into a single causal RNA-decay result.

\paragraph{Acceptance rule.}
The chapter accepts only a bounded cross-layer bridge with the following finite readback pattern.  First, the high-coordinate versus low-coordinate contrast must be computed after amino-acid quotienting and after the full control block.  Second, the same row must retain the translation readout so that an RNA half-life residual is not promoted to a translation result.  Third, the measured occupancy $O(r)$ must be local to the same editable window and must be experimentally separable from the coordinate label.  Fourth, target-RBP loss must collapse the half-life contrast, wild-type rescue must restore it, and binding-defective or non-target rescue must fail.  In compact form, the required positive pattern is:
$$
\begin{aligned}
  \Delta_H(q \mid T,C) &\neq 0,\\
  \Delta_H(q \mid T,C,O) &\text{ follows the measured occupancy contrast},\\
  \Delta_H^{\mathrm{target\ loss}} &\approx 0,\\
  \Delta_H^{\mathrm{wild\ type\ rescue}} &\approx \Delta_H^{\mathrm{baseline}},\\
  \Delta_H^{\mathrm{binding\ defective\ or\ non\ target}} &\approx 0.
\end{aligned}
$$
If any line is absent, the record remains a finite RNA-stability association or a coordinate descriptor rather than an RBP-mediated RNA half-life bridge.

\paragraph{Local exclusion boundary.}
This record does not infer protein output, protein folding, physical admissibility, biological function, phenotype, adaptation, causation, or a universal sequence law.  It also does not infer translation from RNA half-life alone, and it does not infer an RNA-decay mechanism from a translation readout alone.  Motif-density, RNA-structure, transcription-rate, isoform-state, abundance, GC/dinucleotide, codon-pair, and batch explanations remain live unless they are handled inside the matched finite statistic.  A binding-defective rescue, a non-target rescue, or unchanged local RBP occupancy counts against the bridge rather than for it.  Thus the current chapter is a precise finite-row boundary statement: the Hansen-linked finite occupancy memory supplies $6288$ rows and $5921$ distinct stoichiometric labels for a neighboring acetylation surface, while the claimed Q6 RNA half-life RBP bridge still requires the same-window RNA half-life, translation, RBP occupancy, loss, and rescue panel before any positive mechanism wording is allowed.
