\paragraph{ORF-eligibility reading.}
The attached ORF seed is deliberately weaker than an ORF claim.  Its biological object is open-reading-frame eligibility from start and stop codon enumeration.  The admissible interpretation is only this: start/stop-window enumeration can define a boundary test for whether a nucleotide interval would pass a syntactic eligibility screen, provided a separate observed sequence, transcript, or curated annotation supplies the interval.  Without that separate contact, the packet is a contact-gap record.  It does not assert that any codon-window in the quotient row is translated, folded, chemically admissible, functional, mechanistic, or universal.
