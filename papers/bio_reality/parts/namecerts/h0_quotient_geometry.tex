\paragraph{ORF-eligibility interpretation.}
The biological layer attached to this record is $orf\_eligibility$.  At the seed stage the carrier, distinctions, and readback are explicitly marked as awaiting reality contact, and the internal structure is recorded as none.  Consequently the quotient table may organize possible start/stop-window patterns, but it does not itself certify an open reading frame.  A separate start/stop-window enumeration record later loaded one external window and classified one input window, with scope restricted to external-window start/stop enumeration only and with the value $no\_geometry\_to\_translation\_promotion=orf\_eligibility\_only$. \paragraph{Local limitation.}
The verified self-check records $3$ checked gates and states that no codon geometry is promoted across biological layers.  This chapter therefore draws the following boundary in place.  The quotient geometry, the $20$-row set $M$, the $13$-row motif support $R$, the $10$-row quotient image, the $f$-vectors $(20,38,26,8,1)$ and $(10,14,6,1)$, and the curated ORF-interval statistics can speak about ORF-eligibility only where an external interval annotation supplies the tested biological object. Any such stronger assertion would require a separate contact designed for that layer.
