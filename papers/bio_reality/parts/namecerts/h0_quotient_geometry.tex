\paragraph{Finite coordinate content.}

& CUG,CUU,UAA,UAG,UCA,UCG,UGA,UGG,UUA,UUG\},

$$

$$

The ambient codon list also satisfies the checked equality $M=WNR\cup CUN$, again with twenty elements. These facts make the row suitable for a bounded geometric analysis, because every object in the row is explicitly enumerated.

\paragraph{ORF eligibility reading.}
The biological reading attached to this row is deliberately narrow: start and stop codon enumeration can mark an interval as eligible for an open-reading-frame test only after an external biological interval has been supplied. Without such an interval, the row remains a boundary record describing what would have to be checked. The one-window start/stop enumeration contact confirms that one input window was loaded and that one window was classified, with scope restricted to external window start/stop enumeration only. Its recorded classification is $orf\_eligibility\_only$, so it does not promote geometry into translation or any stronger biological layer.

\paragraph{Curated interval contact.}
The stronger curated-interval contact uses $168$ rows from an NCBI RefSeq GenBank XML CDS interval source for Escherichia coli K-12 MG1655 accession $NC\_000913.3$, with snapshot date $2026$-$05$-$30$. The frozen protocol records that classifier rules, input classes, baselines, and held-out splits were fixed before the external observation time. The row contains three required input classes: boundary cases, matched non-ORF decoys, and positive curated ORFs. Among $72$ positive curated intervals, $72$ were accepted, giving accept rate $1.0$ and one-sided binomial upper-tail value $2.117582368135751\times 10^{-22}$. Among $72$ matched decoys, $72$ were rejected, giving reject rate $1.0$ and the same recorded upper-tail value $2.117582368135751\times 10^{-22}$. The predeclared paired baseline comparison also gives $72$ wins out of $72$ pairs, win rate $1.0$, and upper-tail value $2.117582368135751\times 10^{-22}$.

This matters because the quotient geometry is allowed to organize the finite coordinate side of the test, while the biological assertion is allowed only where curated interval contact is actually present.

\paragraph{Local boundary.}
The row therefore supports the following limited statement: the enumerated quotient geometry of $M$, together with the curated interval experiment, is compatible with ORF-eligibility classification on the stated finite dataset. It does not assert that a geometrically eligible window is translated. It does not assert folded structure, physical admissibility, biological function, molecular mechanism, or a universal law over genomes. The self-check row records $3$ checked gates and states the same boundary: no codon geometry is promoted across biological layers. Any claim above interval-level ORF eligibility would require a separate contact that directly measures or curates that higher layer.
