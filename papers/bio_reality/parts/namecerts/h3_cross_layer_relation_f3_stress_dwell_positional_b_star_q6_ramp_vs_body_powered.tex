\subsection{Position-resolved dwell localization for the $f_3$ stress residual}\label{sec:bioreality-f3-stress-dwell-positional-ramp-body}
\origin{ai}

\paragraph{Finite row surface.}
This chapter records a position-resolved test of the $f_3$ stress coordinate inside the nine-dimensional $B^*_{Q6}$ synonymous residual surface.  The tested rows are Saccharomyces cerevisiae coding sequences for which codon-derived residual coordinates, protein abundance, and file-provided ribosome-occupancy dwell summaries can be joined on the same gene units.  The active positional experiment has run id \texttt{6db78e1bf746}, uses $n=1257$ joined rows from a base pool of $1800$ rows, and fits five held-out folds.  The target is the one-dimensional component
$$
\begin{aligned}
P_{f_3}=\operatorname{proj}_{\widetilde f_3}\bigl(\widetilde{\log_{10}(\mathrm{protein\ abundance})}\bigr),
\end{aligned}
$$
where both the protein abundance vector and the $f_3$ stress coordinate are residualized against the sibling control design.  The reported control basis has rank $24$, while the tested $f_3$ coordinate has rank $1$.  On this joined surface the projected target has squared norm $44.20095750389323$ and accounts for fraction $0.1999063916718794$ of the controlled protein-abundance target.

\paragraph{Positional readout and null design.}
The dwell readout is not a bulk translation-efficiency scalar.  It is a pair of positional relative ribosome-occupancy summaries computed separately from the file-provided $5'$ head window and $3'$ tail window.  The null model fixes the base and full designs and the cross-validation folds, then deterministically permutes the row labels of $P_{f_3}$.  The positional run uses $120$ such permutations separately for each segment and for the joint segment design.  The passed condition is therefore a finite matrix statement: after the same residualization and held-out scoring protocol, at least one segment-specific dwell design has positive held-out increment beyond its fixed row-label null boundary.

\paragraph{Observed segment call.}
The finite call is asymmetric across the two positional windows.  The $5'$ window passes the segment gate, the $3'$ body or tail window does not, and the leading segment by held-out increment is reported as \texttt{5prime}.  The same run records \texttt{dominant\_segment = 5prime}, \texttt{five\_prime\_ramp\_passed = true}, and \texttt{three\_prime\_body\_passed = false}.  Thus the certified statement is not merely that $f_3$ stress has a dwell association; it is that the detectable increment localizes to the head-side dwell summary under the finite-row protocol used here.  In compact form, the readback is
$$
\begin{aligned}
&n_{\mathrm{join}}=1257,\qquad n_{\mathrm{base}}=1800,\qquad K_{\mathrm{fold}}=5,\qquad B_{\mathrm{perm}}=120,\\
&\operatorname{rank}(Z)=24,\qquad \operatorname{rank}(f_3)=1,\\
&\mathrm{segment}_{\mathrm{lead}}=5',\qquad \mathrm{gate}_{5'}=\mathrm{true},\qquad \mathrm{gate}_{3'}=\mathrm{false}.
\end{aligned}
$$
The chapter therefore classifies the powered positional record as a positive $5'$ dwell-localization result for the $f_3$ abundance component, not as a symmetric ramp-and-body result.

\paragraph{Relation to the non-positional dwell mediation run.}
The positional call sits on top of a broader dwell mediation result from run \texttt{946f33083caf}.  In that companion finite-row surface, the same organism and the same $f_3$ target use $n=1257$ joined rows, five folds, $120$ deterministic row-label permutations, control rank $24$, and $f_3$ rank $1$.  The base model has held-out $R^2=0.1855578757644517$, the dwell-only model has $R^2=0.034336580953121976$, and the full base-plus-dwell model has $R^2=0.20412261520502883$.  The held-out increment is $\Delta R^2=0.01856473944057712$, exceeding the permutation null $95\%$ boundary $0.0013115362189692937$; the same run reports $f_3$--dwell correlation $0.1615441450901653$ with approximate $p=7.873916057196935\times 10^{-9}$.  The present positional chapter refines that earlier scalar dwell result by saying where the dwell increment is found: in the $5'$ segment rather than the $3'$ segment.

\paragraph{Contrast with structural-order ramp testing.}
A separate structural-order positional run, \texttt{fd29bb46dde6}, uses a different readout and should not be conflated with this dwell chapter.  Its primary ramp length is $50$, it reports weighted $f_3$ ramp held-out increment $0.0011165640103326878$ and weighted body increment $-0.00026157313923957926$, with weighted ramp-minus-body increment $0.001378137149572267$.  Its sign-flip values are $0.0478515625$ for positive ramp, $0.54296875$ for positive body, and $0.05859375$ for paired ramp-minus-body.  That run concludes \texttt{ramp\_positive\_but\_not\_localized}.  The present dwell result is stronger only for the narrower statement encoded by its own readout: file-provided positional ribosome occupancy dwell summaries localize the $f_3$ abundance component to the $5'$ side under the specified permutation gate.  It does not convert the structural-order readout into a localized structural mechanism.

\paragraph{Reduction and irreducibility context.}
The broader yeast residual context is not fully exhausted by this positional dwell readout.  A partial mediation certificate on the same organism reports $n=1800$ active joined rows from $4758$ available rows, five folds, $120$ permutations, $\rho_{\mathrm{join}}=0.05$, and $\lambda_{\mathrm{DL}}=0.01$.  Its selected readout dictionary covers $0.24538211439730545$ of the residual signal and leaves unexplained fraction $0.7546178856026946$ after a selection-aware null boundary $0.029149007242956115$.  An irreducibility-certificate run with the same $n=1800$, five folds, $120$ permutations, $\rho_{\mathrm{join}}=0.05$, and $\lambda_{\mathrm{DL}}=0.01$ records the tested source as the nine-dimensional $B^*_{Q6}$ synonymous residual coordinates against the unified yeast protein-abundance target.  These companion rows keep the positional result in scale: the $5'$ dwell signal is a real finite-row reduction channel for the $f_3$ component, while the residual family remains only partially accounted for by the listed measured readouts.

\paragraph{Local boundary of interpretation.}
The result is a controlled cross-sectional association on joined yeast rows.  It supports the statement that the $f_3$-projected protein-abundance component has a segment-specific dwell increment, led by the $5'$ occupancy window, under the stated residualization, held-out folds, and permutation null.  It does not by itself establish translation causality, elongation mechanism, ribosome kinetics, folding order, physical admissibility, molecular function, phenotype, adaptation, or universality.  Any such higher-layer conclusion would require a separate layer-matched contact and a statistic built on that contact.  In particular, a direct or localized dwell increment should not be promoted to a claim about folded protein structure or biological function, and the $3'$ null segment should be read as a finite-row non-detection for that readout rather than as a universal absence statement.
