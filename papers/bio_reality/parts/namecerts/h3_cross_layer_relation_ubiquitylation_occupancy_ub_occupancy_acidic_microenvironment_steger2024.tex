\subsection{Translation-bounded RNA decay readback with an RBP-occupancy gate}
\label{subsec:bioreality-q6-rna-decay-rbp-occupancy-gate}

\paragraph{Finite row object.}
This record concerns a finite matched RNA/CDS window panel in which each row is intended to carry a $B^{*}_{Q6}$ residual coordinate label, a synonymous-window comparison class, a same-row translation readout when available, a matched mRNA-abundance control, and an RNA half-life measurement. The proposed cross-layer interpretation is deliberately narrow: a coordinate-associated RNA half-life contrast is not by itself a translation result, a protein-output result, or an RNA-decay mechanism. It can become a bounded RNA-decay/RBP readback only after a prespecified decay-factor RBP occupancy column is measured on the same local window, after coordinate and occupancy are experimentally decoupled, and after target-RBP loss and rescue controls separate binding-dependent decay from coordinate labeling.

The finite reality contacts presently attached to the row design stop before that stronger condition. The RNA half-life contact supplies organism-scoped transcript or gene rows with curated half-life estimates. The mRNA contact supplies a denominator or covariate for separating transcription-layer abundance from translation efficiency. The ribosome-profiling contact supplies the possible translation boundary, but only when joined to the same CDS or window rows. None of these contacts is a measured decay-factor RBP-occupancy table, and none supplies target-RBP depletion, wild-type rescue, binding-defective rescue, or non-target control rows.

\paragraph{Observed finite counts.}
The directly verified finite run associated with the ubiquitylation-occupancy acidic-microenvironment record used $2883$ proteins, $10410$ sites, and $2000$ actual permutations, with deterministic stdout accounting and wall time handled by the harness. Those numbers are not RNA half-life or RBP-occupancy rows; they are cited here only as finite-row calibration for the BioReality discipline that every positive biological sentence must be tied to a measured table of the right kind. Two other checked cross-layer records in the same finite audit family give scale comparisons: the human thermal-stability charge-patterning run contains $6961$ rows, and the degron terminal-motif stability run contains $5303$ C-terminal rows across $5303$ proteins. These counts show that the framework is willing to read finite biological panels when the measured layer is present, but they do not transfer evidence across layers.

A useful way to state the local statistic is:
$$
\begin{aligned}
R &= \{\text{matched RNA/CDS windows with } q_i, T_i, A_i, H_i\},\\
q_i &= \text{$B^{*}_{Q6}$ residual coordinate label},\\
T_i &= \text{same-row translation readout, if present},\\
A_i &= \text{matched mRNA abundance control},\\
H_i &= \text{RNA half-life readout}.
\end{aligned}
$$
For the RBP-bridge claim, the row set would need additional columns:
$$
\begin{aligned}
O_i &= \text{measured decay-factor RBP occupancy on the local window},\\
L_i &= \text{target-RBP loss condition},\\
W_i &= \text{wild-type rescue condition},\\
B_i &= \text{binding-defective or non-target control condition}.
\end{aligned}
$$
The present contact set contains $H_i$, possible $T_i$, and $A_i$ routes, but it does not contain $O_i$, $L_i$, $W_i$, or $B_i$ for the same finite rows.

\paragraph{Admissible claim.}
The admissible claim is therefore a bounded null-facing statement. If a finite same-organism same-window panel is later assembled with coordinate labels, translation readout, mRNA abundance, RNA half-life, measured decay-factor RBP occupancy, coordinate/occupancy decoupling, target-RBP loss, wild-type rescue, and binding-defective or non-target controls, then the panel may test whether high-coordinate and low-coordinate synonymous windows differ in RNA half-life through the measured RBP-occupancy route. The declared readout must condition on transcription rate, local RNA structure, motif density, GC and dinucleotide composition, codon-pair context, splice or isoform state, transcript abundance, amino-acid composition, same-row translation readout, batch, rank sufficiency, and simpler baselines.

Without those columns, the coordinate remains a descriptor of a finite RNA/CDS window, and any RNA half-life difference remains at most an RNA-stability association. The same-row translation boundary is mandatory because an RNA half-life readout must not be promoted to translation realization or protein output. The RBP-occupancy boundary is mandatory because a coordinate-associated half-life difference must not be promoted to an RBP mechanism unless the measured occupancy route explains the effect and the perturbation/rescue rows behave as specified.

\paragraph{Failure modes.}
The strongest local null is exchangeability: after the declared controls, high-coordinate and low-coordinate synonymous RNA windows are exchangeable with respect to RNA half-life. A second failure mode is coordinate-only persistence: if coordinate labels remain predictive when measured RBP occupancy is absent, unchanged, or not decoupled from coordinate state, the result is not an RBP bridge. A third failure mode is perturbation failure: if target-RBP loss does not collapse the half-life effect, or if wild-type rescue does not restore it while binding-defective or non-target controls fail to do so, the RBP interpretation is rejected. A fourth failure mode is layer promotion: if RNA half-life is used to infer translation, folded protein state, physical admissibility, function, phenotype, adaptation, causation, or a universal biological law, the claim has moved beyond its measured surface.

\paragraph{Local conclusion.}
The chapter is ready as a finite boundary record, not as a positive RNA-decay mechanism result. The available evidence supports the design of the test and fixes the blocking conditions. It does not yet support the positive sentence that $B^{*}_{Q6}$ synonymous residual coordinates modulate RNA half-life through a measured decay-factor RBP. A positive version requires a same-row table with the RBP-occupancy and perturbation/rescue columns present, plus a finite statistic showing that the half-life contrast follows measured RBP occupancy after the translation and mRNA-abundance boundaries have been attached.
