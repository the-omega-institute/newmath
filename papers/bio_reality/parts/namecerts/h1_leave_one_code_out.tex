\subsection{Leave-one-code-out readback on the window-six codon tile}
\label{sec:bior-leave-one-code-out-window-six}

\paragraph{Claim and contact layer.}
The claim \texttt{h1.leave.one.code.out} concerns a six-coordinate codon display in which each codon is read as a point of the binary codon cube $Q_6$. The tested biological contact is the curated standard genetic-code table: it assigns each codon to an amino-acid or stop label and therefore supports code-layer readback. The contact does not observe translation dynamics, molecular folding, physical admissibility, biological function, a mechanism of code formation, or a universal biological law. Consequently the finite record below is only a local codon-label certificate: it tests whether the window-six geometry separates a small boundary tile whose labels are informative under leave-one-code-out probes.

\paragraph{Boundary set.}
The distinguished boundary set $R$ has cardinality $13$. The verified row lists
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The same row verifies that this set is a punctured-cube-shaped tile with face vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}
$$
Thus the tested object is not an arbitrary relabeling of all $64$ codons. It is a finite local subcomplex singled out inside the codon cube, together with the curated amino-acid or stop labels attached to its vertices.

The finite certificate supports a narrow conclusion. In the standard-code label table, the window-six coordinate system exposes a small punctured-cube boundary whose leave-one-code-out behavior is far above the sampled baseline, and whose module partition covers exactly the $13$ listed codons. The result is a code-label readback fact, not a claim about ribosomal realization, codon usage across organisms, tRNA biology, protein structure, thermodynamic feasibility, phenotype, or evolutionary necessity.
