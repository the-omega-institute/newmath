\subsection{Leave-One-Code-Out Readback for the Window-Six Codon Tile}\label{subsec:h1-leave-one-code-out-readback}
\origin{ai}

\paragraph{Finite codon coordinate packet.}
The object considered here is the standard-code codon table, read only at the code-label layer.  Each codon is placed in the six-bit codon cube $Q_6$, where a local tile face, singleton label corner, and three-point label class can be inspected without treating the geometry as a biological mechanism.  The finite residue set singled out by the coordinate test has cardinality $13$:
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The corresponding punctured-cube check gives the same set $R$ and records the face-vector $(13,16,4)$.  Thus the packet is not a free verbal analogy: it contains a finite named list of codons and a small combinatorial boundary summary attached to that list.  The carrier is still only a codon-coordinate carrier; its readback is the curated standard-code label table, not translation dynamics, protein structure, or cellular function.

\paragraph{Spectral and randomization checks.}
The finite row also records a spectral comparison between the marked set and its complement-like boundary data.  The observed values are
$$
\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128.
\end{aligned}
$$
The radial cubic residual is $-6.224354365258478\times 10^{-12}$, which is at numerical tolerance for the recorded polynomial relation.  Shape rarity was tested against $N=2000$ sampled comparators with seed $42$.  The exact-shape count was $1$, giving $p_{\mathrm{exact}}=0.0005$, and the high-overlap threshold $J\geq 0.9$ was met $25$ times, giving $p_{J\geq 0.9}=0.0125$.  The sampling log also records $57377$ distinct-sample attempts and $55377$ duplicate retries, so the null comparison is finite and explicitly bounded by the actual run.  Under an amino-acid-class-preserving null with the same sample size and seed, the exact-match count was $0$, the observed marked size was $20$, and the lower-tail count at or below that size was $7$, giving $p=0.0035$ for that tail event.  These numbers support a local code-table pattern; they do not by themselves identify a generative law for biology.

\paragraph{Leave-one-code-out result.}
The leave-one-code-out test evaluated $23$ code tables and $63$ held-out targets.  The baseline hit rate was $0.19821739130434785$.  The coordinate packet reached a hit rate of $0.9365079365079365$ inside $M\setminus T$, and $0.9841269841269841$ after adjoining the recorded boundary allowance.  The same value, $0.9841269841269841$, is reported for hit rate above baseline.  In percentage language, the boundary-augmented finite rule recovers about $98.41\%$ of the held-out targets, while the baseline sits near $19.82\%$.  This is the central empirical row for claim $\mathrm{h1.leave.one.code.out}$: the local window-six tile has strong readback performance on the curated label table when one code is withheld.

The alternative-yeast family is the only listed family below perfect recovery in this row, and it still exceeds five sixths.  The correct reading is therefore a robust code-label readback phenomenon across the listed families, not an unrestricted claim about how the organisms translate, regulate, fold, or use the resulting amino-acid strings.

\paragraph{Module coverage.}
The residue set $R$ is partitioned into six named codon modules with no missing or extra codons.  The module record has $R$-size $13$, assigned count $13$, empty extra-module codons, empty missing-from-modules, and empty unassigned-codon list.  The modules are
$$
\begin{aligned}
\mathrm{agr}&=\{\mathrm{AGA},\mathrm{AGG}\},\\
\mathrm{ar\_lys}&=\{\mathrm{AAA}\},\\
\mathrm{cun}&=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\},\\
\mathrm{ile\_met}&=\{\mathrm{AUA}\},\\
\mathrm{ssn}&=\{\mathrm{UCA},\mathrm{UUA}\},\\
\mathrm{stop\_trp}&=\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}.
\end{aligned}
$$
Every listed module has either predictable or boundary status in the leave-one-codon-out classification.  That companion run reports boundary count $5$, predictable count $8$, anchor count $0$, high closure coverage $8$, and recovery rate $1.0$.  These module rows make the local boundary interpretation sharper: all thirteen codons in $R$ are accounted for by the finite module classification, but the classification is still a code-table classification.

\paragraph{Reality contact and scope limit.}
The only reality contact used here is the curated standard-code table assigning codons to amino-acid or stop labels.  It can test code-layer readback and local codon-tile label splits.  It cannot test translation realization, folded structure, structural order, physical admissibility, biological function, mechanism, or universality.  Consequently, amino-acid label sequences obtained from this table remain labels in a code table.  No claim about a folded protein, a viable molecule, an organism-level function, or a general biological law follows from the finite rows above unless a separate contact supplies that higher-layer observation.  The present claim is therefore ready only as a bounded code-read result: the window-six coordinates expose a strong local boundary-tile pattern for the curated codon labels, while the biological promotion boundary remains closed.
