\subsection{Leave-one-code-out stability for codon label readback}
\label{sec:bioreality-h1-leave-one-code-out}

\paragraph{Finite claim.}
This record studies a window-six codon display on the codon cube $Q_6$ as a code-layer object.  The finite carrier is the six-bit codon coordinate system, and the observed labels are supplied by a curated standard-code table assigning codons to amino-acid or stop labels.  The claim is deliberately local: the coordinate geometry may expose a boundary-tile pattern in the code table, but the label table remains the biological contact.  The tested layer is therefore code readback only.  The contact does not observe translation in a cell, folding, physical admissibility, biochemical function, an evolutionary mechanism, or a universal biological law.

\paragraph{Observed exceptional set.}
The finite exceptional codon set $R$ has cardinality $13$.  In lexicographic codon notation it is
$$\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}$$
The same row was checked as a punctured-cube pattern with face-vector
$$\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}$$
Thus the geometric signal is not recorded as a vague visual analogy: it is a finite thirteen-codon subset with sixteen one-dimensional adjacencies and four two-dimensional faces inside the six-coordinate codon cube.

\paragraph{Spectral row.}
The finite spectral summary attached to the same coordinate packet gives
$$\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128.
\end{aligned}$$
The reported cubic residual is $-6.224354365258478\times 10^{-12}$, the same value reported for the radial polynomial evaluation, and the spectral-radius row records $0.6752479308830213$ within tolerance.  These numbers are used here only as finite diagnostics of the codon-coordinate construction; they do not supply a separate biological mechanism.

\paragraph{Shape significance.}
Against the sampled null row for the $M$-shape test, $N=2000$ samples were evaluated with seed $42$.  The sampler made $57377$ distinct-sample attempts and encountered $55377$ duplicate retries.  Exactly one sampled shape matched the observed shape, giving $p_{\mathrm{exact}}=0.0005$.  The high-Jaccard event at threshold $0.9$ occurred $25$ times, giving $p_{J\geq 0.9}=0.0125$.  These rows indicate that the observed finite shape is rare under that sampling procedure.  They do not by themselves say why biology uses any label assignment.

\paragraph{Amino-acid-class preserving null row.}
A second null row preserves amino-acid class information.  In that run, $N=2000$, seed $42$, the observed $M$ size was $20$.  The exact-shape count was $0$, so the exact-shape empirical value was recorded as $0.0$.  The lower-tail count at or below the observed $M$ size was $7$, giving a lower-tail value $0.0035$.  This strengthens the finite-code observation while keeping the interpretation fixed at the label layer: the row compares label-preserving rearrangements of codon data; it does not observe folded proteins or physical realizability.

\paragraph{Leave-one-code-out test.}
The main leave-one-code-out row evaluated $23$ tables and $63$ total targets.  The baseline hit rate was $0.19821739130434785$.  The hit rate above baseline was $0.9841269841269841$, the hit rate inside $M\setminus T$ was $0.9365079365079365$, and the hit rate inside $M\setminus T$ plus the boundary class was $0.9841269841269841$.  In finite-row terms, almost all held-out code targets were recovered above the baseline once the local coordinate-and-boundary information was used.  The number is a stability measurement for code labels under held-out-table testing, not a claim that codon geometry realizes translation.

\paragraph{Family breakdown.}
The family-level row contains five families.  The hit rates above baseline were
$$\begin{aligned}
\mathrm{alternative\ yeast}&:0.8333333333333334,\\
\mathrm{bacterial\ plastid}&:1.0,\\
\mathrm{candidate\ other}&:1.0,\\
\mathrm{mitochondrial}&:1.0,\\
\mathrm{nuclear\ ciliate}&:1.0.
\end{aligned}$$
The weakest listed family is alternative yeast, but it still lies far above the baseline row.  The other four families are recorded at full hit rate in this finite test.  The family split is useful because it checks that the held-out-code signal is not confined to a single named table group.

\paragraph{Leave-one-codon-out and module classification.}
The codon-level row records $0$ anchors, $5$ boundary codons, $8$ predictable codons, $8$ high-coverage closure codons, and recovery rate $1.0$.  The associated module classification assigns all thirteen $R$ codons with no extras, no missing codons, and no unassigned codons.  The modules are
$$\begin{aligned}
\mathrm{agr}&=\{AGA,AGG\},\\
\mathrm{ar\_lys}&=\{AAA\},\\
\mathrm{cun}&=\{CUA,CUC,CUG,CUU\},\\
\mathrm{ile\_met}&=\{AUA\},\\
\mathrm{ssn}&=\{UCA,UUA\},\\
\mathrm{stop\_trp}&=\{UAA,UAG,UGA\}.
\end{aligned}$$
This partition is the local boundary bookkeeping used by the test.  It records how the thirteen-codon set decomposes into code-relevant modules; it does not turn a module name into evidence about organismal translation, tRNA copy number, protein structure, or function.

\paragraph{Reality contact.}
The biological contact is the curated standard genetic-code table.  It supplies a finite codon-to-label readback at codon-label resolution.  The contact can test whether a codon coordinate pattern agrees with code labels and whether local tile splits align with observed label assignments.  It cannot test translation realization, structural order, physical admissibility, or function realization.  Those would require separate contacts with their own observations and their own error models.

\paragraph{Boundary condition.}
The supported statement is that a window-six codon-coordinate construction exposes a rare, stable local pattern in code-label data: the thirteen-codon set $R$, its punctured-cube face-vector $(13,16,4)$, the spectral row above, the shape-null values $0.0005$ and $0.0125$, the amino-acid-class lower-tail value $0.0035$, and the leave-one-code-out hit rate $0.9841269841269841$ above baseline all point to a finite code-layer regularity.  The unsupported promotion is equally important.  No translation process, folded structure, physical admissibility condition, biological function, universal mechanism, or global law follows from these rows unless an additional external contact supplies that higher-layer observation.
