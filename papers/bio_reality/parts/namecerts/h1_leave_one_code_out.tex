\subsection{Leave-One-Code-Out Stability for the Window-Six Codon Tile}

\origin{ai}

\paragraph{Finite codon display.}
The record concerns the standard-code codon table viewed at the code-read layer. The finite carrier is the six-bit codon cube $Q_6$, with coordinates used only to organize codon labels and local neighborhood data. In this packet the biological contact is a curated codon-to-label table: each codon is assigned an amino-acid or stop label, and the experiment asks whether a local tile cut in the $Q_6$ display remains predictive under leave-one-code-out stress. The contact is intentionally narrow. It observes label readback, not translation in a cell, not folded protein structure, not physical admissibility, not function, not a mechanism, and not a universal biological law.

\paragraph{Distinguished boundary set.}
The finite boundary set $R$ has cardinality $13$. Its listed codons are
$$
\begin{aligned}
R = \{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.

The punctured-cube check returns the same list and the face-count vector $(13,16,4)$. Thus the boundary is not being inferred from a free prose description of the genetic code; it is a concrete finite row in the codon-coordinate display. The row should be read as a local label-tile boundary, not as a claim that DNA, translation, or protein structure is governed by this geometry.

\paragraph{Spectral row.}

\paragraph{Shape significance.}
Against the recorded null sample for the $M$-shape comparison, $N=2000$ random trials were evaluated after $57377$ distinct-sample attempts and $55377$ duplicate retries. The exact-shape match count was $1$, giving $p=0.0005$. The high-overlap criterion with Jaccard score at least $0.9$ had $25$ matches, giving $p=0.0125$. A second amino-acid-class-preserving null model used $N=2000$ trials with observed $M$ size $20$. It found $0$ exact matches, so the exact-shape finite-sample value is $0.0$, and it found $7$ trials in the lower tail at or below the observed $M$ size, giving $p=0.0035$. These rows support the claim that the displayed local shape is not typical under the recorded null procedures. They still remain code-layer evidence: they concern finite codon labels and coordinate structure, not protein realization.

\paragraph{Leave-one-code-out result.}
The direct leave-one-code-out experiment evaluated $23$ tables and $63$ total targets. The baseline hit rate was $0.19821739130434785$. The hit rate above baseline was $0.9841269841269841$. Inside $M\setminus T$ the hit rate was $0.9365079365079365$, while inside $M\setminus T$ plus the boundary allowance it was $0.9841269841269841$. The test therefore says that, when one code table is left out, the local codon-coordinate tile almost always recovers the held-out code-layer target above baseline once the specified boundary is admitted. The result is a stability statement about codon-label readback under this finite protocol, not a statement that the same pattern enforces biological mechanism across organisms.
