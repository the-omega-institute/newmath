\subsection{Leave-One-Code-Out Readback for the Window-Six Codon Tile}
\label{subsec:h1-leave-one-code-out}

\paragraph{Finite codon carrier.}
The record is evaluated on the six-coordinate codon cube $Q_6$, where each codon is treated as a finite coordinate display rather than as a biochemical process.  The contact used here is the curated standard-code table: it supplies codon-to-label assignments, including amino-acid labels and stop labels, but it does not supply translation dynamics, folded structures, admissible physical conformations, biological function, or a universal mechanism.  The finite readback therefore has one job: test whether the window-six coordinate geometry organizes local code-label changes around a small boundary tile.

The distinguished boundary set $R$ has cardinality $13$ and is exactly
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The punctured-cube check returns the same thirteen codons, with face-vector data $(13,16,4)$.  Thus the local object is not a loose verbal cluster: it is a finite subcomplex with thirteen vertices, sixteen edges, and four two-dimensional faces.  The module assignment is complete on this same set: $\{AGA,AGG\}$ form the $agr$ module, $\{AAA\}$ the $ar\_lys$ module, $\{CUA,CUC,CUG,CUU\}$ the $cun$ module, $\{AUA\}$ the $ile\_met$ module, $\{UCA,UUA\}$ the $ssn$ module, and $\{UAA,UAG,UGA\}$ the $stop\_trp$ module.  The reported module audit has $R\_size=13$, assigned count $13$, no extra module codons, no missing codons, and no unassigned codons.

\paragraph{Spectral and sampling evidence.}
The coordinate computation separates the local tile from random label-preserving alternatives.  The spectrum row reports
$$
\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128,
\end{aligned}
$$
with the cubic or radial residual equal to $-6.224354365258478\times 10^{-12}$, which is numerically zero at the stated tolerance.  The row for $M$-shape significance used $N=2000$ sampled tables with seed $42$.  Only one sampled table matched the exact observed shape, giving $p_{exact}=0.0005$, while $25$ tables reached Jaccard similarity at least $0.9$, giving $p_{J\geq 0.9}=0.0125$.  The sampling process required $57377$ distinct-sample attempts and $55377$ duplicate retries, so the row records a constrained finite search rather than a casual resampling count.

The amino-acid-class-preserving null model gives an independent finite comparison.  In $N=2000$ samples, the exact-shape count is $0$, hence the reported exact-shape value is $0.0$.  The observed $M$-size is $20$, and the lower-tail count at or below that observed size is $7$, giving lower-tail probability $0.0035$.  These rows do not prove that biology must obey the coordinate geometry.  They say that the observed local code-label tile is uncommon under the finite null models that were run.

\paragraph{Leave-one-code-out test.}
The central claim is the leave-one-code-out row.  Across $23$ evaluated code tables and $63$ held-out targets, the baseline hit rate is $0.19821739130434785$.  The hit rate above baseline is $0.9841269841269841$.  Restricting to $M-T$ gives $0.9365079365079365$, and allowing the boundary again gives $0.9841269841269841$.  In plain terms, almost all held-out code-level targets are recovered by the local finite tile plus its boundary allowance, while the baseline is near one fifth.  The family split keeps the same shape: bacterial/plastid, candidate-other, mitochondrial, and nuclear-ciliate families each report $1.0$, while alternative yeast reports $0.8333333333333334$.  The family count is $5$.

The codon-level row is consistent with this interpretation.  It reports anchor count $0$, boundary count $5$, predictable count $8$, closure-coverage-high count $8$, and recovery rate $1.0$.  This supports a local code-read statement: the finite coordinate tile and its boundary recover the relevant label-change targets in the tested rows.  It does not support promotion from label readback to protein realization.

\paragraph{Local scientific conclusion.}
The finite evidence supports the following bounded claim.  In the standard-code label table, the six-coordinate codon display exposes a small local boundary tile whose thirteen codons form a complete module classification and whose leave-one-code-out behavior is much stronger than the reported baseline.  The result is a code-layer readback result: it concerns codons, labels, local closure, boundary membership, module assignment, and finite null comparisons.

The same finite rows also set the limit of the claim.  A curated code table is not a translation experiment.  It does not observe ribosomal realization, tRNA availability, folded protein structure, physical admissibility, organism-specific function, or a biological law applying across all contexts.  Amino-acid label sequences obtained from a codon table remain labels until another contact supplies structural or functional evidence.  Consequently, the local tile may be used as a finite code-read probe, but any assertion about folding, mechanism, universality, or biological function must wait for a separate observation designed for that higher layer.
