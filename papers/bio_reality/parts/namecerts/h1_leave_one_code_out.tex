\subsection{Leave-one-code-out recovery inside a local codon tile}
\label{sec:codon-leave-one-code-out}

\paragraph{Finite object.}
The record concerns the standard-code codon table viewed through a six-coordinate codon display. The carrier is the codon cube $Q_6$, and the readout under test is only the assignment of codons to amino-acid or stop labels in the curated standard code. The finite distinction is not a claim about translation dynamics. It is a local question about whether the observed label split is recoverable from a tile-shaped boundary pattern after one code table is withheld from the comparison set.

The distinguished codon set $R$ has cardinality $13$. In the recorded run it is exactly
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The same row certifies the punctured-cube shape by the finite vector $(13,16,4)$. Thus the observed set is not being treated as a free verbal category: it is a named subset of $Q_6$ with $13$ vertices, $16$ local adjacencies, and $4$ square faces in the tile calculation.

\paragraph{Shape evidence.}
Against $2000$ sampled null trials with seed $42$, the exact local shape appeared once. The corresponding exact-shape probability is $0.0005$. The high-overlap comparison, using Jaccard threshold $0.9$, appeared $25$ times, giving $0.0125$. The sampling log records $57377$ distinct-sample attempts and $55377$ duplicate retries. These numbers make the shape test concrete: the row is not merely saying that the tile looks organized, but that this exact finite configuration was rare in the sampled comparison class.

The amino-acid-class-preserving null gives a separate control. In $2000$ trials with seed $42$, the exact shape count was $0$, so the recorded exact-shape probability is $0.0$. The observed $M$ size is $20$, and only $7$ null rows fell in the lower tail at or below that size, giving $0.0035$. This supports the limited statement that the local codon-label arrangement is not reproduced frequently by the tested class-preserving randomizations.

\paragraph{Leave-one-code-out result.}
The main leave-one-code-out row evaluated $23$ tables and $63$ targets. Its baseline hit rate is $0.19821739130434785$. The hit rate above baseline is $0.9841269841269841$. The stricter interior score, using $M\setminus T$, is $0.9365079365079365$, while the interior-plus-boundary score returns $0.9841269841269841$. In finite terms, the recovery test says that the withheld-code targets are almost always recovered once the local tile boundary is allowed, and that most targets are already recovered before the extra boundary allowance.

The family split is also finite. Five families are recorded. The family hit rates above baseline are $0.8333333333333334$ for alternative yeast, $1.0$ for bacterial plastid, $1.0$ for candidate other, $1.0$ for mitochondrial, and $1.0$ for nuclear ciliate. The only family in this row below perfect recovery is alternative yeast, and it still remains far above the baseline rate.

\paragraph{Module accounting.}
The codons in $R$ are completely assigned to six modules. The AGR module is $\{\mathrm{AGA},\mathrm{AGG}\}$; the AR-Lys module is $\{\mathrm{AAA}\}$; the CUN module is $\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\}$; the Ile-Met module is $\{\mathrm{AUA}\}$; the SSN module is $\{\mathrm{UCA},\mathrm{UUA}\}$; and the Stop-Trp module is $\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}$. The module classification row reports $R\_\mathrm{size}=13$, assigned count $13$, no extra module codons, no missing codons, and no unassigned codons. Each module has either predictable or boundary status in the recorded classifier.

The leave-one-codon-out check is compatible with this module picture. It reports anchor count $0$, boundary count $5$, high closure coverage $8$, predictable count $8$, and recovery rate $1.0$. Thus the local mechanism visible in the finite rows is a boundary-and-closure readout over codon labels, not a statement that a biochemical process has been derived from geometry.

\paragraph{Reality contact and scope.}
The external contact used here is the curated standard genetic-code table: it supplies codon-to-label assignments for amino-acid and stop labels. That contact can test code-layer readback and local label splitting. It does not observe ribosomal translation, folded protein structure, thermodynamic admissibility, organism-level function, or a universal generative mechanism. Therefore the correct conclusion is narrow. Window-six coordinates expose a robust local tile pattern for code labels, and the leave-one-code-out row shows strong recovery across the tested tables. No claim about translation, folding, physical realizability, biological function, mechanism, or universality follows from this packet unless an independent contact at that higher layer is supplied.
