\subsection{Leave-one-code-out recovery in the window-six codon cube}
\label{sec:h1-leave-one-code-out}

\paragraph{Question.}
The record tests whether the window-six codon coordinate system carries local predictive information about codon-label changes across curated code tables.  The carrier is the six-coordinate codon cube $Q_6$, read only through finite codon labels.  The biological contact is therefore narrow: a curated standard-code table assigns each codon to an amino-acid or stop label, and the experiment asks whether local tile and boundary data help recover held-out code differences.  It does not ask whether the coordinate system realizes translation, folded structure, molecular admissibility, biological function, a mechanism, or a universal law.

\paragraph{Finite codon support.}
The exceptional region $R$ has cardinality $13$.  The verified row list is
$$\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}$$
The same rows are certified as a punctured-cube support with face vector
$$\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}$$
Thus the code-read object is not an unconstrained table lookup: it has a finite local shape in $Q_6$, with thirteen vertices, sixteen one-dimensional adjacencies, and four square faces in the recorded tile complex.  The comparison set $M$ is recorded with observed size $20$ in the amino-acid-class preserving null experiment; no additional row list for $M$ is needed here beyond the reported finite counts and the recovery regions computed from them.

\paragraph{Null comparisons.}
The shape signal is not treated as self-certifying.  Against $2000$ distinct sampled tables, the exact shape match count is $1$, giving $p_{\mathrm{exact}}=0.0005$.  The high-overlap threshold $J\ge 0.9$ has $25$ matches, giving $p_{J\ge 0.9}=0.0125$.  The sampling run required $57377$ distinct-sample attempts and $55377$ duplicate retries at seed $42$, so the finite comparison is explicitly reported with its sampling burden.  Under the amino-acid-class preserving null model, $2000$ samples produced $0$ exact matches to the observed shape and $7$ lower-tail samples at or below the observed $M$-size threshold $20$.  The reported values are
$$\begin{aligned}
p_{\mathrm{class\ exact}}&=0.0,\\
p_{\mathrm{class\ lower\ tail}}&=0.0035.
\end{aligned}$$
These null rows support a code-layer statement: the finite tile pattern is atypical under the reported randomizations.  They do not license any claim about protein realization, folding, physical possibility, function, or evolutionary necessity.

\paragraph{Leave-one-code-out recovery.}
For the primary held-out-code test, $23$ code tables and $63$ target rows were evaluated.  The baseline hit rate is $0.19821739130434785$.  Using the local window-six recovery region, the hit rate above baseline is $0.9841269841269841$.  The stricter region $M\setminus T$ has hit rate $0.9365079365079365$, and adding the boundary rows gives
$$\begin{aligned}
\mathrm{hit}(M\setminus T\;\mathrm{plus\ boundary})=0.9841269841269841.
\end{aligned}$$
The result is therefore a finite readback fact: almost all held-out code changes in the recorded target set land in the local recovery region or its boundary extension.  The comparison to the baseline rate is large, but its interpretation remains confined to codon-label recovery across curated code tables.

\paragraph{Boundary of the claim.}
The warranted conclusion is that window-six codon coordinates expose a reproducible local tile and boundary structure for code-label readback.  The curated table supplies the label contact; the coordinate system supplies the finite neighborhood geometry; the experiments report atypical shape statistics and high held-out recovery.  Nothing in this packet observes ribosomal translation, folded protein structure, physical admissibility, biological function, mechanism, or universality.  An amino-acid label sequence is not a folded structure, and a local codon tile is not a law of biology.  Any future claim beyond code labels must attach an independent contact at that higher layer before the statement can move past this boundary.
