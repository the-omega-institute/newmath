\subsection{Leave-One-Code-Out Boundary Test for the Standard Code}
\label{subsec:h1-leave-one-code-out}

\paragraph{Question and finite carrier.}
The record tests whether a six-bit codon-coordinate presentation can recover local label-boundary information in the standard-code table without treating that recovery as a biological mechanism. The carrier is the codon cube $Q_6$, read as a finite coordinate display for the $64$ codons. The biological contact used here is deliberately narrow: the curated standard genetic-code table supplies codon-to-label assignments, so the observable layer is code readback only. It does not supply translation dynamics, folding, physical admissibility, biological function, or a universal law of coding.

\paragraph{Distinguished codon set.}
The finite set $R$ contains exactly $13$ codons. In lexicographic RNA notation the observed list is
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The same row reports that $R$ is a punctured-cube-shaped object with face vector $(13,16,4)$. Thus the relevant boundary is not merely a list of exceptional labels; it has a finite cubical incidence profile inside the six-bit coordinate carrier. The module decomposition is complete: $13$ assigned codons, no missing elements from the modules, no extra module codons, and no unassigned codons. The six modules are
$$
\begin{aligned}
\mathrm{agr}&=\{\mathrm{AGA},\mathrm{AGG}\},\quad
\mathrm{ar\_lys}=\{\mathrm{AAA}\},\quad
\mathrm{cun}=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\},\\
\mathrm{ile\_met}&=\{\mathrm{AUA}\},\quad
\mathrm{ssn}=\{\mathrm{UCA},\mathrm{UUA}\},\quad
\mathrm{stop\_trp}=\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}.
\end{aligned}
$$
Each module has at least one codon classified as predictable or boundary-supported, so the finite classification covers the full $R$-packet rather than a selected subfamily.

\paragraph{Spectral and shape checks.}
The spectrum row gives $\lambda_M=0.6752479308830213$, $\lambda_R=0.4758352843197002$, and $\mu=3.051487585298128$. The radial polynomial residual is $-6.224354365258478\times 10^{-12}$, the same value reported for the cubic polynomial check, so the numerical witness is at the displayed tolerance scale rather than a qualitative label. The shape row uses $N=2000$ sampled controls with seed $42$: exact shape matches occur once, giving $p_{\mathrm{exact}}=0.0005$, while $25$ samples reach Jaccard score at least $0.9$, giving $p_{J\ge 0.9}=0.0125$. A second control preserving amino-acid classes also uses $N=2000$ and seed $42$; it reports observed $|M|=20$, exact-match count $0$, lower-tail count $7$, $p_{\mathrm{class,exact}}=0.0$, and $p_{\mathrm{class,lower}}=0.0035$. These rows make the local tile nontrivial as finite code-table geometry, while still leaving the biological interpretation at the label layer.

\paragraph{Leave-one-code-out readback.}
The leave-one-code-out experiment evaluates $23$ code tables and $63$ total targets. The baseline hit rate is $0.19821739130434785$. The observed hit rate above baseline is $0.9841269841269841$, the hit rate inside $M\setminus T$ is $0.9365079365079365$, and the rate inside $M\setminus T$ plus boundary codons is $0.9841269841269841$. Family stratification gives $5$ families: alternative yeast has hit rate $0.8333333333333334$ above baseline, while bacterial/plastid, candidate-other, mitochondrial, and nuclear-ciliate families each report $1.0$. These numbers support a claim about local recovery of code-label perturbations: the coordinate-and-boundary packet tracks most leave-one-code-out targets once the curated label table is supplied.

\paragraph{Codon-level recovery and boundary role.}
The leave-one-codon-out row reports anchor count $0$, boundary count $5$, predictable count $8$, high closure coverage $8$, and recovery rate $1.0$. The absence of anchors matters: recovery is not being attributed to a fixed privileged codon that forces the table. The evidence instead points to a local boundary-and-closure pattern on the six-bit display. The boundary count of $5$ and predictable count of $8$ together account for the $13$-codon distinguished set, matching the module-complete classification above.

\paragraph{Local verdict.}
The finite evidence supports the following bounded statement. Given the curated standard-code label table as contact data, the six-bit codon coordinate carrier exposes a local tile boundary whose $R$-packet has size $13$, face vector $(13,16,4)$, complete module coverage, significant sampled shape rarity, and strong leave-one-code-out recovery across $23$ evaluated code tables. This is a code-read result. It does not show that translation is generated by the geometry, that amino-acid sequences fold, that a molecule is physically admissible, that any biological function is realized, that the same pattern is a universal mechanism, or that DNA must obey this geometry as a law. Any such higher-layer assertion would require a separate empirical contact with its own finite rows.
