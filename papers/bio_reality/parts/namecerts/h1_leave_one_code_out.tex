\subsection{Leave-One-Code-Out Code-Label Readback}\label{sec:h1-leave-one-code-out}
\origin{ai}

\paragraph{Finite codon window.}
The record concerns a six-coordinate codon display $Q_6$ whose observable readback is the curated standard-code assignment of codons to amino-acid or stop labels.  The object tested here is not a biochemical mechanism.  It is a finite code-layer question: when one code table is withheld from the comparison, do the remaining local tile and boundary coordinates still locate the held-out label changes above a simple baseline?  The distinguished boundary set $R$ has cardinality $13$ and is exactly
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The same row records this set as a punctured-cube boundary with $f$-vector $(13,16,4)$.  Thus the chapter is anchored in a concrete finite shape: thirteen codon vertices, sixteen one-dimensional adjacencies, and four local faces.  The available $M$-side scalar is an observed size of $20$; no enumerated $M$ codon list is supplied in this row, so this chapter does not assert one.

\paragraph{Spectral and shape checks.}
The boundary is not being treated as a visual coincidence alone.  The finite spectral row gives
$$
\begin{aligned}
\lambda_M &= 0.6752479308830213,\\
\lambda_R &= 0.4758352843197002,\\
\mu &= 3.051487585298128.
\end{aligned}
$$
The associated cubic residual is $-6.224354365258478\times 10^{-12}$, the same value reported for the radial polynomial check, so the numerical witness is at floating tolerance rather than a fresh symbolic theorem.  Against $N=2000$ sampled null shapes, the exact shape appeared once, giving $p_{\mathrm{exact}}=0.0005$; a high-overlap threshold $J\geq 0.9$ appeared $25$ times, giving $p=0.0125$.  The sampling row also records $57377$ distinct-sample attempts and $55377$ duplicate retries, which is important: the sample space is finite and collision-heavy, so the evidence is a calibrated finite comparison, not an asymptotic law.

\paragraph{Leave-one-code-out result.}
For claim $h1.leave.one.code.out$, the finite run evaluates $23$ code tables and $63$ held-out targets.  The baseline hit rate is $0.19821739130434785$.  The local coordinate test gives a hit rate above baseline of $0.9841269841269841$, and the stricter $M\setminus T$ component gives $0.9365079365079365$.  When the boundary contribution is admitted, the rate is again $0.9841269841269841$:
$$
\begin{aligned}
\mathrm{baseline} &= 0.19821739130434785,\\
\mathrm{hit}(M\setminus T) &= 0.9365079365079365,\\
\mathrm{hit}(M\setminus T\;\mathrm{plus\ boundary}) &= 0.9841269841269841.
\end{aligned}
$$
This is the central finite-row statement of the chapter.  With one code table left out, the six-bit local tile and its boundary recover almost all code-layer targets in the tested collection, far above the baseline frequency.  The result is about label readback in curated code tables; it does not identify a translation apparatus, a folding process, a physical admissibility condition, a functional phenotype, or a universal biological principle.

\paragraph{Family stratification.}
The family-level row splits the same phenomenon into five families.  The recorded above-baseline hit rates are $1.0$ for bacterial/plastid, $1.0$ for candidate-other, $1.0$ for mitochondrial, $1.0$ for nuclear-ciliate, and $0.8333333333333334$ for alternative-yeast.  The alternative-yeast family is therefore the only reported family below perfect above-baseline recovery in this finite table, but it remains well above the baseline rate of $0.19821739130434785$.  This supports a chapter-specific reading: the local window is stable across the tested family partition, while still allowing family-dependent weakening.

\paragraph{Module accounting.}
The module classification is complete on the $13$-codon boundary set: $R$ has size $13$, the assigned count is $13$, and the lists of extra module codons, missing module codons, and unassigned codons are all empty.  The six modules are
$$
\begin{aligned}
\mathrm{agr} &= \{AGA, AGG\},\\
\mathrm{ar\_lys} &= \{AAA\},\\
\mathrm{cun} &= \{CUA, CUC, CUG, CUU\},\\
\mathrm{ile\_met} &= \{AUA\},\\
\mathrm{ssn} &= \{UCA, UUA\},\\
\mathrm{stop\_trp} &= \{UAA, UAG, UGA\}.
\end{aligned}
$$
Every module is reported as having either a predictable member or a boundary member.  The companion leave-one-codon-out row records $5$ boundary codons, $8$ predictable codons, $0$ anchors, closure coverage $8$, and recovery rate $1.0$.  These numbers explain why the code-level leave-one-code-out result is not just a table-wide aggregate: the finite boundary decomposes into named local modules without leftovers.

\paragraph{Null comparison.}
An amino-acid-class-preserving null model was also run with $N=2000$.  It reports observed $M$-size $20$, exact-match count $0$, lower-tail count $7$, exact-shape $p$-value $0.0$, and lower-tail $p$-value $0.0035$.  This is a sharper control than an unconstrained shuffle because it preserves amino-acid class information while still failing to reproduce the observed local shape at the recorded frequency.  The correct conclusion is limited: the finite coordinate package detects a nonrandom code-label boundary pattern under the tested nulls.  It does not show that biology must implement the geometry, nor that codon labels determine molecular structure.

\paragraph{Reality contact and blocked promotions.}
The only declared empirical contact in this row is the curated standard genetic-code table.  That contact supplies codon-to-label assignments and supports local split checks at the code-read layer.  It does not contain a ribosome model, a kinetic translation trace, a protein fold, an admissibility experiment, or a functional assay.  Consequently, amino-acid label sequences remain label sequences here.  Any claim about translation realization, folded structure, physical feasibility, biological function, mechanism, or universality requires a separate contact with those observations.  The finite result is therefore ready as a code-layer chapter: strong local readback, complete boundary-module accounting, explicit null comparisons, and a local boundary that is not promoted beyond the data that actually touched the record.
