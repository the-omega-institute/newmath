\subsection{Leave-One-Code-Out Recovery in a Window-Six Codon Tile}\label{sec:h1-leave-one-code-out}\origin{ai}

\paragraph{Claim and finite setting.}
This record studies a code-level recovery test for the standard-code codon table inside a six-coordinate codon display.  The carrier is the finite codon cube $Q_6$, where each codon is read as a six-bit coordinate object and then compared with the curated codon-to-label table.  The claim is not that the geometry creates translation.  The claim is narrower: when code tables are perturbed by leaving one code assignment route out, the finite window-six tile supplies a strong local recovery signal for the affected codon-label positions.

The distinguished boundary set $R$ has cardinality $13$ and is exactly
$$
\begin{aligned}
R=\{&AAA,AGA,AGG,AUA,CUA,CUC,CUG,CUU,\\
&UAA,UAG,UCA,UGA,UUA\}.
\end{aligned}
$$
Its punctured-cube face data have $f$-vector $(13,16,4)$.  Thus the relevant finite object is not an undifferentiated subset of codons: it is a thirteen-vertex local piece with sixteen one-dimensional incidences and four two-dimensional faces in the codon-coordinate display.

\paragraph{Leave-one-code-out row.}
For claim id $h1.leave.one.code.out$, the verified run $429e6e2c4eb4$ evaluated $23$ code tables and $63$ target events.  The baseline hit rate was $0.19821739130434785$.  The recovery rate above that baseline was $0.9841269841269841$.  The stricter interior count, using $M-T$, gave $0.9365079365079365$, while adjoining the boundary restored the rate to $0.9841269841269841$:
$$
\begin{aligned}
\operatorname{hit}_{\mathrm{base}}&=0.19821739130434785,\\
\operatorname{hit}_{>\mathrm{base}}&=0.9841269841269841,\\
\operatorname{hit}_{M-T}&=0.9365079365079365,\\
\operatorname{hit}_{M-T+\partial}&=0.9841269841269841.
\end{aligned}
$$
The comparison is therefore finite and row-wise: $63$ targets are tested against a fixed local codon geometry and against the observed label table.  The result supports a local recovery phenomenon at the code-read layer, not a biological mechanism.

\paragraph{Shape and null comparisons.}
The shape row supplies a separate check that the observed local object is rare under the sampled coordinate-preserving comparison.  In run $0b267c88f8e4$, $N=2000$ samples were drawn with seed $42$.  The process required $57377$ distinct-sample attempts and encountered $55377$ duplicate retries.  Exactly one sample matched the observed shape, giving $p_{\mathrm{exact}}=0.0005$.  Twenty-five samples reached Jaccard similarity at least $0.9$, giving $p_{J\ge 0.9}=0.0125$:
$$
\begin{aligned}
N&=2000,\\
\#\mathrm{exact}&=1,\\
p_{\mathrm{exact}}&=0.0005,\\
\#\{J\ge 0.9\}&=25,\\
p_{J\ge 0.9}&=0.0125.
\end{aligned}
$$
A second null row preserves amino-acid class information.  In run $e8d5de747a0c$, the observed $M$ size was $20$, the exact-match count was $0$, and the lower-tail count at or below the observed $M$ size was $7$ among $2000$ samples.  The corresponding values were $p_{\mathrm{class,exact}}=0.0$ and $p_{\mathrm{class,lower}}=0.0035$.  This matters because the local recovery signal is not merely a restatement of broad amino-acid class preservation.

\paragraph{Spectral coordinates.}
The spectral row gives a compact numerical fingerprint for the same finite object.  In run $1026324eff41$, the reported values were

\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\

$$
The cubic radial relation was satisfied to numerical residual $-6.224354365258478\times 10^{-12}$, recorded both as the cubic-polynomial residual and as the radial-polynomial value.  These numbers do not enlarge the biological interpretation.  They record that the same finite codon tile has a stable coordinate-spectrum signature while the curated table supplies the label readback.

\paragraph{Module decomposition.}
The thirteen boundary codons are exhausted by six named modules.  The AGR module is $\{AGA,AGG\}$; the AR-Lys module is $\{AAA\}$; the CUN module is $\{CUA,CUC,CUG,CUU\}$; the Ile-Met module is $\{AUA\}$; the SSN module is $\{UCA,UUA\}$; and the Stop-Trp module is $\{UAA,UAG,UGA\}$.  The module-classification row reports $R$ size $13$, assigned count $13$, no extra module codons, no missing codons, and no unassigned codons.  Hence the local tile is not only recovered as a set; it is partitioned without residue by the finite module classification.

The family-level leave-one-code-out row evaluated five families.  Their hit rates above baseline were $0.8333333333333334$ for alternative yeast, $1.0$ for bacterial plastid, $1.0$ for candidate other, $1.0$ for mitochondrial, and $1.0$ for nuclear ciliate.  This family stratification is consistent with the main $23$-table, $63$-target result while retaining a visible weaker family at $5/6$ rather than hiding all variation behind a single aggregate number.

\paragraph{Related leave-one-codon-out boundary.}
The codon-level companion row reports recovery rate $1.0$, predictable count $8$, closure coverage high $8$, boundary count $5$, and anchor count $0$.  This supports the same reading from the opposite direction: some codons are recovered by predictable closure behavior, while the remaining five are explicitly boundary cases.  Since no anchor codons were recorded in that row, the interpretation should remain local and combinatorial rather than causal.

\paragraph{Reality contact and scope.}
The only external contact used here is the curated standard-code table, which states codon-to-amino-acid or codon-to-stop labels.  That contact can test code-read agreement and local codon-tile label splits.  It does not observe ribosomal translation, molecular folding, thermodynamic admissibility, biological function, organism-level mechanism, or universality.  Therefore the allowed conclusion is: the window-six codon coordinate system exposes a finite local boundary-tile pattern with strong leave-one-code-out recovery against curated code labels.  No claim about translation realization, folded protein structure, physical admissibility, biological function, global mechanism, or universal biological law follows from this chapter unless a separate contact directly measures that higher layer.
