\subsection{Leave-One-Code-Out Recovery Inside a Window-Six Codon Tile}

\paragraph{Record.}
This record concerns the claim $\mathrm{h1.leave.one.code.out}$ for the standard-code codon table.  The carrier is the finite six-coordinate codon cube $Q_6$, read as a display of the $64$ codons with local face, corner-label, and three-point label-class distinctions.  The biological contact used here is only the curated codon-to-label table for the standard genetic code.  Thus the row is a code-layer readback test: it asks whether the window-six coordinate presentation exposes a stable local boundary pattern around code labels, while treating the labels themselves as empirical inputs from the curated table.

This is not a statement about a biological mechanism.  It is a finite combinatorial description of where the code-label table falls when displayed in the six-coordinate codon window.

\paragraph{Local conclusion.}
The finite data support the code-layer claim that window-six codon coordinates expose a stable local tile around the standard-code label table.  The residual set has the verified $13$-codon punctured-cube shape, the spectral values are numerically coherent, the exact-shape and amino-acid-class-preserving nulls place the observed shape in a small tail, and leave-one-code-out recovery remains $0.9841269841269841$ above baseline across $63$ targets from $23$ tables when the recorded boundary allowance is used.
