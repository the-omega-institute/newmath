\subsection{G418 Stop-Context Readthrough as a Bounded Translation-Termination Contact}
\label{sec:bioreality-g418-stop-context-readthrough-wangen2020}

\paragraph{Finite measurement table.}
This record concerns a finite stop-context readthrough table from the Wangen 2020 G418 condition, not a free-standing law of synonymous coding geometry.  The verified finite panel is the sheet named \emph{G418 2.0mg|mL 24hr merged}.  Before the nonzero-response restriction, the joined table contains $7658$ rows.  After restricting to the nonzero G418-induced RRTS subset, the analyzed panel contains $4982$ rows, with nonzero fraction $0.65056$.  The endpoint is the G418-induced RRTS nonzero subset, rank-averaged and scaled to $[0,1]$.  The corresponding finite-row assertion is therefore not that stop codons, wobble classes, or local nucleotide contexts themselves realize a biological mechanism; it is that a specified readthrough readout can be placed into a bounded finite table whose rows are already joined to the measured G418 response surface.

\paragraph{Coordinate discipline.}
The admissible coordinate is a stop-context or local coding-window descriptor only after it is paired with the measured readthrough endpoint in the same finite table.  In the intended $f_3$-stress reading, the carrier must contain a residual coordinate after amino-acid quotienting, local synonymous codon counts, a bounded wobble-weight context, a matched position-resolved ribosome-occupancy or translation-efficiency readout, an mRNA control, and amino-acid or position-bin controls.  The Wangen G418 table supplies a concrete termination-layer response surface for stop-context readthrough, but it does not by itself supply the complete same-window $f_3$-stress survival matrix.  Thus the chapter treats the Wangen rows as a translation-termination contact that can constrain a cross-layer hypothesis only when the relevant residual coordinate, wobble asymmetry, and control columns are actually joined row by row.

\paragraph{Bounded statistic.}
Let $T_i$ denote the rank-scaled G418-induced readthrough endpoint for row $i$ in the nonzero subset, and let $Z_i$ denote the available controls for row $i$.  The finite statistic requested by the $f_3$-stress conjecture is not an unconditional correlation.  It is a controlled survival entry of the form
$$
\begin{aligned}
S_{f_3}(T_{\mathrm{position}}\mid Z) > 0,
\end{aligned}
$$
where the comparison must beat amino-acid composition, position bin, GC3, length, M-density, mRNA abundance, codon-count, and simpler-baseline alternatives on held-out rows.  The present verified table fixes the readthrough side of such a test at $n=4982$ analyzed nonzero rows from $7658$ joined rows, but it does not certify that every control and residual-coordinate column required for $S_{f_3}$ has already been attached.  The finite contact is therefore real and useful, while the stronger $f_3$-stress survival claim remains conditional on the missing joined design matrix.

\paragraph{Readthrough-specific interpretation.}
The G418 condition is important because it creates a termination-layer perturbation under which stop-context readthrough can be rank-read.  A row with a larger scaled endpoint is a row with stronger measured readthrough response under the stated nonzero-subset definition; it is not automatically a row with higher protein abundance, altered folding, changed cellular function, or a universal codon rule.  The verified runtime for the run was $303.534$ seconds, and the run identifier is \texttt{fe18fff6841f}; these values identify the finite computational surface used for this chapter.  As a related Wangen cross-dataset check, a separate stop-readthrough audit reports $55886$ rows and an untreated Spearman-type summary $\rho = 0.032718$ with runtime $133.552797$ seconds.  That companion scalar is useful as a weak background sanity check on untreated readthrough structure, but it is not substituted for the G418 nonzero endpoint used here.

\paragraph{Boundary of the claim.}
This chapter supports only the following local statement: the Wangen G418 stop-context table provides a finite, row-counted translation-termination readout surface suitable for controlled readthrough analyses, and it can serve as one measured contact for a stricter cross-layer $f_3$-stress test if the same rows are joined to the required residual-coordinate and control fields.  It does not establish translation realization from codon geometry alone.  It does not treat modeled tAI or stAI weights as observed ribosome occupancy.  It does not infer protein abundance, folded structure, physical admissibility, molecular function, mechanism, phenotype, or universality.  Any such downstream statement would require its own layer-matched measurement table and its own controlled finite statistic.

\paragraph{Local null condition.}
The claim fails locally if the readthrough endpoint is used without the row join that produced the $4982$ analyzed nonzero rows, if the endpoint is promoted to a general translation mechanism, or if an $f_3$-stress survival score is asserted before the same-row residual coordinate, wobble-weight asymmetry, mRNA control, amino-acid or position controls, coverage limits, rank sufficiency, and simpler-baseline ablations are present.  Under those restrictions, the Wangen G418 result remains a bounded readthrough contact rather than a completed proof of the broader $f_3$-stress position-resolved translation-survival conjecture.
