\subsection{Start--Stop Window Eligibility as a Bounded ORF Contact}

\paragraph{Question.}
This record asks for a deliberately narrow biological assertion: whether a finite nucleotide window is eligible under a start--stop codon enumeration.  The assertion is not that translation occurs, not that a protein is produced, not that a folded structure exists, not that the molecule is physically admissible in a cell, and not that the interval has biological function.  The only permitted layer is $\mathrm{orf\_eligibility}$, meaning that the observed finite row has been checked against a fixed start/stop-window rule after a separate curated interval input has supplied the window being tested.
