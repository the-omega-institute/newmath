\subsection{Start--stop enumeration as an ORF-eligibility boundary test}
\label{sec:h2-orf-start-stop-window-eligibility}

\paragraph{Claim being recorded.}
The object of this chapter is the finite classification task in which a nucleotide window is inspected only for start--stop compatibility. The recorded layer is \emph{orf eligibility}: a window may be sorted by the presence of an admissible start and stop pattern, but that sorting is not yet an observation of translation and is not a statement about a protein product. In the finite run for \texttt{h2.orf.start\_stop.window\_eligibility}, the input table contained one window and the classifier returned one classified window. The external manifest was loaded, with \texttt{external\_window\_dataset\_loaded}=1, \texttt{window\_count}=1, \texttt{input\_windows}=1, and \texttt{classified}=1. The declared scope was \texttt{external\_window\_start\_stop\_enumeration\_only}, and the recorded layer cap was \texttt{orf\_eligibility\_only}.

\paragraph{What the one-window run establishes.}
The run establishes only that the supplied manifest row was accepted by the start--stop-window enumeration procedure under the stated scope. Its source was a curated finite nucleotide-window manifest for ORF start--stop enumeration, with snapshot date \texttt{2026-05-25}. The manifest entries are annotation inputs to the experiment, not consequences extracted from codon geometry alone. Thus the finite conclusion is the conditional one: given this loaded external window table, the enumerator classified all supplied windows, namely $1$ of $1$. No further biological layer is reached by this operation.

The interval-contact row also records three held-out folds. The protocol was frozen before observation: classifier rules, input classes, baselines, and held-out splits were fixed, with the protocol timestamp \texttt{2026-05-29T19:11:13+00:00} and the external evidence timestamp \texttt{2026-05-30T10:29:31+00:00}. \paragraph{Local boundary on interpretation.}
The start--stop-window result permits only an ORF-eligibility classification for the supplied manifest row. It does not assert that translation occurred, that a folded protein structure exists, that the molecule is physically admissible, that a biological function is present, that a mechanism has been identified, or that a universal biological law follows. Those stronger readings require their own contact with sequence annotation, transcript evidence, peptide or proteomic observation, structural measurement, physical assay, functional assay, or another suitable external biological record. Without such a separate contact, start--stop geometry remains a finite eligibility filter and nothing more.
