\paragraph{Finite coordinate surface.}
This record concerns the finite CDS-by-organism residual surface obtained after amino-acid projection, with special attention to the $f_3$-paired synonymous imbalance coordinate inside the $B^*_{Q6}$ panel.  The finite seed row for the $f_3$ saturation calculation fixes
$$
\begin{aligned}
M &= \{\mathrm{AAA},\mathrm{AAG},\mathrm{ACA},\mathrm{ACG},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{AUG},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UCG},\mathrm{UGA},\mathrm{UGG},\mathrm{UUA},\mathrm{UUG}\},\\
\operatorname{Sat}_{f_3}(R) &= \{\mathrm{AAA},\mathrm{AAG},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{AUG},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UCG},\mathrm{UGA},\mathrm{UGG},\mathrm{UUA},\mathrm{UUG}\},\\
\partial_{f_3}(R) &= \varnothing .
\end{aligned}
$$
Thus the displayed saturation removes exactly $\mathrm{ACA}$ and $\mathrm{ACG}$ from the twenty-codon set while leaving an empty $f_3$ boundary.  This is a coordinate statement about a finite codon surface.  It is not, by itself, an observation of translation, ribosome dwell time, protein output, folded structure, physical admissibility, cellular function, or a universal biological rule.

\paragraph{Powered organism panel.}
The powered core-adaptation row was evaluated under experiment run $373843\mathrm{e}81379$ with deterministic seed $\mathrm{sha256:b\_star\_q6\_universal\_core\_is\_trna\_adaptation\_powered:deterministic}$.  The run status is reported as passed, using $5$ folds, a minimum of $500$ proteins per organism, $41$ synonymous design columns, and $11$ computed organisms out of $16$ requested organisms.  The finite interpretation is that the universal core direction in this panel is compatible with tRNA adaptation as the leading bounded readout among the encoded synonymous residual coordinates.  The companion R-sense tRNA-poverty row strengthens the same local interpretation: experiment run $\mathrm{d7728cc8768e}$ used $40$ computed organisms out of $46$ requested organisms, skipped $6$ organisms, used $1000$ permutations at $\alpha=0.05$, and returned the mechanism call that R sense codons are systematically tRNA-poor under GtRNAdb tGCN together with dos Reis wobble weights.  This supports a tRNA-supply interpretation for R avoidance within the specified finite assay.

\paragraph{Residual-axis decomposition.}
The non-tRNA residual direction was separately classified in experiment run $2\mathrm{a}526\mathrm{c}9\mathrm{fb}7\mathrm{f}4$ as aligning most with $f_3$ translation selection.  That run also used $5$ folds, at least $500$ proteins per organism, $41$ synonymous design columns, and $11$ computed organisms out of $16$ requested.  The two-axis closure row, run $99\mathrm{dc}7\mathrm{e}2\mathrm{d}5\mathrm{abf}$, reported a third axis present because the perpendicular direction had systematically positive held-out $R^2$ and mutually same-signed directions across organisms.  The third-axis identity row, run $377671\mathrm{f}96\mathrm{e}96$, identified $d_\perp$ provisionally with usage frequency within family, with mean cosine $0.128$ and one-sided sign-test $p=0.000488$.  The related mechanism row, run $\mathrm{d0893337f0dd}$, classified the same axis as selection-not-GC and not wobble-clustered, while leaving the CSC or positional identity as requiring a further contact.  These rows place the tRNA core direction in a finite spectrum rather than as an isolated scalar.

\paragraph{Higher-axis boundary.}
The three-axis sufficiency run $2436\mathrm{cae}9\mathrm{d}455$ returned $\mathrm{fourth\_mechanism\_present}$ with $5$ folds, $11$ computed organisms out of $16$ requested, and $41$ synonymous design columns.  The organism-level axis-strength spectrum run $0146012\mathrm{d}8909$ reported $d_{\mathrm{resid4}}$ as the average leader, followed by $d_{\mathrm{tRNA}}$, with per-organism dominant counts $\{d_{\mathrm{resid4}}:11\}$ and a largest GC3 rank effect $\rho=0.136$ for $d_{\mathrm{usage}}$.  Because the domain counts were imbalanced, with $1$ archaeal, $2$ bacterial, and $8$ eukaryotic organisms, those domain means are descriptive only.  The fourth-axis checks also constrain over-reading: mRNA stability was rejected as the dominant fourth-axis identity in run $377\mathrm{abd}67\mathrm{b}8\mathrm{b}3$, codon-pair identity returned $\mathrm{not\_codon\_pair}$ in run $\mathrm{b519b5ebd34d}$ using $50$ shuffle nulls, translation accuracy returned $\mathrm{not\_accuracy}$ in run $0\mathrm{dc}44\mathrm{df}59\mathrm{ba}7$ using $200$ permutations, and elongation dwell returned only $\mathrm{partial}$ for $\mathrm{saccharomyces\_cerevisiae}$ in run $\mathrm{e4edcde459b7}$.  The finite evidence therefore favors a core tRNA-adaptation direction and a residual $f_3$-translation-selection component, while explicitly leaving additional axes unresolved.

\paragraph{Translation-readout gate.}
The biologically bounded readback for this chapter is the controlled survival entry $S_{f_3\text{-}\mathrm{stress},T_j}$ for tAI, stAI, ribosome occupancy, or translation efficiency.  The local support condition is not merely a nonzero modeled coupling.  It requires a same-organism, and where appropriate same-CDS, matrix of codon counts, wobble or tRNA weights, a translation-layer row, and matched controls.  The statistic must remain positive after amino-acid composition, organism, GC3, CDS length, M-density baseline, matched mRNA, rank, and simpler-baseline controls.  In symbols, the admissible positive statement has the form
$$
\begin{aligned}
S_{f_3\text{-}\mathrm{stress},T_j \mid Z} &> 0,\\
Z &= \{\mathrm{amino\ acid\ composition},\mathrm{organism},\mathrm{GC3},\mathrm{CDS\ length},M\text{-}\mathrm{density},\mathrm{mRNA},\mathrm{rank},\mathrm{simpler\ baselines}\}.
\end{aligned}
$$
If every such controlled entry is non-positive, or if the observed matrix is rank-degenerate, then the proposed translation-readout survival fails at this layer.  In particular, a three-organism all-$1.0$ controlled surface is treated as rank saturation, not as biological survival.

\paragraph{Local cannot-claim boundary.}
The finite rows in this chapter justify only a scoped statement about a $B^*_{Q6}$ synonymous residual direction, tRNA or wobble asymmetry, and bounded translation-readout testing.  They do not assert that $f_3$ stress changes mature protein abundance, folded structure, localization, stability, molecular function, physical admissibility, phenotype, mechanism, adaptation in general, causation, or universality.  Any such statement would need its own layer-matched contact and its own controlled statistic.  Modeled tAI or stAI weights can be used as bounded codon-adaptation readbacks; they are not observed ribosome occupancy.  Ribosome profiling or translation-efficiency rows, when attached, can test a translation-layer statistic; they are not protein abundance or structure measurements.  Matched mRNA abundance belongs in the control set and does not itself constitute translation realization.  The chapter therefore records a powered finite direction for tRNA adaptation and a precise survival test for the $f_3$-stress row, while refusing promotion beyond the measured or explicitly bounded translation layer.
