\paragraph{Local boundary.}
The direct one-window start--stop run and the larger curated-interval run should not be conflated. The first establishes only that a supplied window can be classified by start and stop enumeration under the declared finite rule. The second is a separate curated biological contact for interval-level testing and still records its own limits: it does not establish translation, protein structure, physical admissibility, biological function, a global law, or classification outside the dataset. The self-check row reports $3$ checked gates and states that no codon geometry is promoted across biological layers. Consequently this chapter records an ORF-eligibility boundary result: finite start/stop enumeration may define an eligible interval class after a suitable contact supplies the interval, but no claim about expression, folding, biochemical viability, organismal role, mechanism, or universality follows from the enumeration itself.
