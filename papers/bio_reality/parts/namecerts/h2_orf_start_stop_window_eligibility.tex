\paragraph{Finite row under examination.}
This record concerns the biological question of whether a nucleotide interval is eligible, at the start--stop enumeration level, to be treated as an open-reading-frame candidate.  The row is deliberately narrow.  It does not assert translation, protein production, folded structure, physical realizability, function, mechanism, or a universal biological regularity.  Its direct verified run loaded one curated nucleotide-window manifest, classified the one input window by start/stop enumeration, and reported that all loaded windows were classified:
$$
\begin{aligned}
\mathrm{input\_windows} &= 1,\\
\mathrm{classified} &= 1,\\
\mathrm{window\_count} &= 1.
\end{aligned}
$$
The snapshot date attached to this contact is $2026$-$05$-$25$, and the recorded scope is external window start--stop enumeration only.  The source statement is also part of the finite row: the window manifest is an external annotation input to the experiment, not a fact generated by the BEDC coordinate system.  Thus the row supplies a checkable eligibility datum only after the finite biological interval has been supplied from outside the formal geometry.

These equalities are used here only to specify the finite codon-side apparatus available to the start--stop enumeration rule.  They are not observations of expression, transcripts, ribosomes, protein products, or selection.

\paragraph{Observed interval contact.}
A separate curated interval contact gives the stronger biological calibration that this seed row requires before eligibility can be tested against finite intervals.  That contact loaded $168$ rows from a curated ORF interval dataset derived from NCBI RefSeq GenBank XML CDS intervals for \emph{Escherichia coli} K-$12$ MG$1655$ accession $NC\_000913.3$, with snapshot date $2026$-$05$-$30$.  The required input classes were present: boundary cases, matched non-ORF decoys, and positive curated ORFs.  The positive class had $72$ accepted intervals out of $72$, and the matched decoy class had $72$ rejected intervals out of $72$:
$$
\begin{aligned}
\mathrm{positive\ accept\ rate} &= 72/72 = 1,\\
\mathrm{matched\ decoy\ reject\ rate} &= 72/72 = 1,\\
p_{\mathrm{positive}} &= 2.117582368135751\cdot 10^{-22},\\
p_{\mathrm{decoy}} &= 2.117582368135751\cdot 10^{-22}.
\end{aligned}
$$
The predeclared paired baseline comparison likewise recorded $72$ wins in $72$ pairs, with the same one-sided binomial upper-tail value $2.117582368135751\cdot 10^{-22}$.  Boundary controls contained $24$ cases and promoted none of them, so the boundary-promotion fraction was $0/24 = 0$.  Held-out stability was checked over three folds: the left, middle, and right locus folds each had $24$ positive cases accepted at rate $1$ and $24$ decoys rejected at rate $1$.

\paragraph{Local non-promotion rule.}
The self-check attached to the same finite packet reports three checked gates and states that no codon geometry is promoted across biological layers.  Accordingly, the conclusion of this subsection is only the following: for the loaded finite manifest, one window was classified by a frozen start--stop enumeration rule, and a separate curated interval contact supplies a stronger $168$-row calibration for the ORF-eligibility layer.  Nothing in this row establishes that an interval is translated, that a protein folds, that a molecule is physically admissible, that a function exists, that a mechanism has been discovered, or that the rule applies universally.  Any such claim would require an additional contact whose measurements directly bear on that higher biological layer.
