The object is not an observed translated gene product. It is a row-level eligibility classifier whose present scope is the externally supplied window manifest, with one input window and one classified window. The finite run reports

The snapshot date for this start--stop enumeration record is 2026-05-25, and the source description identifies the row as a curated finite nucleotide-window manifest used as an external annotation input to the experiment. Thus the datum is not generated by the codon-geometry calculus itself; it is a biological-row input against which the finite classifier is applied.

\paragraph{Window classifier.}
The start--stop run is deliberately recorded at layer $\mathrm{orf\_eligibility}$ and no higher. Its own scalar output states that the classification scope is $\mathrm{external\_window\_start\_stop\_enumeration\_only}$ and that geometry-to-translation promotion is blocked by the value $\mathrm{orf\_eligibility\_only}$. In local terms, the record says: when an externally listed nucleotide window is handed to the pipeline, the frozen start--stop enumerator can classify that window for boundary eligibility. It does not say that the window is transcribed, translated, conserved, folded, physically admissible as a protein, functional in a cell, mechanistically explanatory, or universal across genomes.

\paragraph{Local boundary.}
The admissible conclusion is therefore small and explicit. The start--stop-window entry is a finite external-row classification at the ORF-eligibility layer. The curated interval contact supplies $168$ annotated rows and exact finite controls for that contact, including $72$ accepted positives, $72$ rejected matched decoys, $24$ non-promoted boundary cases, and three stable held-out folds. None of these numbers by themselves establishes translation, folding, physical admissibility, molecular function, mechanism, or universality. Any such claim would require a separate contact of the appropriate biological kind, such as translation evidence, structural measurement, biochemical assay, mechanistic perturbation, or cross-context validation.
