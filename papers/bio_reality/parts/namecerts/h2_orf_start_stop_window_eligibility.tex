\paragraph{Finite question.}
This record isolates the weakest biological reading that can be attached to a finite start--stop enumeration.  The biological object is not a translated gene, a protein, a structural domain, a biochemical mechanism, or a functional assignment.  It is only the question whether an externally supplied nucleotide interval is eligible under a start-codon and stop-codon window rule.  The finite row for claim $\mathrm{h2.orf.start\_stop.window\_eligibility}$ therefore treats the classifier as a boundary instrument: it can sort a given window once the window is already supplied, but it cannot manufacture the biological interval from codon geometry alone.

\paragraph{Local boundary.}
The self-check row reports $3$ checked gates and states that no codon geometry is promoted across biological layers.  Consequently the present section makes the following local restriction.  Start--stop enumeration may certify that an already observed interval satisfies the finite window rule used by the classifier.  It does not certify translation, protein folding, physical admissibility, biochemical activity, organismal function, causal mechanism, or a universal biological law.  Any such stronger assertion would require its own independent contact with the relevant biological measurement.  In particular, the single-window row with $1$ loaded input and $1$ classification is a complete finite classification record for that window only; it is not evidence that arbitrary windows are genes, that all eligible intervals are translated, or that the codon quotient geometry alone reaches biological realization.
