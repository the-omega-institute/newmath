\subsection{ORF Start--Stop Window Eligibility}\label{subsec:h2-orf-start-stop-window-eligibility}
\origin{ai}

\paragraph{Question.}
This record isolates the weakest biological reading that can be made from a finite start--stop codon enumeration.  The object is not a translated protein, not a transcript, not a folded molecule, and not a functional locus.  It is only a window-eligibility question: given an externally supplied nucleotide interval, does the frozen start--stop classifier place that interval in the syntactic class called $\mathrm{orf\_eligibility}$?  The local rule is deliberately narrow.  A codon window may pass this syntactic test only after a separate biological interval has been supplied by annotation, sequence, or transcript evidence.  Enumeration by itself is not an observation of an open reading frame.

\paragraph{Window-contact row.}
The direct start--stop-window experiment loaded one external finite window manifest.  Its scope was $\mathrm{external\_window\_start\_stop\_enumeration\_only}$, its snapshot date was $2026$--$05$--$25$, and its source was a curated finite nucleotide-window manifest whose records are annotation inputs rather than facts derived from the codon geometry.  The row count was $1$, and the classifier reported
$$\begin{aligned}

\end{aligned}$$
Thus every supplied window in that manifest was classified by the start--stop enumeration.  The stored promotion flag is $\mathrm{orf\_eligibility\_only}$, which is the important negative part of the result: the row licenses only the named eligibility layer for the supplied window, not translation or any higher biological interpretation.

That dataset contained $168$ rows and included the required input classes $\mathrm{positive\_curated\_orf}$, $\mathrm{matched\_non\_orf\_decoy}$, and $\mathrm{boundary\_case}$. The protocol was fixed before the external observation: classifier rules, input classes, baselines, and held-out splits were fixed at $2026$--$05$--$29T19{:}11{:}13{+}00{:}00$, while the external evidence was observed at $2026$--$05$--$30T10{:}29{:}31{+}00{:}00$.

\paragraph{Local conclusion.}
For this record, the finite evidence supports the following bounded statement.  When the externally supplied window or curated interval is present, the frozen start--stop classifier classifies the supplied interval at the $\mathrm{orf\_eligibility}$ layer.  The direct window manifest has $1$ classified input out of $1$; the curated interval contact has $72$ positive acceptances, $72$ matched decoy rejections, $24$ non-promoted boundary cases, and three stable held-out folds.  The self-check records $3$ checked gates and states that no codon geometry is promoted across biological layers.  Therefore the result is an eligibility classification for externally supplied intervals only.  It does not establish that translation occurred, that a protein folded, that a molecular state is physically admissible, that a locus has biological function, that a mechanism has been identified, or that a universal biological law has been found.  Any such stronger conclusion would require a further contact designed for that higher layer.
