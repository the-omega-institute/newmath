\paragraph{Object of the record.}
This record isolates a narrow biological question: whether a finite nucleotide window is eligible, at the level of start and stop codon enumeration, to be treated as an open-reading-frame candidate. The object under discussion is not a translated protein, not a folded structure, not a physically admissible molecule, and not a biological function. It is only a finite classification problem over externally supplied nucleotide-window records. The relevant run reports one loaded window dataset, one input window, and one classified window. Thus the numerical content of the local classification is
$$
\begin{aligned}

The recorded scope is external window start--stop enumeration only, with snapshot date 2026-05-25. The source is a curated finite nucleotide-window manifest for ORF start/stop enumeration, and the records are external annotation inputs to the experiment rather than facts generated by the coordinate formalism itself.

\paragraph{Contact boundary for ORF eligibility.}
The start--stop window run makes only the following assertion: all supplied windows in the external finite manifest were classified by the start/stop enumeration rule. Since the manifest contains one supplied window and the classifier reports one classified window, the local success fraction for this supplied manifest is
$$
\begin{aligned}
\frac{\operatorname{classified\ windows}}{\operatorname{input\ windows}} = \frac{1}{1}=1.
\end{aligned}
$$
This fraction is not a translation rate, not an expression rate, and not evidence for protein production. It is the complete finite result of the window-eligibility classifier on the supplied data. The run explicitly records the promotion limit as \texttt{orf\_eligibility\_only}. Therefore the correct reading is: start and stop codons can classify a supplied interval as an ORF-eligibility candidate, but no conclusion about translation, folding, physical admissibility, mechanism, biological function, or universality follows without a separate biological contact that supplies the relevant observation.

\paragraph{Separate curated interval contact.}
A stronger but still layer-bounded contact is present in the linked curated interval experiment. That experiment loaded $168$ rows from a curated ORF interval dataset with snapshot date 2026-05-30. The source is NCBI RefSeq GenBank XML CDS intervals from \emph{Escherichia coli} K-12 MG1655 complete genome accession NC\_000913.3. The input classes were boundary cases, matched non-ORF decoys, and positive curated ORFs. The classifier identifier was \texttt{orf\_start\_stop\_window\_eligibility}, and the classifier rules were not modified after observation of the external evidence.

\paragraph{Local cannot-claim boundary.}
The admissible conclusion is intentionally small. The finite codon lists, the quotient geometry, the one-window start/stop classification, and the $168$-row curated interval contact jointly support an ORF-eligibility statement at the level of externally supplied nucleotide intervals and predeclared start/stop enumeration. They do not establish translation realization, protein folding, physical admissibility, biochemical mechanism, organismal function, or a universal biological law. Any such stronger layer would require a separate contact whose measurements are appropriate to that layer. In particular, the NCBI RefSeq contact remains external curated biological reality and is not kernel content of the codon geometry. The chapter therefore records a bounded finite observation: enumeration can classify supplied windows for ORF eligibility, and curated interval contact can test that layer, but the result stops exactly at ORF eligibility.
