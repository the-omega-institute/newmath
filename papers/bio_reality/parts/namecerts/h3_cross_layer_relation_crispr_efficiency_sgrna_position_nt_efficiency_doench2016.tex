\subsection{Position-resolved sgRNA nucleotide efficiency in the Doench2016 screen}
\label{sec:bioreality-crispr-sgrna-position-nt-doench2016}
\origin{ai}

\paragraph{Finite row surface.}
This record concerns a finite CRISPR-efficiency table in which each row is an sgRNA observation with a measured activity endpoint and position-indexed nucleotide information. The checked Doench2016 run is identified by experiment run \texttt{b6c6363256e0}; it contains $5310$ finite rows and completed in $24.6506$ seconds. The scalar GC control readout recorded for this surface is $r_{GC}=-0.0582917$. Thus the available evidence is not a symbolic claim about all guide RNAs, but a bounded row table with a definite sample size, a definite GC-direction summary, and an observed endpoint attached to the same guide-level rows.

\paragraph{Coordinate tested by the chapter.}
The chapter-specific coordinate is the position-resolved nucleotide pattern of an sgRNA, read against CRISPR efficiency after keeping the guide row, target context, and simpler nucleotide-composition effects distinct. A useful way to state the tested surface is that each admissible row contributes a guide-level response $Y_i$, a vector of position-nucleotide indicators $X_i$, and a control block $Z_i$ containing at least global or local composition summaries such as GC. The finite test is then a controlled survival question:
$$
\begin{aligned}
S_{\mathrm{posNT}} &= \operatorname{score}(Y \mid Z,X)-\operatorname{score}(Y \mid Z),\\
\text{admissible support} &\Longleftrightarrow S_{\mathrm{posNT}}>0
\text{ on held-out or otherwise guarded rows.}
\end{aligned}
$$
The recorded $r_{GC}=-0.0582917$ is therefore not treated as the main biological law. It is a concrete guardrail showing that a composition-associated direction was measured and must not be confused with a position-specific guide-design signal.

\paragraph{Cross-dataset boundary.}
A separate CRISPR-efficiency cross-dataset contact is available under experiment run \texttt{2e9cce255c01}. That run records $10543$ Luo2020 rows, marks \texttt{cross\_protocol=true}, uses the Doench2016 repository as the frozen source, and completed in $33.705459$ seconds. This second finite table is useful because it prevents the Doench2016 record from being phrased as a closed biological principle. The Doench2016 table supplies the primary position-nucleotide efficiency surface; the Luo2020 route supplies an explicitly cross-protocol comparison surface. The two together support a bounded claim of the following form: position-indexed sgRNA nucleotide features are admissible finite-row predictors of CRISPR efficiency only where their contribution survives the relevant composition and dataset-boundary controls.

\paragraph{What the evidence does not establish.}
The present chapter does not infer translation, ribosome occupancy, protein abundance, folding, physical admissibility, molecular function, mechanism, phenotype, or universality from the sgRNA position-nucleotide result. The Doench2016 row count, the GC scalar $-0.0582917$, and the Luo2020 cross-protocol table concern guide efficiency surfaces, not protein-state readouts. Any statement about translation or downstream biological realization would require a separate same-row contact carrying that layer's measurement. In the present record, the only admissible biological reading is narrower: finite guide rows can carry a controlled association between position-resolved guide sequence features and measured CRISPR efficiency.

\paragraph{Local name certificate.}
The name certified here is \texttt{h3.cross\_layer\_relation.crispr\_efficiency.sgrna\_position\_nt\_efficiency\_doench2016}. Its concrete support is the $5310$-row Doench2016 efficiency surface with $r_{GC}=-0.0582917$, together with the related $10543$-row Luo2020 cross-protocol route. The certificate is deliberately finite: it names the row-bearing guide-efficiency contact, records the measured scalar guard, and keeps the cross-protocol contact separate from the primary Doench2016 table. The break condition is reached if the chapter is read as a universal sgRNA-design law, as evidence for translation or protein-level behavior, or as a mechanism claim rather than a controlled finite-row efficiency association.
