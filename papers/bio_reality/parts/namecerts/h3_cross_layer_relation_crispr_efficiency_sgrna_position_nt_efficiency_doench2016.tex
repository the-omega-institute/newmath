\subsection{Doench2016 position--nucleotide guide-efficiency boundary}
\label{sec:bioreality-doench2016-sgrna-position-nt-efficiency-boundary}

\paragraph{Finite row surface.}
The Doench2016 guide-efficiency surface gives a finite row contact for a position-resolved nucleotide model of CRISPR guide activity.  In the verified Doench2016 run, the analyzable table contains $n=5310$ guide rows, and the recorded main GC association is $r_{\mathrm{GC}}=-0.0582917$ with runtime $24.6506$ seconds under run identifier $\mathrm{b6c6363256e0}$.  A separate cross-protocol CRISPR routing check records $n=10543$ Luo rows with \texttt{cross\_protocol=true} and runtime $33.705459$ seconds under run identifier $\mathrm{2e9cce255c01}$.  These numbers are enough to certify a concrete finite-row guide-design contact: ordered guide positions, nucleotide indicators, and guide-efficiency scores can be joined inside a bounded CRISPR-efficiency regression problem.

\paragraph{What the row table supports.}
The supported statement is deliberately narrow.  Let $G$ be the finite set of guide rows in the Doench2016 contact, let $Y_g$ denote the measured guide-efficiency readout for row $g\in G$, and let $X_{g,p,b}$ mark base $b$ at guide position $p$.  The finite analysis asks whether the position--nucleotide coordinates improve prediction of $Y_g$ over simpler guide-level summaries such as GC content.  In schematic form the admissible comparison is
$$
\begin{aligned}
\Delta_{\mathrm{posNT}}
  &= \mathcal{S}(Y \mid Z, X_{p,b})-\mathcal{S}(Y \mid Z), \\
Z
  &\supseteq \{\mathrm{GC},\ \mathrm{guide\ length},\ \mathrm{available\ design\ controls}\},
\end{aligned}
$$
where $\mathcal{S}$ is a finite held-out or rank-controlled score chosen by the analysis protocol.  The observed Doench2016 scalar $r_{\mathrm{GC}}=-0.0582917$ is therefore not the claim itself; it is a recorded finite-row covariate fact showing that GC is present as a measured guide-level baseline rather than an unobserved explanatory story.  The row count $n=5310$ fixes the scale at which the Doench2016 position--nucleotide comparison is grounded.

\paragraph{Why this does not promote the f\_3-stress translation conjecture.}
The BioReality packet tied to this chapter asks about an $f_3$-stress synonymous residual coordinate in coding-sequence windows and its possible survival against matched position-resolved ribosome-occupancy or translation-efficiency readouts.  The Doench2016 CRISPR table is a real finite biological contact, but it is not that contact.  It does not contain same-organism, same-CDS, same-window codon counts, wobble-weight rows, matched mRNA abundance, amino-acid-bin controls, or codon-indexed ribosome-footprint occupancy.  Hence the available CRISPR guide rows cannot instantiate
$$
\begin{aligned}
S_{f_3}(T_{\mathrm{position}}\mid Z)>0,
\end{aligned}
$$
where $T_{\mathrm{position}}$ is a translation-layer readout and $Z$ includes amino-acid composition, position bins, GC3, length, M-density, mRNA control, and simpler-baseline ablations.  The guide-efficiency table and the translation-window table live on different row keys and different measured endpoints.

\paragraph{Local null boundary.}
The admissible conclusion is that Doench2016 supplies a finite CRISPR-efficiency row surface for position--nucleotide guide features, with $5310$ analyzed rows and a recorded GC main association of $-0.0582917$.  It does not supply evidence for translation realization, ribosome occupancy, protein abundance, folding, physical admissibility, biological function, mechanism, phenotype, or universality.  In particular, a position--nucleotide guide-efficiency signal cannot be reinterpreted as an $f_3$-stress translation-survival signal unless a separate same-window coding-sequence contact supplies codon counts, wobble weights, matched mRNA controls, and position-resolved ribosome or translation-efficiency readouts on the same finite rows.

\paragraph{Break condition for future promotion.}
A future positive statement would require a new finite panel whose row key is a coding-sequence window rather than a CRISPR guide.  Each row would need an $f_3$-stress residual coordinate after the amino-acid quotient, local synonymous codon counts, a bounded wobble-weight context with observed asymmetry $w_c\ne w_c^{f_3}$, matched mRNA abundance, and a same-window translation readout.  Only after a positive held-out improvement survives the declared controls may the packet state a bounded cross-layer translation-readout relation.  Until that matrix exists, the Doench2016 contact remains a CRISPR guide-efficiency contact and nothing stronger.
