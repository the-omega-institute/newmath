\paragraph{Finite code-layer object.}

The finite check reports

\begin{aligned}

The point of the construction is not to derive the genetic code from geometry.  It is to ask whether a finite window-six coordinate system isolates a stable local boundary pattern after the curated standard-code labels are supplied as an observed table.

\paragraph{Punctured-cube geometry.}
The same row is verified as a punctured-cube tile with face-vector
$$
\begin{aligned}

$$
Thus the object is not merely a list of exceptional labels; it has a finite local shape with thirteen vertices, sixteen one-dimensional incidences, and four two-dimensional faces inside the chosen codon-coordinate display.  The singleton-label corner and the three-point label class are read as local features of this finite tile, while the label names themselves remain supplied by the curated code table.  The row therefore supports a code-read statement: the tile can organize codon-to-label readback, but it does not by itself assert a biochemical process.

\paragraph{Scope boundary.}
The empirical contact is a curated standard-code table assigning codons to amino-acid or stop labels.  That contact is adequate for code-layer readback and for testing local label splits inside $Q_6$.  It is not a translation experiment, not a folding observation, not a physical-admissibility assay, not a functional assay, not a mechanism, and not a universality theorem.  Consequently, an amino-acid label sequence obtained from this table remains a label sequence.  No folded protein structure, biological function, organism-level law, or necessary biochemical realization follows from the finite row unless another independently specified contact supplies that higher-layer evidence.
