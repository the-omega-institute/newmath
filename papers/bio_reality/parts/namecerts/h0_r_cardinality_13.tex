\paragraph{Finite carrier and observed boundary set.}
The record concerns a six-bit codon display in which the standard genetic-code table is used only as a curated codon-to-label contact.  The finite carrier is the codon cube $Q_6$, and the row selected for the boundary region $R$ has cardinality $13$.  The verified membership list is
$$
\begin{aligned}
R=\{&AAA,AGA,AGG,AUA,CUA,CUC,CUG,CUU,\\
&UAA,UAG,UCA,UGA,UUA\}.
\end{aligned}
$$
Thus the finite row is not merely a size assertion: it records exactly which standard-code codons form the local boundary tile.  The same row is also recorded as a punctured-cube configuration with $f$-vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4),
\end{aligned}
$$
so the boundary data carry vertices, edges, and square faces inside the codon-cube geometry.  This is a code-layer statement about the organization of curated labels on a finite codon coordinate system.  It is not a claim that biological translation is generated by the cube, nor that this local tile is a physical or functional law.
