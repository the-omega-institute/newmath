\paragraph{Finite object.}
This record concerns the standard-code codon table at the code-read layer. The finite carrier is the six-bit codon cube $Q_6$, with one display bit-pair for each codon position after the four nucleotide letters are encoded as binary choices. The observed object is not a translation machine and not a folded protein. It is the curated assignment table that sends each codon to an amino-acid label or a stop label. Within that finite table, the distinguished local boundary row is the set
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The direct cardinality check gives $|R|=13$, and the independent row-size field also reports $13$. Thus the local tile is not a verbal summary of the code table; it is a concrete finite subset of the $64$ codon positions.

\paragraph{Local geometry.}
The same row is verified as a punctured-cube pattern with face data

\end{aligned}

Here the first coordinate is the number of selected codon vertices, the second is the number of selected local edges in the induced cubical boundary, and the third is the number of selected square faces. This is the geometric content of the claim: the window-six display exposes a small codon tile with a stable boundary shape. It does not assert that the geometry is a biological necessity. The code labels remain supplied by the curated standard-code table, and the local cubical shape is only a finite pattern in those labels.

\begin{aligned}

A second null constrained by amino-acid class preservation also used $N=2000$ and seed $42$. It found $0$ exact matches, while $7$ samples lay in the lower tail at or below the observed $M$-row size $20$. Its reported values are

\begin{aligned}

The data therefore support a finite rarity statement for the local row shape, not a mechanistic statement about how organisms realize translation.

\paragraph{Local scope.}
The validated contact is the curated standard genetic-code table as a codon-label readback. It can test code labels and local codon-tile label splits. It cannot test translation realization, folded structural order, physical admissibility, function, or a universal biological mechanism. Consequently no claim in this subsection crosses from the code table into protein structure or organismal mechanism. Such a crossing would require a separate contact carrying the relevant observation, and no such contact is part of this finite row.
