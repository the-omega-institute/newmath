\paragraph{Claim.}
The record concerns a code-layer phenomenon in the standard genetic-code table. Codons are displayed as six-bit window coordinates over the codon cube $Q_6$, and the observed object is a distinguished boundary set $R$ whose members are read against the curated standard-code label table. The finite claim is not that the geometry explains translation. It is that the six-bit display exposes a local tile boundary whose thirteen codons are exactly
$$
\begin{aligned}
R=\{&AAA,AGA,AGG,AUA,CUA,CUC,CUG,CUU,\\
&UAA,UAG,UCA,UGA,UUA\}.
\end{aligned}
$$
The verified cardinality row reports $|R|=13$ with experiment run $5d4a3459997d$. A second finite check identifies the same row set as a punctured-cube pattern with face data
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).

Thus the row is not merely a named list of codons: it is also a local cubical boundary pattern inside the window-six coordinate presentation.

\paragraph{Coordinate and label readback.}
