\paragraph{Finite carrier and observed contact.}

A codon is read as a six-bit coordinate obtained from its three nucleotide positions, and the only external contact used here is the curated standard-code table assigning each codon an amino-acid or stop label. This contact is deliberately narrow: it observes code labels, not ribosomal dynamics, molecular folding, energetic feasibility, cellular function, evolutionary optimality, or a universal biological mechanism. The finite readback therefore tests whether a local coordinate tile aligns with the standard-code labels at the code layer.
