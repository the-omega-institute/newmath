\subsection{Window-Six Codon Tile Significance}\label{sec:h0-m-shape-significance}\origin{ai}

\paragraph{Finite codon display.} The object considered here is the standard-code codon table read through a six-bit codon cube $Q_6$. Each codon is treated as a finite coordinate word, and the biological labels are not inferred from the cube itself: they enter through the curated standard genetic-code table. The relevant local object is a boundary-shaped tile inside the cube, together with the label split induced by the standard code. The verified boundary set is
$$\begin{aligned}
R = \{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}$$
Its recorded cardinality is $|R|=13$. The same finite run identifies this set as a punctured-cube boundary pattern with $f$-vector $(13,16,4)$, so the local shape contains thirteen vertices, sixteen one-dimensional adjacencies, and four two-dimensional faces in the induced tile. This is a code-layer observation: it concerns codon labels and local cube geometry, not the biochemical act of translation.

\paragraph{Monte Carlo shape test.} The primary significance run used $N=2000$ distinct sampled comparison shapes with seed $42$. Because the null sampler rejected duplicates heavily, the run made $57377$ distinct-sample attempts and encountered $55377$ duplicate retries. Among the accepted samples, there was $1$ exact shape match, giving
$$\begin{aligned}
p_{\mathrm{exact}} &= 0.0005,\\
p_{J\geq 0.9} &= 0.0125,
\end{aligned}$$
where the second value counts $25$ high-Jaccard matches at threshold $0.9$. These values support the narrow statement that the observed local shape is unusual relative to that finite null model. They do not establish a general law for codons, organisms, proteins, or evolution. A separate amino-acid-class-preserving null test sharpened the same point: with $N=2000$ and seed $42$, the observed $M$-side size was $20$, the exact-shape match count was $0$, and the lower-tail count at or below the observed size was $7$. The corresponding finite-run values were $p=0.0$ for exact shape under this sampled null and $p=0.0035$ for the lower tail. This confirms that the boundary-label configuration is not easily reproduced by that label-class-preserving randomization, while still leaving the contact restricted to curated code readback.

\paragraph{Spectral signature.} The same packet records a numerical spectrum for the local object. The values are
$$\begin{aligned}
\lambda_M &= 0.6752479308830213,\\
\lambda_R &= 0.4758352843197002,\\
\mu &= 3.051487585298128.
\end{aligned}$$
The radial cubic residual is $-6.224354365258478\times 10^{-12}$, the same value recorded for the cubic-polynomial check, and the spectral-radius value in tolerance is $0.6752479308830213$. These numbers give an internal numerical fingerprint for the boundary tile. They are useful for distinguishing this finite coordinate pattern from nearby random or relabeled patterns, but they are not structural biology evidence. In particular, an amino-acid label sequence read from codons is not a folded protein, a physical conformation, an admissibility certificate, or a functional assay.

\paragraph{Leave-one-code and leave-one-codon checks.} The leave-one-code-out run evaluated $23$ genetic-code tables and $63$ total targets. Its baseline hit rate was $0.19821739130434785$, while the hit rate above baseline was $0.9841269841269841$. The rate inside $M-T$ was $0.9365079365079365$, and the rate inside $M-T$ together with the boundary was $0.9841269841269841$. Broken down by family, the hit rates above baseline were $1.0$ for bacterial/plastid, $1.0$ for mitochondrial, $1.0$ for nuclear ciliate, $1.0$ for candidate other, and $0.8333333333333334$ for alternative yeast. The leave-one-codon-out run recorded $0$ anchors, $5$ boundary cases, $8$ high-coverage closure cases, $8$ predictable cases, and recovery rate $1.0$. These finite checks say that the local coordinate pattern has predictive behavior under code-table and codon deletion probes. They still remain at the label-table layer.

\paragraph{Module accounting.} The module classification accounts for all thirteen codons in $R$. The recorded module map is
$$\begin{aligned}
\mathrm{agr} &= \{\mathrm{AGA},\mathrm{AGG}\},\\
\mathrm{ar\_lys} &= \{\mathrm{AAA}\},\\
\mathrm{cun} &= \{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\},\\
\mathrm{ile\_met} &= \{\mathrm{AUA}\},\\
\mathrm{ssn} &= \{\mathrm{UCA},\mathrm{UUA}\},\\
\mathrm{stop\_trp} &= \{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}.
\end{aligned}$$
The classification reports $R$-size $13$, assigned count $13$, no missing module codons, no extra module codons, and no unassigned codons. Thus the local boundary is not merely a set-size anomaly: it has a complete finite partition by biologically named codon modules after the standard-code labels are supplied. The contact, however, supplies only codon-to-label assignments. It does not observe ribosomes, tRNA availability, organism-specific translational dynamics, protein folding, thermodynamic stability, phenotype, or function.

\paragraph{Local verdict.} The finite evidence supports the following bounded conclusion. In the standard-code table, the six-bit codon-coordinate display exposes a thirteen-codon boundary tile with a punctured-cube face profile, a stable numerical spectrum, low exact-match probability under sampled null models, and strong leave-one-out recovery behavior across the recorded code and codon probes. The result is therefore ready as a code-read claim about local codon geometry and label split. No claim follows here about translation realization, folded structure, physical admissibility, biological function, mechanism, or universality. Any statement crossing one of those boundaries must be supported by an additional contact that directly measures the higher layer.
