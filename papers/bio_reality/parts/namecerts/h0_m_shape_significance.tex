\subsection{Window-six local codon shape significance}
\label{sec:biorality-h0-m-shape-significance}

\paragraph{Finite carrier and code-layer contact.}
The packet records a finite window-six representation of the standard-code codon table. The carrier is the codon cube $Q_6$: each codon is read as a six-bit coordinate, with the standard-code label table supplying the only biological contact used here. The internal distinctions are coordinate position, closure membership, spectral response, and codon-label relation. The biological assertion is therefore deliberately narrow: the computation tests whether a local codon tile and its boundary pattern are unusually arranged relative to code labels. It does not test translation in a cell, folded structure, physical admissibility, biological function, molecular mechanism, or universality across biology.

The distinguished boundary row $R$ has cardinality $13$. In the verified run it is exactly

The same row is recorded as a punctured-cube face pattern with $f$-vector

This is the local object under discussion: a finite row of codons inside the window-six cube together with its tile incidence data. The statement does not promote this local tile to a global law of DNA or protein realization.

\paragraph{Shape-significance experiment.}
The main shape test used seed $42$ and sampled $N=2000$ distinct null rows. Producing those distinct rows required $57377$ sample attempts, including $55377$ duplicate retries. The exact observed shape appeared once among the $2000$ rows, giving
$$\begin{aligned}
\#\{\text{exact matches}\}=1,\qquad p_{\mathrm{exact}}=0.0005.
\end{aligned}$$
A relaxed comparison using Jaccard threshold at least $0.9$ produced $25$ matches, hence
$$\begin{aligned}
\#\{J\geq 0.9\}=25,\qquad p_{J\geq 0.9}=0.0125.
\end{aligned}$$
The finite-row reading is that the observed local tile is rare under this sampling design. The conclusion remains a code-layer shape claim: the curated table supplies amino-acid and stop labels, while the window-six geometry supplies coordinates and local incidence.

\paragraph{Amino-acid-class preserving null comparison.}
A second null row preserves amino-acid class information. In that check the observed $M$-row size is $20$. Over $N=2000$ sampled rows, the exact shape count is $0$, so the recorded exact-shape tail is
$$\begin{aligned}
p_{\mathrm{aa\ class, exact}}=0.0.
\end{aligned}$$
The lower-tail count for rows with size at most the observed $M$ size is $7$, giving
$$\begin{aligned}
p_{\mathrm{aa\ class, lower\ tail}}=0.0035.
\end{aligned}$$
This supports the same local reading from a stricter control: the signal is not only a generic consequence of preserving amino-acid-class counts in the sampled table. It still does not identify a biochemical cause.

\paragraph{Local verdict and limitation.}
The verified rows support a ready code-layer claim. The standard-code labels, placed on $Q_6$, produce a local boundary tile with $|R|=13$, punctured-cube incidence $(13,16,4)$, rare exact shape occurrence $p=0.0005$, rare high-Jaccard occurrence $p=0.0125$, and an amino-acid-class preserving lower-tail value $0.0035$. The leave-one and module checks make the row robust as a finite codon-label phenomenon. The admissible conclusion is therefore: window-six codon coordinates expose a significant local boundary-tile pattern in the curated standard-code table. Nothing in this chapter licenses claims about actual translation dynamics, folded protein structure, physical realizability, biological function, causal mechanism, or universal biological necessity without an additional contact designed for that higher layer.
