\subsection{Window-Six Local Tile Significance in the Standard Code}\label{sec:h0-m-shape-significance}
\origin{ai}

\paragraph{Claim and finite setting.}
This record treats the standard-code codon table as a code-layer object, not as a claim about the molecular execution of translation.  The carrier is the six-coordinate codon cube $Q_6$, where each codon occupies a six-bit display position and the curated standard-code table supplies the amino-acid or stop label attached to that position.  The tested object is a local tile pattern whose readout uses the table only as a label assignment.  The relevant distinctions are the six-bit codon display, a local tile face, singleton label corners, and three-point label classes.  The internal bookkeeping uses coordinate, closure, spectrum, and relation data, while the biological contact is the standard-code label table itself.

\paragraph{Observed relation row.}
The distinguished relation row $R$ has cardinality $13$.  The verified row is
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\

Thus the evidence is not merely a count: the codons assemble into a finite local shape with thirteen vertices, sixteen edges, and four two-dimensional faces in the tested window-six geometry.

\paragraph{Shape significance.}
The principal finite-row significance test used seed $42$ and drew $N=2000$ distinct sampled objects.  Because duplicate samples were rejected, the run made $57377$ distinct-sample attempts and recorded $55377$ duplicate retries.  Exactly one sampled object matched the observed shape, giving
$$
\begin{aligned}
p_{\mathrm{exact}}=\frac{1}{2000}=0.0005.
\end{aligned}
$$
The high-overlap test counted $25$ samples with Jaccard score at least $0.9$, giving
$$
\begin{aligned}
p_{J\geq 0.9}=\frac{25}{2000}=0.0125.
\end{aligned}
$$
The run stores both values as significant: $p\_value\_exact\_shape\_significant=0.0005$ and $p\_value\_high\_jaccard\_significant=0.0125$.  This supports the claim that the observed local tile is statistically unusual under the sampled finite null, while still keeping the conclusion at the code-read layer.

\paragraph{Amino-acid-class preserving null.}
A second null preserves amino-acid class information.  In that test the observed $M$ size is $20$.  With $N=2000$ and seed $42$, the exact-shape count is $0$, so the exact-shape empirical value is $0.0$.  The lower-tail count at or below the observed $M$ size is $7$, giving
$$
\begin{aligned}
p_{\mathrm{lower\ tail}}=\frac{7}{2000}=0.0035.
\end{aligned}
$$
The stored significance entries are $p\_value\_aa\_class\_exact\_shape\_significant=0.0$ and $p\_value\_aa\_class\_lower\_tail\_significant=0.0035$.  This test is stricter than a label-blind shuffle, since it keeps part of the biochemical label organization fixed while asking whether the same local shape still appears frequently.

\paragraph{Interpretation.}
The finite evidence supports a narrow statement: in the standard-code label table, window-six codon coordinates expose a local boundary-tile pattern that is rare under the recorded null experiments and coherent under the recorded leave-one probes.  The contact is the curated codon-to-label table, so the confirmed readout is an amino-acid or stop-label readout.  The data do not by themselves assert that DNA must obey this geometry, that the cell implements the tile as a mechanism, or that the pattern explains translation.

\paragraph{Local limits.}
No conclusion about translation realization, folded protein structure, physical admissibility, biological function, mechanism, or universality follows from this row.  Amino-acid label-sequence readback remains a code-layer observation.  Any claim about folding or function would require a separate structure or function contact, and any claim about translation dynamics would require a separate molecular-realization contact.  Within the present record, the measured object is a statistically unusual local codon-label tile in $Q_6$, not a global biological law.
