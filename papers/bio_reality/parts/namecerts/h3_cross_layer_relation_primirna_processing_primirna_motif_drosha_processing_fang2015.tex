\subsection{Fang-style pri-miRNA motif anchoring as a bounded processing readout}
\label{subsec:bioreality-primirna-motif-drosha-processing-fang2015}

\paragraph{Finite row object.}
This record concerns a finite table of pri-miRNA sequence rows in which local motif windows are attached to fixed scaffold landmarks before any processing readout is interpreted. The row key is not a free RNA-structure model and not a de novo folding call. It is a landmarked sequence object: the mature $5p$ and $3p$ arms are first matched exactly within each fixed scaffold, the basal flank is then placed at the $5p$ Drosha end, the downstream basal flank is placed after the $3p$ Drosha end, and the apical loop is placed between the mature arms. The verified run reports that the wild-type consensus was obtained from input-count-weighted bases, so the row construction is tied to the observed input pool rather than to a hand-selected consensus string. The run id is $9cfc036ef9a5$, and the finite computation completed in $409.285$ seconds.

\paragraph{Coordinate carried by the chapter.}
The chapter-specific coordinate is the anchored pri-miRNA motif position relative to Drosha-processing landmarks. In the finite row table, the coordinate can be written schematically as
$$
\begin{aligned}
  x_r = (s_r, b^{5p}_r, b^{3p}_r, a_r, y_r, z_r),
\end{aligned}
$$
where $s_r$ is the scaffold-resolved sequence row, $b^{5p}_r$ is the basal-flank coordinate at the $5p$ Drosha end, $b^{3p}_r$ is the downstream basal coordinate after the $3p$ Drosha end, $a_r$ is the apical-loop coordinate between mature arms, $y_r$ is the processing readout available for the row, and $z_r$ denotes local controls such as GC content, position class, scaffold identity, and abundance-derived input information. The computation explicitly avoided de novo RNA-structure inference, so the coordinate should be read as a sequence-landmark processing coordinate, not as a thermodynamic or folded-state coordinate.

\paragraph{Observed finite scalar.}
The primary scalar reported for this chapter is the main GC association, $r=-0.0479934$. This value is small in magnitude and negative. Its role is therefore not to certify a large GC-driven biological law, but to mark that a GC-only reading is weak for this finite processing table. In a bounded processing interpretation, this is useful because it prevents the motif-landmark record from being collapsed into a generic GC-composition story. The relevant local statement is that the anchored motif rows survive as a processing-boundary object only if their landmarked motif information is evaluated against the Drosha-processing readout after composition and scaffold-position controls, not merely by reporting GC content.

\paragraph{Local survival statistic.}
For this chapter the admissible survival quantity is a controlled improvement in pri-miRNA processing prediction from landmarked motif coordinates. A compact form is
$$
\begin{aligned}
  S_{\mathrm{Drosha}}(M\mid Z)
    &= Q(Y, Z) - Q(Y, Z, M),
\end{aligned}
$$
where $M$ denotes the anchored motif-window coordinate, $Z$ denotes the finite control set, $Y$ is the processing readout, and $Q$ is any fixed held-out loss or description-length score chosen before model comparison. Positive survival means that the motif coordinate reduces held-out error after the controls are already present. The verified GC value $r=-0.0479934$ is not itself this survival statistic; it is a reported finite scalar that helps delimit the composition background against which the motif coordinate must be tested.

\paragraph{Why the row construction matters.}
The anchoring note is the central evidence item. Exact matching of mature $5p$ and $3p$ sequences in fixed scaffolds prevents the row key from drifting across incompatible sequence contexts. Placing the basal and apical windows relative to Drosha landmarks gives the statistic a processing interpretation: the row asks whether sequence features at biologically named pri-miRNA positions help read back processing behavior. Because no de novo RNA-structure inference was used, the statistic cannot be reinterpreted as a claim about hairpin folding energy, folded-state admissibility, or a general physical mechanism. It remains a finite, landmarked sequence-to-processing test.

\paragraph{Control boundary.}
The chapter permits a local processing claim only at the level of the attached finite rows. It may say that a scaffold-anchored motif coordinate is eligible for a Drosha-processing survival test. It may also report the run metadata and the weak main GC association. It may not say that the motif coordinate establishes translation, ribosome occupancy, protein abundance, protein folding, physical admissibility, molecular function, phenotype, mechanism, or universality. Those would require separate measured contacts at their own layers. In particular, a pri-miRNA processing row does not become a translation row merely because other records in the same audit universe mention ribosome occupancy, translation efficiency, or codon-based residual coordinates.

\paragraph{Separation from other layer records.}
The finite audit also contains a transcription-elongation axis-modulation run with $11668$ windows, $1000$ permutations, $p=0.001$, held-out $R^2=0.3438$ for the control baseline, $R^2=0.3652$ after adding sequence, and incremental held-out values $0.0214$ for the positive readout and $0.0393$ for the negative-specificity readout. Those numbers show how a different finite layer can carry row counts, permutation counts, and held-out improvements. They are not imported into this pri-miRNA chapter as evidence for Drosha processing. Their role here is only methodological: they illustrate that finite-row support must stay attached to the row family that generated it. The Fang-style pri-miRNA record keeps its own support surface: run $9cfc036ef9a5$, runtime $409.285$ seconds, exact mature-arm scaffold matching, landmarked basal and apical windows, no de novo structure inference, and $r=-0.0479934$ for the main GC association.

\paragraph{Admissible conclusion.}
The ready conclusion is narrow. The finite evidence supports writing a BioReality chapter for a pri-miRNA motif-processing boundary in which landmarked motif windows are tested against Drosha-processing behavior under local controls. The strongest local content is the scaffold-anchored construction itself: input-count-weighted wild-type consensus, exact mature-arm matching, basal and apical landmark placement, and an explicit refusal to use inferred structure as the row source. The numerical evidence supplied here is sufficient for a bounded chapter record, but not sufficient for a broad mechanistic, structural, functional, translational, or universal biological claim.
