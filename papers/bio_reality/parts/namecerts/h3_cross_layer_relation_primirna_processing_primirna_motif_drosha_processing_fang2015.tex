\subsection{Pri-miRNA motif anchoring and the Drosha-processing boundary}
\label{sec:bioreality-primirna-motif-drosha-processing-fang2015}

\paragraph{Finite row.}
This record concerns the row with claim identifier
$\mathrm{h3.cross\_layer\_relation.primirna\_processing.primirna\_motif\_drosha\_processing\_fang2015}$.
The biological object is not a coding-sequence translation statistic.  It is a pri-miRNA processing surface in which sequence motifs are aligned to fixed scaffold landmarks and then tested against a Drosha-processing readout.  The verified run identifier is $\mathrm{9cfc036ef9a5}$, and the finite audit reports a runtime of $409.285$ seconds.  The recorded main GC association is
$$
\begin{aligned}
  r_{\mathrm{GC,main}} &= -0.0479934 .
\end{aligned}
$$
This scalar is small in magnitude and negative.  In this chapter it is treated only as a finite control diagnostic for the pri-miRNA row, not as a mechanism by which GC content explains Drosha processing.

\paragraph{Anchored construction.}
The row is scaffold-anchored rather than structure-inferred.  The wild-type consensus was obtained from input-count-weighted bases.  Mature $5p$ and $3p$ sequences were matched exactly inside each fixed scaffold.  Motif windows were then placed relative to three processing landmarks: the basal flank at the $5p$ Drosha end, the downstream basal flank after the $3p$ Drosha end, and the apical loop between the mature arms.  No de-novo RNA-structure inference entered this finite construction.  Thus the carrier for the row is a table of scaffold-indexed pri-miRNA sequence windows, landmark labels, local motif coordinates, count-derived consensus bases, and a Drosha-processing response.

\paragraph{Mathematical form.}
Let $W$ be the finite set of anchored motif windows in the Fang-style scaffold panel, and let $Y_w$ denote the Drosha-processing readout attached to window $w \in W$.  Let $G_w$ be the local GC diagnostic and let $A_w$ encode the scaffold landmark class: basal $5p$ flank, downstream basal $3p$ flank, or apical loop.  The row supports only a bounded relation of the form
$$
\begin{aligned}
  (w, A_w, G_w, Y_w) \in \mathcal{T}_{\mathrm{Drosha}} .
\end{aligned}
$$
The verified scalar $r_{\mathrm{GC,main}}=-0.0479934$ belongs to this finite table as a control-level association.  It does not license a general statement that GC content determines processing, and it does not provide a structural folding readout.  The correct reading is narrower: within this anchored scaffold panel, the motif-coordinate table has a measured processing surface, and the GC diagnostic did not dominate the finite row.

\paragraph{Relation to translation rows.}
The supplied audit bundle also contains a separate translation-initiation row,
$\mathrm{h3.cross\_layer\_relation.translation\_initiation.utr5\_features\_ribosome\_load\_sample2019}$, with $n=80000$, runtime $172.864$ seconds, and $\mathrm{cross\_sample}=\mathrm{null}$.  That row is useful here only as a boundary comparison: it records a ribosome-load setting, whereas the present Fang row records pri-miRNA processing.  The existence of the translation-initiation row does not convert the pri-miRNA motif surface into translation evidence.  Conversely, the Drosha-processing run does not supply ribosome occupancy, translation efficiency, protein abundance, or any protein-layer measurement.

\paragraph{Allowed claim.}
The allowed claim is a finite cross-layer processing statement: scaffold-anchored pri-miRNA motif windows can be joined to a Drosha-processing readout, with landmark placement fixed by mature-arm matches and with the observed GC diagnostic $r_{\mathrm{GC,main}}=-0.0479934$ carried as a control-level scalar.  The row is therefore admissible as evidence for a bounded sequence-to-processing relation in a fixed pri-miRNA scaffold system.  Its content is not a free-standing law of RNA processing; it is a finite anchored table with a measured processing endpoint and a documented construction path.

\paragraph{Local refusal boundary.}
No translation claim follows from this row.  In particular, the row does not provide position-resolved ribosome occupancy, translation efficiency, modeled or measured codon-adaptation survival, protein abundance, folded protein structure, physical admissibility, biological function, organismal phenotype, mechanism, or universality.  Such claims would require separate rows at those layers, with their own matched readouts and controls.  The pri-miRNA scaffold record also does not use the proposed $f_3$-stress coding-window statistic: no same-CDS codon-window table, wobble-weight surface, matched mRNA control, or position-resolved ribosome-footprint matrix is present in this Fang processing row.

\paragraph{Verdict.}
The finite evidence is ready for a BioReality chapter at the pri-miRNA-processing level.  The supported object is the anchored motif--Drosha-processing relation, not any downstream translation or protein-layer effect.  The strongest local statement is that the run $\mathrm{9cfc036ef9a5}$ supplies a concrete, scaffold-aligned processing surface with runtime $409.285$ seconds and a recorded GC diagnostic of $-0.0479934$, under an anchoring procedure that fixes mature-arm matches and avoids de-novo structure inference.
