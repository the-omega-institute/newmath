\subsection{Finite scaffold anchoring for pri-miRNA processing motifs}
\label{sec:bioreality-primirna-motif-drosha-processing-fang2015}

\paragraph{Claim surface.}
The finite record for \texttt{h3.cross\_layer\_relation.primirna\_processing.primirna\_motif\_drosha\_processing\_fang2015} is a bounded claim about pri-miRNA processing geometry, not a claim about coding-sequence translation.  The row table is interpreted as a scaffold-indexed sequence assay in which mature-arm landmarks determine the local windows used for motif evaluation.  The verified run reports that the wild-type consensus was obtained from input-count-weighted bases; mature $5p$ and $3p$ sequences were matched exactly in each fixed scaffold; and the windows were then anchored to three named scaffold landmarks: the basal flank at the $5p$ Drosha end, the downstream basal flank after the $3p$ Drosha end, and the apical loop between the mature arms.  No de-novo RNA-structure inference was used in this anchoring step.  Thus the carrier is a finite landmarked pri-miRNA table with observed sequence windows and processing-oriented motif coordinates, rather than a free structural model of the hairpin.

\paragraph{Finite numerical content.}
The Fang2015 processing run \texttt{9cfc036ef9a5} records a main GC association of $r=-0.0479934$ and a runtime of $409.285$ seconds.  The sign and magnitude are treated only as a weak scalar diagnostic for the finite window table; they are not used as evidence for a general GC law.  The anchored scaffold construction is the operative datum: each motif row must inherit its position from the exact mature-arm match and the declared basal or apical landmark.  For comparison of scale only, the separate random-promoter expression run \texttt{8d1d1ac78ab7} used $n_{\mathrm{designed}}=75111$, $n_{\mathrm{hq}}=8027$, an analysis subset of $2500$ high-quality rows, $200$ permutations, seed $20260239$, and runtime $530.4038379192352$ seconds.  That promoter table is not imported as evidence for miRNA processing; it only shows that this BioReality ledger keeps each finite assay surface keyed to its own row construction, endpoint, and controls.

\paragraph{Local statistic.}
Let $W$ be the finite set of anchored pri-miRNA windows after exact mature-arm matching.  A row $w\in W$ carries a scaffold identifier, a landmark class $\ell(w)$, a local sequence context, and a processing readout from the Fang-style assay.  The admissible local summary has the form
$$
\begin{aligned}
S_{\mathrm{Drosha}}(w\mid Z) &= \Delta\mathcal{L}\bigl(\mathrm{readout}(w);\, \mathrm{motif}(w), Z(w)\bigr),\\
Z(w) &= \{\mathrm{GC},\ \mathrm{scaffold},\ \mathrm{landmark},\ \mathrm{arm\ identity},\ \mathrm{input\ count\ weight}\}.
\end{aligned}
$$
Here $S_{\mathrm{Drosha}}$ denotes only a controlled finite-row processing statistic.  The verified scalar $r=-0.0479934$ is compatible with this framing because it is reported as a single GC-main diagnostic, while the scientific object of the chapter is the landmarked motif table.  A positive processing claim would require the motif term to improve held-out or permutation-calibrated prediction after the scaffold and composition controls are present in the same rows.

\paragraph{Interpretation discipline.}
This chapter does not identify a translation coordinate, a ribosome-occupancy coordinate, or a protein-output coordinate.  The contact is pri-miRNA processing through fixed sequence landmarks.  The exact-match mature-arm rule prevents the motif windows from floating across incompatible hairpin coordinates, and the absence of de-novo structure inference keeps the finite carrier tied to observed scaffold sequence rather than inferred folding geometry.  Consequently, the valid conclusion is narrow: the run supplies an anchored finite surface on which basal-flank, downstream-basal, and apical-loop motif effects can be tested against Drosha-oriented processing readouts.

\paragraph{Cannot-claim boundary.}
No translation realization follows from this pri-miRNA processing record.  No protein abundance, protein folding, physical admissibility, molecular function, cellular mechanism, phenotype, or universal biological law follows from the anchored motif table or from the reported GC diagnostic.  Such claims would require separate finite contacts at the relevant layer, with matched rows and their own controls.  In particular, a coding-sequence wobble-weight surface, a ribosome-footprint matrix, a translation-efficiency denominator, or a protein-level endpoint cannot be inferred from the Fang2015 scaffold anchoring note.  The record is therefore ready only as a self-contained finite processing chapter: exact mature-arm matching fixes the window coordinates; the three scaffold landmarks define the motif sites; $r=-0.0479934$ is a local GC-main diagnostic; and any larger biological interpretation remains outside the claim unless separately measured.
