\subsection{Pri-miRNA motif anchoring as a bounded processing readout}
\label{sec:bioreality-primirna-motif-drosha-processing-fang2015}
\origin{ai}

\paragraph{Finite row object.}
This record isolates the Fang-style pri-miRNA processing surface as a finite table of sequence-scaffold rows, motif-window coordinates, and Drosha-processing readouts.  The verified run attached to this chapter is \texttt{9cfc036ef9a5}.  Its finite audit reports runtime $409.285$ seconds and a main GC association $r_{\mathrm{GC}}=-0.0479934$.  The row construction is not a free RNA-structure search: the wild-type consensus is obtained from input-count-weighted bases, mature $5p$ and $3p$ sequences are matched exactly inside each fixed scaffold, and motif windows are then placed relative to scaffold landmarks.  The basal flank is anchored at the $5p$ Drosha end, the downstream basal flank is anchored after the $3p$ Drosha end, and the apical-loop window is anchored between the mature arms.  Thus the mathematical carrier for this chapter is a finite scaffold-indexed table with columns for landmark identity, local motif coordinates, input-weighted consensus bases, processing readout, and nuisance controls such as GC content.

\paragraph{Local statistic.}
Let $x$ range over scaffold-window rows.  Write $Y(x)$ for the processing readout, $M_{\ell}(x)$ for the motif coordinates in landmark class $\ell$, and $Z(x)$ for the attached control vector, including the GC component whose main finite-run association is $-0.0479934$.  The chapter-level claim is only that the landmarked motif coordinates are admissible as a controlled pri-miRNA-processing readout surface.  In symbolic form the admissible statistic has the shape
$$
\begin{aligned}
S_{\mathrm{Drosha}}(\ell)
  &= \operatorname{Score}\bigl(Y; M_{\ell} \mid Z,\mathrm{scaffold}\bigr),\\
\ell
  &\in \{\mathrm{basal\ at\ }5p\mathrm{\ Drosha\ end},\mathrm{downstream\ basal\ after\ }3p\mathrm{\ end},\mathrm{apical\ loop}\}.
\end{aligned}
$$
The point of the anchoring rule is that $M_{\ell}$ is read from fixed mature-arm landmarks before the statistic is computed.  The record therefore concerns processing grammar in a defined pri-miRNA scaffold, not a de novo structural fold, not a global RNA law, and not a translation-layer measurement.

\paragraph{Reality contact.}
The observed finite contact is a pri-miRNA motif-processing table: the rows are sequence-scaffold rows with matched mature-arm landmarks and measured processing behavior.  The run makes a bounded contact with biological reality because the motif windows are tied to experimentally meaningful Drosha landmarks rather than to an abstract coordinate invented after model fitting.  The GC scalar $r_{\mathrm{GC}}=-0.0479934$ is included as a local covariate diagnostic; its small negative value does not by itself establish a motif mechanism, but it records that the run carried a concrete composition check rather than leaving composition outside the finite table.

\paragraph{Comparison surface.}
A separate finite-row record in the same evidence ledger, \texttt{8d1d1ac78ab7}, gives a useful scale check for high-throughput regulatory tables: the random-promoter expression boundary used $75111$ designed sequences, $8027$ high-quality rows, an analysis subsample of $2500$ high-quality rows, seed $20260239$, $200$ actual permutations, and runtime $530.4038379192352$ seconds.  This comparison is not imported as evidence for Drosha processing.  It is used only to mark the difference between two finite regulatory contacts: promoter-expression rows test cis-regulatory expression grammar, whereas the Fang-style table here tests motif placement relative to pri-miRNA processing landmarks.  No survival or mechanism can be transferred between those tables merely because both are finite sequence-to-readout surfaces.

\paragraph{Admissible conclusion.}
The chapter may state the following bounded conclusion.  A pri-miRNA motif coordinate can be evaluated as a controlled Drosha-processing coordinate when each row carries fixed scaffold landmarks, exact mature-arm matching, landmark-anchored motif windows, a measured processing readout, and composition controls.  The verified run supplies the concrete anchor note, the GC scalar $-0.0479934$, and the runtime $409.285$ seconds for that finite construction.  The result is a processing-readout boundary, not a general principle about RNA structure or expression.

\paragraph{Non-promotion boundary.}
Nothing in this record supplies translation, ribosome occupancy, protein abundance, folding, physical admissibility, molecular function, phenotype, mechanism, or universality.  A same-row pri-miRNA processing statistic does not become a translation statistic, and a landmarked motif window does not become a structure or function certificate.  Any downstream claim at another layer would need its own layer-matched table and its own controlled statistic.  In particular, modeled codon-adaptation weights, ribosome-footprint contacts, protein-abundance contacts, or residual codon-window geometry are not consequences of the Fang-style pri-miRNA motif table.  They would have to be attached as separate rows with their own controls before any cross-layer statement could be made.
