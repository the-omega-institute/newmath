\subsection{Fang-style pri-miRNA landmark anchoring as a bounded processing-readout record}
\label{subsec:bioreality-primirna-motif-drosha-processing-fang2015}

\paragraph{Finite row object.}
This record concerns a pri-miRNA processing panel in which sequence windows are not treated as free RNA strings.  The finite carrier is a table of scaffold-indexed rows: each row carries an input-count-weighted wild-type consensus, exact mature-arm matches for the $5p$ and $3p$ products inside the fixed scaffold, and motif windows anchored to Drosha-related landmarks.  The verified run for this record is \texttt{9cfc036ef9a5}; it completed in $409.285$ seconds and reported a GC main-effect correlation of $-0.0479934$.  The important biological normalization is local rather than global: the basal flank is placed at the $5p$ Drosha end, the downstream basal flank is placed after the $3p$ Drosha end, and the apical-loop window is placed between the mature arms.  No de-novo RNA-structure inference is part of this certificate, so the row object is a landmark-anchored motif-processing table rather than a folded-RNA model.

\paragraph{Processing coordinate.}
For a scaffold row $r$, write $A_{5p}(r)$ and $A_{3p}(r)$ for the exact mature-arm anchors, and write $B_5(r)$, $B_3(r)$, and $L(r)$ for the basal-left, basal-right, and loop windows induced by those anchors.  The chapter-level statistic is a bounded processing association, not a mechanistic model of Drosha cleavage:
$$
\begin{aligned}
P_{\mathrm{Drosha}}(r)
  &= \Phi\bigl(B_5(r), B_3(r), L(r), C_{\mathrm{WT}}(r), Z(r)\bigr),\\
Z(r)
  &= \{\text{scaffold identity, mature-arm placement, input-count weighting, GC context}\}.
\end{aligned}
$$
Here $C_{\mathrm{WT}}(r)$ denotes the wild-type consensus derived from input-count-weighted bases.  The scalar $-0.0479934$ is therefore read as a run-level GC diagnostic attached to the finite processing table; it is not a claim that GC content explains pri-miRNA processing, nor that the motif coordinate has been reduced to a single nucleotide-composition effect.

\paragraph{Evidence boundary.}
The positive content of the Fang-style row is narrow but concrete.  The run verifies that the processing coordinate can be built from fixed-scaffold, mature-arm-exact, landmark-anchored windows and audited against a GC diagnostic.  This supports a bounded cross-layer relation between local pri-miRNA motif placement and a Drosha-processing readout only at the level of the declared finite table.  It does not supply a translation readout, ribosome occupancy, protein abundance, protein folding, physical admissibility, downstream function, organismal phenotype, molecular mechanism, or universal biological rule.  Those stronger interpretations require separate rows at the appropriate biological layer.

\paragraph{Adjacent calibration rows.}
The same finite ledger contains independent benchmark rows showing that this chapter is not relying on a generic claim of sequence-to-function transfer.  The random-promoter expression boundary row \texttt{8d1d1ac78ab7} reports $75111$ designed promoter sequences, $8027$ high-quality rows, an analysis subsample of $2500$ rows, $200$ permutations, seed $20260239$, and runtime $530.4038379192352$ seconds.  The G418 stop-context readthrough row \texttt{fe18fff6841f} reports an inner-joined nonzero-RRTS subset with $7658$ joined rows before filtering, $4982$ retained nonzero rows, nonzero fraction $0.65056$, and runtime $303.534$ seconds.  These rows are not imported as evidence for pri-miRNA processing; they serve as finite-row comparators showing that separate biological contacts remain separate.  Promoter expression, stop-context readthrough, and Drosha processing have distinct row keys, readouts, and admissible controls.

\paragraph{Local refusal rule.}
The chapter permits the following statement and no stronger one: a fixed-scaffold pri-miRNA table can carry a Drosha-landmark motif coordinate whose construction is externally checkable from exact mature-arm placement and input-weighted consensus sequence, with the verified run recording $gc\_main\_r=-0.0479934$.  The chapter refuses to infer translation, folding, physical admissibility, function, mechanism, or universality from that coordinate.  It also refuses to treat the absence of de-novo structure inference as evidence against RNA structure; it only says that this particular finite record did not use such inference.  A later structure, mechanism, function, or phenotype claim would need its own matched contact, row joins, controls, and scalar survival statistic.
