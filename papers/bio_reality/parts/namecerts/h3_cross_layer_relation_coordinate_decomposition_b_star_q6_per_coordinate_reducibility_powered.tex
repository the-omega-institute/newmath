\subsection{Coordinate-Level Reducibility of the $B^{\ast}_{Q6}$ Abundance Residual}\label{subsec:b-star-q6-coordinate-decomposition}\origin{ai}

\paragraph{Finite object.}
This record isolates the nine-dimensional $B^{\ast}_{Q6}$ synonymous residual packet one coordinate at a time and asks whether the protein-abundance component assigned to each coordinate can be reconstructed from a fixed measured-readout dictionary after the same covariates have been removed.  The computation is organism-specific: the realized row set is \textit{Saccharomyces cerevisiae}, with $n=1258$ joined proteins inside a source table whose base size is $1800$.  The covariate basis has rank $24$, and the measured-readout dictionary has residual rank $3$.  The nine coordinates tested are
$$
\begin{aligned}
&\texttt{K\_AAA},\ \texttt{Arg\_AGR},\ \texttt{Ile\_AUA},\ \texttt{Leu\_CUN\_vs\_UUR},\ \texttt{Leu\_UUA\_vs\_UUG},\\
&\texttt{Ser\_UCR\_vs\_AGY},\ \texttt{Ser\_UCA\_vs\_UCG},\ \texttt{Thr\_ACR\_vs\_ACY},\ \texttt{f3\_stress}.
\end{aligned}
$$
The target is log$_{10}$ protein abundance after residualization against the sibling control set, and the source design uses the same $Z$-residualized $B^{\ast}_{Q6}$ coordinate system throughout.

\paragraph{Statistic.}
For each coordinate $x_i$, the target component assigned to that coordinate is the orthogonal projection $P_i=\operatorname{Proj}_{x_i}(Y_Z)$, where $Y_Z$ is the abundance readout after the control projection has been removed.  The tested quantity is the held-out coverage of $P_i$ by the fixed residualized measured-readout dictionary $D_Z$.  In finite-row form, the reported score is a five-fold held-out $R^2$ for each single-coordinate projection, compared with a deterministic target-label permutation null using the same folds and the same design matrix.  The run used $5$ folds, $120$ permutations, and a minimum-protein gate of $500$ per organism.  The permutation seed was \texttt{sha256:b\_star\_q6\_coordinate\_decomposition\_powered:deterministic}.  The decomposition table contains exactly $9$ coordinate rows, matching the coordinate list above.

\paragraph{Positive coordinate source call.}
The finite table reports real-source support for eight of the nine coordinates:
$$
\begin{aligned}
\{&\texttt{K\_AAA},\ \texttt{Arg\_AGR},\ \texttt{Ile\_AUA},\ \texttt{Leu\_CUN\_vs\_UUR},\ \texttt{Leu\_UUA\_vs\_UUG},\\
&\texttt{Ser\_UCR\_vs\_AGY},\ \texttt{Thr\_ACR\_vs\_ACY},\ \texttt{f3\_stress}\}.
\end{aligned}
$$
The coordinate \texttt{Ser\_UCA\_vs\_UCG} is still listed in the nine-row decomposition, but it is not included in the reported real-source set for this run.  Thus the result is not merely a joint nine-dimensional abundance association: it gives a coordinate-resolved statement that most single-coordinate abundance components have measurable reconstruction support under held-out evaluation against a fixed dictionary.  The status of the run is \texttt{passed}, with $9$ decomposed rows and at least one coordinate crossing the held-out/permutation gate.

\paragraph{Readout boundary.}
This subsection makes a finite statistical statement about yeast protein-abundance residuals and the reducibility of single-coordinate $B^{\ast}_{Q6}$ abundance components through a measured-readout dictionary.  It does not state that the same coordinates realize translation in the ribosome, determine folding, establish physical admissibility, encode biochemical function, identify a mechanism, or define a universal biological rule. The finite-row verdict is that the coordinate-decomposition packet is realized for the yeast abundance join: $9$ coordinates were decomposed, $8$ coordinates were called as real abundance sources under five-fold held-out testing against a $120$-permutation null, and the dictionary rank after residualization was $3$.  The strongest permissible conclusion is therefore coordinate-level non-absorption of the $B^{\ast}_{Q6}$ protein-abundance residual by the declared controls and dictionary on this yeast row set.
