\subsection{Leave-One-Codon-Out Recovery at the Codon Boundary}
\label{sec:h1-leave-one-codon-out}

\paragraph{Claim and finite setting.}
This record studies the claim \texttt{h1.leave.one.codon.out} at the code-read layer of the standard genetic-code table.  The carrier is the six-coordinate codon cube: each codon is treated as a finite word over a two-bit nucleotide display, so the table can be queried by local faces, singleton corners, and three-point label classes.  The biological contact used here is deliberately narrow.  It is the curated standard-code assignment from codons to amino-acid or stop labels, and it is used only to read codon labels and to test local codon-tile splits.  The reported pattern is therefore a code-layer boundary phenomenon, not a claim about ribosomal realization, molecular folding, admissible chemistry, phenotype, mechanism, or a universal law.

\paragraph{Recovered boundary set.}
The distinguished recovery set $R$ has cardinality $13$.  The finite row gives
$$
\begin{aligned}
R = \{&\texttt{AAA},\texttt{AGA},\texttt{AGG},\texttt{AUA},\texttt{CUA},\texttt{CUC},\texttt{CUG},\\
&\texttt{CUU},\texttt{UAA},\texttt{UAG},\texttt{UCA},\texttt{UGA},\texttt{UUA}\}.
\end{aligned}
$$
The same row identifies this set as a punctured cubical object with face-vector $(13,16,4)$.  Thus the evidence is not merely that thirteen codons were selected; it is that the selected codons carry a small local cell structure inside the codon cube.  The point of the leave-one-codon test is to ask whether a hidden codon can be recovered from the surrounding local code geometry without changing the interpretation layer from label readback to biology.

\paragraph{Leave-one-codon-out result.}
For \texttt{h1.leave.one.codon.out}, the verified run reports anchor count $0$, boundary count $5$, high closure coverage $8$, predictable count $8$, and recovery rate $1.0$.  The threshold comparison is also $1.0$.  In local terms, all held-out codons classified by the test are recovered through predictable or boundary behavior, with no separate anchor codons recorded.  This supports the narrow statement that the codon table contains a finite local boundary signal in the six-coordinate representation.  It does not support replacing the curated label table by geometry; the labels remain supplied by the table contact.

The module classification covers all $13$ codons in $R$: the row has $R$-size $13$, assigned count $13$, no missing module codons, no extra module codons, and no unassigned codons.  The six modules are

Each module has either predictable or boundary status.  This is important because the recovery claim is not concentrated in a single codon family: the covered modules include arginine-family reassignment codons, CUN leucine-family codons, an isoleucine-methionine singleton, a serine/leucine pair, and stop/tryptophan codons.

\paragraph{Local boundary of interpretation.}
The conclusion is a finite code-read statement: in the six-coordinate codon display, the standard-code labels expose a recoverable local boundary tile whose held-out codon behavior is fully recovered in the recorded run.  The table contact does not observe translation taking place, does not observe a folded protein, does not establish physical admissibility, does not measure biological function, and does not prove a universal mechanism.  Any future promotion beyond codon-label readback must bring an additional contact that directly observes the higher layer being claimed.
