\subsection{Leave-One-Codon-Out Module Classification in the Standard Code}
\label{sec:h1-leave-one-codon-out-module-classification}

\paragraph{Finite codon window.}
This record treats the standard-code codon table as a finite code-layer object.  The carrier is the six-coordinate codon cube $Q_6$, read with codons as vertices and with the curated standard-code table supplying the amino-acid or stop labels.  The mathematical datum is not a mechanism for translation.  It is a finite coordinate experiment on a labeled cube: codon strings are placed in a window-six display, local faces and boundary positions are inspected, and the resulting label splits are compared with the curated code labels.

The distinguished residual set $R$ has cardinality $13$.  In codon notation the finite row is
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The same row is certified as a punctured-cube pattern with face-vector $(13,16,4)$.  Thus the object under discussion is a concrete thirteen-vertex residue inside the codon cube, not an asymptotic or population-level biological claim.

\paragraph{Spectral and sampling checks.}
The finite spectral row reports two local radii and one ambient comparison scalar:
$$
\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128.
\end{aligned}
$$
The associated radial polynomial residual is $-6.224354365258478\cdot 10^{-12}$, the same value recorded for the cubic polynomial check, so the numerical certificate is at floating-point zero for the purposes of this finite run.  Against $2000$ sampled comparators with seed $42$, the exact shape count is $1$, giving $p_{\mathrm{exact}}=0.0005$.  The high-overlap threshold $J\geq 0.9$ is reached by $25$ sampled comparators, giving $p_{J\geq 0.9}=0.0125$.  The run also records $57377$ distinct-sample attempts and $55377$ duplicate retries, which matters because the sampled universe is small enough for repeated candidates to appear frequently.

A second null comparison preserves amino-acid classes.  In that row, $2000$ trials give exact match count $0$, lower-tail count $7$, observed $M$-size $20$, exact-shape value $0.0$, and lower-tail value $0.0035$.  This supports the claim that the observed local shape is not well described by the tested amino-acid-class-preserving shuffle, while still leaving the interpretation at the code-label layer.

\paragraph{Leave-one-code and leave-one-codon behavior.}
The leave-one-code-out row evaluates $23$ code tables and $63$ targets.  Its baseline hit rate is $0.19821739130434785$.  The hit rate above that baseline is $0.9841269841269841$, the rate inside $M-T$ is $0.9365079365079365$, and the rate inside $M-T$ plus the boundary is $0.9841269841269841$.  Grouping by code family gives five families: alternative yeast has hit rate $0.8333333333333334$, while bacterial plastid, candidate other, mitochondrial, and nuclear ciliate each have hit rate $1.0$ above baseline.

The direct leave-one-codon-out row is sharper for this chapter.  It records anchor count $0$, boundary count $5$, high closure coverage $8$, predictable count $8$, and recovery rate $1.0$.  Thus every recovered target in this finite row is accounted for by the predictable-or-boundary dichotomy, with no separate anchor class used in the reported classification.

\paragraph{Module classification.}
The module row assigns all thirteen members of $R$ and reports no extra module codons, no missing codons from the modules, and no unassigned codons.  The complete classification is
$$
\begin{aligned}
\mathrm{AGR}&=\{AGA,AGG\},\\
\mathrm{AR\_Lys}&=\{AAA\},\\
\mathrm{CUN}&=\{CUA,CUC,CUG,CUU\},\\
\mathrm{Ile\_Met}&=\{AUA\},\\
\mathrm{SSN}&=\{UCA,UUA\},\\
\mathrm{Stop\_Trp}&=\{UAA,UAG,UGA\}.
\end{aligned}
$$
The accounting identity is therefore
$$
\begin{aligned}
2+1+4+1+2+3=13=|R|,
\end{aligned}
$$
with assigned count $13$, residual extra set $\varnothing$, residual missing set $\varnothing$, and residual unassigned set $\varnothing$.  The chapter claim is precisely this finite module statement: every codon in the residual set belongs to one of the six named local modules, and each module has at least one codon classified by the predictable-or-boundary criterion supplied by the leave-one-codon-out run.

\paragraph{Biological contact.}
The only biological contact used here is the curated standard genetic-code table.  It states that codons have amino-acid or stop labels in the standard code.  This contact is sufficient for code-label readback and for checking whether a codon-coordinate pattern separates label classes.  It is not an observation of ribosomal translation, protein folding, structural order, thermodynamic admissibility, biochemical function, or cross-organism necessity.

Consequently the scientific conclusion is deliberately local.  Window-six codon coordinates expose a stable thirteen-codon residue, a punctured-cube face profile $(13,16,4)$, a spectral separation with $\lambda_M=0.6752479308830213$ and $\lambda_R=0.4758352843197002$, and a complete six-module assignment.  The leave-one rows show strong finite recovery relative to the tested baselines.  They do not by themselves establish that the geometry is a biological law, that DNA must realize this geometry, that amino-acid strings fold in any particular way, or that a function follows from the codon labels.  Any such higher-layer claim would require an additional contact measuring that higher layer directly.
