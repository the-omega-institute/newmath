\subsection{Leave-One-Codon-Out Module Classification}\label{subsec:h1-leave-one-codon-out-module-classification}
\origin{ai}

\paragraph{Question.}
The object of this record is the standard-code codon table viewed only at the code-read layer.  Codons are represented as a six-coordinate cube display, while labels are supplied by a curated standard genetic-code table.  The question is whether the finite codon set selected by the window-six construction decomposes into named local modules in a way that is compatible with leave-one-codon-out recovery.  The tested claim is not that codon geometry causes translation, folding, physical admissibility, biological function, mechanism, or universality.  It is only that a finite code-table contact can be read against a local coordinate pattern and then checked for module completeness.

\paragraph{Finite carrier and selected codons.}
The verified residual set has cardinality $13$.  The codons in this set are
$$
\begin{aligned}
R=\{&\texttt{AAA},\texttt{AGA},\texttt{AGG},\texttt{AUA},\texttt{CUA},\texttt{CUC},\texttt{CUG},\texttt{CUU},\\
&\texttt{UAA},\texttt{UAG},\texttt{UCA},\texttt{UGA},\texttt{UUA}\}.
\end{aligned}
$$
The same run verifies that this set is the punctured-cube row, with face-vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}
$$
Thus the finite object used here is not an unrestricted biological universe.  It is a thirteen-codon residue inside the six-bit codon display, together with standard-code labels read from the curated table.

\paragraph{Null-model pressure.}
Against the reported randomization with $N=2000$ samples and seed $42$, the exact shape count was $1$, giving $p=0.0005$.  The high-Jaccard count at threshold $0.9$ was $25$, giving $p=0.0125$.  The sampler made $57377$ distinct-sample attempts and encountered $55377$ duplicate retries, so the finite codon universe is visibly constrained rather than large and diffuse.  A second amino-acid-class-preserving null run, also with $N=2000$ and seed $42$, had observed $M$-size $20$, exact-match count $0$, lower-tail count $7$, exact-shape $p=0.0$, and lower-tail $p=0.0035$.  These rows support the use of the coordinate residue as a non-generic local pattern, but they still do not identify a translation mechanism or a protein-level effect.

\paragraph{Leave-one rows.}
The leave-one-code-out run evaluated $23$ code tables and $63$ targets.  Its baseline hit rate was $0.19821739130434785$, while the hit rate above baseline was $0.9841269841269841$.  The hit rate inside $M-T$ was $0.9365079365079365$, and the hit rate inside $M-T$ plus boundary was $0.9841269841269841$.  The leave-one-codon-out run found $0$ anchors, $5$ boundary cases, $8$ high-closure-coverage cases, $8$ predictable cases, and recovery rate $1.0$.  In words, recovery is carried by predictable or boundary behavior, not by an independent biological assertion about translation or function.

\paragraph{Module classification.}
The module classification is complete on the thirteen-codon set.  The run reports $R\_\mathrm{size}=13$, assigned count $13$, no extra module codons, no missing codons, and no unassigned codons.  The module allocation is

\begin{aligned}

Every displayed module has at least one codon classified through predictable or boundary behavior.  Since the union of these six modules has size $13$ and the run reports no missing or unassigned codons, the finite module partition exhausts the verified residue.

\paragraph{Family row.}
The code-family summary contains $5$ families.  The hit-rate-above-baseline values are $1.0$ for bacterial-plastid, candidate-other, mitochondrial, and nuclear-ciliate families, and $0.8333333333333334$ for the alternative-yeast family.  This family row is consistent with strong local recovery across the tested table family split, while also showing that the result is empirical and finite-row based rather than a universal biological theorem.

\paragraph{Readback boundary.}
The only biological contact used here is the curated standard-code table assigning codons to amino-acid or stop labels.  That contact licenses codon-label readback and local tile checks.  It does not observe ribosomal translation, folded structure, physical admissibility, biological function, organism-level mechanism, or a universal law.  Therefore the ready claim is the following bounded statement: in the supplied finite rows, the thirteen-codon residue is completely classified into six local modules, and leave-one-codon-out recovery is accounted for by predictable or boundary cases.  Any assertion beyond code-layer label readback requires a separate contact with the relevant biological layer.
