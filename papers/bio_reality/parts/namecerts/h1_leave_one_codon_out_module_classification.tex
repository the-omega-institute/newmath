\subsection{Leave-one-codon module classification in the window-six codon cube}
\label{sec:h1-leave-one-codon-out-module-classification}

\paragraph{Scope of the claim.}
This record concerns the standard-code codon table only at the code-read layer.  Codons are represented in the six-coordinate cube $Q_6$, with the curated standard genetic-code table used as the finite contact that assigns each codon an amino-acid or stop label.  The question is whether the leave-one-codon-out residue set admits a coherent local module classification inside this coordinate display.  The answer is affirmative for the finite rows reported here: all thirteen residue codons are assigned to named modules, and every module contains a codon that is either predictable by the closure procedure or lies on the observed boundary class.

\paragraph{Residue set and cube shape.}
The residue set $R$ has cardinality $13$ and is exactly
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The punctured-cube check reports the same thirteen codons and the face-count vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}
$$
Thus the row is not merely a label list: it also records the local cubical incidence data visible from the window-six coordinate representation.  This is the finite combinatorial object whose module partition is being tested.

\paragraph{Module classification.}
The module assignment is complete.  The row reports $R\_\mathrm{size}=13$, $\mathrm{assigned\_count}=13$, no extra module codons, no missing codons, and no unassigned codons.  The complete assignment is
$$
\begin{aligned}
\mathrm{AGR}&=\{\mathrm{AGA},\mathrm{AGG}\},\\
\mathrm{AR\_Lys}&=\{\mathrm{AAA}\},\\
\mathrm{CUN}&=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\},\\
\mathrm{Ile\_Met}&=\{\mathrm{AUA}\},\\
\mathrm{SSN}&=\{\mathrm{UCA},\mathrm{UUA}\},\\
\mathrm{Stop\_Trp}&=\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}.
\end{aligned}
$$
The defining finite-row property is that each displayed module contains predictable or boundary-supported material: $\mathrm{AGR}$ contains $\mathrm{AGA}$ and $\mathrm{AGG}$, $\mathrm{AR\_Lys}$ contains $\mathrm{AAA}$, $\mathrm{CUN}$ contains all four $\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}$ codons, $\mathrm{Ile\_Met}$ contains $\mathrm{AUA}$, $\mathrm{SSN}$ contains $\mathrm{UCA}$ and $\mathrm{UUA}$, and $\mathrm{Stop\_Trp}$ contains $\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}$.  This is the chapter-specific content of the classification claim: the local residue set is exhausted by six biologically named codon modules, and none of the thirteen codons falls outside the module table.

\paragraph{Leave-one-codon-out recovery.}
The direct leave-one-codon-out row reports $8$ predictable codons, $5$ boundary codons, $8$ high-coverage closure codons, and no anchor codons.  Its recovery rate is $1.0$, above the stated threshold by the same recorded value $1.0$.  These numbers explain why the module table is not an arbitrary relabeling of $R$: the module classes sit over a split between closure-predictable codons and boundary codons.  The row therefore supports a local code-read statement: when a codon is removed from the standard-code contact and the window-six residue geometry is recomputed, the recovered residue behavior remains organized by the six modules above.

\paragraph{Local boundary.}
The contact used here is the curated standard-code table, whose observed fact is a codon-to-label assignment.  It can test code-read behavior and local codon-tile label splits.  It does not observe ribosomal translation, folded protein structure, physical admissibility, biological function, a molecular mechanism, or a universal law of biological organization.  Consequently the module classification may be stated as a finite local pattern of the standard-code label table in $Q_6$, but no claim about translation realization, folding, structural order, physical feasibility, function, mechanism, or universality follows from these rows unless a separate contact supplies that higher-layer evidence.
