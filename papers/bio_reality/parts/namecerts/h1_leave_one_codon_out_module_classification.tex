\subsection{Leave-One-Codon Module Classification in the Standard Code}
\label{sec:bioreality-h1-leave-one-codon-out-module-classification}

\paragraph{Finite codon window and observed contact.}
The finite object considered here is the six-coordinate codon window $Q_6$, read with the ordinary standard-code codon labels as the observed contact. The contact is deliberately narrow: it supplies codon-to-label assignments, including amino-acid and stop labels, but it does not supply a translation experiment, a folding assay, a physical-realizability test, or a functional phenotype. Within this restricted contact, the distinguished residual set is exactly the following thirteen-codon subset:
$$
\begin{aligned}
R = \{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\},\qquad |R|=13.
\end{aligned}
$$
The same row records the punctured-cube face count vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4),
\end{aligned}
$$
so the finite pattern is not merely a list of exceptional codons. It also has an internal local-face shape in the six-bit display. The present claim asks whether this thirteen-point residual pattern decomposes into biologically named modules in a way that remains local to code-label readback.

\paragraph{Module partition.}
The leave-one-codon-out module classification is complete. The verified assignment covers all $13$ codons in $R$, assigns no codon outside $R$, and leaves no residual codon unassigned:
$$
\begin{aligned}
R_{\mathrm{AGR}}&=\{\mathrm{AGA},\mathrm{AGG}\},\\
R_{\mathrm{AR/Lys}}&=\{\mathrm{AAA}\},\\
R_{\mathrm{CUN}}&=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\},\\
R_{\mathrm{Ile/Met}}&=\{\mathrm{AUA}\},\\
R_{\mathrm{SSN}}&=\{\mathrm{UCA},\mathrm{UUA}\},\\
R_{\mathrm{Stop/Trp}}&=\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}.
\end{aligned}
$$
Equivalently, the bookkeeping row gives
$$
\begin{aligned}
|R|=13,\qquad \mathrm{assigned}=13,\qquad \mathrm{missing}=0,\qquad \mathrm{extra}=0,\qquad \mathrm{unassigned}=0.
\end{aligned}
$$
Every named module has at least one codon lying in the predictable-or-boundary class. Thus the module classification is not a partial annotation placed on top of the residual set after the fact; it is a complete finite covering of the residual codon packet by the six named local code modules recorded above.

\paragraph{Predictive rows.}
The companion leave-one-codon-out row reports $8$ predictable codons, $5$ boundary codons, and no anchor codons in the tested residual packet. \paragraph{Shape and spectral checks.}
The residual geometry is also supported by finite shape and spectral rows. In the shape-significance run with $N=2000$ sampled alternatives and seed $42$, there was $1$ exact shape match after $57377$ distinct-sample attempts and $55377$ duplicate retries. These numbers make the row suitable for a finite mathematical chapter: the claim rests on explicit codon sets, exact module coverage, sampled null comparisons, and a numerical spectrum tied to the displayed residual geometry.

\paragraph{Local interpretation.}
The scientific reading is intentionally modest. The six-coordinate codon display exposes a local boundary-tile structure in the standard-code label table, and the thirteen residual codons split completely into the six named modules. The code labels remain curated biological contacts rather than consequences of the coordinate system alone. Thus the result supports a code-layer statement: in this finite row, leaving one codon out still leaves a residual module pattern whose predictable-or-boundary coverage is complete. It does not license any stronger claim about protein realization, folded structure, physical admissibility, biochemical function, a universal mechanism, or biological necessity. Any such stronger statement would require a separate contact whose observations live at that higher layer.
