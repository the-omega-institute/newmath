\subsection{Leave-one-codon module classification}
\label{sec:h1-leave-one-codon-out-module-classification}

\paragraph{Object and contact.}
The record concerns the standard-code codon table at the code-read layer. The finite carrier is the six-coordinate codon cube obtained from a three-position codon display with two binary coordinates per nucleotide position. The observed contact is a curated standard-code table assigning codons to amino-acid or stop labels. This contact is sufficient for checking label readback, local tile membership, and leave-one-codon recovery classes. It is not a contact for translation dynamics, folded structure, physical admissibility, biological function, a biochemical mechanism, or a universal biological law. Any assertion crossing one of those layers would require a separate observation of that layer.

Thus the local object is not an open-ended biological narrative: it is a finite subset of the codon cube with an explicitly enumerated row set and a finite incidence profile.

\paragraph{Interpretation.}
The result is a local code-table classification. Window-six coordinates expose a finite boundary-tile organization inside the curated standard-code labels, and the verified module row shows that this organization accounts for every codon in $R$ under the predictable-or-boundary dichotomy. The evidence reaches codon-label readback, local tile splitting, finite module coverage, and the stated null comparisons. It does not show that DNA must obey this geometry as a biological necessity. It also does not show translation realization, folded protein structure, physical admissibility, protein function, or a universal mechanism. Amino-acid label sequences remain labels read from the code table unless an independent structural or functional contact is supplied.
