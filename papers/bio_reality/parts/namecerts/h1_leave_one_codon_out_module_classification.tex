\subsection{Leave-One-Codon Module Classification in the Window-Six Codon Cube}
\label{subsec:h1-leave-one-codon-out-module-classification}

\paragraph{Finite object and readout.}
This record treats the standard-code codon table as a finite labelled object read through a six-bit codon display.  The carrier is the codon cube $Q_6$, while the observed labels are supplied by a curated standard-code table assigning each codon to an amino-acid or stop label.  The construction separates the coordinate calculation from the biological contact: the cube, its local faces, and the induced boundary pattern are finite combinatorial data, whereas the label table is the empirical readout used to test whether the local pattern meets the code layer.

\paragraph{Residual codon set.}
The finite residual set $R$ has cardinality $13$.  In the verified row it is exactly
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The same row records the punctured-cube face data by the vector
$$
\begin{aligned}
f(R)=(13,16,4),
\end{aligned}
$$
so the residual set is not merely a list of exceptional codons: it is also a local cubical pattern with $13$ vertices, $16$ one-dimensional incidences, and $4$ two-dimensional faces.  This is the finite geometric substrate on which the leave-one-codon classification is evaluated.

\paragraph{Module partition.}
The module classification assigns every element of $R$ to one of six named local classes:
$$
\begin{aligned}
\mathrm{AGR}&=\{\mathrm{AGA},\mathrm{AGG}\},\\
\mathrm{AR\_LYS}&=\{\mathrm{AAA}\},\\

$$
The completeness counters are exact: $R$ has size $13$, the assigned count is $13$, and the lists of extra module codons, missing codons, and unassigned codons are all empty.  Thus the classification is not a partial annotation of the residual set.  It is a closed finite partition of the observed $R$ row into modules relevant to local codon-label behavior.

\paragraph{Leave-one-codon signal.}
The leave-one-codon test records no anchor codons, $5$ boundary codons, $8$ high-coverage closure cases, and $8$ predictable cases.  The recovery rate is $1.0$, and the threshold comparison is also $1.0$.  These values say that the test does not need an additional unclassified residue to recover the finite module behavior: each module already contains a predictable or boundary representative.  In symbolic form, the row verifies
$$
\begin{aligned}
\#R&=13, & \#\mathrm{assigned}&=13,\\
\#\mathrm{boundary}&=5, & \#\mathrm{predictable}&=8,\\
\mathrm{recovery\ rate}&=1.0, & \mathrm{unassigned}&=0.
\end{aligned}
$$
The point of the classification is therefore local and exact: the module names cover the residual codons, and the leave-one-codon probe sees every module through predictable or boundary behavior.

\paragraph{Family-level stability.}

\paragraph{Scientific boundary.}
The conclusion is deliberately narrow.  The data support a code-layer statement: in the six-bit codon cube, the residual codons form a punctured local pattern, and the verified module classification covers all $13$ residual codons with predictable or boundary behavior under the curated standard-code label table.  No claim about translation realization, folded protein structure, structural order, physical admissibility, biological function, organism-wide mechanism, or universal biological law follows from this row alone.  Crossing any of those boundaries would require a separate contact that observes the corresponding layer directly, rather than an inference from codon-label readback.
