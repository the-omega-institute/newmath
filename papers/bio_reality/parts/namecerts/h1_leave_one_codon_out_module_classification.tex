\subsection{Leave-one-codon-out module classification in the standard-code codon table}
\label{subsec:bioreality-h1-leave-one-codon-out-module-classification}
\origin{ai}

\paragraph{Finite display.}
This record treats the standard genetic-code table as a finite code-layer observation over a six-coordinate codon display. The carrier is the codon cube $Q_6$, read only at the level of codon labels. The distinctions used here are the six-bit codon presentation, local tile faces, singleton label corners, and three-point label classes. The biological contact is a curated standard-code table assigning each codon to an amino-acid or stop label. That contact is sufficient for code readback and local label-split tests, but it is not a contact with translation dynamics, protein structure, physical chemistry, organismal function, or universal mechanism.

\paragraph{Observed exceptional row.}
The verified exceptional set $R$ has cardinality $13$ and is exactly
$$\begin{aligned}
R = \{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}$$
The same run verifies that this row is a punctured-cube pattern with $f$-vector $(13,16,4)$. Thus the row is not being summarized merely by its size: it carries a finite face structure in the codon-cube coordinates. The present chapter uses that structure only as a code-layer classification signal.

\paragraph{Spectral and sampling checks.}
The associated spectral calculation gives $\lambda_M = 0.6752479308830213$, $\lambda_R = 0.4758352843197002$, and $\mu = 3.051487585298128$. The cubic relation was numerically checked with residual $-6.224354365258478\times 10^{-12}$, the same value reported for the radial polynomial residual. The randomized shape comparison used $N=2000$ samples with seed $42$ and found one exact shape match, giving $p_{\mathrm{exact}}=0.0005$. The high-overlap comparison found $25$ samples with Jaccard score at least $0.9$, giving $p_{J\geq 0.9}=0.0125$. A separate amino-acid-class-preserving null model, also with $N=2000$ and seed $42$, had observed $|M|=20$, exact-match count $0$, lower-tail count $7$, exact-shape value $0.0$, and lower-tail value $0.0035$. These checks support the claim that the displayed row has non-generic finite geometry relative to the tested nulls; they do not identify a biological cause.

\paragraph{Leave-one-code-out behavior.}
Across $23$ evaluated code tables and $63$ total targets, the leave-one-code-out test reports baseline hit rate $0.19821739130434785$, hit rate inside $M\setminus T$ equal to $0.9365079365079365$, and hit rate inside $M\setminus T$ plus the boundary equal to $0.9841269841269841$. The same value $0.9841269841269841$ is recorded as the hit rate above baseline. Family stratification gives five families: alternative yeast has hit rate $0.8333333333333334$, while bacterial/plastid, candidate other, mitochondrial, and nuclear ciliate each have hit rate $1.0$ above baseline. This supports a finite code-read regularity across the tested table family, not a statement about cellular realization.

\paragraph{Leave-one-codon-out recovery.}
The leave-one-codon-out run records anchor count $0$, boundary count $5$, closure-coverage-high count $8$, predictable count $8$, and recovery rate $1.0$. The recovery threshold check is also $1.0$. These numbers say that the codon-level omissions are recovered by predictable or boundary behavior in the tested finite row; the absence of anchors is part of the observation, not an error term to be filled by biological speculation.

\paragraph{Module classification.}
The module classification is complete for the $13$ codons in $R$: the assigned count is $13$, with no extra module codons, no missing codons, and no unassigned codons. The modules are
$$\begin{aligned}
\mathrm{agr} &= \{\mathrm{AGA},\mathrm{AGG}\},\\
\mathrm{ar\_lys} &= \{\mathrm{AAA}\},\\
\mathrm{cun} &= \{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\},\\
\mathrm{ile\_met} &= \{\mathrm{AUA}\},\\
\mathrm{ssn} &= \{\mathrm{UCA},\mathrm{UUA}\},\\
\mathrm{stop\_trp} &= \{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}.
\end{aligned}$$
Each listed module has predictable-or-boundary status. In particular, the four-codon $\mathrm{cun}$ block is a full local block in the displayed row, the three-codon $\mathrm{stop\_trp}$ block is a stop/tryptophan-side code-label module, and the singleton modules $\mathrm{ar\_lys}$ and $\mathrm{ile\_met}$ are retained as singleton corners rather than absorbed into a larger biological interpretation.

\paragraph{Scope boundary.}
The admissible conclusion is narrow. Window-six coordinates expose a local boundary-tile organization in the standard-code label table, and the tested leave-one-code-out and leave-one-codon-out probes give strong finite support for predictable-or-boundary module membership in the listed row. Nothing in this contact observes ribosomal translation, folded protein geometry, energetic admissibility, biological function, a mechanism of code formation, or a universal law of biology. Any claim crossing one of those layers would require a separate empirical contact designed for that layer. Amino-acid label readback is therefore kept at the code layer: it is a finite label observation, not a structure or function observation.
