\paragraph{Claim and finite carrier.}
The claim concerns the standard-code codon table as a finite code-layer object, displayed in six binary coordinates over the codon cube $Q_6$. The tested distinction is local: a codon may lie in a tile face, in a singleton label corner, or in a small label class whose behavior is visible only after the curated codon-to-label table is read. The packet does not treat the six-bit display as a biochemical mechanism. It treats it as a finite coordinate carrier on which closure, spectrum, and relation probes can be compared against the standard-code labels.

The distinguished row $R$ has cardinality $13$ and is exactly

\begin{aligned}

The codon list is the object whose module classification is tested below.

The module classification is complete for the thirteen codons of $R$. The row reports $R$ size $13$, assigned count $13$, no extra module codons, no missing codons, and no unassigned codons. The modules are

Each module contains a codon whose leave-one-codon-out status is predictable or boundary-supported. The classification therefore closes the finite row: the thirteen-codon punctured-cube object is exhausted by six named modules, and no residue remains outside the table.
