\paragraph{Finite codon display.}
The object in this record is the standard-code codon table viewed only at the code-read layer.  Each codon is placed in the six-coordinate binary codon cube $Q_6$, using the finite codon display as a coordinate surface and using the curated standard-code table only as the label contact.  The contact says that codons receive amino-acid or stop labels; it does not say that the cube geometry is a mechanism of translation, a folding law, an admissibility test, a function test, or a universal biological principle.

The distinguished codon set $R$ has size $13$.  In this finite run it is exactly
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The punctured-cube check returns the same thirteen codons and the face-count vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}
$$
Thus the record is not merely a label list: it has a finite coordinate footprint, a boundary shape, and a code-label readback.  The singleton-corner and three-point label-class distinctions are therefore used only to sort local codon-table phenomena inside this footprint.

\paragraph{Spectral and shape checks.}
The associated spectral computation gives

\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128.

$$
The radial polynomial residual is $-6.224354365258478\times 10^{-12}$, the same value reported for the cubic-polynomial check, so the numerical witness is at machine-zero scale for this finite computation.  The shape-significance run used $N=2000$ samples with seed $42$.  It found $1$ exact shape match, giving $p=0.0005$, and $25$ matches at Jaccard threshold at least $0.9$, giving $p=0.0125$.  The sampling process required $57377$ distinct-sample attempts and recorded $55377$ duplicate retries, which should be read as a warning that the null ensemble is combinatorially constrained rather than as extra biological evidence.

A second null model preserves amino-acid class structure.  In that run the observed module-size statistic was $20$, the exact-shape count was $0$ out of $2000$, and the lower-tail count at or below the observed size was $7$, giving $p=0.0035$.  These figures support the claim that the displayed shape is not an ordinary draw from the tested finite nulls, while still leaving the biological interpretation at the codon-label layer.

\paragraph{Leave-one-code and leave-one-codon readbacks.}
The leave-one-code-out probe evaluated $23$ tables and $63$ targets.  Its baseline hit rate was $0.19821739130434785$.  The rate above baseline was $0.9841269841269841$, the rate inside $M-T$ was $0.9365079365079365$, and the rate inside $M-T$ together with the boundary was again $0.9841269841269841$.  By family, the run grouped the rows into $5$ families.  The hit rates above baseline were $1.0$ for bacterial-plastid, mitochondrial, nuclear-ciliate, and candidate-other families, and $0.8333333333333334$ for the alternative-yeast family.

The leave-one-codon-out computation gives a sharper local test.  It reports $0$ anchors, $5$ boundary codons, $8$ codons with high closure coverage, $8$ predictable codons, and recovery rate $1.0$.  The same value $1.0$ appears for recovery above the stated threshold.  This is the finite reason for treating the thirteen-codon set as a local boundary-and-prediction object rather than as a free narrative grouping.

\paragraph{Module classification.}
The module classifier assigns all thirteen codons in $R$ and reports no missing, extra, or unassigned codons.  The completeness row is
$$
\begin{aligned}
|R|&=13,\\
\mathrm{assigned\_count}&=13,\\
\mathrm{missing\_from\_modules}&=\varnothing,\\
\mathrm{extra\_module\_codons}&=\varnothing,\\
\mathrm{unassigned\_codons}&=\varnothing.
\end{aligned}
$$
The six modules are
$$
\begin{aligned}
\mathrm{AGR}&=\{\mathrm{AGA},\mathrm{AGG}\},\\
\mathrm{AR\_Lys}&=\{\mathrm{AAA}\},\\
\mathrm{CUN}&=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\},\\

Every module has at least one codon accounted for by predictability or boundary behavior.  This is the main finite-row conclusion: the leave-one-codon-out pattern is not scattered across the table but is exhausted by a short list of label modules, and the modules partition the observed thirteen-codon boundary set without residue.

\paragraph{Biological scope.}
The result is a code-read classification of a finite codon-table pattern.  The standard-code table supplies codon-to-label assignments and permits local split checks among singleton corners, three-point classes, and tile faces.  Nothing in this record observes ribosomal translation, tRNA charging, molecular dynamics, protein folding, cellular fitness, organism-level function, or a physical admissibility boundary.  Therefore the chapter asserts only that window-six codon coordinates expose a reproducible local module structure in the curated standard-code labels.  Any claim about translation, folded structure, physical possibility, function, mechanism, or universality would require a separate empirical contact whose rows directly measure that higher layer.
