\paragraph{ORF-eligibility reading.}
The biological object associated with this row is open-reading-frame eligibility from start/stop codon enumeration. The phrase is narrower than a realized open reading frame. A start/stop-window enumeration may define a candidate interval test, but eligibility is not licensed until a separate contact provides the external interval to which the test is applied. The two probes attached to this row express the same limitation in operational form. The first probe breaks if the pipeline asserts ORF eligibility, translation, folding, physical admissibility, or function from the start/stop geometry alone. The second probe breaks if an ORF-eligibility claim is recorded while no sequence database, transcript evidence, or curated annotation contact can test the proposed interval.

A one-window external start/stop enumeration was loaded in experiment $\mathrm{c26a0d6656f7}$. That row records $1$ input window and $1$ classified window, with scope restricted to external-window start/stop enumeration only and with the explicit classification $\mathrm{orf\_eligibility\_only}$. This is enough to say that the enumeration rule can classify the supplied window at the eligibility layer. It is not enough to infer translation, folded protein structure, physical admissibility, cellular mechanism, or biological function.
