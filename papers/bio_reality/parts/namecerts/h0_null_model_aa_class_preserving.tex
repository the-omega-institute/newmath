\subsection{Amino-acid-class-preserving null test for the local codon tile}
\label{subsec:h0-null-model-aa-class-preserving}

\paragraph{Claim record.}
The object studied here is the standard-code codon table, read only at the codon-label layer.  The finite display is the six-bit codon cube $Q_6$, with local distinctions for codon coordinates, tile faces, singleton label corners, and three-point label classes.  The biological contact is a curated standard-code table assigning each codon to an amino-acid or stop label.  This contact is strong enough to test codon-label readback and local tile separation, but it is not a contact with translation dynamics, folded structure, molecular admissibility, biological function, or a universal mechanism.  Those higher layers require separate observations before they can be asserted.

\paragraph{Observed boundary set.}
The verified boundary set $R$ has cardinality $13$.  Its codons are
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
A separate finite check identifies the same set as a punctured-cube pattern and records the face-count vector
$$
\begin{aligned}
f(R)=(13,16,4).
\end{aligned}
$$
Thus the local pattern is not merely a list of exceptional labels: it has a recorded combinatorial shape inside the six-bit codon display.  The row for the amino-acid-class-preserving null test records the observed comparison size as $|M|=20$; the finite data supplied for this packet do not enumerate the members of $M$, so this chapter uses only the recorded cardinality for $M$.

\paragraph{Amino-acid-class-preserving null model.}
The null model preserves amino-acid label classes and samples $N=2000$ class-compatible alternatives with seed $42$.  In those trials, the exact-match count is $0$.  The number of sampled alternatives with comparison size at most the observed value $|M|=20$ is $7$.  The reported probabilities are
$$
\begin{aligned}
p_{\mathrm{exact}}&=0.0,\\
p_{\mathrm{lower\ tail}}&=0.0035.
\end{aligned}
$$
Within this null family, the observed local tile is therefore not explained by class preservation alone.  The lower-tail statistic says that only $7$ out of $2000$ sampled class-preserving alternatives fall at or below the observed $M$ size, while no sampled alternative reproduces the exact observed shape.

\paragraph{Shape and spectrum checks.}
The broader shape significance run used $N=2000$ samples with seed $42$.  It required $57377$ distinct-sample attempts and incurred $55377$ duplicate retries.  Exactly one sampled alternative matched the observed shape, giving
$$
\begin{aligned}
p_{\mathrm{shape}}=0.0005.
\end{aligned}
$$
The same run found $25$ alternatives with Jaccard similarity at least $0.9$, giving
$$
\begin{aligned}
p_{J\geq 0.9}=0.0125.
\end{aligned}
$$
The spectral row records
$$
\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128.
\end{aligned}
$$
The associated radial cubic residual is $-6.224354365258478\times 10^{-12}$, reported again as the cubic-polynomial residual.  This is within numerical tolerance for the recorded spectral relation.  The spectrum therefore supplies an independent finite invariant of the same local pattern, not a biological mechanism.

\paragraph{Leave-one readback behavior.}
The leave-one-code-out row evaluated $23$ tables and $63$ total targets.  The baseline hit rate is $0.19821739130434785$.  The hit rate inside $M\setminus T$ is $0.9365079365079365$, while the hit rate inside $M\setminus T$ plus boundary is $0.9841269841269841$.  The reported hit rate above baseline is also $0.9841269841269841$.  A complementary leave-one-codon-out row records anchor count $0$, boundary count $5$, high closure coverage $8$, predictable count $8$, and recovery rate $1.0$.  These are code-layer recovery statistics: they show that the local codon-label pattern has predictive readback behavior under finite omissions, not that a translation apparatus or folded protein state has been observed.

\paragraph{Local interpretation.}
The amino-acid-class-preserving null result supports a narrow conclusion.  In the standard-code label table, the six-bit codon display exposes a local boundary-tile pattern whose exact shape is not recovered in $2000$ amino-acid-class-preserving samples, and whose lower-tail count is $7$ at the observed value $|M|=20$.  The same packet records a $13$-codon punctured-cube boundary with $f(R)=(13,16,4)$, a small exact-shape probability $0.0005$ under the broader shape run, and stable leave-one recovery statistics.  The conclusion remains at code readback: a local codon-label geometry is present in these finite rows.  No statement about actual translation, protein folding, structural order, physical possibility, realized function, universal biological law, or mechanism follows from these rows alone.
