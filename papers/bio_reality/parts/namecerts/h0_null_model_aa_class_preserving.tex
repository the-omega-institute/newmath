\subsection{Amino-acid-class-preserving null comparison for a window-six codon tile}
\label{sec:bioreality-h0-null-model-aa-class-preserving}

\paragraph{Claim scope.}
This record concerns the standard-code codon table at the label-read layer.  The coordinate carrier is the codon cube $Q_6$, displayed as six binary positions for a codon window.  The chapter tests whether the observed local tile, including a face-like region, a singleton label corner, and a three-point label class, is reproduced when amino-acid classes are preserved but the detailed codon positions are randomized.  The claim is deliberately local: the table supplies codon-to-label assignments, and the coordinate system supplies a finite geometry in which those labels can be read and compared.  No statement here upgrades the tile to translation dynamics, folded structure, physical admissibility, biological function, mechanism, or universality.  Such an upgrade would require a distinct contact carrying that higher-layer observation.

\paragraph{Reality contact.}
The contact is the curated standard genetic-code table, used only as a codon-label readback.  It assigns each codon to an amino-acid or stop label and thereby allows a finite local split to be inspected inside $Q_6$.  The contact does not observe ribosomal realization, tRNA availability, protein folding, energetic admissibility, or organism-level function.  Thus the same finite row can support a code-layer statement while blocking structural or mechanistic interpretations.  In particular, amino-acid label sequences are not protein structures, and a codon tile is not a global law of biology.

\paragraph{Observed boundary set.}
The distinguished boundary set $R$ has cardinality $13$.  The row records
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The same set is certified as a punctured-cube shape with $f$-vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}
$$
The observed module decomposition covers all thirteen codons without extras or omissions.  The modules are $\{AGA,AGG\}$ for $agr$, $\{AAA\}$ for $ar\_lys$, $\{CUA,CUC,CUG,CUU\}$ for $cun$, $\{AUA\}$ for $ile\_met$, $\{UCA,UUA\}$ for $ssn$, and $\{UAA,UAG,UGA\}$ for $stop\_trp$.  The classification row reports $R\_size=13$, assigned count $13$, no extra module codons, no missing codons, and no unassigned codons.  This makes the boundary set finite, auditable, and exactly matched to the listed codon modules.

\paragraph{Amino-acid-class-preserving null row.}
The null experiment keeps amino-acid class information fixed while sampling alternative codon placements.  With seed $42$ and $N=2000$ samples, the observed set has $|M|=20$.  The exact tile shape is never reproduced: exact match count $0$, with empirical exact-shape value $p=0.0$.  The lower-tail count at or below the observed $M$ size is $7$, giving
$$
\begin{aligned}
p_{\mathrm{lower\ tail}}=\frac{7}{2000}=0.0035.
\end{aligned}
$$
The finite-row interpretation is that the observed code-layer tile is unusual under this amino-acid-class-preserving shuffle.  The exact-shape statistic is more severe, while the lower-tail statistic gives a nonzero empirical estimate for size-level scarcity.  These are code-table statistics only; they do not identify a cause of the standard code and do not determine which biological processes selected or maintained it.

\paragraph{Shape comparison against broader samples.}
A separate finite row compares the observed $M$ shape against a broader randomized shape sample.  With $N=2000$ and seed $42$, the run required $57377$ distinct-sample attempts and encountered $55377$ duplicate retries.  It found $1$ exact shape match, so
$$
\begin{aligned}
p_{\mathrm{exact}}=\frac{1}{2000}=0.0005.
\end{aligned}
$$
It also found $25$ samples with Jaccard similarity at least $0.9$, giving $p=0.0125$.  These values agree with the amino-acid-class-preserving row in treating the observed local geometry as scarce among the finite comparison ensembles.  The conclusion remains bounded: scarcity of a code-layer tile is not itself a translation, folding, physical, functional, or universal claim.

\paragraph{Leave-one-code and leave-one-codon rows.}
The leave-one-code-out row evaluates $23$ tables and $63$ targets.  Its baseline hit rate is $0.19821739130434785$, while the hit rate above baseline is $0.9841269841269841$.  The hit rate inside $M-T$ is $0.9365079365079365$, and the rate inside $M-T$ plus boundary is $0.9841269841269841$.  By family, the row reports $5$ families: alternative yeast has hit rate $0.8333333333333334$, while bacterial plastid, candidate other, mitochondrial, and nuclear ciliate each have hit rate $1.0$ above baseline.  The leave-one-codon-out row has anchor count $0$, boundary count $5$, predictable count $8$, closure coverage high $8$, and recovery rate $1.0$.  These rows show that the local coordinate-and-boundary description has predictive organization at the label layer, especially around module and boundary membership.  They do not show that missing codons are physically generated or that a protein-level object is reconstructed.

\paragraph{Boundary discipline.}
The finite rows support a narrow statement: window-six codon coordinates expose a local boundary-tile pattern in the standard-code label table, and that pattern is scarce under the recorded null comparisons.  The amino-acid-class-preserving null row gives $0$ exact matches in $2000$ trials and a lower-tail value $0.0035$ at observed $|M|=20$; the broader shape row gives exact-shape value $0.0005$ and high-Jaccard value $0.0125$; the boundary set $R$ has exactly the listed $13$ codons with $f$-vector $(13,16,4)$; and the module classification assigns all $13$ boundary codons.  The chapter therefore records a finite code-read phenomenon, not a claim about translation realization, folding, physical admissibility, biological function, biological mechanism, or universal necessity.  Any later claim crossing one of those boundaries must attach a separate contact that actually observes the relevant layer.
