\subsection{Amino-acid-class-preserving null model for the codon boundary tile}\label{sec:h0-null-model-aa-class-preserving}

\paragraph{Finite object and readback.}
This record concerns the standard-code codon table only at the label-readback layer. The carrier is the six-coordinate codon cube $Q_6$, where each codon is represented by a six-bit display induced by its three nucleotide positions. The observed contact is a curated standard-code assignment from codons to amino-acid or stop labels. The finite row does not treat that table as a mechanism for translation; it treats it as the label table against which a local codon-window geometry can be compared.

The distinguished boundary set $R$ has cardinality $13$ and is given explicitly by
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The same finite row verifies that this set is the punctured-cube boundary object used in the computation, with $f$-vector $(13,16,4)$. Thus the observed tile is not a vague motif: it is a finite subcomplex with $13$ vertices, $16$ one-dimensional faces, and $4$ two-dimensional faces inside the codon cube display.

\paragraph{Observed size and null experiment.}
The amino-acid-class-preserving null model fixes the standard-code label classes and samples code-label arrangements subject to that class constraint. Against $N=2000$ sampled arrangements with seed $42$, the observed boundary-associated set has size $20$. The exact observed tile shape appeared $0$ times in the amino-acid-class-preserving sample, so the reported exact-shape rate is
$$
\begin{aligned}
p_{\mathrm{exact,class}} &= 0.0,\\
\#\{\hbox{exact matches}\} &= 0,\\
N &= 2000.
\end{aligned}
$$
The lower-tail count for samples with size at most the observed $M$-size is $7$, giving
$$
\begin{aligned}
p_{\mathrm{lower\ tail,class}} = \frac{7}{2000}=0.0035.
\end{aligned}
$$
This is the finite statistical content of the row: within the class-preserving null ensemble supplied here, the standard-code boundary tile is not reproduced exactly, and the observed size lies in a low lower tail of the sampled distribution.

\paragraph{Comparison with the unconstrained shape sample.}
A separate shape-significance row reports $N=2000$ samples, $57377$ distinct-sample attempts, and $55377$ duplicate retries under seed $42$. In that run the exact shape count is $1$, giving $p_{\mathrm{exact}}=0.0005$, while $25$ samples have Jaccard overlap at least $0.9$, giving $p_{J\geq 0.9}=0.0125$. These values are consistent with the class-preserving null result: the boundary tile is a finite, sharply specified shape whose exact occurrence is rare under the sampled controls, and whose high-overlap occurrence remains uncommon.

\paragraph{Local conclusion.}
The row supports the following bounded conclusion. In the six-coordinate codon display, the standard-code labels determine a local boundary tile $R$ with $13$ codons, $16$ edges, and $4$ faces. Under the amino-acid-class-preserving null experiment reported here, the exact observed shape has empirical rate $0.0$ over $2000$ samples, and the lower-tail rate for the observed $M$-size is $0.0035$. Together with the unconstrained shape run, the spectral residual, the leave-one-code-out rates, the leave-one-codon-out recovery rate, and the complete module partition, this is evidence for a code-layer boundary pattern in the curated standard-code table.

No stronger biological statement is licensed by this row. The computation does not show translation as a realized biochemical process, does not infer folded protein structure from an amino-acid label sequence, does not establish physical admissibility, does not identify biological function, does not provide a mechanism, and does not assert universality across organisms. Any such statement would require a separate empirical contact designed for that higher layer.
