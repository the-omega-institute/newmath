\subsection{Null comparison and shape rarity}
\label{sec:bioreality-aa-class-preserving-null-comparison}

\paragraph{Amino-acid-class-preserving test.}
The amino-acid-class-preserving null run used seed $42$ and $N=2000$ samples. The observed $M$-size was $20$. Among the $2000$ null samples, the exact local shape match count was $0$, giving
$$
\begin{aligned}
p_{\mathrm{aa,class,exact}} &= 0.0,\\
p_{\mathrm{aa,class,lower\ tail}} &= 0.0035.
\end{aligned}
$$
The lower-tail count at or below the observed $M$-size was $7$. Thus, even after the null model respects amino-acid label classes, the observed local configuration sits in a small lower-tail region of the sampled distribution. The exact-shape test is stronger in this finite run: no sampled amino-acid-class-preserving reshuffle reproduced the observed shape.

\paragraph{Unrestricted shape comparison.}
A separate shape-significance row used the same seed $42$ with $N=2000$. It required $57377$ distinct-sample attempts and recorded $55377$ duplicate retries, so the finite sample space was being hit repeatedly during sampling. In that run there was $1$ exact shape match and $25$ samples with Jaccard score at least $0.9$. The reported probabilities were
$$
\begin{aligned}
p_{\mathrm{exact}} &= 0.0005,\\
p_{\mathrm{Jaccard}\geq 0.9} &= 0.0125.
\end{aligned}
$$
Together with the amino-acid-class-preserving row, this separates two claims. First, the local window-six shape is rare among sampled alternatives. Second, its rarity is not explained away merely by preserving the amino-acid label classes used by the standard code. Both claims are finite-row claims about the displayed table and sampled null procedures; neither is a theorem about all possible genetic codes or all biological contexts.
