\subsection{Amino-acid-class-preserving null model for the window-six codon tile}
\label{sec:h0-null-model-aa-class-preserving}

\paragraph{Finite object under test.}
The record concerns the standard-code codon table viewed only at the code-read layer. The finite carrier is the six-coordinate codon cube $Q_6$, with codons displayed as six-bit positions after the usual nucleotide-to-coordinate encoding. The biological contact is deliberately narrow: a curated standard genetic-code table supplies codon-to-amino-acid or codon-to-stop labels. The test does not treat that table as a translation machine, a folding experiment, a physical-admissibility assay, a functional assay, or a universal mechanism. It supplies labels for a finite readback question and nothing above that layer.

The distinguished residual set $R$ has cardinality $13$. Its member codons are
$$

Thus the local residual geometry is not merely a count: it carries a finite incidence profile with thirteen vertices, sixteen one-dimensional adjacencies, and four square faces. The complementary observed tile $M$ has size $20$ in the amino-acid-class-preserving null-model run. No membership list for $M$ is included in this finite row, so the chapter uses only its observed size and the separate shape statistics supplied by the run.

\paragraph{Class-preserving null model.}
The null model keeps the amino-acid-class constraint while randomizing the relevant label placement. In $N=2000$ sampled tables, the exact observed shape was never reproduced:
$$
\begin{aligned}
N&=2000,\\
\#\{\hbox{exact matches}\}&=0,\\
p_{\mathrm{exact}}&=0.0.
\end{aligned}
$$
The lower-tail comparison against the observed $M$ size is also sparse. Only $7$ samples fell at or below the observed value $|M|=20$, giving
$$
\begin{aligned}
\#\{\hbox{samples with } |M_{\mathrm{sample}}|\leq 20\}&=7,\\
p_{\mathrm{lower\ tail}}&=0.0035.
\end{aligned}
$$
With seed $42$ and experiment run id $\mathrm{e8d5de747a0c}$, the finite evidence says that preserving amino-acid class does not by itself make the observed local tile common. The result is a code-table regularity statement, not a biological-law statement.

\paragraph{Independent shape comparison.}
A separate shape-significance run used $N=2000$ samples with seed $42$. It found one exact shape match and $25$ samples with Jaccard similarity at least $0.9$:
$$
\begin{aligned}
\#\{\hbox{exact shape matches}\}&=1, & p_{\mathrm{exact\ shape}}&=0.0005,\\
\#\{\hbox{Jaccard}\geq 0.9\}&=25, & p_{\mathrm{Jaccard}\geq 0.9}&=0.0125.
\end{aligned}
$$
The distinct-sample process attempted $57377$ draws and recorded $55377$ duplicate retries. These retry counts matter because they show that the reported null comparison is being made over distinct finite samples rather than over a stream where duplicate tables silently inflate the apparent evidence. The exact-shape and high-Jaccard rows both point in the same direction as the amino-acid-class-preserving null model: the observed local pattern is uncommon under the tested finite randomizations.

\paragraph{Boundary of the claim.}
The evidential status is therefore positive but scoped. The record supports the following finite claim: in the standard-code label table, the six-coordinate codon display exposes a local residual tile whose size, punctured-cube face vector, module partition, spectral numbers, and null-model rarity are all explicitly recorded. The amino-acid-class-preserving null model gives $0$ exact matches in $2000$ samples and a lower-tail value $0.0035$ for the observed $M$ size. The broader shape comparison gives $p=0.0005$ for exact shape and $p=0.0125$ for high-Jaccard similarity. These are finite code-layer facts.

No stronger biological conclusion follows from this row. In particular, the row does not show translation realization, folded structure, physical admissibility, biological function, mechanism, or universality. Any claim at one of those higher layers would need a separate contact of the corresponding kind. A codon-to-label table can certify label readback and local split behavior; it cannot by itself certify structure or function.
