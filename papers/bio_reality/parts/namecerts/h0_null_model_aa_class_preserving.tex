\subsection{Amino-acid-class-preserving null test for the local codon tile}
\label{sec:h0-null-model-aa-class-preserving}
\origin{ai}

\paragraph{Finite codon display.}
This record treats the standard-code codon table as a finite labelled object on the six-bit codon cube $Q_6$.  The readout used here is deliberately narrow: each codon is read only as a standard-code amino-acid or stop label, and the coordinate geometry is used only to ask whether a local tile boundary has a stable finite shape.  The distinguished boundary set is the thirteen-codon set
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The finite audit reports $|R|=13$, with the same thirteen codons appearing in the punctured-cube check.  Its face-count summary is $f(R)=(13,16,4)$, so the object under discussion is not an unlabelled global law over all codons, but a concrete local boundary pattern with thirteen vertices, sixteen one-dimensional adjacencies, and four filled two-dimensional faces in the induced codon-cube geometry.

\paragraph{Observed tile size and null model.}
The class-preserving null experiment keeps amino-acid class information fixed while randomizing the relevant label arrangement.  Against $N=2000$ sampled null tables with seed $42$, the observed local tile has $|M|=20$.  No sampled class-preserving null table reproduced the exact observed tile shape: the exact-match count was $0$, giving
$$
\begin{aligned}
p_{\mathrm{class,exact}}&=0.0,\\
\#\{\text{null samples with exact shape}\}&=0.
\end{aligned}
$$
The lower-tail check counted $7$ null samples with tile size at most the observed value, so
$$
\begin{aligned}
p_{\mathrm{class,lower\ tail}}&=\frac{7}{2000}=0.0035.
\end{aligned}
$$
Thus the observed tile is small and shaped in a way that is rare under this amino-acid-class-preserving null, without being promoted into a biological mechanism.  The companion unstructured shape run used the same $N=2000$ and seed $42$ and found $1$ exact shape match after $57377$ distinct-sample attempts with $55377$ duplicate retries, giving $p_{\mathrm{exact}}=0.0005$.  It also found $25$ samples with Jaccard similarity at least $0.9$, giving $p_{J\ge 0.9}=0.0125$.  These values support a finite significance statement for the code-layer tile shape, not an inference about translation chemistry or protein structure.

\paragraph{Module-level accounting.}
The thirteen boundary codons are completely assigned by the module classification.  The recorded modules are
$$
\begin{aligned}

\mathrm{AR/Lys}&=\{AAA\},\\
\mathrm{CUN}&=\{CUA,CUC,CUG,CUU\},\\
\mathrm{Ile/Met}&=\{AUA\},\\

The classification row gives $R_{\mathrm{size}}=13$, assigned count $13$, no missing codons, no extra module codons, and no unassigned codons.  Every listed module has either a predictable or boundary status.  This matters because the null result is not merely a scalar $p$-value: it is attached to a named finite inventory of codon modules, and that inventory accounts for every member of $R$ exactly once.

\paragraph{Leave-out checks.}
Two finite prediction-style checks reinforce the same limited reading.  In the leave-one-code-out row, $23$ tables were evaluated over $63$ total targets.  The baseline hit rate was $0.19821739130434785$, while the hit rate above baseline was $0.9841269841269841$.  The hit rate inside $M-T$ was $0.9365079365079365$, and the rate inside $M-T$ plus boundary was $0.9841269841269841$.  By family, the five reported hit rates above baseline were $1.0$ for bacterial-plastid, mitochondrial, nuclear-ciliate, and candidate-other families, and $0.8333333333333334$ for alternative yeast.  In the leave-one-codon-out row, the anchor count was $0$, the boundary count was $5$, the predictable count was $8$, and the closure-coverage-high count was $8$, with recovery rate $1.0$.  These finite rows say that the same local codon-tile organization is useful for code-label recovery tasks.  They still remain label-recovery tests, not observations of ribosomal realization, protein folding, physical admissibility, or biological function.

\paragraph{Local verdict.}
The amino-acid-class-preserving null model gives a ready code-layer result: the observed standard-code tile has $|M|=20$, its boundary set is the thirteen-codon set $R$ above, its module accounting is complete, and its exact class-preserving null shape probability is recorded as $0.0$ with lower-tail value $0.0035$ over $2000$ samples.  The result is therefore a finite, reproducible local-tile statement about codon-label readback.  It must not be restated as a claim that window-six geometry explains translation, determines folded structure, imposes physical admissibility, realizes function, supplies a mechanism, or establishes a universal biological law.  Any such stronger statement would require a separate contact that directly measures the higher layer being claimed.
