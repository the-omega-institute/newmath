\subsection{Amino-acid-class preserving null model for the local codon tile}
\label{sec:bioreality-h0-null-model-aa-class-preserving}
\origin{ai}

\paragraph{Finite object under test.}
The record concerns a window-six presentation of the standard-code codon table.  The finite carrier is the six-coordinate codon cube, read only at the code-label layer: each codon is supplied with its curated amino-acid or stop label, and the analysis asks whether the observed local boundary tile is reproduced under a null model that preserves amino-acid label classes.  The biological contact is therefore the curated standard genetic-code table, not a translation apparatus, not a folding experiment, and not a physical model of admissible proteins.  The data item under audit is the claim identified by $\mathrm{h0.null.model.aa\_class\_preserving}$, whose run id is $\mathrm{d5daec4c4b5f}$, with seed $42$ and $N=2000$ sampled null tables.

The finite row supplies the distinguished boundary set $R$ explicitly.  In codon notation it is

&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.

Its cardinality and face data are

Thus the local object being compared is not an arbitrary list of codons: it is the thirteen-codon boundary set whose finite face vector has $13$ vertices, $16$ edges, and $4$ two-faces in the recorded punctured-cube calculation.  The same thirteen codons are also the rows classified by the module audit, so the null-model comparison, the punctured-cube description, and the module partition are referring to the same finite code-layer subset.

\paragraph{Amino-acid-class preserving null result.}
The amino-acid-class preserving null model sampled $2000$ alternatives.  The observed size of the local tile $M$ was $20$.  Among the $2000$ class-preserving samples, the exact observed shape appeared $0$ times, while only $7$ samples lay in the lower tail at or below the observed $M$ size.  The recorded probabilities are
$$
\begin{aligned}
N&=2000,\\
\#\{\hbox{exact shape matches}\}&=0,\\
\#\{\hbox{samples with } |M_{\mathrm{null}}|\leq 20\}&=7,\\
p_{\mathrm{exact}}&=0.0,\\
p_{\mathrm{lower\ tail}}&=0.0035.
\end{aligned}
$$
This is the central finite-row conclusion for the chapter: once amino-acid label classes are preserved, the recorded local codon-tile shape is still rare in the null ensemble.  The claim is not that the table is forced by geometry, but that this particular code-label boundary pattern is not reproduced by the sampled class-preserving reshufflings at the observed resolution.

\paragraph{Comparison with the broader shape null.}
A separate shape-significance run with id $\mathrm{263bb3eb52d7}$ also used seed $42$ and $N=2000$.  It required $57377$ distinct-sample attempts and incurred $55377$ duplicate retries.  In that run there was $1$ exact shape match and $25$ samples with Jaccard similarity at least $0.9$, giving
$$
\begin{aligned}
p_{\mathrm{exact\ shape}}&=0.0005,\\
p_{\mathrm{Jaccard}\geq 0.9}&=0.0125.
\end{aligned}
$$
The amino-acid-class preserving audit is therefore not an isolated numerical curiosity.  It agrees directionally with the broader local-shape audit: exact recovery is scarce, and high-overlap recovery remains uncommon.  The class-preserving null is stricter in the relevant biological sense because it keeps the amino-acid label partition fixed while testing whether the local tile shape is an incidental consequence of that partition.

\paragraph{Interpretation of the claim.}
The supported reading is narrow and finite.  Window-six codon coordinates expose a local boundary-tile pattern in the standard-code label table, and that pattern remains rare under the sampled amino-acid-class preserving null model.  The evidence basis combines the curated code-label contact with computed coordinate, closure, spectrum, and module probes.  It does not say that DNA or translation is governed by the coordinate geometry.  It says that, after labels are supplied from the curated table, the resulting finite boundary pattern has measurable non-random structure relative to the stated null family.

\paragraph{Local limits.}
No claim about translation realization, folded structure, physical admissibility, biological function, mechanism, or universality follows from this row.  The standard-code table contains codon-to-label assignments only.  It does not observe ribosomal translation, tRNA availability, molecular folding, protein stability, organismal fitness, or universal biological necessity.  In particular, amino-acid label-sequence readback is not folded protein structure, and a local codon tile is not a global law of biology.  Any assertion crossing from the code-label layer to translation, structure, physical admissibility, function, mechanism, or universality would require a separate empirical contact whose rows actually measure that higher layer.
