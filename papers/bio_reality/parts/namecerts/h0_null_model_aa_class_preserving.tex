\subsection{Amino-acid-class preserving null model for the codon tile}
\label{subsec:h0-null-model-aa-class-preserving}

\paragraph{Claim under test.}
This record tests whether the window-six codon display has more structure than would be expected after preserving only amino-acid class information in the standard-code label table. The biological contact is deliberately narrow: the curated table assigns each codon to an amino-acid or stop label, and the present computation asks whether a local tile boundary in the six-bit codon cube is reproduced by null samples that respect that label-class constraint. The contact is a code-layer observation only. It does not observe translation as a cellular process, folded protein geometry, physical admissibility, realized function, a mechanism, or a universal biological law.

\paragraph{Finite codon row.}
The distinguished boundary set has cardinality $13$ and is the following explicit subset of the codon cube:
$$
\begin{aligned}
R={}&\{\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The same row is verified as a punctured-cube shape with $f$-vector $(13,16,4)$. Thus the finite object being compared is not just a list of codons: it has a local face count and boundary incidence profile inside the six-coordinate display. The complementary measured tile size used by the null experiment is $|M|=20$; the exact membership list for $M$ is not part of the supplied row, so the prose uses only the verified size and the reported comparisons.

\paragraph{Spectral coordinate check.}
The associated spectral measurements give
$$
\begin{aligned}
\lambda_M &= 0.6752479308830213,\\
\lambda_R &= 0.4758352843197002,\\
\mu &= 3.051487585298128.
\end{aligned}
$$
The radial cubic check evaluates to $-6.224354365258478\times 10^{-12}$, which is within numerical tolerance for zero at the recorded precision. The spectrum therefore supplies an independent finite-coordinate summary of the same row, separate from the label-preserving permutation test.

\paragraph{Amino-acid-class preserving null.}
The null model sampled $N=2000$ class-preserving alternatives with seed $42$. Among these samples, the exact codon-tile shape was observed $0$ times, giving an exact-shape Monte Carlo value $p=0$. The lower-tail count for samples with size at most the observed $|M|=20$ was $7$, giving
$$
\begin{aligned}
p_{\mathrm{lower\ tail}}=\frac{7}{2000}=0.0035.
\end{aligned}
$$
The comparison is therefore not explained by the amino-acid class partition alone at this sample scale. A broader shape-significance run, also with $N=2000$ and seed $42$, recorded one exact shape match, so $p_{\mathrm{exact}}=0.0005$, and $25$ samples with Jaccard similarity at least $0.9$, so $p_{J\geq 0.9}=0.0125$. That run required $57377$ distinct-sample attempts and encountered $55377$ duplicate retries, which makes the finite sampling regime explicit rather than hiding it behind an asymptotic claim.

\paragraph{Leave-out behavior.}
Two predictive checks give the boundary row a limited code-readback role. In the leave-one-code-out experiment, $23$ tables supplied $63$ targets. The baseline hit rate was $0.19821739130434785$, while the rate above baseline was $0.9841269841269841$. The hit rate inside $M-T$ was $0.9365079365079365$, and the rate inside $M-T$ together with the boundary was $0.9841269841269841$. In the leave-one-codon-out experiment, the recovery rate was $1.0$, with $8$ predictable cases, $5$ boundary cases, $8$ high-coverage closure cases, and no anchor cases. These numbers support a local readback regularity, not a claim about molecular execution.

\paragraph{Module account.}
The thirteen codons in $R$ are fully assigned to six named modules. The recorded module partition is
$$
\begin{aligned}
\mathrm{agr}&=\{\mathrm{AGA},\mathrm{AGG}\},\\
\mathrm{ar\_lys}&=\{\mathrm{AAA}\},\\
\mathrm{cun}&=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\},\\
\mathrm{ile\_met}&=\{\mathrm{AUA}\},\\
\mathrm{ssn}&=\{\mathrm{UCA},\mathrm{UUA}\},\\
\mathrm{stop\_trp}&=\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}.
\end{aligned}
$$
The module audit reports $R$-size $13$, assigned count $13$, no missing codons, no unassigned codons, and no extra module codons. Family-level leave-one-code-out rates were recorded for five families: alternative yeast $0.8333333333333334$, bacterial plastid $1.0$, candidate other $1.0$, mitochondrial $1.0$, and nuclear ciliate $1.0$. This is a strong finite-row summary of code-label behavior across the sampled families, while still remaining inside the codon-label layer.

\paragraph{Local boundary.}
The correct reading is that the six-bit codon coordinate system exposes a repeatable local boundary-tile pattern tied to the curated standard-code labels. The evidence is finite, numerical, and row-specific: a $13$-codon punctured-cube boundary, a $20$-codon measured tile size, spectral values satisfying the recorded cubic relation to tolerance, a class-preserving null with $0$ exact matches in $2000$ samples, a lower-tail value $0.0035$, and complete module assignment for the boundary row. The same facts also set the limit of the claim. Without an additional observation that directly measures translation, structure, physical admissibility, function, mechanism, or cross-context universality, no such higher-layer statement follows from this chapter.
