\subsection{Amino-acid-class-preserving null model for the local codon tile}\label{sec:bior-h0-null-model-aa-class-preserving}
\origin{ai}

\paragraph{Finite claim.}
This record concerns the standard-code codon table viewed through a six-coordinate codon display.  The tested object is not translation itself, and not a model of molecular realization.  It is the finite code-layer question of whether the observed local tile boundary can be recovered, or easily imitated, when the amino-acid or stop label classes are preserved while the codon positions are randomized.  The biological contact is the curated standard-code assignment of codons to amino-acid or stop labels.  That contact permits codon-label readback and local split checks, but it does not observe a folded protein, a physical pathway, a biochemical mechanism, an admissible structure, a function, or a universal law.

\paragraph{Observed boundary row.}
The distinguished boundary set $R$ has cardinality $13$.  In this row it is exactly
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The punctured-cube check reports the same thirteen codons and gives the face-count vector $(13,16,4)$.  Thus the local combinatorial object is not merely a count; it is a concrete punctured face pattern inside the codon cube.  The row also records an observed module size $|M|=20$ for the complementary shape statistic used by the amino-acid-class-preserving null test.

\paragraph{Null-model outcome.}
The amino-acid-class-preserving null run used $N=2000$ samples with seed $42$.  It produced no exact shape match: the exact-match count was $0$, so the recorded exact-shape Monte Carlo value was $p=0.0$ at this sample resolution.  The lower-tail event, counting samples with size at most the observed $|M|=20$, occurred $7$ times, giving $p=0.0035$.  The row therefore supports the limited statement that the observed code-layer shape is not typical under this finite label-class-preserving randomization scheme.  It does not support promotion to a claim about why the code exists, how translation is physically implemented, whether a protein folds, or whether a biological function follows.

\paragraph{Shape comparison against unrestricted samples.}
A related shape-significance run, also with $N=2000$ and seed $42$, required $57377$ distinct-sample attempts and recorded $55377$ duplicate retries.  In that run there was $1$ exact shape match, giving $p=0.0005$, and $25$ samples with Jaccard similarity at least $0.9$, giving $p=0.0125$.  These companion values reinforce the same finite conclusion: the observed local tile has a scarce combinatorial shape among the sampled alternatives.  The evidence remains a code-readback and geometry statement, because the input contact is still only the curated codon-to-label table.

\paragraph{Scope boundary.}
The admissible conclusion is narrow.  Window-six codon coordinates expose a finite local boundary-tile pattern in the curated standard-code label table, and the amino-acid-class-preserving null model makes that pattern rare in the sampled comparison class.  The row cannot be used as evidence for translation realization, folded structure, structural order, physical admissibility, biological function, mechanism, or universality.  Any one of those stronger claims would require a different contact that directly measures the relevant higher layer.  In particular, amino-acid label readback is not folded protein structure, and cross-organism wording about codon families or tRNA notation does not become structural evidence without an organism-matched structure or mechanism contact.
