\paragraph{Amino-acid-class preserving null.}
The null comparison keeps amino-acid class structure fixed while randomizing the shape witness.  With seed $42$ and $N=2000$ samples, the exact amino-acid-class preserving null produced $0$ exact matches to the observed shape.  The recorded exact-shape probability is therefore $p=0.0$ at this Monte Carlo resolution.  For the lower-tail statistic, $7$ sampled configurations had size at most the observed $|M|=20$, giving
$$
\begin{aligned}
p_{\mathrm{lower\ tail}} &= \frac{7}{2000}=0.0035,\\
p_{\mathrm{exact\ shape}} &= \frac{0}{2000}=0.0.
\end{aligned}
$$
The class-preserving null is the relevant stress test for this row because it does not merely ask whether an arbitrary codon subset can look similar.  It asks whether the label-class constraints already explain the local tile.
