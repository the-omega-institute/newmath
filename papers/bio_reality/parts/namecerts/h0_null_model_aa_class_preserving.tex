\subsection{Amino-acid-class-preserving null model for the window-six codon tile}
\label{sec:bior reality-h0-null-model-aa-class-preserving}

\paragraph{Finite object and contact.}
The record concerns the standard-code codon table viewed only at the code-read layer.  The finite carrier is the six-coordinate codon cube $Q_6$, where each codon is represented by a six-bit display of its three nucleotide positions.  The inspected distinctions are the coordinate positions, local tile faces, singleton label corners, and three-point label classes.  The outside contact is a curated standard genetic-code table: it assigns each codon to an amino-acid or stop label, but it is not itself a model of translation dynamics, molecular folding, admissible chemistry, biological activity, or a universal biological mechanism.  The question tested here is therefore narrow: whether the observed local codon-window tile is unusually shaped when compared with amino-acid-class-preserving randomized labelings.

\paragraph{Observed residue set.}
The distinguished boundary set $R$ has cardinality $13$.  Its codons are
$$
\begin{aligned}
R = \{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The same finite row reports that this set is a punctured-cube object with face-vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}
$$
Thus the observed tile is not merely a list of exceptional codons; it has an internal local-face profile inside $Q_6$.  The module decomposition accounts for all $13$ codons: $\mathrm{agr}=\{\mathrm{AGA},\mathrm{AGG}\}$, $\mathrm{ar\_lys}=\{\mathrm{AAA}\}$, $\mathrm{cun}=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\}$, $\mathrm{ile\_met}=\{\mathrm{AUA}\}$, $\mathrm{ssn}=\{\mathrm{UCA},\mathrm{UUA}\}$, and $\mathrm{stop\_trp}=\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}$.  The classification row has $R$-size $13$, assigned count $13$, no extra module codons, no missing codons, and no unassigned codons.

\paragraph{Amino-acid-class-preserving null row.}
The null experiment preserves amino-acid class while randomizing the finite code-label pattern.  It used seed $42$ and $N=2000$ trials.  The observed comparison size was $|M|=20$.  Exact recovery of the observed shape occurred $0$ times, giving
$$
\begin{aligned}
 p_{\mathrm{aa\ class,exact}} &= 0.0.
\end{aligned}
$$
The lower-tail count at or below the observed $M$-size was $7$, giving
$$
\begin{aligned}
 p_{\mathrm{aa\ class,lower\ tail}} &= 0.0035.
\end{aligned}
$$
Both reported significance fields match these values: the exact-shape significance is $0.0$, and the lower-tail significance is $0.0035$.  A companion shape-significance run with $N=2000$ distinct samples required $57377$ sample attempts and $55377$ duplicate retries; it found $1$ exact shape match and $25$ matches with Jaccard similarity at least $0.9$, yielding $p_{\mathrm{exact}}=0.0005$ and $p_{J\geq 0.9}=0.0125$.  The finite evidence therefore supports an unusually constrained local tile under the stated null models.

\paragraph{Local verdict.}
The finite rows support the following claim and no stronger one: the six-bit codon coordinate system exposes a stable local boundary-tile pattern in the standard-code label table, and this pattern remains rare under an amino-acid-class-preserving null model.  The evidence is a code-read statement about finite codon labels.  No inference to translation realization, folded structure, structural order, physical admissibility, biological function, mechanism, or universality is licensed by these rows.  Any such promotion would require an additional contact of the appropriate kind, separate from the curated codon-to-label table used here.
