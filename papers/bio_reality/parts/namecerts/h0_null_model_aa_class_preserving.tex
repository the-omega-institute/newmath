\paragraph{Amino-acid-class-preserving null.}
The null model tested here keeps amino-acid-class information fixed while randomizing the shape comparison.  In $N=2000$ sampled null rows, the observed tile shape was matched exactly $0$ times.  The resulting exact-shape frequency is reported as
$$
\begin{aligned}
p_{\mathrm{exact,aa}}=0.0.
\end{aligned}
$$
The same null run records $|M|=20$ for the observed module-side set size and finds $7$ null rows in the lower tail at or below that size, giving
$$
\begin{aligned}
p_{\mathrm{lower\ tail,aa}}=\frac{7}{2000}=0.0035.
\end{aligned}
$$
The seed was $42$, and the experiment run identifier was \texttt{e8d5de747a0c}.  These numbers say that the observed window-six tile is not well explained by the amino-acid-class-preserving null at this finite sampling resolution.  They do not say that the coordinate pattern performs translation, determines a folded structure, enforces physical admissibility, realizes function, supplies a molecular mechanism, or holds universally across biology.

\paragraph{Local verdict and boundary.}
The verdict for \texttt{h0.null.model.aa\_class\_preserving} is that the window-six codon tile has a finite, statistically unusual local shape under the amino-acid-class-preserving null.
