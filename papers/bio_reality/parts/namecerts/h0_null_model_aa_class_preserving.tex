\paragraph{Record.}

Codons are displayed as points of a six-coordinate cube, and the test asks whether the observed local tile can be reproduced after preserving amino-acid class information while otherwise randomizing the assignment compatible with that null condition.  The biological contact used here is only a curated codon-to-label table.  It supplies amino-acid and stop labels for codons, but it does not itself observe translation dynamics, folded molecular geometry, physical admissibility, function, mechanism, or universality.

\paragraph{Interpretation.}
The finite rows jointly support a narrow conclusion.  Window-six codon coordinates expose a stable local boundary-tile pattern in the standard-code label table, and the amino-acid-class-preserving null makes that pattern hard to attribute to class preservation alone in the sampled experiment.  The appropriate reading is code-layer readback: codon labels, local cubical geometry, module coverage, finite spectral values, and null-model rarity.  Nothing in these rows observes ribosomal realization, folded protein structure, thermodynamic or kinetic admissibility, biological function, a causal mechanism, or a universal rule across living systems.
