\paragraph{Amino-acid-class-preserving null.}
The null model keeps amino-acid class structure fixed while testing whether the observed local tile shape is reproduced by randomized relabelings of the relevant finite table.  With seed $42$ and $N=2000$ trials, the exact-shape count is $0$, giving
$$\begin{aligned}
p_{\mathrm{class,exact}}&=0.0,\\
\#\{\mathrm{exact\ matches}\}&=0.
\end{aligned}$$
For the lower-tail statistic at the observed size $|M|=20$, the row gives $7$ trials with size at most the observed value, hence
$$\begin{aligned}
p_{\mathrm{class,lower\ tail}}&=\frac{7}{2000}=0.0035.
\end{aligned}$$
The finite interpretation is that the observed local tile is unusual even after preserving amino-acid-class information.  This is a statement about the code table as a labeled finite object; it is not a statement about translation dynamics or protein structure.

\paragraph{Comparison with the broader shape null.}
A companion finite-row test over $N=2000$ samples, also with seed $42$, reports one exact shape match after $57377$ distinct-sample attempts and $55377$ duplicate retries. The amino-acid-class-preserving null is therefore not the only source of finite surprise: both the unrestricted shape test and the class-preserving test mark the same local object as a low-frequency event.  The class-preserving test is the stricter code-layer comparison because it asks for persistence after respecting label-class information.
