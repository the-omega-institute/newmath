\subsection{Amino-Acid-Class-Preserving Null Test for the Window-Six Codon Tile}
\label{sec:bior-h0-null-model-aa-class-preserving}

\paragraph{Finite object under test.}
This record concerns the standard-code codon table as a code-layer object. The finite carrier is the six-coordinate codon cube $Q_6$, read through a standard codon-label table whose entries assign each codon either an amino-acid label or a stop label. The tested claim is not that the codon cube explains translation. It is that the window-six coordinate display exposes a local tile-and-boundary pattern whose labels can be compared against the curated standard-code table. The relevant row for the null model is $\mathrm{h0.null.model.aa\_class\_preserving}$, whose experiment run $\mathrm{e8d5de747a0c}$ used $N=2000$ amino-acid-class-preserving samples with seed $42$.

\paragraph{Observed boundary set.}
The finite boundary set $R$ is not inferred by verbal analogy; it is the recorded thirteen-codon set from $\mathrm{h0.R.cardinality.13}$ and $\mathrm{h0.R.punctured.cube}$:
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\mathrm{UAA},\\
&\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The recorded cardinality is $|R|=13$. The same finite row identifies this set as a punctured-cube shape with face-vector $(13,16,4)$. Thus the code-read comparison has a definite combinatorial target: thirteen labeled codons, sixteen local adjacencies, and four two-dimensional faces in the reported tile shape.

\paragraph{Null-model outcome.}
The amino-acid-class-preserving null test asks whether reshufflings that keep amino-acid class information intact reproduce the observed local shape. In the row $\mathrm{h0.null.model.aa\_class\_preserving}$, the observed marked region has size $20$. Among $2000$ class-preserving draws, the exact observed shape appears $0$ times. The lower-tail count at or below the observed marked size is $7$. The reported values are therefore
$$
\begin{aligned}
N&=2000,\\
\#\{\text{exact shape matches}\}&=0,\\
p_{\mathrm{exact}}&=0.0,\\
\#\{\text{lower-tail samples}\leq 20\}&=7,\\
p_{\mathrm{lower\ tail}}&=0.0035.
\end{aligned}
$$
This is the finite-row reason for treating the observed window-six pattern as non-generic under this particular null model. The conclusion is deliberately narrow: amino-acid-class preservation alone did not reproduce the recorded local tile shape in the sampled population.

\paragraph{Comparison with the unconstrained shape row.}
The separate row $\mathrm{h0.M.shape.significance}$ gives a useful scale check. With $N=2000$ and seed $42$, it records $57377$ distinct-sample attempts, $55377$ duplicate retries, $1$ exact shape match, and $25$ samples with Jaccard score at least $0.9$. The corresponding probabilities are $p_{\mathrm{exact}}=0.0005$ and $p_{J\geq 0.9}=0.0125$. The class-preserving null is therefore not merely repeating the same count: it reports zero exact matches and a lower-tail probability of $0.0035$ under a different constraint, while the broader shape row reports one exact match and a high-Jaccard rate of $0.0125$.

\paragraph{Spectral scale.}
The row $\mathrm{h0.spectrum}$ supplies a numerical spectral summary for the same finite code-read setting. It records $\lambda_M=0.6752479308830213$, $\lambda_R=0.4758352843197002$, and $\mu=3.051487585298128$. The cubic or radial consistency check is numerically small, with value $-6.224354365258478\times 10^{-12}$, and the spectral radius recorded in tolerance is $0.6752479308830213$. These numbers do not add a biological mechanism. They only state that the finite tile description also has a stable numerical spectrum at the code-label level.

\paragraph{Leave-one evidence.}
The leave-one-code-out row $\mathrm{h1.leave.one.code.out}$ evaluates $23$ code tables and $63$ total targets. Its baseline hit rate is $0.19821739130434785$, while the hit rate above baseline is $0.9841269841269841$. The rate inside $M-T$ is $0.9365079365079365$, and the rate inside $M-T$ plus boundary is again $0.9841269841269841$. The leave-one-codon-out row $\mathrm{h1.leave.one.codon.out}$ records $0$ anchors, $5$ boundary cases, $8$ high-coverage cases, $8$ predictable cases, and recovery rate $1.0$. These rows support a local predictive reading: when one codon or one code table entry is withheld, the finite code-level neighborhood often places the missing label back inside the marked or boundary region.

\paragraph{Family and module decomposition.}
The by-family row $\mathrm{h1.leave\_one\_code\_out.by\_family}$ records $5$ families. The reported family hit rates above baseline are $1.0$ for bacterial-plastid, candidate-other, mitochondrial, and nuclear-ciliate cases, and $0.8333333333333334$ for alternative-yeast cases. The module row $\mathrm{h1.leave\_one\_codon\_out.module\_classification}$ assigns all thirteen $R$ codons to six modules with no extras, no missing codons, and no unassigned codons. The modules are
$$
\begin{aligned}

\mathrm{ar\_lys}&=\{\mathrm{AAA}\},\\

The classification row reports $R_{\mathrm{size}}=13$ and $\mathrm{assigned\_count}=13$. Hence the boundary set is not only a list of codons; it is also fully partitioned into named finite modules in the recorded data.

\paragraph{Local contact with reality.}
The reality contact used here is the curated standard genetic-code table. It supports the statement that codons have code-layer labels in the standard table, and it permits finite checks of the local split described above. It does not observe ribosomal translation, protein folding, physical admissibility of a molecule, biological function, or a universal mechanism. Those would require different contacts with different measured objects. In particular, amino-acid label readback is not a folded protein structure, and a local codon tile is not a global biological law.

\paragraph{Scope of the claim.}
The ready claim is therefore this: within the six-coordinate codon display, the standard-code labels produce a thirteen-codon boundary tile whose punctured-cube face-vector is $(13,16,4)$, whose spectral summary includes $\lambda_M=0.6752479308830213$ and $\lambda_R=0.4758352843197002$, and whose amino-acid-class-preserving null sample gives $0$ exact matches in $2000$ draws with lower-tail probability $0.0035$. The claim remains at code-read level. No translation process, folded structure, physical admissibility statement, biological function, causal mechanism, or universality principle follows from this row unless a separate empirical contact supplies that higher-layer information.
