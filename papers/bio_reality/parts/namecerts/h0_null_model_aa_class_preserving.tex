\subsection{Amino-acid-class-preserving null test for the window-six codon tile}\label{sec:bioreality-aa-class-preserving-null}
\origin{ai}

\paragraph{Question.}
This record tests whether the window-six codon coordinate picture is merely an artifact of preserving amino-acid label classes in the standard code table.  The carrier is the six-bit codon cube $Q_6$, read through a curated standard-code table that assigns each codon an amino-acid or stop label.  The internal distinctions used here are the coordinate display, the induced closure operation, the spectral profile of the local split, and the relation between a singleton label corner and a three-point label class.  The biological contact is deliberately narrow: it is the codon-to-label table itself.  It does not observe translation as a cellular process, protein folding, physical admissibility, molecular function, a mechanism, or a universal biological law.

\paragraph{Observed boundary set.}
The distinguished residual set $R$ has cardinality $13$.  In the finite run it is exactly
$$\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}$$
The punctured-cube check returns the same set and records the face-vector data
$$\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}$$
Thus the code-layer phenomenon is not just a count: the same thirteen codons appear as a structured local boundary in the six-bit cube.  The observed marked set $M$ has size $20$ in the amino-acid-class-preserving null experiment; the supplied finite row gives this size but does not include a separate codon-by-codon listing of $M$.

\paragraph{Spectral profile.}
The corresponding spectral row reports
$$\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128.
\end{aligned}$$
The radial cubic check is numerically stable at the reported precision: both the cubic-polynomial residual and the radial-polynomial value are $-6.224354365258478\times 10^{-12}$.  The recorded spectral radius in tolerance is $0.6752479308830213$, matching $\lambda_M$ in the row.  This supports the claim that the local tile has a reproducible finite-coordinate signature, while still leaving the biological interpretation at the label-readout layer only.

\paragraph{Amino-acid-class-preserving null.}
The null model sampled $N=2000$ amino-acid-class-preserving rearrangements with seed $42$.  It produced no exact shape match:
$$\begin{aligned}
\#\{\text{exact shape matches}\}&=0,\\
p_{\mathrm{exact}}&=0.0.
\end{aligned}$$
The lower-tail statistic compares null samples with marked-set size at most the observed value $|M|=20$.  The finite row reports $7$ such samples, hence
$$\begin{aligned}
p_{\mathrm{lower\ tail}}=\frac{7}{2000}=0.0035.
\end{aligned}$$
Both the exact-shape value $0.0$ and the lower-tail value $0.0035$ are recorded as significant in this finite run.  The conclusion is not that the codon table must obey this geometry as a biological necessity.  The conclusion is more limited: after preserving amino-acid classes, the observed window-six tile remains unusually constrained relative to the sampled null ensemble.

\paragraph{Shape significance against an unrestricted sampled comparison.}
A related shape-significance run used $N=2000$ samples with seed $42$.  It required $57377$ distinct-sample attempts and incurred $55377$ duplicate retries.  The exact-shape count was $1$, giving
$$\begin{aligned}
p_{\mathrm{exact\ shape}}=0.0005.
\end{aligned}$$
The high-overlap count at Jaccard threshold $0.9$ was $25$, giving
$$\begin{aligned}
p_{J\geq 0.9}=0.0125.
\end{aligned}$$
These numbers agree with the narrower null result in the only sense needed here: the local tile is not a generic consequence of simply drawing comparable finite codon subsets.  They do not promote the tile into a statement about translation dynamics, protein structure, physical chemistry, or organism-level function.

This is evidence for a stable code-label readback pattern across the evaluated table variants.  It is not evidence that the local tile realizes a folding rule, a translation mechanism, or a universal biological principle.

The leave-one-codon-out row records $0$ anchors, $5$ boundary codons, $8$ predictable codons, closure coverage $8$, and recovery rate $1.0$. Every listed module has either predictable or boundary status in the finite row.  This gives a compact finite account of how the thirteen-codon residual set is partitioned by the observed local-tile behavior.

\paragraph{Interpretation.}
The amino-acid-class-preserving null result supports the following bounded statement.  In the standard-code label table, represented on the six-bit codon cube, the observed local boundary tile is rarer than expected under the sampled null that preserves amino-acid classes: $0$ exact matches among $2000$ samples and a lower-tail rate of $0.0035$ at observed size $20$.  The same packet is consistent with the independent thirteen-codon residual set, the punctured-cube face vector $(13,16,4)$, the spectral values $\lambda_M=0.6752479308830213$, $\lambda_R=0.4758352843197002$, $\mu=3.051487585298128$, and the leave-one-out recovery and module rows.

\paragraph{Local boundary of the claim.}
The contact used here is a curated code table, so the claim stops at codon-label readback and local finite-coordinate structure.  No conclusion is drawn about whether translation is physically realized by this geometry, whether a label sequence folds into a protein structure, whether any sequence is physically admissible, whether a protein has biological function, whether a mechanism is present, or whether the pattern is universal across biology.  Crossing any of those boundaries would require a separate observation at the relevant layer, not merely the codon-to-label table used in this record.
