\subsection{Amino-acid-class preserving null test for the codon boundary tile}\label{sec:biorality-h0-null-model-aa-class-preserving}
\origin{ai}

\paragraph{Claim.}
The finite object in this record is the standard-code codon table viewed through the six-coordinate codon cube $Q_6$.  The coordinate layer is not treated as a biochemical mechanism.  It is a finite display in which codons occupy vertices, local tile faces record adjacency, singleton label corners record isolated label behavior, and three-point label classes record small amino-acid or stop-label groupings.  The claim tested here is that the observed local boundary pattern is not reproduced by a null model that preserves amino-acid class sizes while randomizing the codon-to-label placement.  The biological contact is only the curated standard-code assignment of codons to amino-acid or stop labels.

\paragraph{Observed boundary set.}
The distinguished boundary set $R$ has cardinality $13$ and is exactly the following codon list:
$$\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}$$
The same row verifies that this set is the punctured-cube boundary pattern measured in the coordinate display, with face-vector
$$\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}$$
Thus the finite datum is not merely a count: it includes the full $13$-codon boundary list and its local two-dimensional incidence signature.

\paragraph{Unrestricted shape null.}
A broader shape-randomization experiment with $N=2000$ samples and seed $42$ records one exact shape match.  Its exact-shape probability is
$$\begin{aligned}
p_{\mathrm{exact}}=0.0005.
\end{aligned}$$
The same experiment reports $25$ samples with Jaccard similarity at least $0.9$, giving
$$\begin{aligned}
p_{J\geq 0.9}=0.0125.
\end{aligned}$$
The sampler attempted $57377$ distinct draws and rejected $55377$ duplicates, so the reported probabilities are attached to a concrete finite sampling run rather than to an asymptotic slogan.  This row supports the descriptive statement that the observed shape is rare under that sampling protocol.

\paragraph{Amino-acid-class preserving null.}
The claim-specific null model keeps amino-acid class sizes fixed.  In this stricter finite experiment, the observed $M$-size is $20$, the number of samples is $N=2000$, and the seed is again $42$.  The exact observed shape appears zero times:
$$\begin{aligned}
\#\{\text{exact matches}\}=0,\qquad p_{\mathrm{class},\mathrm{exact}}=0.0.
\end{aligned}$$
The lower-tail count at or below the observed $M$-size is $7$, hence
$$\begin{aligned}
p_{\mathrm{class},\mathrm{lower\ tail}}={7\over 2000}=0.0035.
\end{aligned}$$
Both reported significance fields equal the corresponding probabilities, namely $0.0$ for exact shape and $0.0035$ for the lower tail.  The finite conclusion is therefore narrow but sharp: among the $2000$ amino-acid-class preserving trials in this run, no trial recreated the exact local boundary shape, and only seven landed at or below the observed $M$-size.

These numbers are evidence that the coordinate tile is useful for code-layer recovery checks, but they remain checks against codon labels.

The leave-one-codon-out row reports no anchors, five boundary cases, eight high-coverage closure cases, eight predictable cases, and recovery rate $1.0$.  Written as finite counters,
$$\begin{aligned}
\mathrm{anchor}=0,\quad \mathrm{boundary}=5,\quad \mathrm{closure\ high}=8,\quad \mathrm{predictable}=8,\quad \mathrm{recovery}=1.0.

This again supports only the codon-label layer: the row says that omitted codons are recovered or classified within the finite code display, not that translation dynamics or protein structure has been measured.

\paragraph{Interpretation boundary.}
The contact used here is the curated standard-code table.  It observes that codons are assigned to amino-acid or stop labels; it does not observe translation realization, folded structure, physical admissibility, molecular function, a universal mechanism, or organism-wide necessity.  Therefore the result may be stated only as a code-read statement: the six-coordinate codon display exposes a rare local boundary tile under the recorded null models, and the curated label table lets that tile be read as a finite codon-label pattern.  No claim about protein folding, structure order, biochemical viability, biological function, translation machinery, or universality follows from these rows unless a separate observation supplies that higher-layer contact.
