\subsection{Curated interval contact for ORF eligibility}
\label{sec:bioreality-orf-eligibility-curated-interval-contact}

\paragraph{Claim scope.}
The record h2.orf\_eligibility.curated\_interval\_contact concerns a narrow biological layer: open-reading-frame eligibility as tested by start and stop codon interval enumeration against a curated genomic annotation table.  The biological object is not a protein, a transcript, a folded molecule, or a functional gene claim.  It is a finite interval-contact test for whether a frozen start/stop-window classifier agrees with externally curated CDS interval records in the supplied finite dataset.  The layer is therefore orf\_eligibility only.  No statement in this section asserts translation, folding, physical admissibility, biological function, mechanism, or universality; each of those would require a distinct contact carrying the relevant kind of observation.

\paragraph{Local conclusion.}
The finite row is ready at the orf\_eligibility layer.  It upgrades the earlier contact-gap packet into a curated-interval contact for the particular finite RefSeq-derived table, because the classifier was frozen before observation, the table has $168$ rows, the positive and decoy tests each have $72/72$ perfect outcomes with exact one-sided binomial value $2.117582368135751\times 10^{-22}$, the paired baseline comparison has $72/72$ wins with the same value, the $24$ boundary cases have no promotion, and all three held-out splits pass with $24$ positives and $24$ decoys each.
