\paragraph{Object and local scope.}
This record concerns only open-reading-frame eligibility as tested by a curated interval contact.  The biological object is not protein expression, folding, physical admissibility, mechanism, or function.  It is the narrower finite question of whether a start--stop interval, after a pre-specified start/stop-window enumeration, is supported by an external curated coding-sequence annotation.  The contact used here is the NCBI RefSeq GenBank XML CDS interval source for \emph{Escherichia coli} K-12 MG1655 complete genome accession NC\_000913.3, with snapshot date 2026-05-30.  The dataset contains $168$ rows, divided into the required input classes $\{\mathrm{boundary\_case},\mathrm{matched\_non\_orf\_decoy},\mathrm{positive\_curated\_orf}\}$.  The analysis was locked before observing the external evidence: the protocol time was 2026-05-29T19:11:13+00:00, while the external evidence time was 2026-05-30T10:29:31+00:00.  The classifier identifier is $\mathrm{orf\_start\_stop\_window\_eligibility}$, and the recorded classifier-rules-modified flag is false.
