\subsection{Curated interval contact for ORF eligibility}\label{sec:h2-orf-eligibility-curated-interval-contact}
\origin{ai}

\paragraph{Claim and local scope.}
This record concerns the layer named \emph{ORF eligibility}: the finite question whether a nucleotide interval is accepted by a start--stop codon enumeration rule after an observed interval has been supplied by a curated biological annotation. The claim is deliberately narrow. It does not say that a transcript is expressed, that a peptide is translated, that a protein folds, that the molecule is physically admissible, that a function is present, that a mechanism has been found, or that a universal biological law has been isolated. The only asserted contact is the finite comparison between a predeclared geometry-only classifier and a curated interval table drawn from NCBI RefSeq GenBank XML CDS intervals for \emph{Escherichia coli} K--12 MG1655 complete genome accession NC\_000913.3, with snapshot date 2026--05--30.

\paragraph{Finite codon geometry before contact.}
The upstream codon packet fixes the alphabetic substrate used by the start--stop enumeration. The motif-compressed set is
$R=\{\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}$,
with no missing and no extra entries against the recorded motif union. The ambient set $M$ has cardinality $20$ and is exactly
$\{\mathrm{AAA},\mathrm{AAG},\mathrm{ACA},\mathrm{ACG},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{AUG},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UCG},\mathrm{UGA},\mathrm{UGG},\mathrm{UUA},\mathrm{UUG}\}$.
The saturation check records
$\mathrm{Sat}_{f3}(R)=M\setminus\{\mathrm{ACA},\mathrm{ACG}\}$, so the saturated list is
$\{\mathrm{AAA},\mathrm{AAG},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{AUG},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UCG},\mathrm{UGA},\mathrm{UGG},\mathrm{UUA},\mathrm{UUG}\}$,
while the recorded $f3$ boundary set is empty. The quotient geometry is also finite: the $M$ face vector is $(20,38,26,8,1)$, the quotient face vector is $(10,14,6,1)$, and $|\pi(M)|=10$. These figures are geometry facts only; by themselves they do not supply an observed gene interval.

\paragraph{Protocol and observed table.}
The protocol was frozen at 2026--05--29T19:11:13+00:00, before the external evidence was observed at 2026--05--30T10:29:31+00:00. The input classes, held-out splits, baselines, and classifier rules were fixed before that observation. The classifier identifier was \texttt{orf\_start\_stop\_window\_eligibility}; its rules were not modified during the contact check, and the analysis used no translation or structure input. The curated interval dataset was loaded from \texttt{tools/bio\_reality/data/curated\_orf\_interval\_contact\_dataset.json}. It contains $168$ rows, partitioned into the required input classes \texttt{positive\_curated\_orf}, \texttt{matched\_non\_orf\_decoy}, and \texttt{boundary\_case}. The earlier window manifest check had loaded one external start--stop window, classified that one window by start/stop enumeration, and kept the scope at \texttt{external\_window\_start\_stop\_enumeration\_only}; this chapter uses the larger curated interval contact, whose scope is \texttt{external\_orf\_interval\_contact\_only}.

\paragraph{Positive, decoy, and boundary outcomes.}
The contact table gives $72$ positive curated intervals and $72$ matched non-ORF decoys. All $72$ positives were accepted by the frozen classifier, and all $72$ matched decoys were rejected. The exact one-sided binomial upper-tail value recorded for the positive acceptance statistic is $2.117582368135751\times 10^{-22}$, and the same value is recorded for the matched decoy rejection statistic. The predeclared paired baseline comparison has $72$ wins in $72$ pairs, hence win rate $1.0$, again with exact one-sided binomial upper-tail value $2.117582368135751\times 10^{-22}$. The boundary class contains $24$ cases; $0$ were promoted, so the promotion fraction is $0.0$. In compact form, the contact result is
$$
\begin{aligned}
\mathrm{positive\ accepted} &= 72/72,\\
\mathrm{matched\ decoy\ rejected} &= 72/72,\\
\mathrm{paired\ baseline\ wins} &= 72/72,\\
\mathrm{boundary\ promoted} &= 0/24.
\end{aligned}
$$
Thus the observed row-level evidence supports only this finite eligibility discrimination on the curated table.

\paragraph{Held-out split stability.}
The held-out split audit used three named folds. On \texttt{refseq\_nc\_000913\_left\_locus\_fold}, the positive count was $24$ with positive accept rate $1.0$, and the decoy count was $24$ with decoy reject rate $1.0$. The same numbers were recorded for \texttt{refseq\_nc\_000913\_middle\_locus\_fold} and \texttt{refseq\_nc\_000913\_right\_locus\_fold}. All three splits passed. This matters because the result is not merely a single pooled count: each of the three locus folds preserves the same finite separation between curated positives and matched decoys.

\paragraph{Interpretive boundary.}
The contact upgrades the packet from a contact-gap seed to a finite external-annotation eligibility result, but it does not move the claim into higher biological layers. The NCBI RefSeq annotation remains curated biological input rather than kernel content of the coordinate system. The matched decoy and boundary controls do not classify windows outside the loaded dataset. No conclusion about translation realization, folded structure, physical admissibility, biological function, biochemical mechanism, organism-level role, or universality follows from these counts. Any such assertion would require a separate contact appropriate to that layer, such as transcript evidence for expression, peptide evidence for translation, structure evidence for folding, physicochemical evidence for admissibility, or functional perturbation evidence for role. The self-check records this same gate explicitly: three checks passed while preserving the boundary that codon geometry is not promoted across biological layers.
