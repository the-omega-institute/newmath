\subsection{Curated interval contact for open-reading-frame eligibility}
\label{sec:bior-orf-eligibility-curated-interval-contact}

\paragraph{Finite object under test.}
The object tested here is not translation, protein production, folding, biochemical activity, or fitness. It is the narrower eligibility question obtained when a nucleotide interval is compared with a frozen start--stop codon classifier. The contact is a curated interval table from NCBI RefSeq GenBank XML CDS intervals for \emph{Escherichia coli} K-12 MG1655 complete genome accession NC\_000913.3, with snapshot date 2026-05-30. The loaded table has $168$ rows from the file path \texttt{tools/bio\_reality/data/curated\_orf\_interval\_contact\_dataset.json}. Its declared input classes are \texttt{positive\_curated\_orf}, \texttt{matched\_non\_orf\_decoy}, and \texttt{boundary\_case}. The frozen classifier is \texttt{orf\_start\_stop\_window\_eligibility}; its rules were not modified after the contact was observed.

\paragraph{Protocol chronology.}
The analysis protocol was fixed before the external curated table was inspected. The protocol timestamp is 2026-05-29T19:11:13+00:00, while the external evidence timestamp is 2026-05-30T10:29:31+00:00. The recorded protocol flags say that the input classes, classifier rules, held-out splits, and baselines were fixed in advance, and that the analysis used no translation or structural input. Thus the test is a contact test for interval eligibility only: a curated positive interval must be accepted by the start--stop window rule, a matched non-ORF decoy must be rejected by the same rule, and a boundary case must not be promoted into a positive biological assertion.

\paragraph{Curated interval results.}
The contact contains $72$ positive curated ORF intervals and $72$ matched non-ORF decoys in the strong paired test. All $72$ positives were accepted, giving accept rate $1.0$ and exact one-sided binomial upper-tail value $2.117582368135751\times 10^{-22}$. All $72$ decoys were rejected, giving reject rate $1.0$ with the same exact one-sided binomial upper-tail value $2.117582368135751\times 10^{-22}$. The predeclared paired baseline comparison has $72$ wins out of $72$ pairs, win rate $1.0$, and exact one-sided binomial upper-tail value $2.117582368135751\times 10^{-22}$.

\paragraph{Held-out split stability.}
The contact was also checked across three frozen held-out splits. In \texttt{refseq\_nc\_000913\_left\_locus\_fold}, $24$ positives were accepted at rate $1.0$ and $24$ decoys were rejected at rate $1.0$. The same $24$--$24$ perfect positive and decoy rates hold in \texttt{refseq\_nc\_000913\_middle\_locus\_fold} and \texttt{refseq\_nc\_000913\_right\_locus\_fold}. Each split is marked as passed. The boundary control has $24$ cases, $0$ promoted cases, and promoted fraction $0.0$.

\paragraph{Earlier window check.}
A smaller start--stop window enumeration check, dated 2026-05-25, loaded one external window record and classified one input window. Its recorded scope was \texttt{external\_window\_start\_stop\_enumeration\_only}, and it explicitly marked the output as \texttt{orf\_eligibility\_only}. This earlier check supports the same separation used here: start--stop enumeration can classify a window with respect to the frozen eligibility rule, but it is not a claim that translation, folding, physical realization, or function has occurred.

\paragraph{Local conclusion.}
Within the finite contact table and the frozen classifier just described, the observed row-level result is strong: positives are accepted, matched decoys are rejected, three held-out folds are stable, and boundary cases remain unpromoted. The supported claim is therefore restricted to curated-interval ORF eligibility for this dataset and this classifier. No translation event, folded protein structure, physical admissibility, molecular mechanism, biological function, organism-level consequence, universal genomic law, or classification of windows outside the table follows from these rows. Any such stronger assertion would require a separate contact carrying the relevant biological observation.
