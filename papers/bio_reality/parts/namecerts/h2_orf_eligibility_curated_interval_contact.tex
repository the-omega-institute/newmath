\paragraph{Finite biological question.}
This record concerns the narrow layer called open-reading-frame eligibility.  The biological object is not a translated protein, a folded molecule, a biochemical mechanism, or a functional annotation.  It is the finite question whether a nucleotide interval supplied by a curated sequence annotation is accepted by a start/stop-window eligibility rule whose inputs are restricted to interval boundaries and codon enumeration.  The contact used here is an NCBI RefSeq GenBank XML CDS interval collection from \textit{Escherichia coli} K-12 MG1655, complete genome accession NC\_000913.3, with snapshot date 2026-05-30.  The loaded file is \texttt{tools/bio\_reality/data/curated\_orf\_interval\_contact\_dataset.json}; it contains $168$ rows and exactly the three declared input classes $\{\text{boundary\_case},\text{matched\_non\_orf\_decoy},\text{positive\_curated\_orf}\}$.

\paragraph{Pre-observation protocol.}
The eligibility classifier was the rule system named \texttt{orf\_start\_stop\_window\_eligibility}.  Its rules were fixed before the curated intervals were inspected: the protocol time was 2026-05-29T19:11:13+00:00, while the external curated evidence was first observed at 2026-05-30T10:29:31+00:00.  The analysis used no translation evidence and no structural evidence; the baselines, held-out splits, and input classes were also fixed in advance.  Thus the reported contact tests a finite interval classifier against curated interval rows, rather than fitting the classifier after seeing the annotations.
