The biological object is open-reading-frame eligibility, not translation and not protein formation. The packet begins from a boundary seed: a start/stop window can specify what kind of biological interval would have to be checked, but the window itself is not an observation of an open reading frame. The earlier start/stop-window run loaded one external finite nucleotide-window manifest with one input window and classified that one window by start/stop enumeration only. That earlier run fixed the scope as \texttt{external\_window\_start\_stop\_enumeration\_only}; the present contact refines the test to curated ORF interval contact and keeps the scope at \texttt{external\_orf\_interval\_contact\_only}.
