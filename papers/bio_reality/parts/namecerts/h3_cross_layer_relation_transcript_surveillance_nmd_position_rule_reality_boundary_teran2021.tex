\subsection{Transcript-surveillance position rule as an RNA-stability boundary}
\label{sec:bioreality-transcript-surveillance-nmd-position-rule-teran2021}

\paragraph{Finite row carrier.}
The record treats a coding-transcript surveillance claim as a finite matched-row question rather than as a general rule about protein output or organismal fitness.  A row is a synonymously addressable coding-RNA window with a coordinate label, amino-acid composition control, same-row translation readout when available, RNA half-life or decay readout, transcript abundance control, transcription-rate control when present, isoform state, batch, local sequence composition, codon-pair context, motif density, and local RNA-structure covariates.  The intended positive bridge is narrower than an RNA-stability association: the same rows would also need measured local occupancy of a prespecified decay-factor RNA-binding protein, target-factor loss, restoration by wild-type rescue, failure of restoration under a binding-defective or non-target control, and a declared break condition for coordinate--occupancy decoupling.  Without those rows, the object remains a transcript-surveillance boundary surface.

\paragraph{Audited finite contact.}
For the primary audit key \texttt{h3.cross\_layer\_relation.transcript\_surveillance.nmd\_position\_rule\_reality\_boundary\_teran2021}, the verified run \texttt{c362df6daa98} retained $38576$ joined rows and used $1000$ permutations; the runtime was $55.602$ seconds.  These numbers certify that the record is not an ungrounded narrative claim: it has a finite transcript-surveillance table and a declared permutation depth.  They do not by themselves identify an RBP mechanism, because the verified payload does not include measured decay-factor occupancy, loss-of-factor rows, rescue rows, or binding-defective controls.  The correct reading is therefore a bounded position-rule contact with an RNA-stability readout, not a mechanism assignment.

\paragraph{Coordinate and boundary statement.}
Let $q$ denote the finite coordinate label on a coding window, $H$ the RNA half-life or decay readout, $T$ the same-row translation readout when supplied, $A$ the transcript-abundance or transcription control surface, $C$ the local covariate bundle, and $B$ the measured decay-factor RBP occupancy surface.  The licensed bridge would require the following finite separation pattern:
$$
\begin{aligned}
q &\leadsto B,\\
B &\leadsto H,\\
\text{target-factor loss} &\text{ collapses the } H \text{ pattern},\\
\text{wild-type rescue} &\text{ restores it},\\
\text{binding-defective or non-target rescue} &\text{ does not restore it},\\
T,A,C &\text{ remain recorded as controls rather than promoted outcomes.}
\end{aligned}
$$
The Teran-surveillance row set supplies the finite RNA-stability side of this pattern, but the supplied verified fields stop before the occupancy and perturbation requirements.  Thus the chapter records a real boundary hit for transcript surveillance and refuses the stronger decay-factor RBP bridge.

\paragraph{Calibration against adjacent RNA-stability rows.}
Two linked RNA-stability audits show how the boundary behaves when richer scalar data are present.  The m6A site-load half-life row \texttt{h3.cross\_layer\_relation.rna\_modification.m6a\_site\_load\_mrna\_halflife\_boundary\_gse163500} retained $5837$ genes, reported a static Spearman value of $-0.388929$ between m6A load and DMSO log half-life, a causal Spearman value of $0.245804$ for m6A load against the change in log half-life, a length-partial Spearman value of $0.227683$, and a two-sided partial permutation value of $0.000999001$.  The ARE deletion row \texttt{h3.cross\_layer\_relation.utr3\_are.are\_deletion\_mrna\_stability\_boundary\_siegel2022} used $1000$ actual permutations, $2000$ grading permutations, $226$ BEAS2B rows, and $2242$ Jurkat rows, with sign concordance marked true.  These neighboring rows illustrate the intended standard: scalar evidence may support a bounded RNA-stability boundary, while mechanism language still requires the matching perturbation and molecular-contact rows.

\paragraph{Local refusal conditions.}
If high-coordinate and low-coordinate synonymous labels become exchangeable for RNA half-life after controlling transcription rate, local RNA structure, motif density, GC and dinucleotide composition, codon-pair context, splice or isoform state, transcript abundance, amino-acid composition, and batch, the coordinate is only a descriptor.  If RNA half-life changes but measured local decay-factor RBP occupancy is absent or unchanged, the record is only an RNA-stability association.  If target-factor loss does not collapse the pattern, if wild-type rescue does not restore it, or if a binding-defective or non-target control reproduces the effect, the RBP bridge is rejected.  If the same pattern is explained by transcriptional rate, abundance, isoform mixture, local structure, motif density, codon-pair context, batch, or composition, the row cannot be read as coordinate-directed RNA decay.

\paragraph{Layer boundary.}
The local conclusion is deliberately modest.  The finite Teran-position audit establishes a transcript-surveillance RNA-stability boundary with $38576$ retained rows and a $1000$-permutation finite test.  It does not establish translation realization, ribosome dynamics, protein abundance, folded structure, physical admissibility, biological function, system phenotype, adaptation, causation, mechanism, or a universal biological law.  Those interpretations would require a separate layer-matched contact with its own rows and statistic.  In particular, a same-row translation readout is a boundary condition for not confusing RNA decay with translation, not evidence that the RNA half-life result has become a protein-level or function-level result.
