\subsection{Translation-conditioned RNA half-life as a bounded RBP-occupancy problem}
\label{sec:bioreality-q6-translation-conditioned-rna-half-life-rbp-bridge}

\paragraph{Finite carrier.}
The record considered here is a finite matched panel whose rows are indexed by coding transcript windows after amino-acid quotienting.  Each row carries a synonymous residual coordinate label $q \in B^{*}_{Q6}$, a same-row translation readout $T$, an RNA half-life readout $H$, matched transcription and abundance controls, and a declared slot for a measured decay-factor RBP occupancy value $O$.  The intended row type is not a sequence-law object: it is a controlled table in which high-coordinate and low-coordinate synonymous labels can be compared only after amino-acid sequence, transcription rate, local RNA structure, motif density, GC and dinucleotide composition, codon-pair context, splice or isoform state, transcript abundance, batch, and the same-row translation readout have been represented in the row.

\paragraph{Observed finite contacts.}
The local evidence ledger contains a completed run for the named DNA-mechanics entry, with experiment run id \texttt{f8464f8328f6} and runtime $196.505904$ seconds.  That entry supplies no row count, no list of $R$ values, no list of $M$ values, no fitted $\lambda$, no $p$-value, no module class, and no hit-rate for the RNA half-life/RBP panel.  For calibration of nearby contact surfaces, the RBP-binding contact \texttt{h3.cross\_layer\_relation.rbp\_binding.rbns\_affinity\_eclip\_binding\_encode} records $900$ total peaks and $3$ cross-RBP concordant cases in run \texttt{b225890251c2}.  The translation readout contact \texttt{h3.cross\_layer\_relation.mtor\_translation.topscore\_mtor\_translation\_thoreen2012} records $n=6494$ rows from the GEO source \texttt{GSE36892\_RAW.tar}.  A separate RNA-modification contact, \texttt{h3.cross\_layer\_relation.rna\_m6am\_methylation.m6am\_flanking\_identity\_stoichiometry\_crownseq}, records $n=31886$, $19406$ distinct sites, $3230$ low-tail sites with value below $0.8$, a saturated fraction $0.343223$ at threshold $0.95$, $20942$ variable-subset rows, cross-cell concordance, partial correlations $0.268094$, $0.098666$, and $0.168335$ on the listed subsets, and a GC-matched null value $p=0.000833$.  These numbers show that finite biological surfaces can be parsed and audited in this corpus, but they do not fill the missing same-window RBP perturbation panel for the present RNA half-life claim.

\paragraph{Null model.}
Let $Q_i$ denote the residual-coordinate label on row $i$, $T_i$ the same-row translation readout, $H_i$ the RNA half-life readout, $O_i$ the measured local occupancy of the prespecified decay-factor RBP, and $Z_i$ the vector of ordinary controls.  The matched null is the exchangeability assertion
$$
\begin{aligned}
H_i \perp Q_i \mid T_i, Z_i
\end{aligned}
$$
for high-coordinate and low-coordinate synonymous labels after the amino-acid quotient.  A nonzero association between $Q_i$ and $H_i$ is therefore not enough.  The RBP-mediated interpretation requires the finite table to show a coordinated pattern: the local occupancy $O_i$ must move with the coordinate contrast after the same controls, experimental decoupling must separate coordinate from occupancy, target-RBP loss must collapse the half-life effect, wild-type target-RBP rescue must return it, and binding-defective or non-target controls must fail to return it.

\paragraph{Admissible bridge statistic.}
The smallest admissible positive statistic is a paired finite readback of the form
$$
\begin{aligned}
\Delta_H &= \widehat{H}(Q=\mathrm{high})-\widehat{H}(Q=\mathrm{low}),\\
\Delta_O &= \widehat{O}(Q=\mathrm{high})-\widehat{O}(Q=\mathrm{low}),\\
C_{\mathrm{loss}} &= \Delta_H^{\mathrm{target\ loss}},\\
C_{\mathrm{wt}} &= \Delta_H^{\mathrm{wild\ type\ rescue}},\\
C_{\mathrm{bad}} &= \Delta_H^{\mathrm{binding\ defective\ or\ non\ target\ rescue}}.
\end{aligned}
$$
The bounded RBP claim is licensed only when $\Delta_H$ remains after $T$ and $Z$ conditioning, $\Delta_O$ is observed for the prespecified decay-factor RBP, $C_{\mathrm{loss}}$ collapses toward the matched null, $C_{\mathrm{wt}}$ returns toward the original effect, and $C_{\mathrm{bad}}$ does not return it.  If any one of these finite checks is absent, the row set can at most support an RNA-stability association or a coordinate descriptor.  It cannot be read as a decay-factor RBP mechanism.

\paragraph{Present verdict of the row set.}
The available rows do not contain the same-organism, same-window tuple $(Q_i,T_i,H_i,O_i,Z_i)$ together with target-RBP loss, wild-type rescue, and binding-defective or non-target rescue.  The local half-life contacts are transcript or gene half-life surfaces; the translation contact supplies a ribosome or translation-efficiency boundary; the mRNA contact supplies a transcription-layer denominator or abundance control.  None of these contacts is itself a measured local decay-factor RBP occupancy panel, and none is a perturbation/rescue matrix.  Consequently the present chapter records a precise negative boundary: translation-conditioned RNA half-life can be asked on finite rows, but a positive RBP-bridge reading is not obtained from the supplied data.

\paragraph{What is not licensed.}
No translation realization follows from RNA half-life alone.  No RNA-decay mechanism follows from the mere presence of a same-row translation readout.  No decay-factor RBP interpretation follows if local RBP occupancy is unchanged, if coordinate and occupancy are not experimentally decoupled, if target-RBP loss fails to collapse the effect, or if wild-type rescue and binding-defective or non-target controls do not separate.  RNA-structure-only, motif-density-only, transcription-rate, isoform-state, transcript-abundance, GC/dinucleotide, codon-pair-context, and batch explanations remain live until defeated inside the same finite panel.  The row geometry also does not imply protein output, protein folding, physical admissibility, biological function, system phenotype, adaptation, causation, or universality; each of those readings would require its own layer-matched measurement surface and statistic.
