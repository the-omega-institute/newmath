\subsection{Cross-dataset sgRNA position signal and the bounded reality contact}
\label{sec:bioreality-crispr-efficiency-sgrna-position-crossdataset-luo2020}

\paragraph{Finite-row carrier.}
This record concerns a finite table of CRISPR guide observations in which each row is keyed by an sgRNA sequence, a position-resolved nucleotide description, and an efficiency readout.  The row carrier is not a molecular-mechanism claim.  It is a bounded empirical surface: position-indexed guide-sequence coordinates are tested against observed CRISPR efficiency after the data have been separated from unrelated translation, protein-folding, and phenotype layers.  The cross-dataset contact is anchored by the Luo panel with $n_{\mathrm{Luo}}=10543$ rows.  The run certificate reports cross-protocol status as true, uses the Doench2016 repository as the frozen source, and records runtime $33.705459$ seconds for the Luo cross-dataset computation.

\paragraph{Primary coordinate.}
For a guide $g$ and a position $p$, write $x_{p,b}(g)$ for the finite indicator that base $b$ is observed at position $p$ in $g$.  The chapter only uses such coordinates as row-level predictors of the measured guide-efficiency surface.  The admissible statistic is therefore a controlled survival entry of the form
$$
\begin{aligned}
S_{p,b}(E\mid Z)
  &= \Delta\mathcal{Q}\bigl(E; x_{p,b} \mid Z, \mathcal{B}\bigr),
\end{aligned}
$$
where $E$ is the guide-efficiency readout, $Z$ denotes the attached controls, and $\mathcal{B}$ denotes simpler baselines that do not use the tested position-nucleotide coordinate.  The notation is local to this chapter: a positive entry means that the tested position/base coordinate improves the finite guide-efficiency description relative to the declared controls and baseline, not that it explains Cas9 binding chemistry or downstream cellular outcome.

\paragraph{Cross-protocol evidence.}
The cross-dataset row set is explicitly marked as cross-protocol.  This matters because a position-nucleotide signal that is only visible inside one measurement protocol may be a library, normalization, or assay-design artifact.  The Luo-side run contains $10543$ rows and is paired with a frozen Doench2016 source.  The linked Doench2016 finite-row run contains $n=5310$ guide rows, reports a GC main correlation $r=-0.0582917$, and records runtime $24.6506$ seconds.  These numbers give two concrete row surfaces for the same scientific boundary: the coordinate can be discussed as a reproducible guide-efficiency predictor only insofar as it survives movement between the Doench source surface and the Luo cross-protocol surface.

\paragraph{Controlled interpretation.}
The local empirical claim is deliberately narrow.  The admissible reading is that position-resolved sgRNA nucleotide coordinates can be evaluated as finite predictors of CRISPR efficiency across a Luo cross-dataset panel, with the Doench2016 source serving as the frozen reference surface.  The observation that the Doench run has $r=-0.0582917$ for the GC main coordinate prevents a careless simplification in which all guide-efficiency structure is reduced to a single GC effect.  The finite claim is instead about whether position-indexed nucleotide information retains predictive rank after simpler summaries such as GC content are available.  The Luo run supplies the larger cross-protocol row count, $10543$, while the Doench run supplies the linked source count, $5310$.

\paragraph{Reality boundary.}
Nothing in this chapter converts the sgRNA position coordinate into a statement about translation, ribosome occupancy, protein abundance, folding, physical admissibility, molecular function, mechanism, phenotype, or universality.  Those layers require separate row contacts.  In particular, modeled codon-adaptation weights, mRNA abundance controls, ribosome-footprint rows, protein-localization rows, protein-abundance rows, and structure or perturbation assays are not supplied by the CRISPR efficiency table.  The sgRNA result remains a guide-design readout: it may say that a finite position-nucleotide coordinate helps predict guide efficiency across the declared panels, but it does not say why the molecular complex behaves as it does, and it does not license transfer to protein-level or translation-level biology.

\paragraph{Break condition.}
The chapter would fail as a BioReality record if the cross-protocol flag were absent, if the Luo row panel were not joined to the declared source route, or if the asserted coordinate were promoted from guide-efficiency prediction to mechanism.  A stronger empirical claim would require held-out improvement values, explicit per-position effect lists, uncertainty estimates, and control-by-control ablation results.  Those values are not present in the finite-row certificate supplied here.  Consequently the present record is ready only as a bounded cross-dataset CRISPR-efficiency chapter: $n_{\mathrm{Luo}}=10543$, Doench source frozen, cross-protocol true, linked Doench row count $5310$, and no higher-layer biological promotion.
