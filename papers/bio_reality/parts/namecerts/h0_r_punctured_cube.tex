The biological reading is deliberately narrower than a mechanistic claim: these codons are read through a curated standard-code table that assigns amino-acid or stop labels, and the table supplies code-level labels only.

\paragraph{Randomization checks.}
The shape-significance run used $N=2000$ null samples with seed $42$. It required $57377$ distinct-sample attempts and incurred $55377$ duplicate retries. Among those samples there was $1$ exact shape match, giving $p_{\mathrm{exact}}=0.0005$, and there were $25$ matches at Jaccard threshold at least $0.9$, giving $p_{J\geq 0.9}=0.0125$. A second null model preserving amino-acid class also used $N=2000$ and seed $42$. In that run the observed comparison size was $20$, the exact-shape count was $0$, the lower-tail count at or below the observed size was $7$, the exact-shape value was $p=0.0$ at the displayed finite precision, and the lower-tail value was $p=0.0035$. These two randomization rows make the local pattern difficult to dismiss as an arbitrary relabeling artifact under the tested finite procedures. They still remain code-table tests: the computation evaluates codon-label geometry and does not observe ribosomal realization, molecular structure, thermodynamic feasibility, or organismal function.

\paragraph{Scope of the contact.}
The standard-code table is a curated code-label contact: it says which codon is read as which amino-acid label or stop label in the standard code. It does not contain a folded-protein observation, a translation experiment, a structural assay, a physical-admissibility test, a functional assay, or a universal-law measurement. Consequently, this chapter licenses only the following claim: in a six-bit codon coordinate display, the thirteen-codon set $R$ forms a reproducible local punctured-cube pattern with finite incidence vector $(13,16,4)$, nontrivial spectral statistics, significant shape behavior under the stated null procedures, and strong leave-one-out recovery at the code-label layer. Any statement about translation realization, protein folding, structural order, physical feasibility, biological function, global mechanism, or universality requires an additional observational contact not present in this finite row.
