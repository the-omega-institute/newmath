\subsection{The punctured cube packet for the standard-code read layer}
\label{subsec:h0-r-punctured-cube}
\origin{ai}

\paragraph{Finite carrier and observed row.}
This packet treats the standard genetic-code table only as a finite codon-to-label contact.  The carrier is the six-coordinate codon cube $Q_6$, where each codon is read as a six-bit window after the nucleotide display has been fixed.  The distinguished row $R$ is the thirteen-codon set
$$
\begin{aligned}
R = \{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
     &UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The direct cardinality audit gives $|R|=13$, with the same ordered row reported by the independent cardinality run.  The punctured-cube audit identifies this row with a local cube-shaped boundary pattern whose face data have $f$-vector
$$
\begin{aligned}
f(R)=(13,16,4).
\end{aligned}
$$
Thus the packet is not merely a list of exceptional codons: it has a concrete finite incidence profile, thirteen vertices, sixteen one-dimensional boundary incidences, and four two-dimensional faces in the chosen window-six coordinate system.

\paragraph{Code-read meaning of the row.}
The read layer is deliberately narrow.  The curated standard-code table supplies the assignments from codons to amino-acid or stop labels, so the row can be tested against label splits and local boundary behavior.  It does not supply translation dynamics, ribosomal realization, tertiary structure, physical admissibility, biological function, or a universal mechanism.  Any claim crossing one of those lines would require a separate contact with the corresponding observation type.  In this packet the biological object is therefore the standard-code codon table as a label table, not a protein-production theory.

\paragraph{Spectral and shape checks.}
The spectrum run reports two label-side radii and one radial parameter:
$$
\begin{aligned}
\lambda_M &= 0.6752479308830213,\\
\lambda_R &= 0.4758352843197002,\\
\mu &= 3.051487585298128.
\end{aligned}
$$
The cubic consistency residual is $-6.224354365258478\times 10^{-12}$, the same value recorded for the radial polynomial residual, so the numerical certificate is at floating-point tolerance rather than at a visible macroscopic error scale.  The shape-significance run used $N=2000$ sampled alternatives with seed $42$.  It saw one exact shape match, giving $p_{\mathrm{exact}}=0.0005$, and twenty-five high-overlap matches at Jaccard threshold $0.9$, giving $p_{J\geq 0.9}=0.0125$.  The sampler needed $57377$ distinct-sample attempts and recorded $55377$ duplicate retries, so the finite null comparison is visibly constrained by the combinatorics of the sample space.  Even with that constraint, the observed row is rare under the sampled coordinate-preserving comparison.

\paragraph{Amino-acid-class preserving null.}
A second null keeps amino-acid class information fixed while testing whether the same shape is forced by the label inventory alone.  In $N=2000$ trials with seed $42$, the exact-shape count was $0$, so the finite-sample exact-shape estimate was $0.0$.  The same run reports observed $M$-size $20$ and a lower-tail count of $7$, giving $p_{\mathrm{lower}}=0.0035$.  This separates the packet from the trivial explanation that a twenty-label code table automatically produces the observed local tile.  The result is still a finite-row comparison, not a causal explanation of why the biological code has the observed labels.

\paragraph{Leave-one tests.}
The leave-one-code-out run evaluated $23$ code tables and $63$ total targets.  Its baseline hit rate was $0.19821739130434785$, while the hit rate above baseline was $0.9841269841269841$.  The hit rate inside $M\setminus T$ was $0.9365079365079365$, and the rate after adjoining the boundary was again $0.9841269841269841$.  The leave-one-codon-out run reports no anchors, five boundary cases, eight high-coverage closure cases, and eight predictable cases, with recovery rate $1.0$.  These numbers support a local recovery pattern for the code-read row.  They do not say that omitted codons are recovered by an organismal process; they say that the finite coordinate-and-label packet has strong internal recovery behavior against the curated table contact.

\paragraph{Family and module resolution.}
The family-level leave-one-code-out audit splits the $23$ evaluated tables into five families.  The hit-rate-above-baseline values are $0.8333333333333334$ for alternative yeast, and $1.0$ for bacterial or plastid tables, candidate-other tables, mitochondrial tables, and nuclear-ciliate tables.  The module classification accounts for all thirteen row codons with no missing members, no extra module codons, and no unassigned codons.  The assigned modules are
$$
\begin{aligned}
\mathrm{agr} &= \{AGA, AGG\},\\
\mathrm{ar\_lys} &= \{AAA\},\\
\mathrm{cun} &= \{CUA, CUC, CUG, CUU\},\\
\mathrm{ile\_met} &= \{AUA\},\\
\mathrm{ssn} &= \{UCA, UUA\},\\
\mathrm{stop\_trp} &= \{UAA, UAG, UGA\}.
\end{aligned}
$$
Every module has either predictable or boundary support in the reported classification.  This is the strongest local statement made by the packet: the punctured-cube row is a finite, module-complete, code-label boundary pattern in the standard-code read layer.

\paragraph{Local verdict.}
The packet is ready as a code-read claim.  The row $R$ is fixed, its cardinality is $13$, its punctured-cube face vector is $(13,16,4)$, the spectral residual is numerically negligible at the recorded precision, the exact-shape and high-Jaccard null comparisons are small, and the leave-one tests give high recovery against the curated code table.  The conclusion remains bounded: a local codon tile is observed in a six-bit display of the standard-code label table.  No statement about translation, folding, physical admissibility, function, mechanism, or universality follows from these rows alone.
