\subsection{Punctured-cube codon boundary}
\label{sec:h0-r-punctured-cube}

\paragraph{Finite object.}
The record concerns the standard-code codon table only at the label-read layer.  The carrier is the six-coordinate codon cube, with each codon read as a finite word over the RNA alphabet and compared through the window-six coordinate display.  The distinguished row set is
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The verified cardinality computation gives $|R|=13$, and the independent punctured-cube check returns the same thirteen rows.  Its cell structure has $f$-vector $(13,16,4)$: thirteen selected vertices, sixteen selected one-dimensional adjacencies, and four selected square faces.  This is the finite shape under discussion.  It is not being promoted to a law of coding, translation, or molecular realization.

\paragraph{Local geometry.}
The punctured-cube description says that the selected codons form a boundary-like local tile inside the six-bit display.  The evidence is intentionally small and row-level: it separates singleton-corner behavior from a three-point label class while preserving the surrounding codon-table labels as curated data.  The list contains the stop-associated block $\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}$, the arginine block $\{\mathrm{AGA},\mathrm{AGG}\}$, the isoleucine-methionine row $\{\mathrm{AUA}\}$, the lysine row $\{\mathrm{AAA}\}$, the leucine block $\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\}$, and the two-row class $\{\mathrm{UCA},\mathrm{UUA}\}$.  The module audit assigns all thirteen rows with no missing module rows, no extra module rows, and no unassigned codons: $R_{\mathrm{size}}=13$, assigned count $13$, extra set $\varnothing$, missing set $\varnothing$, and unassigned set $\varnothing$.

\paragraph{Null comparisons.}
The shape test against sampled alternatives used $N=2000$ draws with seed $42$.  It found one exact shape match, giving $p_{\mathrm{exact}}=0.0005$, and twenty-five high-Jaccard matches at threshold $0.9$, giving $p_{J\geq 0.9}=0.0125$.  The sampling required $57377$ distinct-sample attempts and incurred $55377$ duplicate retries, so the finite comparison is sparse inside a heavily constrained space.  A second amino-acid-class-preserving comparison, again with $N=2000$ and seed $42$, reported observed $M$ size $20$, exact-match count $0$, lower-tail count $7$, $p_{\mathrm{aa\ class\ exact}}=0.0$, and $p_{\mathrm{aa\ class\ lower\ tail}}=0.0035$.  These values support a non-random-looking local split under the stated sampling protocols, but they do not identify a causal biological process.

\paragraph{Code-table readback.}
The curated standard-code table supplies codon-to-label observations.  Under leave-one-code-out evaluation, $23$ tables and $63$ targets were evaluated.  The baseline hit rate was $0.19821739130434785$, while the hit rate above baseline was $0.9841269841269841$.  The hit rate inside $M-T$ was $0.9365079365079365$, and the hit rate inside $M-T$ plus boundary was $0.9841269841269841$.  By family, the hit rates above baseline were $1.0$ for bacterial-plastid, mitochondrial, nuclear-ciliate, and candidate-other families, and $0.8333333333333334$ for the alternative-yeast family.  These figures are code-layer recovery figures: they concern labels in codon tables, not ribosomal realization, folding, energetics, phenotype, or organism-level function.

\paragraph{Codon deletion probe.}
The leave-one-codon-out probe reports anchor count $0$, boundary count $5$, high-closure coverage $8$, predictable count $8$, and recovery rate $1.0$.  Thus every tested withheld row is either recovered through the finite local construction or lands on the recorded boundary class.  This is the strongest finite-row support for the punctured-cube reading: the thirteen-row set is not merely a post hoc list, but a local object with deletion-stability behavior under the specified probe.

\paragraph{Scope boundary.}
The allowed conclusion is deliberately narrow.  The standard-code label table supports codon-label readback and local split checks for the thirteen-row punctured cube.  No conclusion about translation realization, folded protein structure, physical admissibility, biological function, universal mechanism, or global biological necessity follows from this chapter.  In particular, an amino-acid label sequence obtained from the code table is still only a label sequence; it is not a structure contact.  Any future claim crossing from this code layer into folding, chemistry, function, or mechanism must bring an independent observation at that higher layer.  Without such a separate contact, the punctured-cube result remains a finite codon-table boundary fact: sharp enough to be tested, but confined to the code-read layer.
