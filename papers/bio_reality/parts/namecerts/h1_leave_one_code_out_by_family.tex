\paragraph{Claim being recorded.}
The claim \texttt{h1.leave\_one\_code\_out.by\_family} is a finite code-read observation about the standard-code codon table under a window-six codon coordinate. The carrier is the codon cube $Q_6$, read as a six-bit display of codons. The data distinguish a local tile face, a singleton label corner, and a three-point label class, and the intended readback is only the curated codon-to-label table for the standard genetic code. The layer is therefore the code-label layer: the observation concerns which codons are recovered as label-changing or boundary-sensitive sites under finite leave-one tests. It is not a claim about translation being realized in a cell, a protein acquiring folded structure, a sequence being physically admissible, a biological function being present, a mechanism being universal, or a global biological law. Any movement to those layers would require an additional contact with the relevant kind of observation.

\paragraph{Reality contact and scope.}
The contact used here is a curated standard genetic-code table assigning codons to amino-acid or stop labels. That contact can test codon label readback and local codon-tile label splits. It cannot test translation realization, structural order, physical admissibility, or function realization. The aligned mismatch record therefore has a narrow meaning: the code table supports the code-layer readback and blocks promotion to stronger biological claims. Two blocked-null records make the same boundary explicit. Amino-acid label readback is not folded protein structure, and a mixed-case probe token or cross-organism CUN/UUR wording does not turn a code-table observation into evidence about structure, translation, function, physical admissibility, or universal mechanism. The recorded support is finite, concrete, and useful precisely because it stays within the scope of the contact that produced it.
