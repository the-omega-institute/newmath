\paragraph{Reality contact and scope.}
The only contact used here is a curated standard-code table assigning codons to amino-acid or stop labels.  That contact can test code readback and local codon-tile label splitting.  It cannot test translation realization, folded structure, structural order, physical admissibility, biological function, or a universal mechanism.  Consequently, the result is a finite code-layer observation: window-six coordinates expose a stable local boundary pattern against the supplied code labels, and the family-stratified leave-one-code-out row reports high recovery relative to the stated baseline.  No claim about protein folding, molecular admissibility, function, or biological necessity follows from these rows unless a separate observation at that higher layer is supplied.
