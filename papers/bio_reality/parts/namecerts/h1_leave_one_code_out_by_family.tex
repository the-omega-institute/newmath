\subsection{Leave-One-Code-Out Stability by Code Family}
\label{sec:bioreality-h1-leave-one-code-out-by-family}

\paragraph{Question.}
The row asks whether the window-six codon coordinate picture remains informative when whole genetic-code tables are held out by family. The biological contact is intentionally narrow: a curated standard-code table gives codon-to-label assignments, with labels drawn from amino-acid names and stop symbols. The mathematical carrier is the six-bit codon cube, inspected through local faces, singleton corners, and three-point label classes. The claim is not that the cube geometry is a biological mechanism. It is that a finite codon-coordinate calculation gives a reproducible code-layer signal whose family-wise behavior can be measured against a baseline.

\paragraph{Finite carrier and exceptional set.}
The punctured-cube row identifies the same thirteen-codon set in both the cardinality and face-count calculations:
$$
\begin{aligned}
R = \{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The recorded size is $|R|=13$. The punctured-cube computation gives the face vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4),
\end{aligned}
$$
so the data used here are not merely a list of affected labels but a finite cubical subconfiguration with vertices, edges, and square faces. The run also supplies a spectral summary. The measured values are $\lambda_M=0.6752479308830213$, $\lambda_R=0.4758352843197002$, and $\mu=3.051487585298128$, with radial polynomial value $-6.224354365258478\times 10^{-12}$. This numerical residual is treated as tolerance-level evidence for the recorded cubic relation, not as an independent biological law.

\paragraph{Module partition.}
The thirteen codons are completely assigned to named modules. The module audit reports $R\_size=13$, $assigned\_count=13$, no missing codons, no unassigned codons, and no extra module codons. The finite partition is

\begin{aligned}

$$
Every module has either a predictable member or a boundary member in the leave-one-codon-out audit. That row records $predictable\_count=8$, $boundary\_count=5$, $anchor\_count=0$, $closure\_coverage\_high=8$, and $recovery\_rate=1.0$. Thus the local test does not leave a hidden residue outside the declared module partition.

\paragraph{Whole-code holdout result.}
The family-level leave-one-code-out run evaluates $5$ families. Its family-wise hit rates above baseline are
$$
\begin{aligned}
\mathrm{alternative\_yeast} &= 0.8333333333333334,\\
\mathrm{bacterial\_plastid} &= 1.0,\\
\mathrm{candidate\_other} &= 1.0,\\
\mathrm{mitochondrial} &= 1.0,\\
\mathrm{nuclear\_ciliate} &= 1.0.
\end{aligned}
$$
The companion whole-code holdout row reports $23$ evaluated tables and $63$ targets. Its baseline hit rate is $0.19821739130434785$, while the observed hit rate above baseline is $0.9841269841269841$. The same value, $0.9841269841269841$, is obtained after adjoining the boundary class, and the stricter interior count gives $0.9365079365079365$. These numbers make the row suitable for a code-layer stability statement: after a full code table is withheld, the local window-six geometry still recovers most target labels at rates far above the recorded baseline.

\paragraph{Null comparisons.}
Two finite null checks constrain the interpretation. The shape-significance run used $N=2000$ samples with seed $42$. It found $1$ exact shape match, giving $p\_exact=0.0005$, and $25$ samples with Jaccard similarity at least $0.9$, giving $p\_\mathrm{Jaccard\ge 0.9}=0.0125$. The run required $57377$ distinct-sample attempts and recorded $55377$ duplicate retries, which is relevant because the sampled finite space is visibly collision-prone. The amino-acid-class-preserving null also used $N=2000$ and seed $42$. It found $0$ exact matches, so $p\_\mathrm{class\ exact}=0.0$, and it recorded $7$ samples in the lower tail at or below the observed $M$ size $20$, giving $p\_\mathrm{lower\ tail}=0.0035$. The explicit membership list for $M$ is not part of this row, so the present chapter uses only the supplied scalar $observed\_M\_size=20$ and the associated null counts.

\paragraph{Reality contact.}
The empirical contact is the curated standard-code label table. It supports code readback and local label-split tests: codons are associated with amino-acid or stop labels, and those labels can be compared with the coordinate-derived tile structure. The contact does not observe translation events, ribosomal dynamics, molecular folding, thermodynamic admissibility, organismal function, or a universal biological rule. Therefore the family-level result is a finite code-table regularity claim. It does not license promotion from codon labels to protein structure or from a local codon tile to a general mechanism of biology.

\paragraph{Local verdict.}
For the row $h1.leave\_one\_code\_out.by\_family$, the finite evidence is internally coherent. The five family rates are all above the recorded baseline, four are exactly $1.0$, and the remaining family, alternative yeast, is $0.8333333333333334$. The broader holdout calculation over $23$ tables and $63$ targets gives $0.9841269841269841$ above baseline, while the module audit accounts for all thirteen codons in $R$. Together with the punctured-cube face vector, the spectral values, and the two null comparisons, this supports a bounded conclusion: window-six codon coordinates expose a stable local code-read pattern across the tested code families. The result remains confined to label-level readback unless a separate observation supplies translation, folding, physical admissibility, function, mechanism, or universality.
