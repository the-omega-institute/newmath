\subsection{Family-resolved leave-one-code-out behavior for the window-six codon tile}\label{sec:bioreality-h1-leave-one-code-out-by-family}
\origin{ai}

\paragraph{Finite object under test.}
The object tested here is the standard-code codon label table viewed through a six-coordinate codon display.  The finite coordinate carrier is the $64$-point codon cube $Q_6$, with codons read as six-bit words after separating the three nucleotide positions into binary coordinates.  The observed local boundary set $R$ has cardinality $13$ and is exactly
$$
\begin{aligned}
R=\{&AAA,AGA,AGG,AUA,CUA,CUC,CUG,CUU,\\
&UAA,UAG,UCA,UGA,UUA\}.
\end{aligned}
$$
The same set is recorded as a punctured-cube tile with face data
$$
\begin{aligned}
f(R)=(13,16,4).
\end{aligned}
$$
Thus the row being tested is not an unconstrained biological narrative: it is a finite codon-coordinate pattern together with an externally curated codon-to-label table.  The table can tell us which codon labels are present, but it does not by itself observe ribosomal realization, protein folding, molecular admissibility, biological function, a mechanism, or a universal rule across biology.

\paragraph{Spectral and shape checks.}
The row also carries a finite spectral signature.  The measured values are
$$
\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128.
\end{aligned}
$$
The corresponding cubic residual is $-6.224354365258478\cdot 10^{-12}$, so the numerical spectral certificate is at roundoff scale for the recorded polynomial relation.  In the shape randomization check with $N=2000$, one exact shape match was observed after $57377$ distinct-sample attempts and $55377$ duplicate retries, giving $p_{\mathrm{exact}}=0.0005$.  The high-overlap threshold had $25$ matches with Jaccard score at least $0.9$, giving $p_{\geq 0.9}=0.0125$.  Under the amino-acid-class-preserving null model with $N=2000$, the exact-shape count was $0$, the lower-tail count at the observed $M$ size was $7$, the observed $M$ size was $20$, and the corresponding lower-tail value was $0.0035$.  These checks support the claim that the displayed local tile is a structured finite feature of the code-layer readback, not a generic random artifact of the chosen coordinate display.

\paragraph{Leave-one-code-out family row.}
The family-resolved leave-one-code-out experiment evaluates whether the local tile remains informative when code tables are grouped by biological code family.  The row contains $5$ families.  The hit rate above the baseline is
$$
\begin{aligned}
\mathrm{alternative\_yeast}&=0.8333333333333334,\\
\mathrm{bacterial\_plastid}&=1.0,\\
\mathrm{candidate\_other}&=1.0,\\
\mathrm{mitochondrial}&=1.0,\\
\mathrm{nuclear\_ciliate}&=1.0.
\end{aligned}
$$
The accompanying table-level leave-one-code-out run evaluated $23$ tables and $63$ targets.  Its baseline hit rate was $0.19821739130434785$, while the hit rate above baseline was $0.9841269841269841$.  The rate inside $M-T$ was $0.9365079365079365$, and the rate inside $M-T$ plus the boundary was again $0.9841269841269841$.  The family row therefore says that the finite coordinate tile remains highly concentrated across the listed code families, with the alternative-yeast family weaker than the four perfect-family rows but still substantially above the baseline row.

\paragraph{Codon-level module accounting.}
The leave-one-codon-out companion row supplies a codon-level check on the same boundary.  It records $0$ anchors, $5$ boundary cases, $8$ high-closure-coverage cases, $8$ predictable cases, and recovery rate $1.0$.  The module classification assigns all $13$ codons in $R$, with no missing codons, no extra module codons, and no unassigned codons.  The modules are
$$
\begin{aligned}
\mathrm{agr}&=\{AGA,AGG\},\\
\mathrm{ar\_lys}&=\{AAA\},\\
\mathrm{cun}&=\{CUA,CUC,CUG,CUU\},\\
\mathrm{ile\_met}&=\{AUA\},\\
\mathrm{ssn}&=\{UCA,UUA\},\\
\mathrm{stop\_trp}&=\{UAA,UAG,UGA\}.
\end{aligned}
$$
This accounting is important because the family-level signal is not floating above the codons.  It is grounded in a complete partition of the observed $13$-codon boundary set into named local modules.

\paragraph{Scientific reading.}
The supported reading is narrow.  Window-six codon coordinates expose a finite local boundary-tile pattern that aligns strongly with curated standard-code label readback and remains informative under leave-one-code-out grouping by family.  The evidence belongs to the code-read layer: it compares codon coordinates, boundary membership, label classes, and family-wise held-out performance against finite null checks.  It does not show that the coordinate geometry is a biological necessity, that translation is realized in any particular organism, that an amino-acid label sequence folds, that a product is physically admissible, that a function occurs, or that the pattern is a universal mechanism.  Any such stronger statement would require an additional contact that directly observes the higher layer being claimed.

\paragraph{Boundary condition.}
The row is accepted as a finite code-layer record because the curated code table supplies the codon-to-label contact and the numerical probes stay inside that contact.  The row must be rejected for any promotion beyond this layer.  In particular, a local codon-tile split is not evidence for folded structure, translation dynamics, physical feasibility, biological function, or universal biological law.  The appropriate next test is not to reinterpret the same codon table more strongly, but to attach separate structure, translation, or organism-matched contacts before making claims outside code readback.
