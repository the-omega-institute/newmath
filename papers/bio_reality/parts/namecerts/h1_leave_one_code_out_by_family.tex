\subsection{Leave-one-code-out family stratification for the codon boundary tile}
\label{sec:bioreality-h1-leave-one-code-out-by-family}

\paragraph{Finite setting.}
The record is a code-layer test on the six-coordinate codon cube.  Each codon is treated as a point of the window-six display, and the only biological readback used here is the curated standard genetic-code assignment from codons to amino-acid or stop labels.  The observed boundary set is the thirteen-codon set
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The same finite row reports $|R|=13$ and identifies this set with a punctured-cube shape having $f$-vector $(13,16,4)$.  Thus the object under discussion is not an unrestricted biological mechanism; it is a finite labeled pattern in a codon coordinate cube, with the label table serving as the contact that permits code-level reading.

\paragraph{Shape and spectral calibration.}
The null calibration for the tile is numerically sharp.  In the shape randomization run with $N=2000$ samples and seed $42$, there was $1$ exact shape match, giving $p_{\mathrm{exact}}=0.0005$, and $25$ samples with Jaccard similarity at least $0.9$, giving $p_{\mathrm{Jaccard}\ge 0.9}=0.0125$.  The run attempted $57377$ distinct samples and recorded $55377$ duplicate retries, so the reported probabilities should be read as finite-row empirical tail estimates under the stated sampling procedure.  A second null model preserving amino-acid classes also rejects trivial class-preserving explanation: with $N=2000$ and seed $42$, the exact-match count is $0$, the lower-tail count at the observed $M$ size is $7$, the observed $M$ size is $20$, and the lower-tail probability is $0.0035$.  The spectral row gives
$$
\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128.
\end{aligned}
$$
Its radial cubic residual is $-6.224354365258478\times 10^{-12}$, the same value reported for the cubic-polynomial check, so the spectral calculation is numerically consistent at the displayed tolerance.  These numbers justify treating the thirteen-point set as a statistically and spectrally specific local tile, while still leaving its biological interpretation confined to codon-label readback.

\paragraph{Leave-one-code-out result.}
The leave-one-code-out experiment evaluated $23$ code tables and $63$ total targets.  Its baseline hit rate was $0.19821739130434785$.  Against this baseline, the global finite-row recovery was high: the hit rate in $M\setminus T$ was $0.9365079365079365$, and the hit rate in $M\setminus T$ with the boundary allowance was $0.9841269841269841$.  Equivalently, the run reports a hit rate above baseline of $0.9841269841269841$.  The family-stratified row is the claim-level datum.  It partitions the evaluated alternatives into $5$ families and reports the following above-baseline family hit rates:
$$
\begin{aligned}
\mathrm{alternative\_yeast}&:0.8333333333333334,\\
\mathrm{bacterial\_plastid}&:1.0,\\
\mathrm{candidate\_other}&:1.0,\\
\mathrm{mitochondrial}&:1.0,\\
\mathrm{nuclear\_ciliate}&:1.0.
\end{aligned}
$$
The non-unit alternative-yeast value is important because it prevents the row from being described as a tautological perfect partition: the family view is strong, but not featureless.  Four families attain complete above-baseline recovery under the row criterion, while one family remains high but imperfect.

\paragraph{Codon-level module check.}
The associated leave-one-codon-out row reports no anchors, $5$ boundary codons, $8$ predictable codons, high closure coverage $8$, and recovery rate $1.0$.  Its module classification accounts for all $13$ codons of $R$: assigned count $13$, no extra module codons, no missing codons, and no unassigned codons.  The modules are
$$
\begin{aligned}
\mathrm{agr}&=\{AGA,AGG\},\\
\mathrm{ar\_lys}&=\{AAA\},\\
\mathrm{cun}&=\{CUA,CUC,CUG,CUU\},\\
\mathrm{ile\_met}&=\{AUA\},\\
\mathrm{ssn}&=\{UCA,UUA\},\\
\mathrm{stop\_trp}&=\{UAA,UAG,UGA\}.
\end{aligned}
$$
Every listed module has either predictable or boundary status in the finite row.  This supplies a local explanation of why the family-stratified code-table test concentrates on the same thirteen codons: the module partition is complete on $R$, and the leave-one-codon-out recovery does not leave a residual codon outside the module accounting.

\paragraph{Interpretation.}
The claim supported by these rows is narrow.  Window-six codon coordinates expose a local boundary-tile pattern whose thirteen codons, module decomposition, spectral values, and family-stratified leave-one-code-out recovery are all finite and checkable.  The curated standard-code table supplies the labels needed to read codons at the code layer.  Nothing in these rows observes translation as a process, folded protein structure, physical admissibility, biological function, a mechanism of code emergence, or a universal law for organisms.  Any such stronger statement would require a separate contact measuring that higher layer.  In particular, amino-acid label sequences obtained from the code table are not structural observations, and cross-organism wording about codon usage or tRNA-related notation does not by itself create a folding or function datum.

\paragraph{Verdict.}
For the claim \texttt{h1.leave\_one\_code\_out.by\_family}, the finite-row evidence is ready at the code-read layer.  The decisive data are the $5$-family stratification with four unit above-baseline rates and one rate $0.8333333333333334$, the $23$-table and $63$-target leave-one-code-out run with $0.9841269841269841$ boundary-allowed hit rate, the thirteen-codon punctured-cube set with $f$-vector $(13,16,4)$, the complete six-module classification of $R$, and the independent shape and amino-acid-class null estimates.  The result should be stated as a local codon-label boundary phenomenon, not as a claim about translation, folding, physical realization, function, mechanism, or biological universality.
