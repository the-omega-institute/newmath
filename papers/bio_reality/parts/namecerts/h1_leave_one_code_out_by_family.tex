\paragraph{Finite codon window.}
The experiment uses the six-coordinate codon display as a finite code-reading object, with the curated standard genetic-code table supplying the codon-to-label contact. The distinguished residual set has cardinality $13$ and is exactly
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The same row is reported as a punctured-cube pattern with face data
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}
$$
Thus the object tested here is not an arbitrary amino-acid list: it is the finite row in which the standard-code label table is read through a window-six coordinate frame, and the residual codon set is checked for local tile geometry.

\paragraph{Spectral and shape controls.}

The near-zero value of the cubic residual is used only as a numerical check on the reported finite spectrum. It is not treated as a mechanism. The null sampling row for the shape test used $N=2000$ samples, seed $42$, and $57377$ distinct-sample attempts, with $55377$ duplicate retries. There was $1$ exact shape match, giving $p_{\mathrm{exact}}=0.0005$, and $25$ samples with Jaccard score at least $0.9$, giving $p_{\geq 0.9}=0.0125$. A second amino-acid-class-preserving null used $N=2000$ samples and found $0$ exact matches, so the reported exact-shape probability is $0.0$ at this sample resolution. In the same class-preserving row, $7$ samples fell in the lower tail at or below the observed module size $20$, yielding $p_{\mathrm{lower\ tail}}=0.0035$.

\paragraph{Codon-module accounting.}
The leave-one-codon-out row reports $0$ anchors, $5$ boundary codons, $8$ high-coverage closure codons, $8$ predictable codons, and recovery rate $1.0$. The module classification assigns all $13$ residual codons with no missing codons, no extra module codons, and no unassigned codons. The six module blocks are
$$
\begin{aligned}
\mathrm{agr}&=\{\mathrm{AGA},\mathrm{AGG}\},\\
\mathrm{ar\_lys}&=\{\mathrm{AAA}\},\\
\mathrm{cun}&=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\},\\
\mathrm{ile\_met}&=\{\mathrm{AUA}\},\\
\mathrm{ssn}&=\{\mathrm{UCA},\mathrm{UUA}\},\\
\mathrm{stop\_trp}&=\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}.
\end{aligned}
$$
Every module has either a predictable member or a boundary member, so the finite row is internally accounted for at the code-reading level. The point is not that these modules explain translation. The point is narrower: the observed standard-code labels, when projected into the six-coordinate codon window, produce a residual tile whose family-level leave-one-code-out recovery is numerically high and whose module partition covers the entire residual set.

\paragraph{Scope of the contact.}
The only reality contact used here is the curated standard-code label table. It supports codon-label readback and local split tests. It does not observe ribosomal realization, folded structure, chemical admissibility, biological function, a causal mechanism, or a universal biological law. Any statement crossing from this finite label row to translation, protein folding, physical feasibility, function, mechanism, or universality would require a separate contact of the appropriate kind. The present record therefore remains a code-layer finite-row result: a local boundary-tile pattern in the codon table, supported by the listed finite counts, null comparisons, spectral numbers, family rates, and complete residual-module assignment.
