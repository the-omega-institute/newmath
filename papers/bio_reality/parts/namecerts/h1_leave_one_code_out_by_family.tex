\subsection{Family-resolved leave-one-code-out boundary for the codon table}
\label{sec:bioreality-h1-leave-one-code-out-by-family}
\origin{ai}

\paragraph{Object and contact.}
This record concerns the standard-code codon table at the code-read layer.  The finite object is the six-coordinate codon cube $Q_6$ equipped with codon labels supplied by a curated standard genetic-code table.  The biological contact used here is only the assignment of codons to amino-acid or stop labels.  It is a label table contact, not an observation of translation dynamics, folding, physical admissibility, molecular function, mechanism, or universality.

\paragraph{Distinguished row set.}
The finite row singled out by the coordinate construction has cardinality $13$.  The verified row is
$$\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}$$
The same computation verifies that this row is the punctured-cube row with $f$-vector $(13,16,4)$.  Thus the row is not introduced as a floating biological assertion; it is a finite coordinate object whose label readback is checked against the curated code table.

\paragraph{Spectral and shape checks.}
The associated spectral computation gives $\lambda_M=0.6752479308830213$, $\lambda_R=0.4758352843197002$, and $\mu=3.051487585298128$.  The cubic radial check evaluates to $-6.224354365258478\times 10^{-12}$, which is numerically zero at the tolerance used by the run.  In the unconstrained null model with $N=2000$ samples and seed $42$, the exact-shape count is $1$, giving $p_{\mathrm{exact}}=0.0005$, and the high-overlap count at Jaccard threshold $0.9$ is $25$, giving $p_{\geq 0.9}=0.0125$.  The run reports $57377$ distinct-sample attempts and $55377$ duplicate retries, so the finite sampling cost is visible rather than hidden.  In the amino-acid-class-preserving null model, again with $N=2000$ and seed $42$, the observed $M$-size is $20$, the exact-shape count is $0$, the lower-tail count at or below the observed size is $7$, $p_{\mathrm{class,exact}}=0.0$, and $p_{\mathrm{class,lower}}=0.0035$.

\paragraph{Leave-one-code-out result.}
The leave-one-code-out experiment evaluated $23$ code tables and $63$ target rows.  Its baseline hit rate is $0.19821739130434785$.  The hit rate above baseline is $0.9841269841269841$; the hit rate inside $M\setminus T$ is $0.9365079365079365$; and the hit rate inside $M\setminus T$ together with the boundary rows is $0.9841269841269841$.  The family-resolved refinement groups the same phenomenon into $5$ families.  The verified family rates above baseline are $1.0$ for bacterial/plastid, $1.0$ for candidate-other, $1.0$ for mitochondrial, $1.0$ for nuclear-ciliate, and $0.8333333333333334$ for alternative-yeast.  The alternative-yeast family is therefore the only family in this finite row whose rate is below one, while it still remains far above the baseline rate recorded for the full leave-one-code-out experiment.

\paragraph{Codon-level recovery and modules.}
The leave-one-codon-out run reports no anchor codons, $5$ boundary codons, $8$ high-closure-coverage codons, $8$ predictable codons, and recovery rate $1.0$.  The module classification accounts for all $13$ codons in $R$: assigned count $13$, $R$-size $13$, no extra module codons, no missing row codons, and no unassigned codons.  The verified modules are $\mathrm{agr}=\{\mathrm{AGA},\mathrm{AGG}\}$, $\mathrm{ar\_lys}=\{\mathrm{AAA}\}$, $\mathrm{cun}=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\}$, $\mathrm{ile\_met}=\{\mathrm{AUA}\}$, $\mathrm{ssn}=\{\mathrm{UCA},\mathrm{UUA}\}$, and $\mathrm{stop\_trp}=\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}$.  Each module has either a predictable member or a boundary member, so the family-level result is not a single pooled artifact detached from the codon-row decomposition.

\paragraph{Interpretation.}
The result supports a narrow claim: window-six codon coordinates expose a local boundary-tile pattern whose label split can be read against the standard-code table, and this pattern remains stable under leave-one-code-out tests by biological code family.  The claim is strongest at the code-read layer, where the finite objects are codon strings, label classes, closure rows, spectra, and family-resolved hit rates.  The curated table supplies the amino-acid and stop labels; it does not explain why translation occurs, whether a peptide folds, whether any molecule is physically admissible, whether a biological function is realized, or whether the same local tile is a universal law.

\paragraph{Boundary.}
No higher-layer conclusion is licensed by these rows alone.  In particular, amino-acid label-sequence readback is not folded protein structure; a CUN or UUR wording is not cross-organism structural evidence; and a local tile in $Q_6$ is not a mechanism for translation.  Any future promotion beyond codon-label readback must bring a separate contact appropriate to that layer, such as a translation-realization contact, a structure contact, a physical-admissibility contact, or a function contact.  Until such a contact is supplied, the finite evidence here remains a family-resolved code-table boundary result.
