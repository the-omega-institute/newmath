\paragraph{Finite codon display.}
The packet works over the six-coordinate codon cube $Q_6$, where the standard-code table is used only as a curated assignment of codons to amino-acid or stop labels. The observed exceptional set $R$ has cardinality $13$ and is exactly
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.

$$
The same finite row records the punctured-cube face data for this set by the vector $(13,16,4)$. Thus the code-read object is not an unstructured list of labels: in the six-bit display it occupies a small, face-bearing boundary region. The row does not assert that the region is a biological cause. It says that this curated label table, when read in $Q_6$, has a finite local shape that can be tested by leaving code tables or codons out.

\paragraph{Reality contact and scope.}
The only biological contact used here is the curated standard genetic-code table, resolved at codon-label readback. It can test whether the six-coordinate display and the local tile split agree with curated code labels. It cannot test whether translation is realized in a cell, whether a label sequence folds, whether a molecule is physically admissible, whether a biological function is present, whether a mechanism has been found, or whether a universal biological law holds. Those stronger statements would require separate contacts of the appropriate kind. In particular, an amino-acid label sequence is not a protein structure, a CUN or UUR pattern is not a folding observation, and tRNA-related wording is not evidence of function unless an organism-matched contact is supplied. The verdict of this packet is therefore narrow: the standard-code labels, viewed in $Q_6$, expose a finite local boundary pattern whose leave-one-code-out behavior is stable by family, while all higher biological layers remain outside the demonstrated row.
