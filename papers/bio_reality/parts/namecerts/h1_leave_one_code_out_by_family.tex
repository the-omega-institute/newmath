\paragraph{Finite coordinate object.}
The claim \\texttt{h1.leave\_one\_code\_out.by\_family} is a code-layer statement about the standard codon table viewed through a six-bit codon display.  The finite carrier is the codon cube $Q_6$, with each codon treated as a coordinate point and with the curated standard-code table supplying the amino-acid or stop label attached to that point.  The construction uses four finite distinctions: the six-bit display, a local tile face, singleton label corners, and three-point label classes.  These distinctions are used only to organize a local label-readback test.  They do not by themselves assert translation, folding, physical admissibility, function, mechanism, or biological universality.

\paragraph{Observed residual set.}
The residual codon set $R$ has exactly thirteen codons.  In the verified finite row, the set is
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The same row identifies $R$ with a punctured-cube shape whose face-vector is $(13,16,4)$.  Thus the local object is not an arbitrary list of exceptional labels: it is a thirteen-point subset with sixteen one-dimensional adjacencies and four two-dimensional faces inside the six-bit cube.  This is the finite geometric substrate on which the leave-one-code-out test is evaluated.

\paragraph{Reality contact and scope.}
The reality contact is the curated standard genetic-code table: it assigns each codon to an amino-acid or stop label.  The contact can test code-layer readback and local codon-tile label splitting.  It cannot test translation realization, structural order, folded protein geometry, physical admissibility, biochemical function, or a universal mechanism.  Therefore the supported statement is narrow: the six-bit codon coordinates expose a local boundary-tile pattern whose leave-one-code-out behavior is strong across the recorded family partition, while the actual labels remain supplied by the curated code table.  Any claim beyond code labels would require an additional contact of the appropriate kind.
