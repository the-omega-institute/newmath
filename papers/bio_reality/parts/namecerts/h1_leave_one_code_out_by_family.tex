\subsection{Leave-one-code-out behavior by code family}\label{sec:h1-leave-one-code-out-by-family}
\origin{ai}

\paragraph{Finite object under test.}
This chapter treats the standard-code codon table as a finite label readback problem on the six-coordinate codon cube $Q_6$.  The display is not used as a model of translation itself.  It is used only as a finite coordinate arena in which codons have six binary positions, local faces can be inspected, singleton label corners can be separated from three-point label classes, and the resulting rows can be compared with a curated codon-to-label table.  The row singled out by the boundary computation is the thirteen-codon set
$$
\begin{aligned}
R=\{&AAA, AGA, AGG, AUA, CUA, CUC, CUG, CUU,\\
&UAA, UAG, UCA, UGA, UUA\}.
\end{aligned}
$$
The same row is the punctured-cube row in this packet: its finite face count is $(13,16,4)$ for vertices, edges, and square faces.  The observed mutable label region has size $20$ in the amino-acid-class-preserving null experiment.  No list of the full $M$ row is part of the supplied finite data, so this chapter only uses the verified size and the displayed $R$ membership list.

\paragraph{Spectral and sampling checks.}
The coordinate packet also carries a numerical spectrum check.  The verified scalar values are
$$
\begin{aligned}
\lambda_M &= 0.6752479308830213,\\
\lambda_R &= 0.4758352843197002,\\
\mu &= 3.051487585298128,
\end{aligned}
$$
with radial cubic residual $-6.224354365258478\times 10^{-12}$, within the recorded tolerance for the spectral-radius check.  In the shape randomization test, $N=2000$ distinct samples were retained after $57377$ sample attempts and $55377$ duplicate retries.  Only one exact shape match appeared, giving $p=0.0005$, and $25$ samples had Jaccard overlap at least $0.9$, giving $p=0.0125$.  Under the amino-acid-class-preserving null, again with $N=2000$ and seed $42$, there were no exact shape matches, while $7$ samples lay in the lower tail at or below the observed mutable-region size $20$.  Thus the recorded class-preserving values are $p=0.0$ for exact shape and $p=0.0035$ for the lower tail.  These numbers support a finite coordinate anomaly relative to the tested nulls; they do not identify a biochemical mechanism.

\paragraph{Leave-one-code-out family row.}
The family-level result is a refinement of the leave-one-code-out test.  The parent leave-one-code-out run evaluated $23$ code tables and $63$ targets.  Its baseline hit rate was $0.19821739130434785$, whereas the rate above baseline was $0.9841269841269841$.  The direct $M\setminus T$ hit rate was $0.9365079365079365$, and the rate after adjoining the boundary row was again $0.9841269841269841$.  The family summary has five named families.  Four families reach perfect above-baseline hit rate in the recorded row: bacterial-plastid, candidate-other, mitochondrial, and nuclear-ciliate each have value $1.0$.  The alternative-yeast family is lower but still high, with value $0.8333333333333334$.  The family count is therefore $5$, with one partial family and four complete family-level hits in the supplied finite summary.

\paragraph{Codon-level recovery and module partition.}
The companion leave-one-codon-out row supplies the local recovery check.  It reports $0$ anchors, $5$ boundary codons, $8$ predictable codons, high closure coverage $8$, and recovery rate $1.0$.  The module classification accounts for all $13$ codons of $R$ with no unassigned codons, no missing module members, and no extras.  The verified modules are
$$
\begin{aligned}
agr&=\{AGA,AGG\},\\
ar\_lys&=\{AAA\},\\

ile\_met&=\{AUA\},\\

This partition is important because the family-level leave-one-code-out result is not merely a single scalar.  It is tied to a finite set of boundary and predictable codons whose module assignment is complete at size $13$.

\paragraph{Biological readback.}
The only biological contact used here is a curated standard genetic-code table assigning codons to amino-acid or stop labels.  That contact is adequate for code-layer readback: it lets the finite coordinate rows be compared with standard-code labels and lets local label splits be tested.  It does not observe translation dynamics, ribosomal realization, folded protein structure, physical admissibility, cellular function, or universality across biology.  The family-level result should therefore be read as follows: window-six coordinates expose a strong local boundary pattern for code labels, and this pattern remains high when code families are held out, but the interpretation stops at codon-label organization unless another experiment supplies the missing higher-layer contact.

\paragraph{Scope limit.}
No claim of translation, folding, physical admissibility, function, mechanism, or universal biological law follows from this chapter.  Amino-acid label sequences are not protein structures, and a local codon tile is not a global law of biology.  Cross-organism wording, CUN/UUR notation, or tRNA-Leu vocabulary would require organism-matched contacts before being used as biological evidence beyond the code table.  Within the permitted scope, the finite statement is ready: the thirteen-codon boundary row, the spectral scalars, the null-model probabilities, the leave-one-code-out rates, and the five-family breakdown together support a code-read pattern whose evidential reach is local and explicitly bounded.
