\subsection{Family-stratified leave-one-code-out readback}
\label{sec:h1-leave-one-code-out-by-family}

\paragraph{Finite object under test.}
The object in this record is the standard-code codon label table viewed through a six-coordinate codon display.  The table contact supplies codon-to-label assignments only: it says which triplet is assigned to an amino-acid label or to stop, and it does not by itself describe translation dynamics, molecular structure, chemical admissibility, biological function, a mechanism, or a universal law.  The finite question is therefore deliberately narrower.  After one non-standard code table is withheld from the comparison pool, does the local window-six boundary pattern still recover the relevant code-layer targets above a simple baseline, and does this behavior persist when the withheld tables are grouped by biological family?

\paragraph{The punctured-cube row.}
The recurrent boundary set $R$ has cardinality $13$.  In the recorded run it is exactly
$$
\begin{aligned}
R = \{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}
$$
The same row is reported as a punctured-cube-shaped subcomplex with face-vector
$$
\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}
$$
Thus the row is not merely a list of exceptional codons; it is a finite local tile with thirteen vertices, sixteen one-dimensional incidences, and four two-dimensional faces in the chosen six-bit display.  The module assignment also exhausts this row: the thirteen codons split into $\mathrm{AGR}=\{\mathrm{AGA},\mathrm{AGG}\}$, $\mathrm{ar\_lys}=\{\mathrm{AAA}\}$, $\mathrm{CUN}=\{\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU}\}$, $\mathrm{ile\_met}=\{\mathrm{AUA}\}$, $\mathrm{SSN}=\{\mathrm{UCA},\mathrm{UUA}\}$, and $\mathrm{stop\_trp}=\{\mathrm{UAA},\mathrm{UAG},\mathrm{UGA}\}$.  The classification reports $R$-size $13$, assigned count $13$, no extra module codons, no missing codons from the modules, and no unassigned codons.

The larger tile $M$ is not listed codon-by-codon in this row, but its observed size is $20$ in the amino-acid-class-preserving null model.  Against $2000$ sampled alternatives with seed $42$, the exact-shape count for the main shape test is $1$, giving $p_{\mathrm{exact}}=0.0005$.  The high-overlap count at Jaccard threshold $0.9$ is $25$, giving $p_{J\geq 0.9}=0.0125$. \end{aligned}
$$
whereas the recorded hit rate above baseline is

$$
The hit rate inside $M\setminus T$ is $0.9365079365079365$, and the hit rate inside $M\setminus T$ together with its boundary is $0.9841269841269841$.  These figures support a code-layer statement: the local six-coordinate tile is strongly aligned with the withheld label targets in this finite comparison task.  They do not convert the tile into an explanation of ribosomal translation, folded protein geometry, cellular viability, function, or an organism-independent rule.

\paragraph{Family-stratified result.}
The family-stratified run groups the leave-one-code-out task into $5$ families.  The hit rates above baseline are
$$
\begin{aligned}
\mathrm{alternative\_yeast} &= 0.8333333333333334,\\
\mathrm{bacterial\_plastid} &= 1.0,\\
\mathrm{candidate\_other} &= 1.0,\\
\mathrm{mitochondrial} &= 1.0,\\
\mathrm{nuclear\_ciliate} &= 1.0.
\end{aligned}
$$
Thus four of the five named families reach perfect above-baseline recovery in this finite row, while the alternative-yeast family remains high but not perfect.  The point of the stratification is not that all biological code variation has a single cause.  It is that the same local codon-window boundary continues to organize the finite label-readback task after the comparison is separated by family.

\paragraph{Codon-level recovery and boundary behavior.}
The leave-one-codon-out row records anchor count $0$, boundary count $5$, high closure coverage $8$, predictable count $8$, and recovery rate $1.0$.  The recovery-rate-above-threshold field is also $1.0$.  This is consistent with the module classification: every module contains either predictable or boundary codons, and the modules cover the whole thirteen-codon row.  The correct reading is local and finite.  A codon lying in the boundary tile may be recoverable as a label-table datum, but that recovery is still a property of the code table contact and the coordinate test, not an observation of a folded chain or an experimentally realized molecular process.

\paragraph{Local non-promotion rule.}
The contact used here is the curated standard genetic-code bridge.  Its observed fact is simply that the standard table assigns codons to amino-acid or stop labels at codon-label resolution.  It can test code readback and local tile label splitting.  It cannot test translation realization, structural order, physical admissibility, or function realization.  Therefore the family-stratified row is ready as a code-read claim: a finite six-coordinate codon tile with $|R|=13$, face-vector $(13,16,4)$, complete module coverage, strong spectral consistency, and high leave-one-code-out recovery remains visible when withheld code tables are grouped by family.  No statement about protein folding, molecular admissibility, biological function, global mechanism, or universality follows unless a separate reality contact supplies that higher-layer evidence.
