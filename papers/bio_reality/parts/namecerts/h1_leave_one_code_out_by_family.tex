\subsection{Leave-One-Code-Out Stability by Code Family}
\label{subsec:h1-leave-one-code-out-by-family}
\origin{ai}

\paragraph{Finite codon window.}
The record uses the codon cube $Q_6$ as a six-coordinate display for codon labels.  The data do not treat the cube as a biological cause.  They use it as a finite coordinate chart in which one can ask whether the standard-code labels expose a repeatable local boundary pattern.  The readback contact is the curated standard genetic-code table: it supplies codon-to-label assignments, including amino-acid and stop labels, but it does not supply translation dynamics, protein structure, energetic feasibility, cellular function, or a universal mechanism.

\paragraph{Observed residual tile.}
The verified residual set has thirteen codons.  In the finite row it is exactly
$$
\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\},\\
|R|&=13,\\
f(R)&=(13,16,4).
\end{aligned}
$$
Thus the local object is not an arbitrary list of exceptional codons: it is a punctured-cube shaped row with $13$ vertices, $16$ one-dimensional incidences, and $4$ two-dimensional faces under the chosen window-six coordinate test.  The spectral row gives
$$
\begin{aligned}
\lambda_M&=0.6752479308830213,\\
\lambda_R&=0.4758352843197002,\\
\mu&=3.051487585298128,\\
\operatorname{residual}&=-6.224354365258478\cdot 10^{-12}.
\end{aligned}
$$
The near-zero residual is used only as a numerical consistency check for the finite coordinate computation.  It is not promoted to a physical law.

\paragraph{Null comparisons.}
The shape-significance run used $N=2000$ sampled alternatives with seed $42$.  It found one exact shape match, giving $p_{\mathrm{exact}}=0.0005$, and $25$ samples with Jaccard score at least $0.9$, giving $p_{J\geq 0.9}=0.0125$.  The sampling process required $57377$ distinct-sample attempts and $55377$ duplicate retries, so the row should be read as a finite randomized stress test rather than as an asymptotic theorem.  A separate amino-acid-class preserving null model, also at $N=2000$ and seed $42$, reported observed $M$ size $20$, exact match count $0$, lower-tail count $7$, $p_{\mathrm{class\ exact}}=0.0$, and $p_{\mathrm{lower\ tail}}=0.0035$.  These values support the narrower statement that the displayed local split is difficult to reproduce under the tested label-preserving perturbations.

\paragraph{Scope of the claim.}
The chapter claim is limited to code-layer readback.  The curated table lets the finite coordinate packet compare codon labels and local boundary behavior; it does not observe ribosomal realization, folded structure, physical admissibility, downstream biological function, or organism-wide necessity.  In particular, an amino-acid label sequence is still only a label sequence in this record.  A structural or functional assertion would require a separate contact that measures structure or function directly.  The present row therefore supports a bounded conclusion: the window-six codon display exposes a stable local boundary-tile pattern across the tested code-family leave-out rows, while all higher biological interpretations remain outside the certified data.
