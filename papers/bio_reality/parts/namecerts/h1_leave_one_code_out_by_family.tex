\subsection{Leave-One-Code-Out Stability by Genetic-Code Family}
\label{sec:h1-leave-one-code-out-by-family}

\paragraph{Object and layer.}
This record concerns the standard-code codon table at the code-read layer.  The finite carrier is the six-coordinate codon cube, used only as a coordinate display for codon labels.  The observed contact is a curated table assigning each codon to an amino-acid or stop label.  The question tested here is narrower than biological translation: after one code table is withheld, does the local tile-and-boundary description continue to recover the held-out code-layer targets above the baseline rate, and does that recovery persist when the held-out tables are grouped by family?

\paragraph{Residual codon tile.}
The finite residual set $R$ has cardinality $13$.  In the supplied row it is exactly
$$\begin{aligned}
R=\{&\mathrm{AAA},\mathrm{AGA},\mathrm{AGG},\mathrm{AUA},\mathrm{CUA},\mathrm{CUC},\mathrm{CUG},\mathrm{CUU},\\
&\mathrm{UAA},\mathrm{UAG},\mathrm{UCA},\mathrm{UGA},\mathrm{UUA}\}.
\end{aligned}$$
The same row identifies this set with the punctured-cube residual and records the face-vector data
$$\begin{aligned}
(f_0,f_1,f_2)=(13,16,4).
\end{aligned}$$
Thus the finite object being read is not the full biological process, but a local combinatorial residue in the codon-coordinate cube.  Its label contact is supplied by the standard-code table, so the cube geometry and the curated labels remain distinct inputs to the test.

\paragraph{Spectral and shape checks.}
The spectral row records $\lambda_M=0.6752479308830213$, $\lambda_R=0.4758352843197002$, and $\mu=3.051487585298128$.  The reported cubic residual is numerically negligible,

and the same tolerance value is reported for the radial polynomial calculation.  The shape row used $N=2000$ sampled comparators, with $57377$ distinct-sample attempts and $55377$ duplicate retries.  It found $1$ exact shape match and $25$ comparators with Jaccard score at least $0.9$, giving
$$\begin{aligned}
p_{\mathrm{exact}}=0.0005,\qquad p_{\mathrm{Jaccard}\ge 0.9}=0.0125.
\end{aligned}$$
Under the amino-acid-class-preserving null model, again with $N=2000$, the observed $M$ size is $20$, the exact-match count is $0$, and the lower-tail count at or below the observed $M$ size is $7$.  The corresponding values are
$$\begin{aligned}
p_{\mathrm{class\ exact}}=0.0,\qquad p_{\mathrm{class\ lower\ tail}}=0.0035.
\end{aligned}$$
These rows support a finite code-layer anomaly: the residual tile and the associated $M$-size behavior are atypical among the stated null samples.  They do not by themselves identify a mechanism.

\paragraph{Leave-one-code-out recovery.}
The leave-one-code-out row evaluates $23$ tables and $63$ held-out targets.  Its baseline hit rate is $0.19821739130434785$.  The tile recovery rises to $0.9365079365079365$ inside $M-T$, and to $0.9841269841269841$ after adjoining the boundary.  The same value, $0.9841269841269841$, is reported as the hit rate above baseline.  The tested comparison is therefore a finite recovery contrast:
$$\begin{aligned}
0.19821739130434785
&<0.9365079365079365\\
&<0.9841269841269841.
\end{aligned}$$
Read conservatively, the local codon tile gives a strong code-label recovery signal when one code table is withheld, but the evidence remains a label-table comparison.

Hence every named residual module contains codons accounted for by either predictable recovery or boundary placement in the supplied classification.

\paragraph{Local verdict.}
The finite rows are mutually coherent at the code-read level.  The residual set has size $13$, it has the recorded punctured-cube face vector $(13,16,4)$, the spectral quantities satisfy the stated numerical polynomial check to tolerance, the null comparisons give small empirical tail probabilities, and the leave-one-code-out recovery remains above baseline across all $5$ families.  The result is therefore ready as a finite mathematical record about local codon-label readback under a leave-one-code-out family stratification.
