\paragraph{Finite codon packet.}
This record isolates a finite codon enumeration that is useful for asking whether a proposed nucleotide interval can even pass a start--stop-window eligibility test.  The verified base row is the identity $M=\mathrm{WNR}\cup\mathrm{CUN}$, with cardinality $20$.  The full certified list is
$$
\begin{aligned}
M=\{&AAA,AAG,ACA,ACG,AGA,AGG,AUA,AUG,CUA,CUC,\\
& CUG,CUU,UAA,UAG,UCA,UCG,UGA,UGG,UUA,UUG\}.
\end{aligned}
$$
The row therefore supplies an exact finite vocabulary for the geometric side of the packet: every element asserted in the set is explicitly named, and the count agrees with the list length.  This is only a codon-level enumeration.  By itself it does not say that a sequence interval has been observed, that a transcript is present, or that a protein product exists.

\paragraph{Motif compression and saturation checks.}
A second verified row compresses the related motif set $R$ to the thirteen codons
$$
\begin{aligned}
R=\{&AAA,AGA,AGG,AUA,CUA,CUC,CUG,CUU,\\
&UAA,UAG,UCA,UGA,UUA\}.
\end{aligned}
$$
The audit reported no missing elements and no extra elements for this motif union.  The $f_3$ saturation row then gives
$$
\begin{aligned}
\mathrm{Sat}_{f_3}(R)=\{&AAA,AAG,AGA,AGG,AUA,AUG,CUA,CUC,CUG,CUU,\\
&UAA,UAG,UCA,UCG,UGA,UGG,UUA,UUG\},
\end{aligned}
$$
which is exactly $M$ with $ACA$ and $ACG$ absent.  The same run records $M=\mathrm{Med}(R)\cup\{ACA,ACG\}$ as the twenty-element list displayed above, and its finite boundary residual was the empty list.  Thus the codon geometry has an internally closed enumeration check: the motif compression, the saturation, and the two exceptional codons account for the same twenty symbols.  This check is a constraint on a finite codon table, not an observation of an open reading frame.

These numbers make the packet suitable for a bounded eligibility screen, because the classifier can be audited against a small, explicitly enumerated coordinate set.

\paragraph{ORF eligibility boundary.}
The biological layer attached to this packet is $\mathrm{orf\_eligibility}$.  The governing rule is deliberately narrow: start/stop-window enumeration can mark a proposed interval as eligible for a later biological check only when an outside interval contact supplies the sequence annotation being tested.  The finite start--stop-window run loaded one external window record, classified one input window, and reported the scope as external window start--stop enumeration only, with snapshot date $2026$--$05$--$25$.  Its own output explicitly kept the result at ORF-eligibility level.  Consequently the codon packet may describe what must be checked at the boundary, but it cannot itself certify an observed ORF.

\paragraph{Curated interval contact.}
A later curated-interval run supplied the separate contact needed for an actual interval-level test.  That run loaded $168$ rows from a curated ORF interval dataset based on NCBI RefSeq GenBank XML CDS intervals for \emph{Escherichia coli} K-12 MG1655 accession $NC\_000913.3$, snapshot date $2026$--$05$--$30$.  The required input classes were present: boundary cases, matched non-ORF decoys, and positive curated ORFs.  The protocol was frozen at $2026$--$05$--$29T19{:}11{:}13+00{:}00$, before the external evidence time $2026$--$05$--$30T10{:}29{:}31+00{:}00$; the classifier rules, held-out splits, input classes, and baselines were all recorded as frozen before observation.

\paragraph{Finite statistical contact.}
Within that contacted dataset, $72$ positive intervals were accepted, giving accept rate $1.0$ and exact one-sided binomial upper-tail value $2.117582368135751\times 10^{-22}$.  The matched decoy control rejected $72$ of $72$ decoys, again with rate $1.0$ and the same upper-tail value $2.117582368135751\times 10^{-22}$.  The predeclared paired baseline comparison recorded $72$ wins in $72$ pairs, win rate $1.0$, and the same exact one-sided value.  Held-out stability was reported across three splits: left, middle, and right locus folds each had $24$ positives accepted at rate $1.0$ and $24$ decoys rejected at rate $1.0$.  Boundary cases supplied an additional non-promotion control: $24$ boundary cases were tested and $0$ were promoted, so the promoted fraction was $0.0$.  These finite counts support the contacted ORF-eligibility classifier on this curated dataset, while leaving the codon enumeration itself at boundary status whenever that separate contact is absent.

\paragraph{Local cannot-claim rule.}
The scientific conclusion is therefore two-tiered.  First, the codon-side packet verifies the finite identity $M=\mathrm{WNR}\cup\mathrm{CUN}$, its related motif compression, its $f_3$ saturation behavior, and its quotient geometry.  Second, ORF eligibility is only reached when an external curated interval contact is attached and tested by the frozen start--stop-window classifier.  No translation realization, folded molecular structure, physical admissibility, biological function, causal mechanism, or universal biological law follows from the codon geometry or from start--stop-window enumeration alone.  The self-check row records the same boundary in compact form: three gates were checked, and no codon geometry was promoted across biological layers.
