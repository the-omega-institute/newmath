\paragraph{Mediation boundary.}
The biological conjecture motivating this row is a mediated route $q_i \to T_j \to P_k$ before any function claim. The present finite row does not contain a matched translation readout $T_j$ such as ribosome profiling, translation efficiency, or a direct ribosome-occupancy measurement. It also does not contain a mediation matrix showing that conditioning on $T_j$ absorbs a direct $q_i \to P_k$ association. Instead, it contains a phenotype-side association after protein abundance has already been included as a confounding control. Therefore this row can sit only at a protein-function boundary: it can show that the nine-coordinate $B^{*}_{Q6}$ residual block is not rank-degenerate and has a small beyond-expression association with knockout essentiality, but it cannot itself establish a translation-mediated protein-omics chain.

\paragraph{Layer discipline.}
The function contact is absent. Essentiality is a laboratory knockout phenotype, but the row is observational and cross-sectional. It is not a synonymous-edit experiment, not a ribosome-dynamics experiment, not a protein-folding assay, not a physical-admissibility assay, and not a molecular-function assay. The positive $R^{2}_{FE}$ entries therefore remain associations of codon residual coordinates with a bounded phenotype readback after controls. They do not license a claim of translation realization, folded structure, physical admissibility, biological function, causal mechanism, or organism-general law. Any such promotion would require an additional layer-matched contact: a measured translation readout for $q_i \to T_j$, a matched protein-omics intermediary for $T_j \to P_k$, and then a separate function or phenotype contact if the argument is to move beyond the boundary reported here.

\paragraph{Four-way readback.}
For this row, the four possible outcomes reduce to a local classification. The no-survival case is not the recorded result, since both organisms have positive finite partial-$R^{2}$ values above $10^{-12}$ for the nine-coordinate block. The translation-only case is not established, since no measured translation rows are attached. The protein-omics-survival-without-translation-mediation case is also not established, because measured abundance is used as a control rather than as the downstream endpoint. The honest classification is a rank-powered, abundance-controlled essentiality association at the boundary before translation mediation and before function. It is suitable as a finite contact for later testing, but only if later rows add the missing translation and function measurements rather than treating the present association as if those measurements had already been made.
