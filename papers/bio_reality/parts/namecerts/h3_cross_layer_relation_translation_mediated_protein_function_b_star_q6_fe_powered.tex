\paragraph{Finite carrier.}
The finite object in this record is a row-indexed matrix whose rows are coding genes and whose columns separate four kinds of coordinates: a $B^{\ast}_{Q6}$ residual coordinate $q_i$, a translation readout coordinate $T_j$ when such a readout is present, a protein-omics intermediary $P_k$ when matched protein abundance is present, and a downstream function or phenotype coordinate $F_l$ only when a separate assay supplies it.  The run identified as \texttt{beb31e9e1742} does not yet contain a matched $q_i \to T_j \to P_k \to F_l$ chain.  It contains a powered finite-row test of $B^{\ast}_{Q6}$ residual association with a laboratory knockout essentiality phenotype after amino-acid composition and measured protein-abundance controls.  The residual coordinate list has nine entries:
$$
\begin{aligned}
R_{Q6}=\{&K\_AAA,\ Arg\_AGR,\ Ile\_AUA,\ Leu\_CUN\_vs\_UUR,\ Leu\_UUA\_vs\_UUG,\\

Each $q_i$ is retained only as an amino-acid-quotient codon residual coordinate.  It is not a translation measurement, not a protein-function readout, and not an intervention.

\paragraph{Readback rule.}
The run reports nine surviving coordinates in each organism at the declared positive partial-$R^2$ threshold $10^{-12}$.  This is a finite association statement about codon residuals and a binary laboratory knockout phenotype after the stated residualization.  It is not a causal statement.  The binary readout is handled by an ordinary least-squares linear-probability residualization, so the numeric surface is an association score on the finite joined table rather than a mechanistic probability law.  The admissible readback is therefore:
$$
\begin{aligned}
(q_i,Z,\mathrm{essentiality},\mathrm{abundance})
&\mapsto S^{FE}_i>10^{-12},\\
S^{FE}_i
&\not\mapsto q_i\to T_j,\\
S^{FE}_i
&\not\mapsto q_i\to T_j\to P_k,\\
S^{FE}_i
&\not\mapsto q_i\to T_j\to P_k\to F_l.
\end{aligned}
$$
The positive entries may be described only as beyond-expression codon residual associations with the essentiality readout under the named controls.  Because measured protein abundance is included in $Z$, the result is explicitly not a protein-abundance mediation result.

\paragraph{Layer discipline.}
A translation-mediated protein-function claim would require a same-row panel containing the same $q_i$ residual coordinates, a matched translation readout $T_j$ such as ribosome occupancy or translation efficiency, a matched protein-omics readout $P_k$, and then an additional function or phenotype readout $F_l$.  The present finite rows do not supply that chain.  In particular, a modeled tAI or stAI weight would only be a bounded codon-adaptation readback unless paired with measured ribosome or translation-efficiency rows; matched mRNA abundance would be a transcription-layer control rather than a translation observation; and matched protein abundance would remain an intermediary readout unless a mediation statistic shows that conditioning on $T_j$ reduces the direct $q_i\to P_k$ contribution.

No translation, folding, physical admissibility, function, mechanism, or universality follows from this table unless a separate layer-matched contact supplies the corresponding measurement and the declared controlled statistic is computed on the joined rows.
