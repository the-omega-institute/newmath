\paragraph{Mediation statistic.}
For a row $(q_i,t_j,p_k)$ the intended support statistic is a controlled mediation gain.  One convenient finite-row expression is to compare a baseline description of $p_k$ using amino-acid composition, organism, GC3, CDS length, M-density baseline, matched mRNA abundance, and the translation readout, against the same description with the surviving residual coordinate added through the translation term:
$$
\begin{aligned}
\Delta_{ijk}
&=L\bigl(p_k\mid Z,m,t_j\bigr)-L\bigl(p_k\mid Z,m,t_j,q_i, q_i\leadsto t_j\bigr),\\
Z&=(\mathrm{amino\ acid\ composition},\mathrm{organism},\mathrm{GC3},\mathrm{CDS\ length},\mathrm{M\ density\ baseline}),
\end{aligned}
$$
where $m$ denotes matched mRNA abundance.  The row is positive only if the translation step survives first and the downstream protein-abundance description is improved after the controls are present.
