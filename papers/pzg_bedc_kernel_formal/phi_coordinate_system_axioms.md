## 1. 载体(Carrier)

**公理 C1**。坐标环 𝒪 := ℤ[φ] = ℤ + ℤφ,φ² = φ + 1。元素记 `a + bφ`,坐标对 `(a,b) ∈ ℤ²`。
**公理 C2**（共轭）。对合 σ: φ ↦ 1 − φ = −1/φ,即 σ(a+bφ) = (a+b) − bφ;σ² = id,σ 为环自同构。
**公理 C3**（范数）。N(a+bφ) := (a+bφ)·σ(a+bφ) = a² + ab − b² ∈ ℤ;**N 乘性**:N(xy)=N(x)N(y)。
**公理 C4**（单位）。单位群 𝒪* = {±φⁿ : n∈ℤ},N(φ) = −1;基本单位 φ,Dirichlet 秩 1。

*奠基状态（第 163 轮数值验）*:C3 乘性 10⁵ 例通过;C2 对合+同态 10⁵ 例通过;C4 范数 φⁿ ∈ {±1} 逐项确认。**五地基立。**

## 2. 三坐标轴(the three axes)

GCS 之坐标非单一 |·|,乃**三轴联合读数**——对应账本三运算、6.207 三重离散:

**轴 A · 乘法轴(标度 / DSI)**。deg_×(x) := ⌊log_φ |x|⌋。φⁿ 落整数格;连续标度对称塌缩为 ⟨×φ⟩ 离散子群。**读账本:梯律 ×φ³、Droste、log-周期。**

**轴 Z · 加法轴(Zeckendorf 位)**。Z(n) := 非相邻 Fibonacci 展开之位集(唯一)。
**公理 Z1**（加法闭合）:∀ m,n∈ℕ,Z(m+n) 存在且唯一非相邻——加法在离散轴良定义（进位归约 = Fibonacci 替换 11→100 之有限迭代）。*奠基状态*:2×10⁴ 例非相邻唯一，通过。**读账本:PZG 编码层、纤维词。**

**轴 G · 几何轴（圆周分点 / 三距）**。G(n) := {nφ} ∈ [0,1)。三距定理：任意 N 点间距 ≤ 3 种，Fibonacci 点时恰 2 种（最公平）。**读账本:避峰 Bragg 峰、准晶原子位。**

**联合坐标**：x ↦ (deg_×, Z, G)(x)。GCS 之"位置"非"多大"，乃"标度第几级 · 展开哪几位 · 圆周何扇区"。

## 3. 度量（离散深度，GCS 之卖点）

普通坐标用 |x| 度量大小；GCS 用**离散深度**：

**定义 D**（对数-算术混合度量）。depth(x) := (deg_×(x), |Z(x)|, ‖G(x)‖)，
其中 ‖·‖ 为到最近黄金模 {mφ} 之圆距。**depth 天然与 ζ-正则化三笔（ζ(0)/ζ(−1)/ζ′(−2)）、复极列 log-周期咬合**——账本 S(ε) 展开即 depth 之解析读数。

> 卖点：GCS 擅长笛卡尔坐标最笨拙处——自相似、准周期、离散标度。
> 如对数坐标纸使指数关系现直线，GCS 使自相似结构现格点。**非取代 ℝ，乃 ℝ 上叠一层离散骨架。**

## 4. 素数与算术（内层分类）

**范数素数分家**（6.205 接口）：p 于 𝒪 之分裂由 **mod 5** 定——p ≡ ±1 (5) 分裂、p ≡ ±2 (5) 惰性、p = 5 分歧。**注意:此为 mod 5，非费马 mod 4（ℤ[i]）**——GCS 之"费马定理"判据是 √5 之 5。

**分类双表**：外表（不动点谱系）= 判别式 D + CF 周期（6.206）；内表（GCS 素数分家）= mod-5 范数型 a²+ab−b²。两表皆二次型，套两模数。

## 5. 与既有结构之接口（不重造轮子）

- **代数**：𝒪 = 实二次域 ℚ(√5) 之整数环，类数 h=1（唯一分解！GCS 算术之幸运）。
- **动力**：hull Ω_φ、替换矩阵 M=[[1,1],[1,0]]、本征 φ 与 −1/φ（27.85 两轴）。
- **谱**：K₀-迹像 = ℤ+ℤφ = 𝒪 之迹（Bellissard 隙标定，6.204）——**GCS 坐标环即谱之标签群**。
- **解析**：Beatty-Dirichlet / Hecke 极格（调节子 log φ 定极距，6.188）。

## 6. 表示定理（中形猜想,待证 · M4→M5）

## 8. 边界（诚实清单）

- GCS **不**取代实数、**不**是万物坐标、**不**证明黎曼假设、**不**触动两颗心脏。
