# Missing BEDC Primitives

Use stable gap markers when a bridge row is blocked on a BEDC-side object.

Use this shape, replacing the bracketed placeholder with a concrete stable ID:

```markdown
## Short gap title
<!-- BEDC-GAP: [CONCRETE_ID] -->

Bridge need: `MATRIX.md` row or Lean declaration that needs the object.
BEDC home: target BEDC chapter or namespace.
```
