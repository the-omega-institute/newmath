\begin{definition}[Aronszajn fixed-point carrier]
\label{def:aronszajn-fixed-point-carrier}
An $\AronszajnFixedPointUp$ carrier is a finite $\BHist$ packet
$$
A=(K,Q,F,B,S,T,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $K$ is the $\CompactUp$ source row for the carried domain, including only the compactness evidence visible to the packet.
\item $Q$ is the $\ConvexSetUp$ row for the same domain, exposing membership and finite affine-combination stability.
\item $F$ is the $\ContinuousMapUp$ self-map row whose source and target reads are confined to the displayed compact convex carrier.
\item $B$ is the $\BrouwerFixedPointUp$ finite-subdivision comparison row, used only as the finite approximate fixed-simplex sibling surface.
\item $S$ is the $\SchauderFixedPointUp$ compact-convex approximation row, used only as the compact-convex limiting handoff surface.
\item $T$ is the $\KakutaniFixedPointUp$ graph-selector boundary row, used only when the consumer reads a set-valued or selector-facing comparison.
\item $H$ records componentwise $\hsame$ transport for the compact, convex, self-map, Brouwer, Schauder, Kakutani, continuation, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from compact and convex reads to the self-map row, then to the three fixed-point sibling rows.
\item $P$ is the $\Pkg$ provenance over $\AronszajnFixedPointUp$, $\CompactUp$, $\ConvexSetUp$, $\ContinuousMapUp$, $\BrouwerFixedPointUp$, $\SchauderFixedPointUp$, $\KakutaniFixedPointUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\AronszajnFixedPointUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $K,Q,F,B,S,T,H,C,P,N$. It has no coordinate for a chosen fixed point, a global selector, a host compactness theorem, an ambient topological-vector-space theorem, unrestricted hyperspace compactness, real-completeness choice, Lean verification, or a standard bridge.
\end{definition}

\begin{theorem}[Aronszajn fixed-point NameCert obligations]
\label{thm:aronszajn-fixed-point-namecert-obligations}
For every accepted $\AronszajnFixedPointUp$ carrier $A=(K,Q,F,B,S,T,H,C,P,N)$, the local $\NameCert_{\AronszajnFixedPointUp}$ surface consists exactly of five obligation rows:
\begin{enumerate}
\item compact-convex admission, requiring the compact row $K$ and convex row $Q$ to name the same displayed domain;
\item self-map admission, requiring the $\ContinuousMapUp$ row $F$ to read source and target data only through $K$ and $Q$;
\item fixed-point sibling exposure, requiring the Brouwer row $B$, Schauder row $S$, and Kakutani row $T$ to be read only as displayed sibling handoff surfaces;
\item transport and replay stability, requiring $H$ and $C$ to preserve the same compact, convex, self-map, and sibling rows componentwise;
\item provenance and naming nonescape, requiring $P$ and $N$ to name only the displayed packet and to export no host fixed point, global selector, unrestricted compactness theorem, ambient real completeness, or bridge certificate.
\end{enumerate}
\end{theorem}
\begin{proof}
Carrier admission is projection from \autoref{def:aronszajn-fixed-point-carrier}. The compact and convex rows $K,Q$ are displayed before the self-map row is read, so the domain is fixed by the local packet.

The self-map row $F$ is then read through the same compact-convex surface. It supplies only the source and target data available to $\ContinuousMapUp$, with no separate host map or ambient function-space structure.

The fixed-point sibling rows $B,S,T$ are exposed after $K,Q,F$. They point respectively to the Brouwer finite-subdivision route, the Schauder compact-convex handoff, and the Kakutani graph-selector boundary; none of them adds a chosen fixed point or a global selector to this packet.

Finally $H,C,P,N$ transport, replay, source, and name the same finite carrier. Since no coordinate outside $K,Q,F,B,S,T,H,C,P,N$ is present, the excluded host compactness, real-completeness, choice, and bridge objects cannot enter the local NameCert surface.
\end{proof}
