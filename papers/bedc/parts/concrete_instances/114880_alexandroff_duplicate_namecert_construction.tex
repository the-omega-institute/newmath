\begin{definition}[Alexandroff duplicate carrier]
\label{def:alexandroff-duplicate-carrier}
An $\AlexandroffDuplicateUp$ carrier is a finite $\BHist$ packet
$$
A=(T,B,O,W,R,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $T$ is the $\TopologyUp$ source row naming the finite open data currently under inspection.
\item $B$ is the $\BoolUp$ duplicate-tag row; each inspected point is tagged by one of the two duplicate faces.
\item $O$ is the $\SierpinskiSpaceUp$ observable-open truth row for the inspected tagged points.
\item $W$ is the $\StreamNameUp$ finite-window row listing the tagged observations actually read by the packet.
\item $R$ is an optional $\RealOrderTopologyUp$ source anchor; when absent, the carrier still records the topology row $T$ and duplicate tag row $B$ without importing order-completeness data.
\item $H$ records componentwise $\hsame$ transport for topology rows, duplicate tags, observable-open truth rows, finite windows, the optional order source, continuation rows, provenance rows, and local naming rows.
\item $C$ records displayed $\Cont$ replay from $T,B$ to $O$, from $O$ to $W$, and from any present order-topology anchor $R$ back to the same finite topology source row.
\item $P$ is the $\Pkg$ provenance over $\AlexandroffDuplicateUp$, $\TopologyUp$, $\BoolUp$, $\SierpinskiSpaceUp$, $\StreamNameUp$, $\RealOrderTopologyUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\AlexandroffDuplicateUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $T,B,O,W,R,H,C,P,N$. It has no coordinate for all open subsets of a host duplicate space, a separation axiom, quotient point equality, order completeness, countable choice, or a global topological representation.
\end{definition}

\begin{theorem}[Alexandroff duplicate NameCert obligations]
\label{thm:alexandroff-duplicate-namecert-obligations}

A consumer may read an observable duplicate-open only after those finite rows are displayed; it cannot replace them by a host duplicate-space topology, a hidden open-set lattice, a separation theorem, or ambient real-order completeness.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:alexandroff-duplicate-carrier}. The rows $T,B,O,W,R,H,C,P,N$ are the whole accepted packet, so the duplicate-open consumer cannot detach the observable truth row from the topology source or from the duplicate tag row.

Read the finite route in order. The $\TopologyUp$ row supplies the source open data, the $\BoolUp$ row supplies the duplicate face, the $\SierpinskiSpaceUp$ row records the observable truth value, and the $\StreamNameUp$ row bounds the inspected window.

The optional $\RealOrderTopologyUp$ row only anchors the source topology when it is present. The transport, continuation, provenance, and local naming rows replay the same displayed packet, so no hidden open-set lattice, separation axiom, countable-choice schedule, or real-order completeness datum is exported.
\end{proof}
