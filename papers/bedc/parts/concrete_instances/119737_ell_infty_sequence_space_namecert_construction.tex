\begin{theorem}[Ell-infinity sequence-space NameCert obligations]
\label{thm:ell-infty-sequence-space-namecert-obligations}
For every accepted $\EllInftySequenceSpaceUp$ carrier $E=(S,W,R,B,H,C,P,N)$, the local $\NameCert_{\EllInftySequenceSpaceUp}$ surface consists exactly of five obligation rows:
\begin{enumerate}
\item carrier admission for the displayed schedule, finite windows, regular rational and Real readback, uniform bound ledger, transport, replay, provenance, and local naming rows;
\item sequence-window exposure, requiring every consumer to read $S$ and $W$ before it can inspect coordinate readback;
\item Real readback ordering, requiring $R$ to remain downstream of the displayed finite windows and regular rational rows;
\item uniform bound exactness, requiring $B$ to be read before any exported Real seal is treated as part of the bounded sequence-space packet;
\item ledger refusal, excluding quotient sequence equality, selected representatives, countable-choice schedules, host suprema, ambient Real completeness, and bridge certificates.
\end{enumerate}
No local NameCert obligation is stored outside those rows.
\end{theorem}
\begin{proof}

The bound row is independent of host suprema. It is a displayed ledger row $B$ tied to the inspected windows and readback, so boundedness is consumed as packet data rather than inferred from an ambient function space.

Finally the structural rows $H,C,P,N$ preserve the same finite packet. Since the carrier has no coordinate for quotient sequence equality, selected representatives, choice schedules, host suprema, ambient completeness, or bridge certificates, the five rows exhaust the local NameCert surface.
\end{proof}
