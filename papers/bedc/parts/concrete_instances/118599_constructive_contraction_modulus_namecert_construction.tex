\label{def:constructive-contraction-modulus-carrier}

\item $F$ is the $\ContinuousMapUp$ self-map row, displayed as a graph or local evaluation ledger rather than as an extensional host function.

The classifier compares accepted packets only through these rows. It has no coordinate for a selected fixed point, quotient completion equality, host function extensionality, countable choice, or ambient completeness.

\begin{theorem}[Constructive contraction-modulus NameCert obligations]
\label{thm:constructive-contraction-modulus-namecert-obligations}

Every Picard or fixed-point consumer must read $X,F,L,Q,W,R,E,H,C,P,N$ in that displayed route before it can consume the contraction modulus.
\end{theorem}
\begin{proof}

\end{proof}
