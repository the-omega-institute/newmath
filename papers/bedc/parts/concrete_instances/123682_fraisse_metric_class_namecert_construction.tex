\begin{theorem}[Fraisse metric class NameCert obligations]
\label{thm:fraisse-metric-class-namecert-obligations}
For every accepted $\FraisseMetricClassUp$ carrier
$$
F=(R,M,K,U,A,J,G,E,H,C,P,N),
$$
the local $\NameCert_{\FraisseMetricClassUp}$ surface consists exactly of the following finite obligation rows:
\begin{enumerate}
\item carrier admission for the $\RatUp$ table row, $\MetricUp$ metric row, $\KatetovExtensionUp$ request row, $\UrysohnUniversalMetricUp$ consumer row, age ledger, joint-embedding ledger, amalgamation ledger, extension-property window, transport, replay, provenance, and local name;
\item rational metric exactness, requiring every displayed distance in $R$ to be read as a rational value and every metric law used by the class to be witnessed by $M$;
\item age stability, requiring finite heredity and isomorphism invariance to be recorded by $A$ without invoking a host category of structures;
\item joint-embedding visibility, requiring $J$ to display the finite rational table obtained from two accepted tables before any downstream consumer may read it;
\item amalgamation visibility, requiring $G$ to expose the shared subtable, both side tables, and the rational compatibility window used for the amalgam;
\item Katetov-to-Urysohn handoff, requiring $E$ to read the finite support and rational one-point profile through $K$ before $U$ may consume the request;
\item nonescape, excluding completed Urysohn spaces, host quotient equality, choice-selected amalgams, infinite age enumerations, ambient $\RealUp$ completeness, Lean verification, and bridge checking.
\end{enumerate}
No Fraisse metric class obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:fraisse-metric-class-carrier}. The tuple $R,M,K,U,A,J,G,E,H,C,P,N$ is the whole public surface, so carrier admission is exactly admission of those rows.

Rational metric exactness is read through $R$ and $M$. The rational table supplies the inspected distances, and the metric row supplies the zero, symmetry, and triangle witnesses for the displayed finite table.

Age stability is recorded by $A$. Heredity and isomorphism invariance can only inspect finite subtables and relabelings already visible through $R$ and $M$, so no ambient class object is introduced.

The joint-embedding and amalgamation obligations are $J$ and $G$. They display the finite tables being combined, the shared interface when present, and the rational compatibility cells used by the combined table.

Finally $E$ binds the extension-property window to the Katetov and Urysohn-facing rows. Transport, replay, provenance, and naming through $H,C,P,N$ preserve the same finite route, and the excluded objects are absent from the carrier coordinates.
\end{proof}
