\begin{theorem}[Axis carry critical-pair NameCert obligations]
\label{thm:axis-carry-critical-pair-namecert-obligations}

$$

\item left-branch exactness, requiring $\ell$ to be read only through the displayed left carry window of $s$;
\item right-branch exactness, requiring $r$ to be read only through the displayed right carry window of $s$;
\item join exactness, requiring $j$ to be reached by normalizing the remaining visible carry window from both $\ell$ and $r$;
\item value-ledger exactness, requiring $V$ to record the same finite Fibonacci value for $s,\ell,r,j,n$;

The join and value clauses are downstream. The row $j$ is the common target of the remaining visible carry window from both branches, and $V$ records the finite Fibonacci value read through all displayed windows.

Finally, $B,H,C,P,N$ keep the comparison local. Since history-sameness collapse, quotient normal forms, host arithmetic equality, unbounded critical-pair search, global confluence, Lean verification, and bridge data are absent from the carrier, the listed rows exhaust the local NameCert surface.
