\begin{theorem}[Regular Cauchy rate transform NameCert obligations]
\label{thm:regular-cauchy-rate-transform-namecert-obligations}
For every accepted $\RegularCauchyRateTransformUp$ carrier $T=(M,W,D,R,H,C,P,N)$, the local $\NameCert_{\RegularCauchyRateTransformUp}$ surface consists exactly of the following finite obligation rows:

\item carrier admission for the source Cauchy modulus rows, finite window, dyadic tolerance ledger, rate-normalization replay, transport, replay, provenance, and local naming;
\item source-modulus exposure, requiring every regular-rate request to cite a displayed threshold row in $M$;
\item finite-window exposure, requiring the cited threshold to be read through the $\StreamNameUp$ window row $W$;
\item dyadic tolerance compatibility, requiring $D$ to contain the target regular tolerance and the comparison budget used for the request;
\item rate-normalization replay, requiring $R$ to store the finite route from the target regular rate back to the source modulus row;
\item componentwise transport, continuation replay, package provenance, and local naming through $H,C,P,N$.
\end{enumerate}
No NameCert obligation is stored outside these rows, and none of the rows supplies quotient stream equality, selected limits, countable choice, ambient completeness, or host real equality.
\end{theorem}
\begin{proof}
Project the accepted carrier of \autoref{def:regular-cauchy-rate-transform-carrier}. The tuple exposes exactly the source modulus table, finite window, dyadic tolerance ledger, normalized rate row, transport, replay, provenance, and local name.

The source-modulus and finite-window obligations are immediate from $M$ and $W$. A regular-rate request can cite only displayed source thresholds, and those thresholds are inspected only through the finite window row.

The dyadic obligation is the row $D$. It records the target regular tolerance together with the comparison budget that lets the source threshold be read as a regular-Cauchy rate request.

Finally $R$ records the replay from the target rate to the source row, while $H,C,P,N$ transport, replay, source, and name the same finite packet. Since the carrier omits quotient stream equality, selected limits, countable choice, ambient completeness, and host real equality, none of those principles can be exported by the local certificate.
\end{proof}

\end{theorem}
\begin{proof}

For the induction step, append one further observation from the finite window $W$. The same carrier rows remain available: $M$ supplies the cited source threshold, $D$ supplies the tolerance budget, and $R$ records the normalization replay.

The structural rows $H,C,P,N$ preserve the packet under componentwise transport, continuation replay, provenance, and local naming. \end{proof}
