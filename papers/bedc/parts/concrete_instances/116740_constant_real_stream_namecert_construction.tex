Following Bishop and Bridges on real numbers as regular Cauchy data, the $\ConstantRealStreamUp$ packet records the constant certified point stream generated by one finite rational or dyadic point certificate. It sits between the rational source of \autoref{ch:concrete-instances-rat-namecert}, the dyadic tolerance ledger of \autoref{ch:concrete-instances-dyadicratcore-namecert}, the finite stream naming surface of \autoref{ch:concrete-instances-streamname-namecert}, the regular rational readback of \autoref{ch:concrete-instances-regseqrat-namecert}, and the terminal real seal of \autoref{ch:concrete-instances-real-namecert}. The certificate names a constant stream route inside BEDC; it does not import quotient streams, host functions, selected limits, countable choice, or ambient $\RealUp$ completeness.

\begin{definition}[Constant real stream carrier]
\label{def:constant-real-stream-carrier}
A $\ConstantRealStreamUp$ carrier is a finite $\BHist$ packet
$$
K=(Q,D,S,R,E,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $Q$ is the $\RatUp$ point row naming the rational source value.
\item $D$ is the $\DyadicRatCoreUp$ tolerance row that records the finite precision scale at which the same point is read.
\item $S$ is the $\StreamNameUp$ row whose every displayed window names the same source point.
\item $R$ is the $\RegSeqRatUp$ readback row obtained from the constant stream windows.
\item $E$ is the $\RealUp$ seal row reached only after the regular readback row is displayed.
\item $H$ records componentwise $\hsame$ transport for the rational source, dyadic tolerance, stream window, regular readback, Real seal, continuation, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from the constant point row through the stream and regular readback rows to the Real seal.
\item $P$ is the $\Pkg$ provenance over $\ConstantRealStreamUp$, $\RatUp$, $\DyadicRatCoreUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\ConstantRealStreamUp}$ row.
\end{enumerate}
The classifier compares accepted carriers only through $Q,D,S,R,E,H,C,P,N$. It has no coordinate for host functions $\mathbb{N}\to\mathbb{Q}$, quotient stream equality, selected limits, countable-choice schedules, or ambient $\RealUp$ completeness.
\end{definition}

\begin{theorem}[Constant real stream obligations]
\label{thm:constant-real-stream-obligations}

Every consumer must read these rows before using the constant certified point stream.
\end{theorem}
\begin{proof}
Project the accepted carrier of \autoref{def:constant-real-stream-carrier}. The rational source row $Q$ and dyadic tolerance row $D$ are the only point and precision rows visible to the local classifier.

The stream and readback rows preserve that same source. The $\StreamNameUp$ row $S$ exposes finite windows that all name the point displayed by $Q$, and the $\RegSeqRatUp$ row $R$ is reached only through those windows.

The structural rows $H,C,P,N$ transport, replay, source, and name the same finite route. Since quotient streams, host functions, selected limits, countable-choice schedules, and ambient Real completeness are absent from the carrier, the listed rows exhaust the NameCert obligation surface.
\end{proof}
