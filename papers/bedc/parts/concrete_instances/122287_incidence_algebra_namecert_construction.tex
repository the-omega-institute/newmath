\chapter{A Concrete Naming Certificate for $\IncidenceAlgebraUp$}
\label{ch:concrete-instances-incidence-algebra-namecert}
\origin{human}

Following Rota and Stanley on incidence algebras of finite posets, the $\IncidenceAlgebraUp$ packet records the convolution carrier that makes zeta and Mobius rows inspectable before any inversion consumer reads them. It sits after the order source of \autoref{ch:concrete-instances-poset-namecert}, the scalar operation rows of \autoref{ch:concrete-instances-ring-namecert}, the finite tabular carrier of \autoref{ch:concrete-instances-matrix-namecert}, and the inversion consumer route of \autoref{ch:concrete-instances-mobius-inversion-namecert}. The packet names interval-supported functions and their finite convolution ledger; it does not import an infinite algebra, a host function ring, quotient equality of functions, unbounded sums, or selected inverse matrices.

\begin{definition}[Incidence algebra carrier]
\label{def:incidence-algebra-carrier}
An $\IncidenceAlgebraUp$ carrier is a finite $\BHist$ packet
$$
I=(P,R,F,S,M,Z,U,H,C,G,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $P$ is the $\PosetUp$ source row, including the displayed finite comparable-pair ledger.
\item $R$ is the $\RingUp$ scalar row used for addition, multiplication, zero, and one on interval coefficients.
\item $F$ is the interval-supported function table, assigning a scalar coefficient only to displayed pairs $x\leq y$.
\item $S$ is the finite support ledger, refusing every non-comparable pair and every pair outside the displayed finite source.
\item $M$ is the $\MatrixUp$ table view of the same interval-supported data, indexed by the finite poset enumeration.
\item $Z$ is the zeta row, with unit coefficients on accepted comparable pairs and zero outside the interval support.
\item $U$ is the finite convolution row, listing exactly the intermediate $z$ with $x\leq z\leq y$ for every product read.
\item $H$ records componentwise $\hsame$ transport for the poset source, scalar row, function table, support ledger, matrix view, zeta row, convolution row, replay, provenance, and local naming.
\item $C$ records displayed $\Cont$ replay from a convolution request through $P,R,F,S,M,Z,U,H,G,N$.
\item $G$ is the $\Pkg$ provenance over $\IncidenceAlgebraUp$, $\PosetUp$, $\RingUp$, $\MatrixUp$, $\MobiusInversionUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\IncidenceAlgebraUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $P,R,F,S,M,Z,U,H,C,G,N$. It has no coordinate for an infinite incidence algebra, host function equality, unbounded summation, selected inverse matrices, or ambient algebraic completion.
\end{definition}

\begin{theorem}[Incidence algebra NameCert obligations]
\label{thm:incidence-algebra-namecert-obligations}
For every accepted $\IncidenceAlgebraUp$ carrier
$$
I=(P,R,F,S,M,Z,U,H,C,G,N),
$$
the local $\NameCert_{\IncidenceAlgebraUp}$ surface consists exactly of carrier admission for the finite poset source, scalar ring row, interval-supported function table, support ledger, matrix view, zeta row, finite convolution row, componentwise transport, displayed replay, package provenance, and local naming.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:incidence-algebra-carrier}. The rows $P,R,F,S,M,Z,U$ are the displayed mathematical data, and $H,C,G,N$ are the structural rows that transport, replay, source, and name the same packet.

The support row $S$ and convolution row $U$ keep every product read inside a finite interval of the displayed poset. The matrix row $M$ is only a finite table view of the same interval-supported data, so it cannot add host matrix inversion or quotient function equality.

Since no accepted coordinate stores infinite support, unbounded summation, selected inverses, or ambient completion, the listed rows exhaust the NameCert obligations.
\end{proof}

\begin{theorem}[Incidence algebra convolution stability]
\label{thm:incidence-algebra-convolution-stability}
Every convolution read of two accepted $\IncidenceAlgebraUp$ packets over the same $P$ and $R$ remains an $\IncidenceAlgebraUp$ read over the displayed route
$$
P,R,F,S,M,Z,U,H,C,G,N .
$$
The product coefficient at $x\leq y$ may use only the finite intermediates recorded by $U$ for that interval.
\end{theorem}
\begin{proof}
Start with the common poset and scalar rows $P,R$. The support rows of the two packets restrict both coefficient tables to comparable pairs in the same finite source.

For a displayed interval $x\leq y$, read the convolution row $U$. It lists the only intermediate elements available for the product coefficient, and the scalar multiplication and addition are the operations exposed by $R$.

The resulting table has the same finite support boundary and the same matrix view over the finite poset enumeration. Transport, replay, provenance, and local naming are inherited through $H,C,G,N$, so the product remains inside the stated carrier surface.
\end{proof}

\begin{theorem}[Incidence algebra Mobius consumer route]
\label{thm:incidence-algebra-mobius-consumer-route}
Every $\MobiusInversionUp$ consumer that reads zeta or Mobius rows from an $\IncidenceAlgebraUp$ packet must first expose the finite poset source, scalar row, interval-supported table, support ledger, matrix view, zeta row, and convolution row of that packet. \end{theorem}
\begin{proof}
Use the provenance row $G$ to identify the Mobius inversion consumer and the incidence carrier it reads. The consumer starts from the same finite $\PosetUp$ source and $\RingUp$ scalar row as the incidence packet.

The zeta row $Z$ is visible only after the interval support and matrix table have been displayed. The Mobius-facing inverse check can then consume the finite convolution row $U$, matching the finite interval ledger used by \autoref{ch:concrete-instances-mobius-inversion-namecert}.

Because the route is through $P,R,F,S,M,Z,U,H,C,G,N$, no downstream consumer can replace it by host function equality, an infinite incidence algebra, unbounded summation, or a selected matrix inverse.
\end{proof}
