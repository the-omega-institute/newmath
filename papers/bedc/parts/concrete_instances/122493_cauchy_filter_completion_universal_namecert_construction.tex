Following Bishop and Bridges on completion by Cauchy data, the $\CauchyFilterCompletionUniversalUp$ packet names the finite universal-factorization surface for a Cauchy-filter completion. It sits over the Cauchy-filter carrier of \autoref{ch:concrete-instances-cauchyfilter-namecert}, the completion boundary of \autoref{ch:concrete-instances-cauchyfiltercompletion-namecert}, the abstract completion interface of \autoref{ch:concrete-instances-completion-namecert}, the metric source of \autoref{ch:concrete-instances-metric-namecert}, the continuous-map handoff of \autoref{ch:concrete-instances-continuousmap-namecert}, and the terminal real-name seal of \autoref{ch:concrete-instances-real-namecert}. The packet records the universal property as displayed rows only; it does not quotient filters, select limits, invoke choice, use host function extensionality, or assert ambient $\RealUp$ completeness.

\begin{definition}[Cauchy-filter completion universal carrier]
\label{def:cauchy-filter-completion-universal-carrier}
A $\CauchyFilterCompletionUniversalUp$ carrier is a finite $\BHist$ packet
$$
U=(F,D,Y,u,f,g,U_0,H,C,P,N)
$$
with the following rows:
\begin{enumerate}
\item $F$ is the source $\CauchyFilterUp$ row, exposing only displayed filter bases and finite Cauchy-window requests.
\item $D$ is the dense embedding row from the metric source into the completion boundary.
\item $Y$ is the completion target row, read through $\CompletionUp$ and the Cauchy-filter completion surface.
\item $u$ is the uniformly continuous source map row, routed through the $\ContinuousMapUp$ sibling.
\item $f$ is the factor map row from the completion target to the receiving metric object.
\item $g$ is the uniqueness ledger row comparing two displayed factor rows only after $F,D,Y,u,f$ are visible.
\item $U_0$ is the universal-factorization transport row, recording that $u$ is replayed through $D$ and then through $f$.
\item $H$ records componentwise $\hsame$ transport for the source Cauchy filters, dense embedding, completion target, source map, factor map, uniqueness ledger, universal row, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay of the factorization route.
\item $P$ is the $\Pkg$ provenance over $\CauchyFilterCompletionUniversalUp$, $\CauchyFilterUp$, $\CompletionUp$, $\MetricSpaceUp$, $\ContinuousMapUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\CauchyFilterCompletionUniversalUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $F,D,Y,u,f,g,U_0,H,C,P,N$. It has no coordinate for quotient filters, selected completion points, countable choice, host function extensionality, or ambient completeness.
\end{definition}

\begin{theorem}[Cauchy-filter completion universal NameCert obligations]
\label{thm:cauchy-filter-completion-universal-namecert-obligations}
For every accepted $\CauchyFilterCompletionUniversalUp$ carrier $U=(F,D,Y,u,f,g,U_0,H,C,P,N)$, the local $\NameCert_{\CauchyFilterCompletionUniversalUp}$ surface consists exactly of carrier admission for the source Cauchy-filter row, dense embedding row, completion target row, uniformly continuous source-map row, factor-map row, uniqueness ledger, universal-factorization transport, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming. No obligation may replace these rows by quotient classes of Cauchy filters, selected limits, countable choice, host-level function extensionality, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:cauchy-filter-completion-universal-carrier}. The only available coordinates are $F,D,Y,u,f,g,U_0,H,C,P,N$.

The source side is finite. The Cauchy-filter row $F$ supplies displayed filter-base and Cauchy-window data, while the dense embedding row $D$ and target row $Y$ place that data inside the completion boundary named by the sibling completion chapters.

The mapping side is also row-local. The source map $u$ is consumed through the continuous-map handoff, the factor row $f$ is visible only after $F,D,Y,u$ have been displayed, and the uniqueness ledger $g$ compares factor rows inside that same packet.

Transport, replay, provenance, and local naming are the rows $H,C,P,N$. Since no carrier coordinate records quotient filters, selected limits, choice schedules, host function extensionality, or ambient completeness, no NameCert obligation can read such data.
\end{proof}

\begin{theorem}[Cauchy-filter completion universal factorization]
\label{thm:cauchy-filter-completion-universal-factorization}
Every accepted $\CauchyFilterCompletionUniversalUp$ packet factors a displayed uniformly continuous source map through the displayed completion target by the finite route
$$
F,D,Y,u \longmapsto f \longmapsto g \longmapsto U_0
$$
and then through $H,C,P,N$. The route is universal only over the displayed Cauchy-filter, dense-embedding, completion-target, continuous-map, factor-map, uniqueness, transport, replay, provenance, and local naming rows. It does not assert quotient-filter completion, selected completed points, countable choice, host-level function extensionality, or an ambient completeness theorem for $\RealUp$.
\end{theorem}
\begin{proof}
Read the source Cauchy filters through $F$ and the dense embedding through $D$. The completion target $Y$ is available only as the displayed completion boundary supplied by the sibling completion surfaces.

Use the source-map row $u$ as the only uniformly continuous input. The factor row $f$ is attached after $F,D,Y,u$ have been exposed, and the uniqueness ledger $g$ compares factor rows inside that same displayed route.

Finally read the universal-factorization row $U_0$ and the structural rows $H,C,P,N$. Componentwise transport and replay preserve the same route, while provenance and local naming certify only this finite packet. The excluded host-side objects have no row in the carrier, so no consumer can extract them from the factorization.
\end{proof}
