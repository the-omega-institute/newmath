\chapter{A Concrete Naming Certificate for $\DoobDecompositionUp$}
\label{ch:concrete-instances-doob-decomposition-namecert}
\origin{human}

Following Doob and Meyer, the $\DoobDecompositionUp$ packet records the finite row surface by which a displayed submartingale window is split into a martingale residual row and a predictable increasing compensator row. It sits beside the submartingale and martingale packets of \autoref{ch:concrete-instances-submartingale-namecert} and \autoref{ch:concrete-instances-martingale-namecert}, consumes the conditional-expectation surface of \autoref{ch:concrete-instances-condexp-namecert}, and feeds the bounded stopping and crossing consumers of \autoref{ch:concrete-instances-optionalstopping-namecert} and \autoref{ch:concrete-instances-upcrossing-namecert}. The chapter names only the finite decomposition carrier; it does not import measure completion, almost-sure quotient equality, optional projection, or a host predictable sigma-algebra.

\begin{definition}[Doob decomposition carrier]
\label{def:doob-decomposition-carrier}
A $\DoobDecompositionUp$ carrier is a finite $\BHist$ packet
$$
D=(\Omega,S,M,A,C,F,X,E,R,I,T,H,K,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $\Omega$ is the consumed probability-context row shared with the input stochastic process.
\item $S$ is the accepted $\SubmartingaleUp$ row being decomposed.
\item $M$ is the $\MartingaleUp$ residual row over the same finite filtration window.
\item $A$ is the predictable increasing compensator row, displayed as finite step differences visible at the previous filtration stage.
\item $C$ is the $\CondExpUp$ row used to read the successor conditional-expectation faces.
\item $F$ is the finite filtration and adaptedness ledger shared by $S,M,A$.
\item $X$ is the input submartingale endpoint family.
\item $E$ is the finite conditional-expectation family read from $X$ through $C$.
\item $R$ is the residual endpoint family obtained by subtracting the predictable step differences displayed in $A$ from the input endpoints $X$.
\item $I$ is the increasing-row ledger recording nonnegative displayed step differences of $A$.
\item $T$ is the bounded stopping-window handoff row consumed by $\OptionalStoppingUp$ and crossing consumers.
\item $H$ records componentwise $\hsame$ transport for all displayed rows.
\item $K$ records displayed $\Cont$ replay for input exposure, conditional-expectation exposure, residual readback, predictable step-difference readback, stopping-window routing, and crossing handoff.
\item $P$ is the $\Pkg$ provenance row naming exactly $\SubmartingaleUp$, $\MartingaleUp$, $\CondExpUp$, $\OptionalStoppingUp$, $\UpcrossingUp$, $\BHist$, $\hsame$, $\Cont$, $\Pkg$, $\NameCert$, and the local decomposition rows.
\item $N$ is the local $\NameCert_{\DoobDecompositionUp}$ row.
\end{enumerate}
The local classifier compares accepted carriers only through these displayed finite rows. It has no coordinate for completed filtrations, almost-sure quotient classes, optional projection, selected path representatives, or a host predictable sigma-algebra.
\end{definition}

\begin{theorem}[Doob decomposition NameCert obligations]
\label{thm:doob-decomposition-namecert-obligations}
For the carrier of \autoref{def:doob-decomposition-carrier}, the local $\NameCert_{\DoobDecompositionUp}$ surface consists exactly of carrier admission for
$$
\Omega,S,M,A,C,F,X,E,R,I,T,H,K,P,N,
$$
submartingale input exposure through $S$, residual martingale exposure through $M$, successor conditional-expectation exposure through $C,E$, predictable increasing exposure through $A,I$, shared finite filtration exposure through $F$, endpoint and residual readback through $X,R$, bounded stopping and crossing handoff through $T$, componentwise $\hsame$ transport through $H$, displayed $\Cont$ replay through $K$, package provenance through $P$, and local naming through $N$.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:doob-decomposition-carrier}. Its row list fixes the input submartingale, residual martingale, predictable increasing compensator, conditional-expectation faces, common filtration window, endpoint families, stopping handoff, and structural rows.

The decomposition rows are $S,M,A,C,F,X,E,R,I$. The input row $S$ supplies the one-sided conditional-expectation comparison, $C,E$ display the successor faces, $A,I$ display the predictable nonnegative step differences, and $M,R$ record the residual martingale readback on the same finite filtration window.

The consumer rows remain bounded. The row $T$ exposes only the finite stopped-window route needed by $\OptionalStoppingUp$ and $\UpcrossingUp$, so downstream crossing consumers read the decomposition through displayed finite windows.

The structural rows $H,K,P,N$ transport, replay, source, and name the same finite packet. Since no row names measure completion, almost-sure quotient equality, optional projection, selected path representatives, or a host predictable sigma-algebra, the listed obligations exhaust the local NameCert surface.
\end{proof}

\falsifiablePrediction{An accepted $\DoobDecompositionUp$ consumer that reads a martingale residual or predictable increasing row without first displaying the $\SubmartingaleUp$ input row, the $\CondExpUp$ successor faces, and the shared finite filtration ledger is outside the carrier.}
