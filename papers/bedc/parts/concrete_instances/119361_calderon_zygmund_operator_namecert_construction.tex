\begin{definition}[Calderon-Zygmund operator carrier]
\label{def:calderon-zygmund-operator-carrier}

$$

with the following displayed rows:
\begin{enumerate}
\item $X$ is the metric or measure source row. It records the named points, measurable windows, local ball names, and source-side admission data actually inspected by the singular-integral request.
\item $W$ is the truncated kernel-window row. Each entry records a finite exclusion radius, an outer cutoff, and the displayed source and target coordinates for the kernel read.
\item $S$ is the kernel-size ledger. It stores the finite dyadic comparison budget for the displayed kernel windows, including the scale rows that compare kernel magnitude against the source distance.
\item $A$ is the cancellation ledger. It records the displayed zero-average, antisymmetry, or subtraction row used on each accepted window before any operator value is read.
\item $L$ is the local test-function or average row. It stores the finite test window, local average, or compactly supported probe against which the truncated kernel is evaluated.

\end{enumerate}
The classifier compares accepted carriers only through $X,W,S,A,L,M,D,E,H,C,P,N$. It has no coordinate for a selected principal value, measure completion, quotient function representative, unbounded kernel family, hidden cancellation theorem, or ambient $\RealUp$ completeness principle.
