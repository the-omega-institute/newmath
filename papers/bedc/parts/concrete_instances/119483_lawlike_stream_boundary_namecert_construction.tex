\begin{definition}[Lawlike stream boundary carrier]
\label{def:lawlike-stream-boundary-carrier}

$$

$$
with the following displayed rows:
\begin{enumerate}
\item $S$ is the lawlike source row. It records the displayed rule, finite source ledger, and admissible request boundary for the stream name being inspected.
\item $W$ is the $\StreamNameUp$ finite-window row. It lists exactly the windows through which the lawlike source may be queried before any rational or real-facing read is public.
\item $R$ is the $\RegSeqRatUp$ readback row obtained from the displayed windows and the rational tolerance discipline already exposed by the stream route.
\item $E$ is the terminal $\RealUp$ seal row. It is reached only after the lawlike source row, StreamName window row, and RegSeqRat readback row have been displayed.
\item $O$ is the obstruction and refusal row. It records that the packet refuses selected host sequences, countable-choice selectors, quotient stream equality, trichotomy, and ambient $\RealUp$ completeness, matching the constructive warning surfaces of $\SpeckerSequenceUp$ and $\BrouwerianCounterexampleUp$.
\item $H$ records componentwise $\hsame$ transport for the lawlike source, StreamName windows, RegSeqRat readback, Real seal, obstruction row, continuation replay, provenance, and local naming rows.

\item $N$ is the local $\NameCert_{\LawlikeStreamBoundaryUp}$ row.

The carrier predicate admits exactly these rows. Its classifier compares accepted packets only through $S,W,R,E,O,H,C,P,N$ and has no coordinate for a selected host sequence, a global choice function, quotient stream equality, trichotomy, or a completeness theorem for $\RealUp$.
\end{definition}

\begin{theorem}[Lawlike stream boundary NameCert obligations]
\label{thm:lawlike-stream-boundary-namecert-obligations}
For an accepted $\LawlikeStreamBoundaryUp$ carrier $L=(S,W,R,E,O,H,C,P,N)$, the local $\NameCert_{\LawlikeStreamBoundaryUp}$ surface consists exactly of the following finite obligations:
\begin{enumerate}
\item carrier admission for the lawlike source row, $\StreamNameUp$ finite-window row, $\RegSeqRatUp$ readback row, terminal $\RealUp$ seal, obstruction and refusal row, transport, replay, provenance, and local naming row;
\item source-window compatibility, requiring every public request to start at the displayed lawlike source row $S$ and then pass through the finite window row $W$;
\item regular readback discipline, requiring rational observations to pass through the $\RegSeqRatUp$ row $R$ before the $\RealUp$ seal $E$ is exposed;
\item refusal stability, requiring the obstruction row $O$ to remain visible whenever a consumer asks for host sequence selection, countable choice, quotient stream equality, trichotomy, or Real completeness;
\item transport and replay, requiring $H$ and $C$ to preserve the same ordered route under $\hsame$ transport and displayed $\Cont$ replay;
\item provenance and naming, requiring $P$ and $N$ to name only the finite lawlike-window surface and not an ambient stream object.
\end{enumerate}
No NameCert obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Project the accepted carrier. Its public data are exactly the rows $S,W,R,E,O,H,C,P,N$.

The source-window obligation follows from the first two rows. A consumer begins at the lawlike source row $S$ and then reads only the finite windows displayed in $W$ before asking for rational or Real-facing data.

The regular readback obligation is the row $R$. It binds the finite StreamName observations to the regular rational readback surface before the terminal seal $E$ can be consumed.

The obstruction row $O$ is part of the same packet, so a request for selected host sequences, countable choice, quotient stream equality, trichotomy, or Real completeness is refused at the boundary rather than supplied by another coordinate.

Finally $H,C,P,N$ transport, replay, source, and name the same finite route. Since no additional coordinate appears in the carrier, the local NameCert surface is exactly the displayed lawlike-window boundary.
\end{proof}
