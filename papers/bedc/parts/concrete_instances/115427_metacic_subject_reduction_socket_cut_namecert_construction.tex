\begin{theorem}[MetaCIC subject-reduction socket-cut obligations]
\label{thm:metacic-subject-reduction-socket-cut-namecert-obligations}

\end{theorem}
\begin{proof}
Project the accepted carrier. The four visible discharge sockets are $B,A,L,P$, and the only parameterised subject-reduction row is $T$.

Read the socket discipline through \autoref{ch:concrete-instances-subject-reduction-discharge-socket-namecert}. That packet already separates the four inputs consumed by parameterised subject reduction from the closed obstruction boundary.

Now inspect $T$ and $O$. The row $T$ records the checked parameterised theorem as a consumer of all four sockets, while $O$ records the checked obstruction described in \autoref{prin:metacic-closed-subject-reduction-not-available}. These rows are different coordinates, so the obstruction row cannot be used as a substitute proof of closed subject reduction.

Finally $H,C,G,N$ transport, replay, source, and name the same cut. Since no coordinate stores host conversion, erased derivation semantics, quotient equality, global normalization, or an unparameterised closed theorem, the listed rows exhaust the NameCert surface.
\end{proof}
