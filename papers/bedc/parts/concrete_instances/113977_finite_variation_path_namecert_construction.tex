\chapter{A Concrete Naming Certificate for $\FiniteVariationPathUp$}
\label{ch:concrete-instances-finite-variation-path-namecert}
\origin{human}

Following Jordan and Bishop--Bridges constructive analysis, the $\FiniteVariationPathUp$ packet records finite-variation data for a displayed metric-valued path by finite partition windows and regular rational variation ledgers. It sits beside the bounded-variation surface of \autoref{ch:concrete-instances-boundedvariation-namecert}, the path-length boundary of \autoref{ch:concrete-instances-rectifiable-curve-namecert}, the dyadic tolerance core of \autoref{ch:concrete-instances-dyadicratcore-namecert}, the regular rational readback route of \autoref{ch:concrete-instances-regseqrat-namecert}, and the terminal real-name seal of \autoref{ch:concrete-instances-real-namecert}. The packet names a path-level finite-variation certificate for L10 Real and Completion consumers; it does not import a host path space, a supremum over all partitions, quotient equality of paths, countable choice, or ambient $\RealUp$ completeness.

\begin{definition}[Finite variation path carrier]
\label{def:finite-variation-path-carrier}
A $\FiniteVariationPathUp$ carrier is a finite $\BHist$ packet
$$
V=(M,\gamma,I,\Pi,D,B,Q,E,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $M$ is the metric and continuous-path source row, exposing the accepted metric carrier, the displayed distance read, and the $\ContinuousMapUp$ path graph through the same source and target windows.
\item $\gamma$ is the path-evaluation schedule, recording the finite endpoint probes of the path on the inspected interval row.
\item $I$ is the finite interval-domain row supplying the ordered endpoints and the admissible subdivision boundary.
\item $\Pi$ is the finite partition row over $I$, including adjacency, endpoint membership, and finite common-refinement witnesses for pairs of displayed partitions.
\item $D$ is the $\DyadicRatCoreUp$ edge-distance ledger, recording the adjacent distance terms and partial variation sums for the partition window $\Pi$.
\item $B$ is the variation-sum bound row, comparing the dyadic edge-distance sum in $D$ with the displayed finite bound attached to the accepted path packet.
\item $Q$ is the $\RegSeqRatUp$ readback row by which a downstream regular-rational consumer reads the same edge-distance ledger and bound through finite windows.
\item $E$ is the terminal $\RealUp$ seal row reached only after $M,\gamma,I,\Pi,D,B,Q$ have all been displayed.
\item $H$ records componentwise $\hsame$ transport for the metric source, path schedule, interval, partition, edge-distance ledger, bound row, regular-rational readback, real seal, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a finite-variation request through path evaluation, partition exposure, dyadic edge-distance summation, common-refinement comparison, regular-rational readback, and the real seal.
\item $P$ is the $\Pkg$ provenance over $\FiniteVariationPathUp$, $\BoundedVariationUp$, $\RectifiableCurveUp$, $\DyadicRatCoreUp$, $\RegSeqRatUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\FiniteVariationPathUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $M,\gamma,I,\Pi,D,B,Q,E,H,C,P,N$. It has no coordinate for a host path space, a total variation supremum over all partitions, quotient equality of paths, selected representatives, or ambient completeness of $\RealUp$.
\end{definition}

\begin{theorem}[Finite variation path NameCert obligations]
\label{thm:finite-variation-path-namecert-obligations}
For every accepted $\FiniteVariationPathUp$ carrier $V=(M,\gamma,I,\Pi,D,B,Q,E,H,C,P,N)$, the local $\NameCert_{\FiniteVariationPathUp}$ surface consists exactly of carrier admission, metric and continuous-path source exposure, finite interval and partition exposure, dyadic edge-distance ledger readback, variation-sum bound comparison, common-refinement comparison, RegSeqRat readback, RealUp seal routing, componentwise transport, continuation replay, provenance, and local naming.

Every path-variation consumer in this scope must therefore read the finite route
$$
M,\gamma,I,\Pi
\longmapsto
D,B
\longmapsto
Q,E
$$
together with $H,C,P,N$, and receives no host path-space object, all-partitions supremum, quotient path equality, hidden selector, or ambient $\RealUp$ completeness coordinate.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:finite-variation-path-carrier}. The visible analytic rows are the metric and path source $M,\gamma$, the interval and partition rows $I,\Pi$, the dyadic edge-distance ledger $D$, the bound row $B$, the regular-rational readback $Q$, and the real seal $E$.

The variation request is finite at the displayed partition. The interval row supplies the ordered domain, the path schedule supplies endpoint probes, and the partition row lists the adjacent pairs whose metric distance terms are consumed by $D$.

The bound comparison is read through $B$. Common-refinement witnesses live in $\Pi$ and compare only displayed finite partition ledgers and their dyadic sums, so the classifier does not range over all partitions.

The L10 readback is downstream of the ledger. The row $Q$ returns the inspected variation sum and bound as regular rational data, while $E$ seals that same displayed route as $\RealUp$ data.

Finally $H,C,P,N$ transport, replay, source, and name the same finite packet. Since no remaining coordinate names a host path space, quotient path equality, hidden selector, or completeness principle, the listed rows exhaust the local NameCert obligations.
\end{proof}

\begin{theorem}[Finite variation path RegSeqRat--Real handoff]
\label{thm:finite-variation-path-regseqrat-real-handoff}
Every $\RegSeqRatUp$ or $\RealUp$ consumer of an accepted $\FiniteVariationPathUp$ carrier factors through the displayed metric-path source row, finite partition row, dyadic edge-distance ledger, variation-sum bound, and common-refinement comparison before it may read the regular-rational row $Q$ or the terminal real-name seal $E$.

The handoff is compatible with the bounded-variation and rectifiable-curve neighbors: bounded-variation consumers read only the finite partition-variation ledger, and rectifiable-curve consumers read only the displayed partition-length route. Neither consumer receives a host path space, an all-partitions supremum, quotient equality of paths, selected representatives, countable choice, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Start with a RegSeqRat or Real-facing read. The continuation row $C$ first replays the displayed source rows $M,\gamma$ and the interval-partition rows $I,\Pi$, so the downstream consumer is attached to a finite path window before any variation value is exposed.

Next the dyadic ledger $D$ supplies the adjacent distance terms and the partial sum for the displayed partition. The bound row $B$ compares that finite sum with the accepted variation budget, and the common-refinement data in $\Pi$ compare only finite ledgers over displayed subdivisions.

Only after those rows are present can the read reach $Q$ and $E$. The regular-rational row $Q$ returns the inspected ledger and bound through finite readback windows, and the real seal $E$ packages the same route for $\RealUp$ consumers.

The neighboring bounded-variation and rectifiable-curve reads are projections of the same displayed packet. They use the partition-variation and partition-length coordinates already named above, without adding a path quotient, a selected representative, a supremum over all partitions, or a completeness witness.
\end{proof}
