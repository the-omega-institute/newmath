\begin{definition}[Uniform Cauchy map carrier]
\label{def:uniform-cauchy-map-carrier}

$$

\begin{enumerate}

\item $Y$ is the target carrier row, naming the displayed codomain read surface for each inspected value.
\item $F$ is the displayed family row, routing inspected stage-and-argument pairs through $\FunctionSequenceUp$ and $\ContinuousMapUp$ graph rows.
\item $W$ is the finite window ledger that aligns the source windows with the inspected family stages.
\item $R$ is the $\RegSeqRatUp$ readback row for target values observed in those windows.

\begin{theorem}[Uniform Cauchy map NameCert obligations]
\label{thm:uniform-cauchy-map-namecert-obligations}
For every accepted $\UniformCauchyMapUp$ carrier $U=(X,Y,F,W,R,M,D,E,H,C,P,N)$, the local $\NameCert_{\UniformCauchyMapUp}$ surface consists exactly of carrier admission for the displayed source windows, target row, family row, finite window ledger, $\RegSeqRatUp$ readback, shared uniform Cauchy modulus, $\DyadicRatCoreUp$ tolerance ledger, terminal $\RealUp$ seal, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming. Each tolerance request must read the same threshold row in $M$ for every inspected source window before the target readback in $R$ or the terminal seal $E$ can be consumed.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:uniform-cauchy-map-carrier}. The analytic rows are $X,Y,F,W,R,M,D,E$, and the structural rows are $H,C,P,N$.

The uniform Cauchy condition is carried only by $M$ and $D$. A requested dyadic tolerance first reads the radius and slack from $D$, then reads a single threshold row from $M$ that is shared across the displayed source windows in $W$.

The target readback stays downstream. The row $R$ records only regular rational observations of the inspected values, and the terminal $\RealUp$ seal $E$ appears only after the source windows, family graph rows, modulus row, and tolerance ledger have been displayed.

Transport and replay preserve the same rows through $H$ and $C$, while $P$ and $N$ source and name the local packet. Since none of the refused principles is a carrier coordinate, the NameCert surface cannot use Real completeness, host function equality, selected limits, quotient streams, trichotomy, or choice.
\end{proof}
