The $\LawvereMetricCompletionUp$ directed-profile route consumes symmetric completion data only after the one-sided profile has already passed through $\QuasiMetricUp$, $\YonedaCompletionUp$, and $\FormalBallUp$. The metric-completion dense embedding of \autoref{ch:concrete-instances-metric-completion-dense-embedding-namecert} and the dense-reflector route of \autoref{ch:concrete-instances-cauchy-completion-dense-reflector-namecert} are therefore horizontal consumers of the displayed profile surface, not replacements for the directed source row.

\begin{proposition}[Lawvere metric completion dense-reflector handoff]
\label{prop:lawvere-metric-completion-dense-reflector-handoff}
Any completion-facing read that compares an accepted $\LawvereMetricCompletionUp$ packet with $\MetricCompletionDenseEmbeddingUp$ or $\CauchyCompletionDenseReflectorUp$ must first display the $\QuasiMetricUp$ source row, $\YonedaCompletionUp$ profile row, $\FormalBallUp$ approximation row, $\DyadicRatCoreUp$ tolerance row, $\RegSeqRatUp$ readback row, and $\RealUp$ seal row from \autoref{thm:lawvere-metric-completion-directed-profile-composition}. Only after that directed profile is visible may the read consume the symmetric dense-embedding or Cauchy dense-reflector rows. The handoff exports no selected profile limit, quotient directed Cauchy object, symmetric-collapse equality, countable-choice schedule, or ambient completeness theorem.
\end{proposition}
\begin{proof}
Start with the directed-profile composition theorem. It fixes the visible route through the QuasiMetric source, Yoneda profile, FormalBall approximation, dyadic tolerance ledger, regular rational readback, and Real seal before any completion-facing consumer can inspect the packet.

Next read the sibling dense-completion surfaces. $\MetricCompletionDenseEmbeddingUp$ supplies the symmetric dense-image row for ordinary metric completion, while $\CauchyCompletionDenseReflectorUp$ supplies the Cauchy dense-reflector route through that dense image. Both are consumed after the Lawvere profile has exposed its directed rows.

Thus the comparison is a handoff from the directed profile into the existing completion infrastructure. Since the Lawvere carrier has no coordinate for selected profile limits, quotient directed Cauchy objects, symmetric-collapse equality, countable choice, or ambient completeness, none of those objects is exported by the handoff.
\end{proof}
