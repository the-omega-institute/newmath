\begin{theorem}[FanFunctional root finite-prefix uniform modulus]
\label{thm:fan-functional-root-finite-prefix-uniform-modulus}
For every accepted $\FanFunctionalUp$ carrier $\Phi=(C,F,\varepsilon,B,D,W,M,H,K,P,N)$, the root finite-prefix read exports the row $M$ only after the carrier surface of \autoref{def:fan-functional-carrier-surface} and the local obligations of \autoref{thm:fan-functional-namecert-obligations} have exposed $C,F,\varepsilon,B,D,W,H,K,P,N$ on the same $\BHist$ packet. Thus $M$ is a finite-prefix $\UniformModulusUp$ row supported by the displayed Cantor prefix, fan-depth, tolerance, branch-window, and witness-window rows, not by a host functional, selected branch, or ambient compactness principle.
\end{theorem}
\begin{proof}
Project the carrier. The rows $C,F,\varepsilon,B,D,W,M,H,K,P,N$ are already displayed as finite $\BHist$ coordinates, and the NameCert obligation surface separates carrier admission from the modulus extraction clause.

Read the finite fan-depth ledger before the modulus row. Rows $C,F$ expose the Cantor prefix and finite fan surface, row $\varepsilon$ fixes the tolerance request, rows $B,D$ bind the branch window and depth, and row $W$ records the witnesses whose bounded inspection length is repacked as $M$.

The structural rows keep the handoff root-local. Componentwise transport through $H$, displayed replay through $K$, provenance through $P$, and local naming through $N$ preserve the same finite packet, so no external branch selector, host functional, or open-cover compactness object can contribute to the exported modulus.
\end{proof}

\begin{theorem}[FanFunctional root witness-window coverage]
\label{thm:fan-functional-root-witness-window-coverage}
For every accepted $\FanFunctionalUp$ carrier $\Phi=(C,F,\varepsilon,B,D,W,M,H,K,P,N)$, the witness-window row $W$ covers exactly the retained branch prefixes in $B$ whose finite bar-depth exposure is certified by $D$. Every root read of the modulus row $M$ must first pass through that $C,F,\varepsilon,B,D,W$ coverage surface and then through $H,K,P,N$; it may not omit a displayed prefix, add an unseen prefix, or use a selected infinite branch.
\end{theorem}
\begin{proof}
Start with the carrier surface. The retained prefixes are named by $B$, and the fan row $F$ together with the depth ledger $D$ determines which finite prefixes have reached the displayed bar before any witness is read.

Use the NameCert obligations. Witness-window coverage is a separate finite clause between bar-depth exactness and uniform-modulus extraction, so $W$ cannot be replaced by a later choice of branch or by a host-level compactness proof.

Finally route the coverage through $H,K,P,N$. These rows transport, replay, source, and name the same packet, forcing every public modulus read of $M$ to use the displayed coverage window and excluding omitted, added, or infinitely selected prefixes.
\end{proof}

\begin{theorem}[FanFunctional root nonescape ledger]
\label{thm:fan-functional-root-nonescape-ledger}

\end{theorem}
\begin{proof}
List the available rows. Carrier admission gives exactly $C,F,\varepsilon,B,D,W,M,H,K,P,N$, and the existing NameCert surface assigns the root obligations to these coordinates.

Read the finite obligations in order. Classifier stability uses the displayed Cantor and fan rows, bar-depth exactness uses $D$, witness-window coverage uses $W$, and uniform-modulus extraction exports $M$ only through those finite rows.

Coordinate exhaustion supplies the nonescape claim. Since the carrier has no coordinate for a host functional, branch selector, open cover, choice schedule, or Real-completeness witness, the structural route through $H,K,P,N$ is the whole public ledger.
\end{proof}
