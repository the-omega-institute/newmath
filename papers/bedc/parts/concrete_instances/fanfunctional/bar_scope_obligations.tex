\begin{theorem}[FanFunctional finite bar-depth carrier scope]
\label{thm:fanfunctional-bar-scope-obligations}
Every accepted $\FanFunctionalUp$ root read that exposes finite bar-depth data must route the $\CantorSpaceUp$ prefix row, $\FanTheoremUp$ bar row, $\CompactMetricUp$ finite-window consumer, and $\UniformModulusUp$ target through the displayed $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$ rows. The carrier scope contains no choice-selected branch, host functional, open-cover compactness proof, quotient stream equality, or ambient Real-completeness principle.
\end{theorem}
\leanchecked{BEDC.Derived.FanfunctionalUp.FanFunctionalBarScopeObligations}
\begin{proof}
Project the carrier of \autoref{def:fan-functional-carrier-surface}. The Cantor-prefix row, finite fan row, branch-prefix window, bar-depth evidence, witness window, and extracted modulus are all displayed finite rows.

Use the root-unblock Cantor-prefix and finite fan-depth routes of \autoref{thm:fanfunctional-root-unblock-cantor-prefix} and \autoref{thm:fanfunctional-root-unblock-fan-depth}. They place the $\CantorSpaceUp$ and $\FanTheoremUp$ rows before any compact or modulus consumer can inspect the packet.

The $\CompactMetricUp$ and $\UniformModulusUp$ rows are then replayed through the same $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$ ledger. Since no coordinate contains a selected infinite branch or host functional, the finite bar-depth carrier cannot export one.
\end{proof}

\begin{theorem}[FanFunctional Cantor compactness scope]
\label{thm:fanfunctional-cantor-compactness-scope}
Every $\FanFunctionalUp$ consumer that reads Cantor compactness data reaches it through $\CantorSpaceUp$, $\FanTheoremUp$, $\CompactMetricUp$, $\UniformModulusUp$, $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$ rows displayed by the accepted packet. The scope is finite-prefix compactness replay and not an open-cover compactness theorem, choice-selected branch, host fan functional, quotient stream equality, or ambient real-order argument.
\end{theorem}
\leanchecked{BEDC.Derived.FanfunctionalUp.FanFunctionalCantorCompactnessScope}
\begin{proof}
Read the Cantor prefix row from \autoref{def:fan-functional-carrier-surface}. It supplies finite Boolean observation windows and StreamName schedules before the fan-depth row is visible.

Apply \autoref{thm:fanfunctional-bar-scope-obligations}. The finite bar-depth row bounds the retained prefix window, so the compactness-facing read is a finite-prefix replay over $\CantorSpaceUp$ and $\FanTheoremUp$.

The compact metric consumer is admitted only through the displayed $\CompactMetricUp$ row and the same transport, replay, provenance, and naming rows. Thus the compactness scope cannot detach into an open-cover theorem, selected branch, host functional, quotient stream equality, or ambient real-order argument.
\end{proof}

\begin{theorem}[FanFunctional uniform-modulus export scope]
\label{thm:fanfunctional-uniform-modulus-scope}
Every $\UniformModulusUp$ row exported by an accepted $\FanFunctionalUp$ packet is scoped over $\CantorSpaceUp$, $\FanTheoremUp$, $\CompactMetricUp$, $\UniformModulusUp$, $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$ rows. The export is a finite row replay from prefix depth and witness windows, not a choice-selected branch, host functional, bar-induction proof, open-cover compactness proof, quotient stream equality, or ambient Real-completeness row.
\end{theorem}
\leanchecked{BEDC.Derived.FanfunctionalUp.FanFunctionalUniformModulusScope}
\begin{proof}
Start with the finite bar-depth scope of \autoref{thm:fanfunctional-bar-scope-obligations}. It fixes the Cantor prefix, fan-depth, compact-window, and structural rows available to a modulus export.

Use the Cantor compactness scope of \autoref{thm:fanfunctional-cantor-compactness-scope}. The compact metric row is consumed only as finite-prefix replay through the accepted packet.

Finally apply the root-unblock uniform-modulus handoff of \autoref{thm:fanfunctional-root-unblock-uniform-modulus}. The exported $\UniformModulusUp$ row stays downstream of $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$ rows, so none of the excluded branch, host-functional, induction, compactness, quotient, or Real-completeness data can escape.
\end{proof}
