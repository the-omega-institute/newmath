\begin{theorem}[Farey sequence stream-window adjacency scope]
\label{thm:farey-sequence-stream-window-adjacency-scope}
For every accepted $\FareySequenceUp$ carrier
$$
F=(B,A,M,L,T,S,D,Q,W,R,G,E,H,C,P,N),
$$
the $\StreamNameUp$ window $W$ reads only the displayed ordered boundary row $B$ and the adjacency ledger $A$ when it exports a finite Farey window. In particular, every windowed entry request is classified by the displayed rational boundary row, every neighboring-pair request is classified by the determinant-one rows in $A$, and no host real order, quotient real comparison, selected branch, or ambient completion datum is available to the window classifier.
\end{theorem}
\leanchecked{BEDC.Derived.FareySequenceUp.FareySequenceStreamWindowAdjacencyScope}
\begin{proof}
Project the accepted packet to $B,A,W,H,C,P,N$. The row $W$ is a finite stream window whose entries are requested from the displayed boundary sequence $B$, so the entry classifier is already bounded by the ordered rational rows of $B$.

Neighboring-pair reads then use $A$. Each adjacent request in the window points to the determinant-one ledger row for the displayed consecutive pair, not to a host-order comparison or to an external real representative.

The rows $H,C,P,N$ transport, replay, package, and name the same finite data. Since the carrier has no coordinate for host real order, quotient real comparison, selected branches, or ambient completion, the stream-window classifier cannot escape $B,A,W,H,C,P,N$.
\end{proof}
