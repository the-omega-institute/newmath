Following Bishop and Bridges constructive real analysis, the $\RemovableDiscontinuityUp$ packet records the finite pointwise repair route by which a function value at one displayed puncture is replaced by a displayed limiting value before a continuity-facing consumer reads the repaired function. It sits beside the terminal real-name seal of \autoref{ch:concrete-instances-real-namecert}, the regular rational readback route of \autoref{ch:concrete-instances-regseqrat-namecert}, the finite limiting surface of $\LimitUp$, the continuous-function surfaces $\ContinuousUp$ and $\ContinuousMapUp$, and the Riemann-specific repair packet of \autoref{ch:concrete-instances-riemann-removable-discontinuity-namecert}. The packet repairs only the named local defect; it does not select global functions, identify quotient real functions, invoke countable choice, assume ambient $\RealUp$ completeness, or prove a host extensionality principle.

\begin{definition}[Removable-discontinuity carrier]
\label{def:removable-discontinuity-carrier}
A $\RemovableDiscontinuityUp$ carrier is a finite $\BHist$ packet
$$
M=(P,W,L,V,E,R,H,C,Q,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $P$ is the punctured point row, naming the source point, the displayed domain side, and the fact that the ordinary value at the point is not the row read by the repair certificate.
\item $W$ is the punctured-window row, listing the finite neighbourhood windows and exclusions used to inspect the source function away from $P$.
\item $L$ is the limiting-value row, read through $\LimitUp$, $\RegSeqRatUp$, and $\RealUp$ data attached to the punctured windows.
\item $V$ is the repaired-value row, inserting the displayed limiting value as the value assigned at the puncture.
\item $E$ is the continuous-extension row, recording the repaired local function surface through $\ContinuousUp$ or $\ContinuousMapUp$ after $P,W,L,V$ have been displayed.
\item $R$ is the $\RegSeqRatUp$ and $\RealUp$ readback route for all numeric observations used by $W,L,V,E$.
\item $H$ records componentwise $\hsame$ transport for the puncture, punctured windows, limiting value, repaired value, extension row, readback, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a repair request through $P,W,L,V,E,R,H,Q,N$.
\item $Q$ is the $\Pkg$ provenance over $\RemovableDiscontinuityUp$, $\LimitUp$, $\ContinuousUp$, $\ContinuousMapUp$, $\RegSeqRatUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\RemovableDiscontinuityUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $P,W,L,V,E,R,H,C,Q,N$. It has no coordinate for host function extensionality, selected global functions, quotient real equality, countable choice, ambient $\RealUp$ completeness, Lean verification, or bridge checking.
\end{definition}

\begin{theorem}[Removable-discontinuity NameCert obligations]
\label{thm:removable-discontinuity-namecert-obligations}
For every accepted $\RemovableDiscontinuityUp$ carrier
$$
M=(P,W,L,V,E,R,H,C,Q,N),
$$
the local $\NameCert_{\RemovableDiscontinuityUp}$ surface consists exactly of five rows:
\begin{enumerate}
\item carrier admission for the displayed packet $M$;
\item punctured-window exposure, requiring the source read to pass through $P$ and $W$ before any repair value is consumed;
\item limit-value readback, requiring $L$ and $R$ to expose the $\LimitUp$, $\RegSeqRatUp$, and $\RealUp$ route used for the replacement value;
\item repaired-value insertion and continuous-extension handoff, requiring $V$ to be inserted before $E$ is exported to $\ContinuousUp$ or $\ContinuousMapUp$ consumers;
\item ledger nonescape, meaning every consumer-visible repair claim is projected from $P,W,L,V,E,R,H,C,Q,N$ and from no host extensionality, selected global function, quotient real equality, choice principle, or ambient completeness datum.
\end{enumerate}
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:removable-discontinuity-carrier}. The pointwise repair rows are $P,W,L,V,E$, and the structural rows are $R,H,C,Q,N$.

The puncture row $P$ fixes the only point at which the ordinary source value is not read directly. The punctured-window row $W$ lists the finite neighbourhood observations away from that point, so a consumer cannot infer a global function extension before the local windows are displayed.

The limiting value is read through $L$ together with the numeric route $R$. These rows bind the $\LimitUp$, $\RegSeqRatUp$, and $\RealUp$ data used for the replacement value, while $V$ records that this displayed value is inserted at the puncture.

The handoff row $E$ is therefore available only after $P,W,L,V,R$ have been displayed. Transport and replay use $H$ and $C$, and provenance and local naming use $Q$ and $N$.

Since no excluded principle is a coordinate of the carrier, none can be exported by the local NameCert surface.
\end{proof}
