\begin{theorem}[RandomVar martingale-filtration handoff]
\label{thm:randomvar-martingale-filtration-handoff}
Every $\MartingaleUp$ or $\StoppingTimeUp$ consumer of a $\RandomVarUp$ endpoint must read the source $\ProbSpaceUp$ row, event-preimage exactness rows, total-readback certificate, filtration visibility row, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local $\NameCert$ row before conditional-expectation or stopping decisions are exposed. The handoff exports no host measurable function, completed sigma-algebra, almost-sure quotient equality, or unbounded stopping choice.
\end{theorem}
\begin{proof}
Start with the carrier and certificate surface of \autoref{sec:randomvar-carrier} and \autoref{sec:randomvar-certificate}. The source probability row is supplied by \autoref{ch:concrete-instances-probspace-namecert}, and the preimage rows are the finite event-readback rows recorded in \autoref{thm:randomvar-preimage-measure-probspace-lattice-link}.

Read the exactness children next. The disjoint-union, relative-difference, complement, empty-event, binary-intersection, terminal, and countable preimage rows in the existing random-variable files keep every target-event observation inside the displayed source event ledger. The total-readback certificate of \autoref{def:randomvar-total-readback-certificate} supplies the terminal source coverage needed before an endpoint can be treated as a process value.

For a martingale consumer, the endpoint row is then exposed only through the finite process surface of \autoref{ch:concrete-instances-martingale-namecert}. A stopping-time consumer reads the same endpoint only through the filtration-prefix route of \autoref{ch:concrete-instances-stoppingtime-namecert}, so the visibility row is a finite ledger read rather than a host filtration.

Finally replay the structural rows. Componentwise $\hsame$, displayed $\Cont$, $\Pkg$, and the local $\NameCert$ preserve the same source-probability, preimage, total-readback, and filtration-visibility route before $\CondExpUp$ or bounded stopping data are consumed. Since no row stores a host measurable function, completed sigma-algebra, almost-sure quotient equality, or unbounded stopping choice, the handoff cannot export them.
\end{proof}
