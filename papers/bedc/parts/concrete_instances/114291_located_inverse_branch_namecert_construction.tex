$$

\item $I$ is the $\LocatedRealUp$ source-and-target interval row, carrying the located endpoint data and target window that delimit the inverse request.
\item $J$ is the $\LocatedRealIntervalBisectionUp$ branch row, recording the retained interval side and the finite branch history used to isolate the source window.
\item $M$ is the monotone-window row. It records the finite order comparisons that keep the retained branch compatible with the local inverse request.
