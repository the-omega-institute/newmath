\begin{theorem}[Compact modulus fan NameCert obligations]
\label{thm:compact-modulus-fan-namecert-obligations}
For an accepted $\CompactUniformModulusCertificateUp$ carrier $(K,F,L,Q,S,T,U,H,C,P,N)$, the local $\NameCert_{\CompactUniformModulusCertificateUp}$ surface consists exactly of the following finite obligations:
\begin{enumerate}
\item carrier admission for compact finite-net rows, continuous-map rows, pointwise modulus ledgers, rational lower-bound fold rows, source and target metric triangle rows, uniform-modulus consumer rows, transport, continuation, provenance, and local naming;
\item finite-net coverage, requiring every source-point request to choose a displayed bundled center through $K$ rather than through an external selector;
\item pointwise-modulus lookup, requiring each bundled center to read its local radius and target-tolerance row through $F$ and $L$;
\item rational-fold exactness, requiring $Q$ to be certified below every local radius by $\RatUp$ comparisons;
\item source-target triangle handoff, requiring $S$ and $T$ to turn finite-net coverage plus the folded radius into the final uniform target estimate;
\item uniform-modulus exposure, requiring $U$ to expose only the tolerance request and folded precision as the public $\UniformModulusUp$ row;
\item ledger non-escape, excluding open-cover compactness, host function extensionality, quotient map equality, selected external moduli, countable choice, and ambient completeness of $\RealUp$.
\end{enumerate}
\end{theorem}
\begin{proof}
Project the accepted carrier. Its public coordinates are exactly the compact finite-net row $K$, continuous-map row $F$, local modulus ledger $L$, rational fold $Q$, source and target metric rows $S,T$, uniform-modulus row $U$, and structural rows $H,C,P,N$.

Finite-net coverage is read from $K$. Each source point is routed to a bundled center that is already part of the finite compact packet, so no external center selector is introduced.

Pointwise-modulus lookup uses $F$ and $L$ at each bundled center. The local radius and target-tolerance estimate are stored as displayed rows, and the lower-bound fold $Q$ is obtained by primitive recursion over those finitely many rational radius rows.

The source metric row $S$ moves a nearby pair of source points into the same local ball around the selected center. The target metric row $T$ then combines the two pointwise estimates, and $U$ exposes the resulting tolerance-only precision as the uniform-modulus consumer row.

The transport, continuation, provenance, and local naming rows preserve this same route. Since no carrier coordinate stores open-cover compactness, host extensionality, quotient equality, an external modulus selector, countable choice, or ambient real completeness, those data cannot be read from the packet.
\end{proof}

The real scalar row is sealed only at the end of this displayed estimate route. Componentwise transport in $H$ and replay in $C$ preserve the same carrier coordinates, so the excluded host, quotient, choice, and completeness data remain unavailable.
