\begin{definition}[Uniformly continuous map carrier]
\label{def:uniformly-continuous-map-carrier}
A $\UniformlyContinuousMapUp$ carrier is a finite $\BHist$ packet
$$
U=(X,Y,G,M,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $X$ is the source $\MetricUp$ row, recording the finite source-distance observations and source naming data.
\item $Y$ is the target $\MetricUp$ row, recording the finite target-distance observations read after graph evaluation.
\item $G$ is the displayed graph row, read through $\ContinuousMapUp$ and tying source observations to target observations.
\item $M$ is the tolerance-only $\UniformModulusUp$ ledger: for each displayed target tolerance row it records the permitted source-tolerance row without exposing a pointwise center or host selector.
\item $H$ records componentwise $\hsame$ transport for source metric data, target metric data, graph rows, modulus ledger rows, replay, provenance, and local naming.
\item $C$ records displayed $\Cont$ replay from a source tolerance request through $X,G,M,Y,H,P,N$.
\item $P$ is the $\Pkg$ provenance over $\UniformlyContinuousMapUp$, $\MetricUp$, $\ContinuousMapUp$, $\UniformModulusUp$, $\RealUp$, $\StreamNameUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$ rows.
\item $N$ is the local $\NameCert_{\UniformlyContinuousMapUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $X,Y,G,M,H,C,P,N$. It has no coordinate for host function extensionality, quotient equality of maps, selected moduli outside the ledger, compactness, countable choice, or ambient Real completeness.
\end{definition}

\begin{theorem}[Uniformly continuous map NameCert obligations]
\label{thm:uniformly-continuous-map-namecert-obligations}
For every accepted $\UniformlyContinuousMapUp$ carrier
$$
U=(X,Y,G,M,H,C,P,N),
$$
the local $\NameCert_{\UniformlyContinuousMapUp}$ surface consists exactly of source $\MetricUp$ admission, target $\MetricUp$ admission, displayed graph admission through $\ContinuousMapUp$, tolerance-only $\UniformModulusUp$ ledger admission, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming. Every map consumer must read
$$
X,G,M,Y \longmapsto H,C,P,N
$$
before it can hand the displayed map to a completion, compact-uniform-continuity, $\RealUp$, or $\StreamNameUp$ consumer.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:uniformly-continuous-map-carrier}. The only analytic rows are the source metric row $X$, target metric row $Y$, graph row $G$, and tolerance-only modulus ledger $M$.

The graph row supplies the displayed function read, while the modulus row supplies the source tolerance required for each displayed target tolerance. Since $M$ is a ledger coordinate rather than an external selector, the handoff stays inside the finite packet.

The structural rows $H$ and $C$ preserve the same source, graph, modulus, and target data under componentwise transport and replay. Finally $P$ and $N$ exhaust provenance and local naming, so no host function equality, selected modulus, compactness theorem, countable choice, or ambient Real completeness datum is exported.
\end{proof}
