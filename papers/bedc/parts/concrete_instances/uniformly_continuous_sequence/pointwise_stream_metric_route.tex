\begin{theorem}[Uniformly continuous sequence pointwise stream metric route]
\label{thm:uniformly-continuous-sequence-pointwise-stream-metric-route}
Every accepted $\UniformlyContinuousSequenceUp$ packet whose finite windows are consumed pointwise by a metric-stream reader must expose the same source and target $\MetricSpaceUp$ rows, shared $\UniformModulusUp$ row, $\StreamNameUp$ windows, $\RegSeqRatUp$ readbacks, terminal $\RealUp$ seal, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local $\NameCert$ rows before it can invoke the $\PointwiseStreamMetricUp$ comparison route of \autoref{ch:concrete-instances-pointwise-stream-metric-namecert}. The read is a shared-modulus stream route, not detached pointwise continuity, quotient stream equality, selected limits, countable choice, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:uniformly-continuous-sequence-carrier}. The pointwise metric-stream reader receives only $X,Y,F,M,S,Q,E,H,C,P,N$, so the source and target metric rows and the shared uniform-modulus row remain visible before any inspected sequence entry is read.

Use the NameCert obligations and shared-modulus handoff. They force each finite window to pass through the same $\UniformModulusUp$ row $M$, then through $\StreamNameUp$ windows $S$ and $\RegSeqRatUp$ readback $Q$ before the $\RealUp$ seal $E$ can be consumed.

Finally route the visible windows through \autoref{ch:concrete-instances-pointwise-stream-metric-namecert}. The $\PointwiseStreamMetricUp$ comparison can inspect the displayed metric-stream rows, but the uniformly continuous sequence packet has no coordinate for detached pointwise continuity proofs, quotient stream equality, selected limits, countable-choice schedules, or ambient Real completeness.
\end{proof}
