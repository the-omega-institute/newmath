\begin{theorem}[Uniformly continuous sequence compact-metric forward dependency]
\label{thm:uniformly-continuous-sequence-compact-metric-forward-dependency}
Every $\CompactMetricUp$ consumer of an accepted $\UniformlyContinuousSequenceUp$ packet must first read the visible source and observation route
$$
\MetricSpaceUp,\ \ContinuousMapUp,\ \UniformModulusUp,\ \StreamNameUp,\ \RegSeqRatUp,\ \RealUp .
$$
Only after the metric source row, continuous-map entry rows, shared uniform-modulus row, finite stream windows, regular rational readback, and terminal real seal are displayed may the consumer inspect compact-metric modulus data.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:uniformly-continuous-sequence-carrier}. The compact-facing consumer receives the source metric row $X$, target metric row $Y$, continuous-map entry rows $F$, shared modulus row $M$, stream-window row $S$, readback row $Q$, and real-seal row $E$ before any structural transport or provenance row can be used.

The compact-metric dependency route then reads the compact source through \autoref{ch:concrete-instances-compactmetric-namecert}. That route is downstream of the displayed $\MetricSpaceUp$ source and the same $\UniformModulusUp$ row used by the sequence packet, so compact-metric modulus data cannot be consumed before the shared sequence modulus and finite windows are visible.

Finally the $\RegSeqRatUp$ and $\RealUp$ rows seal the consumer-facing values. Since the carrier has no coordinate for detached pointwise continuity, selected limits, quotient stream equality, countable choice, or ambient real completeness, the compact-metric consumer is forced through the displayed forward dependency.
\end{proof}
