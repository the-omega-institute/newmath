\begin{definition}[Bishop located minimum carrier]
\label{def:bishop-located-minimum-carrier}

$$

\item $F$ is the uniformly continuous $\ContinuousMapUp$ row, exposing only displayed value requests over the compact source row $K$.
\item $N$ is the finite-net cover row, recording the finite list of centers, radii, and coverage witnesses through which every minimum-facing request enters.
\item $W$ is the $\StreamNameUp$ schedule row for the finite value windows attached to the centers of $N$.

\item $E$ is the terminal $\RealUp$ seal row, admitting the displayed value readbacks as Real-facing names before comparisons are consumed.

\end{definition}

\begin{theorem}[Bishop located minimum NameCert obligations]
\label{thm:bishop-located-minimum-namecert-obligations}
For every accepted $\BishopLocatedMinimumUp$ carrier $B=(K,F,N,W,R,E,M,H,C,P,L)$, the local $\NameCert_{\BishopLocatedMinimumUp}$ surface consists exactly of the following obligation rows:
\begin{enumerate}
\item carrier admission for the displayed compact source, uniformly continuous map row, finite-net cover, value windows, regular rational readbacks, Real seal, located lower comparison row, transport, replay, provenance, and local naming;
\item finite-net exposure, requiring every minimum-facing source request to pass through the centers and coverage witnesses named by $N$;
\item value readback through $\StreamNameUp$, $\RegSeqRatUp$, and $\RealUp$, requiring $W,R,E$ to be visible before any lower comparison row is consumed;
\item located lower comparison, requiring $M$ to compare only displayed Real-sealed value windows over the finite net;
\item ledger refusal for selected argmin data, open-cover compactness, quotient real equality, countable choice, and ambient $\RealUp$ completeness.
\end{enumerate}
No NameCert obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:bishop-located-minimum-carrier}. The rows $K,F,N$ expose the compact source, map row, and finite-net coverage surface that every later value read must use.

Read the value rows next. The stream schedule $W$ supplies finite windows, $R$ reads those windows as regular rational data, and $E$ seals the displayed readbacks as $\RealUp$ names before a lower comparison can be used.

The comparison row $M$ has access only to the Real-sealed finite-net values already displayed by $N,W,R,E$. The structural rows $H,C,P,L$ transport, replay, source, and name the same finite route, so the five listed obligations exhaust the local NameCert surface.
\end{proof}

\begin{theorem}[Bishop located minimum finite-net lower route]
\label{thm:bishop-located-minimum-finite-net-lower-route}
Every minimum-facing read exported by an accepted $\BishopLocatedMinimumUp$ carrier factors through the displayed finite route
$$
K,F,N \longmapsto W,R,E \longmapsto M \longmapsto H,C,P,L .
$$
Thus an optimization consumer can inspect only the compact source, uniformly continuous map row, finite net, value windows, located lower comparison, and Real seal before reaching the local naming row. It cannot bypass the finite-net handoff to obtain a selected argmin, open-cover compactness, quotient real equality, countable choice, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Start with the source and map rows. The compact metric source $K$ and uniformly continuous map row $F$ become visible to a minimum-facing read only through the finite-net cover $N$.

The value route is then fixed. The stream schedule $W$ records the finite observation windows attached to the net, the regular rational row $R$ reads those windows, and the terminal seal $E$ is reached before any minimization-facing comparison is available.

Use the located lower comparison row $M$ only after the sealed value windows are displayed. Since $M$ compares the finite family exposed by $N,W,R,E$, it supplies a located minimum comparison surface rather than a selected minimizing point.

Finally replay the same route through $H$ and $C$, while $P$ and $L$ provide provenance and local naming. The carrier has no coordinate for the excluded principles, so every consumer reaches minimum-location data only through the finite lower handoff shown above.
\end{proof}
