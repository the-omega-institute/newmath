\begin{theorem}[CantorBorelSet obligation surface]
\label{thm:cantor-borel-set-obligation-surface}
For every accepted $\CantorBorelSetUp$ carrier $B=(A,C,W,R,E,H,K,P,N)$, the local $\NameCert_{\CantorBorelSetUp}$ surface consists exactly of carrier admission for the Cantor address row, cylinder-window row, $\StreamNameUp$ finite-window row, $\RegSeqRatUp$ readback row, terminal $\RealUp$ seal row, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming. The surface contains no hidden obligation for a completed Borel sigma algebra, quotient set equality, selected branch, countable choice, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:cantor-borel-set-carrier}. The accepted packet exposes $A,C,W,R,E,H,K,P,N$ as separate finite rows, so every local obligation must be read from one of those coordinates.

The cylinder data is supplied by $A$ and $C$. These rows point to Cantor-space prefixes and the cylinder basis, not to a completed host set of all Borel subsets.

The countable-name route is supplied by $W,R,E$. A request first reads finite $\StreamNameUp$ windows, then $\RegSeqRatUp$ readback, and only then the terminal $\RealUp$ seal.

Finally $H,K,P,N$ transport, replay, package, and name the same finite rows. Since no carrier coordinate contains a sigma-algebra completion, quotient equality, selected branch, countable-choice schedule, or ambient completeness principle, the obligation surface is exactly the displayed packet.
\end{proof}

\begin{theorem}[CantorBorelSet cylinder generation]
\label{thm:cantor-borel-set-cylinder-generation}

$$
\CantorSpaceUp \longmapsto \CantorCylinderBasisUp \longmapsto \StreamNameUp .
$$

Thus cylinder generation remains a finite NameCert route, not a host powerset, completed sigma algebra, quotient subset equality, selected infinite branch, or countable-choice enumeration.
\end{theorem}
\begin{proof}

Use the cylinder-window row $C$ next. By construction, $C$ is read through the cylinder basis of \autoref{ch:concrete-instances-cantor-cylinder-basis-namecert}, so generation is by displayed finite cylinder windows.

Finally expose the stream window $W$. The $\StreamNameUp$ row records exactly the bounded countable-name observations used by downstream consumers. Since $R$ and $E$ are downstream and no carrier coordinate names a host powerset or completed sigma algebra, the public cylinder generation route is exhausted by the displayed finite rows.
