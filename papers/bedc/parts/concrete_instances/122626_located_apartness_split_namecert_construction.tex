$$

\item $A$ is the $\ApartnessRealUp$ branch-evidence row, displaying either the positive-side or negative-side separation witness from the named comparison boundary.
\item $D$ is the $\DyadicRatCoreUp$ tolerance ledger carrying the branch radius, endpoint comparison arithmetic, and displayed tolerance budget.

\item $Q$ is the $\RegSeqRatUp$ readback row for the same finite window and dyadic ledger.
\item $E$ is the terminal $\RealUp$ seal row reached only after $L,A,D,W,Q$ have been displayed.

\begin{theorem}[Located apartness split NameCert obligations]
\label{thm:located-apartness-split-namecert-obligations}
For every accepted $\LocatedApartnessSplitUp$ carrier
$$

$$

\begin{enumerate}
\item carrier admission for the located-real source, apartness branch evidence, dyadic tolerance ledger, finite window, regular rational readback, terminal Real seal, transport, replay, provenance, and local naming rows;
\item located source exposure through $L$, requiring the branch request to begin from the displayed $\LocatedRealUp$ interval data rather than from a host real value;
\item branch evidence exposure through $A$, requiring the positive or negative side to be read as already displayed $\ApartnessRealUp$ evidence;
\item dyadic tolerance exactness through $D$, requiring the branch radius and comparison arithmetic to be the rows used by the split;
\item window and readback routing through $W,Q,E$, requiring the Real-facing seal to be downstream of the finite stream window and regular rational readback;

\end{theorem}
\begin{proof}

Read the mathematical rows in dependency order. The located source $L$ fixes the displayed endpoint presentation, and the apartness row $A$ supplies one already evidenced positive or negative branch. The dyadic ledger $D$ then fixes the radius and comparison arithmetic attached to that evidence.

The completion-facing route is finite. The stream window $W$ and regular rational readback $Q$ are the only observation rows available before the Real seal $E$ is reached.

Finally use $H,C,P,N$ to transport, replay, source, and name the same packet. Since no row contains trichotomy, a selected sign decision, quotient equality, countable choice, or completeness, those principles cannot become local NameCert obligations.

\begin{theorem}[Located apartness split branch extraction]
\label{thm:located-apartness-split-branch-extraction}

$$

$$
The extracted branch is positive or negative only relative to the apartness row $A$ and the tolerance ledger $D$. It does not decide a sign for arbitrary $\RealUp$ names and does not choose between equality and apartness.
\end{theorem}
\begin{proof}
Start with the located source row $L$. It supplies the named endpoint presentation and interval data, so any branch read is tied to the displayed located-real packet.

Next read the apartness row $A$. The branch side is already present as positive or negative separation evidence; the split packet does not compute a side by trichotomy.

The dyadic and finite-window rows then determine the scope of the branch. The ledger $D$ supplies the tolerance radius and comparison arithmetic, while $W$ and $Q$ supply the finite observation and regular rational readback used by the same evidence.

Thus branch extraction is row projection from $L,A,D,W,Q$ followed by the structural nonescape rows. Without those rows, the packet has no branch to export; with them, it exports only the guarded branch stated above.
\end{proof}
