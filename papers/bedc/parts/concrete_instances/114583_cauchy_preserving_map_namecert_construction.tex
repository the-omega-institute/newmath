\begin{definition}[CauchyPreservingMap carrier]
\label{def:cauchy-preserving-map-carrier}

$$

\begin{enumerate}

\item $R$ is the source $\RegSeqRatUp$ readback row obtained from $S$ and the displayed tolerance ledger.
\item $T$ is the target $\RegSeqRatUp$ readback row produced by applying the map route to the same source window data.
\item $Q$ is the $\CauchyModulusUp$ preservation row, recording the displayed late-threshold handoff that turns the source regular witness into a target regular witness.

\begin{theorem}[CauchyPreservingMap NameCert obligations]
\label{thm:cauchy-preserving-map-namecert-obligations}
For every accepted $\CauchyPreservingMapUp$ carrier
$$
M=(S,R,T,Q,L,E,H,C,P,N),
$$
the local $\NameCert_{\CauchyPreservingMapUp}$ surface consists exactly of source $\StreamNameUp$ window admission, source $\RegSeqRatUp$ readback, target $\RegSeqRatUp$ readback, $\CauchyModulusUp$ preservation, $\ContinuousMapUp$ graph-and-modulus routing, $\RealUp$ seal handoff, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:cauchy-preserving-map-carrier}. The mathematical rows are $S,R,T,Q,L,E$, and the structural rows are $H,C,P,N$.

The source and target regularity obligations are separated. A source read begins with the displayed $\StreamNameUp$ window $S$ and then reaches the source $\RegSeqRatUp$ row $R$; the map route can expose the target $\RegSeqRatUp$ row $T$ only after the same source window has been read.

The preservation and continuity rows are then read as one finite handoff. The $\CauchyModulusUp$ row $Q$ records the late-threshold preservation, while the $\ContinuousMapUp$ row $L$ records the graph-and-modulus route used by the same read.

Finally $E,H,C,P,N$ seal, transport, replay, source, and name that route. Since no additional coordinate exists, the listed rows are exactly the local NameCert obligations, and the excluded host and quotient objects cannot be exported.
\end{proof}
