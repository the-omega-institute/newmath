\begin{definition}[Closed substitution self-compile carrier]
\label{def:closed-substitution-self-compile-carrier}
A $\ClosedSubstitutionSelfCompileUp$ carrier is a finite $\BHist$ packet
$$
S=(T,D,V,Q,B,L,R,F,K,A,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $T$ is the MetaCIC closed-term source row.
\item $D$ is the de Bruijn depth row at which the closed boundary is read.
\item $V$ is the substitution payload row.
\item $Q$ is the \texttt{ClosedAt} classifier row for $T$ at depth $D$.
\item $B$ is the binder-seal row ensuring that the boundary is read before any recursive binder descent.
\item $L$ is the displayed closed-substitution row for substituting $V$ into $T$ at depth $D$.
\item $R$ is the replay row exposing the same closed substitution route to the compiler-facing consumer.
\item $F$ is the refusal row for open-term substitution, unrestricted binder descent, and host evaluator equality.
\item $K$ is the kernel-acceptance witness row tying the displayed MetaCIC packet to an accepted kernel-facing certificate.
\item $A$ is the self-compile audit row recording that the compiler reads only $T,D,V,Q,B,L,R,F,K$.
\item $H$ records componentwise $\hsame$ transport for the term, depth, payload, classifier, binder seal, substitution, replay, refusal, kernel, and audit rows.
\item $C$ records displayed $\Cont$ replay from each compiler-facing query back through the same finite rows.
\item $P$ is the $\Pkg$ provenance over $\ClosedSubstitutionSelfCompileUp$, $\ClosedSubstitutionBoundaryUp$, $\MetaCICSubstitutionSpineRealizerUp$, $\KernelAcceptanceWitnessUp$, $\MetaCICCriticalPathUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\ClosedSubstitutionSelfCompileUp}$ row.
\end{enumerate}
The carrier has no coordinate for unrestricted substitution, host evaluator equality, open-term semantic preservation, quotient syntax equality, or global compiler correctness.
\end{definition}

\begin{theorem}[Closed substitution self-compile NameCert obligations]
\label{thm:closed-substitution-self-compile-namecert-obligations}
For every accepted $\ClosedSubstitutionSelfCompileUp$ carrier
$$
S=(T,D,V,Q,B,L,R,F,K,A,H,C,P,N),
$$
the local $\NameCert_{\ClosedSubstitutionSelfCompileUp}$ surface consists exactly of carrier admission for the closed MetaCIC term row, depth row, substitution payload row, closedness classifier, binder seal, closed-substitution row, replay row, refusal row, kernel-acceptance witness, self-compile audit row, componentwise transport, displayed replay, provenance, and local naming. A compiler-facing consumer may read the self-compile handoff only through those displayed rows.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:closed-substitution-self-compile-carrier}. The closed term, depth, payload, closedness classifier, binder seal, substitution row, replay row, refusal row, kernel row, and audit row are explicit coordinates.

Read the boundary rows in order. The classifier $Q$ and binder seal $B$ are exposed before the substitution row $L$, so the packet is confined to the closed boundary rather than to unrestricted substitution under binders.

Read the replay and refusal rows. The replay row $R$ is the only compiler-facing route for the closed substitution, while $F$ keeps open-term substitution, host evaluator equality, and quotient syntax equality outside the packet.

Finally consume $K,A,H,C,P,N$. Kernel acceptance, self-compile audit, transport, replay, provenance, and local naming preserve the same finite surface and do not add global compiler correctness.
\end{proof}

\begin{theorem}[Closed substitution self-compile refusal boundary]
\label{thm:closed-substitution-self-compile-refusal-boundary}
Every accepted $\ClosedSubstitutionSelfCompileUp$ read keeps the refusal row $F$ visible whenever the compiler-facing handoff $A$ is consumed. Thus the packet can replay closed-term substitution through $R,A,H,C,P,N$, but it cannot claim unrestricted substitution, open-term semantic preservation, host evaluator equality, quotient syntax equality, or full compiler correctness.
\end{theorem}
\begin{proof}
Start with the handoff row $A$. By the carrier definition, $A$ reads only the displayed rows $T,D,V,Q,B,L,R,F,K$ before transport, continuation, provenance, and local naming are consumed.

The refusal row $F$ is part of that handoff inventory. Removing $F$ changes the carrier read, so an accepted handoff cannot silently turn the closed-boundary packet into an unrestricted substitution theorem.

The structural rows $H,C,P,N$ replay and name the same finite packet. They preserve the visible refusal boundary and therefore block host evaluator equality, quotient syntax equality, open-term preservation, and full compiler correctness claims.
\end{proof}

\end{theorem}
