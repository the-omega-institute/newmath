\begin{theorem}[Gromov--Hausdorff distance metric anchor]
\label{thm:gromov-hausdorff-distance-metric-anchor}
Every $\GromovHausdorffDistanceUp$ read first exposes the $\MetricSpaceUp$ distance witness of each endpoint and the $\CompactMetricUp$ finite-source rows before any correspondence table or distortion comparison is consumed. Thus the local scalar comparison is anchored in displayed metric distance and compact finite-source data, not in a quotient metric space, selected optimal correspondence, cover choice, ambient completion, host isometry class, or completed hyperspace point.
\end{theorem}
\begin{proof}
Start with the endpoint rows $X,Y$ of \autoref{def:gromov-hausdorff-distance-carrier}. Each endpoint is a compact metric carrier, so its metric distance witness and finite-source compact rows are displayed before the local correspondence row $R$ can be read.

Apply the compact-metric route of \autoref{thm:gromov-hausdorff-distance-compact-metric-route}. It orders public comparison reads through the Metric, CompactMetric, HausdorffDistance, GromovHausdorff, and CompactMetricHyperspace surfaces before the local rows $H,C,P,N$ are consumed.

Finally use the metric-correspondence dependency of \autoref{thm:gromov-hausdorff-metric-correspondence-dependency}. Since the finite correspondence table and dyadic distortion ledger compare only already displayed endpoint distances and compact finite-source rows, no accepted Gromov--Hausdorff distance read can bypass the metric anchor.
\end{proof}
