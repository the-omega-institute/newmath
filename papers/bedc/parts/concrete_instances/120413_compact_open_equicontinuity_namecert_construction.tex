\begin{definition}[Compact-open equicontinuity carrier]
\label{def:compact-open-equicontinuity-carrier}
A $\CompactOpenEquicontinuityUp$ carrier is a finite $\BHist$ packet
$$
E=(K,F,A,U,O,S,R,Q,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $K$ is the $\CompactMetricUp$ source row, listing the finite compact windows and coverage entries through which the compact-open inspection is performed.
\item $F$ is the $\ContinuousMapUp$ family graph row, recording the finite graph evaluations visible on those compact windows.
\item $A$ is the $\EquicontinuityFamilyUp$ row, carrying the family-wide local equicontinuity witnesses attached to the same compact windows.
\item $U$ is the $\UniformModulusUp$ handoff row obtained from the compact-window and family-equicontinuity data.
\item $O$ is the compact-open observation ledger: a finite list of compact-window requests, tolerance requests, and graph-value windows that the consumer may inspect.
\item $S$ is the $\StreamNameUp$ finite-window row for graph values and tolerance reads.
\item $R$ is the $\RegSeqRatUp$ readback row attached to those stream windows.
\item $Q$ is the terminal $\RealUp$ seal row for value-facing and tolerance-facing reads.

\item $C$ records displayed $\Cont$ replay of the route

\end{enumerate}
The carrier exports only these displayed rows. It has no coordinate for a host compact-open topology, function-space compactness theorem, selected convergent subnet, quotient equality of functions, countable choice, external modulus oracle, or ambient completeness.
\end{definition}

\begin{theorem}[Compact-open equicontinuity NameCert obligations]
\label{thm:compact-open-equicontinuity-namecert-obligations}
For every accepted $\CompactOpenEquicontinuityUp$ carrier
$$
E=(K,F,A,U,O,S,R,Q,H,C,P,N),
$$
the local $\NameCert_{\CompactOpenEquicontinuityUp}$ surface consists exactly of the following obligations:
\begin{enumerate}
\item compact-window admission, requiring every compact-open request to expose the compact metric row $K$ and the finite observation ledger $O$ before any family read is consumed;
\item continuous-family exposure, requiring graph values to be read through the $\ContinuousMapUp$ row $F$, the stream window $S$, the regular readback row $R$, and the terminal Real seal $Q$;
\item equicontinuity synchronization, requiring the $\EquicontinuityFamilyUp$ row $A$ and the $\UniformModulusUp$ row $U$ to share the compact-window and tolerance requests listed by $O$;
\item structural stability, requiring $H,C,P,N$ to transport, replay, source, and locally name only the displayed rows of the carrier;
\item exclusion of host compact-open topology, selected subnets, quotient function equality, countable choice, external modulus choice, function-space compactness, and ambient completeness.
\end{enumerate}
No NameCert obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:compact-open-equicontinuity-carrier}. The compact-window data are exactly $K$ and $O$, so any compact-open request begins with the displayed finite compact source and its inspection ledger.

The family values are then read through $F,S,R,Q$. This places every visible graph value behind the ContinuousMap row, StreamName window, RegSeqRat readback, and terminal Real seal, not behind a host function graph or quotient equality of maps.

The equicontinuity synchronization clause reads $A$ and $U$ over the same ledger $O$. Thus the family-wide equicontinuity witness and the downstream uniform-modulus handoff are tied to the compact windows already exposed by $K$.

Finally, $H,C,P,N$ only transport, replay, source, and locally name the displayed rows. Since no row stores host compact-open topology, selected subnets, quotient function equality, countable choice, external modulus choice, function-space compactness, or ambient completeness, none of those objects can discharge a local NameCert obligation.
\end{proof}

\begin{theorem}[Compact-open equicontinuity Ascoli handoff]
\label{thm:compact-open-equicontinuity-ascoli-handoff}
Every $\ArzelaAscoliUp$ or compact-family consumer of an accepted $\CompactOpenEquicontinuityUp$ carrier must read the compact metric row $K$, continuous-map family row $F$, equicontinuity-family row $A$, uniform-modulus handoff $U$, compact-open observation ledger $O$, stream window $S$, regular readback row $R$, terminal Real seal $Q$, and structural rows $H,C,P,N$ in the displayed dependency order. Next read the ContinuousMap and equicontinuity rows. The graph values pass through $F,S,R,Q$, while the family-wide equicontinuity data pass through $A$ and the shared uniform-modulus handoff $U$.

The Ascoli-facing boundary is then the structural replay of the same finite route. \end{proof}
