\begin{definition}[MacShaneExtension carrier]
\label{def:macshane-extension-carrier}
A $\MacShaneExtensionUp$ carrier is a finite $\BHist$ packet
$$
M=(X,A,d,f,L,E,S,R,U,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $X$ is the $\MetricSpaceUp$ ambient carrier row, exposing only the metric observations used by the envelope request.
\item $A$ is the located source row, recording the admitted subcarrier points and the finite inclusion evidence read by ambient comparisons.
\item $d$ is the $\LocatedUniformSpaceUp$ compatibility row that keeps source and ambient distance reads on the same located-uniform route.
\item $f$ is the $\RealUp$ source-value graph row for the displayed real-valued map on $A$.
\item $L$ is the $\LipschitzContinuityHandoffUp$ bound row, recording the displayed Lipschitz constant and the finite tolerance handoff used by the envelope.
\item $E$ is the MacShane envelope row, storing finite comparison data of the form source value plus bound times ambient distance, without selecting an arbitrary infimum operator.
\item $S$ is the source-agreement row, requiring every source-admitted ambient read to return through $A,d,f,L,E$ before it is identified with the original source read.
\item $R$ is the $\RealUp$ seal row for source values, envelope comparisons, and ambient extension reads.
\item $U$ is the $\ContinuousMapUp$ replay row that records the continuity-facing readback route after the Lipschitz handoff has been displayed.
\item $H$ records componentwise $\hsame$ transport for the carrier, source, metric, graph, bound, envelope, agreement, Real seal, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a precision request through $X,A,d,f,L,E,S,R,U,H,P,N$.
\item $P$ is the $\Pkg$ provenance over $\MacShaneExtensionUp$, $\MetricSpaceUp$, $\RealUp$, $\ContinuousMapUp$, $\LipschitzContinuityHandoffUp$, $\LocatedUniformSpaceUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\MacShaneExtensionUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through these thirteen rows. It has no coordinate for host choice, quotient real equality, arbitrary infimum operators, selected extrema, countable choice, trichotomy, or ambient completeness.
\end{definition}

\begin{theorem}[MacShaneExtension NameCert obligations]
\label{thm:macshane-extension-namecert-obligations}
For every accepted $\MacShaneExtensionUp$ carrier $M=(X,A,d,f,L,E,S,R,U,H,C,P,N)$, the local $\NameCert_{\MacShaneExtensionUp}$ surface consists of the following finite obligation rows:
\begin{enumerate}
\item carrier admission for the ambient metric-space row, located source row, located-uniform distance row, source-value graph, Lipschitz handoff, envelope, agreement, Real seal, continuity replay, transport, provenance, and local naming rows;
\item domain compatibility, requiring every source-value read to pass through $A$ and $d$ before comparison with an ambient envelope read;
\item bound transport, requiring $L$ to mediate every tolerance and distance-to-value estimate consumed by $E$;
\item envelope exactness, requiring $E$ to store finite MacShane comparison data and no host choice, quotient real equality, selected extremum, or arbitrary infimum operator;
\item source-agreement nonescape, requiring $S,R,U,H,C,P,N$ to preserve the displayed route without adding a host function object, a quotient function, or an ambient completeness witness.
\end{enumerate}
No local obligation is stored outside these five rows.
\end{theorem}
\begin{proof}
Carrier admission is projection from \autoref{def:macshane-extension-carrier}. The accepted packet displays exactly the ambient metric-space, located source, located-uniform distance, source graph, Lipschitz handoff, envelope, agreement, Real seal, continuity replay, and structural rows.

Read the domain and bound clauses next. The rows $A$ and $d$ provide the source admission and ambient distance route, while $f$ and $L$ provide the source value and the displayed Lipschitz constant. Thus an envelope comparison cannot be formed before the carrier has exposed the same finite metric and Real rows used by the source map.

Project the envelope row $E$. It stores finite MacShane comparisons derived from displayed source values and displayed distance bounds, so it can be replayed for a concrete ambient request without selecting a global extremum or quotient real representative.

Finally inspect $S,R,U,H,C,P,N$. Agreement, Real sealing, continuity replay, transport, provenance, and local naming only preserve the displayed rows. Therefore the NameCert surface is exactly the listed five-row obligation sketch, and no host choice, quotient real equality, arbitrary infimum operator, selected extremum, or ambient completeness principle is introduced.
\end{proof}

\label{thm:macshane-extension-lipschitz-envelope}

$$

The packet exports a finite Lipschitz-envelope certificate and no host choice, quotient real equality, arbitrary infimum operator, selected extremum, countable-choice selector, trichotomy branch, or ambient completeness witness.
\end{theorem}
\begin{proof}
Start with an ambient envelope request. The rows $X,A,d$ expose the only metric-space, source-admission, and located-uniform distance information available to the read.

Read the source graph and bound handoff. The row $f$ supplies the displayed Real source values, while $L$ supplies the Lipschitz control that turns distance information into value estimates. This is the only route by which a bound can enter the envelope.
