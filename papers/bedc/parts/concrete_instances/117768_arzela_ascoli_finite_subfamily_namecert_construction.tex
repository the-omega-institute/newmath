\begin{theorem}[Arzela--Ascoli finite-subfamily NameCert obligations]
\label{thm:arzela-ascoli-finite-subfamily-namecert-obligations}

\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:arzela-ascoli-finite-subfamily-carrier}. The analytic rows are exactly $X,F,B,E,Q,W,R,Y$, and the structural rows are exactly $H,C,P,N$.

The source and family rows are read first. Row $X$ supplies the compact-metric finite-net schedule, row $F$ supplies the selected finite family, row $B$ supplies the bounded-family ledger, and row $E$ supplies the shared equicontinuity ledger.

The finite inspection rows are downstream from those ledgers. Row $Q$ exposes the finite epsilon-net centers and tolerance checks, row $W$ exposes only finite StreamName windows and RegSeqRat observations, and row $R$ seals that readback as a displayed Real-facing row.

The handoff row $Y$ is therefore a consumer boundary, not a compactness theorem. Rows $H,C,P,N$ transport, replay, source, and name the same finite route, so the listed rows exhaust the local NameCert surface.
\end{proof}
