\begin{definition}[Sequential order compactness carrier]
\label{def:sequential-order-compactness-carrier}

$$

with the following displayed rows:
\begin{enumerate}
\item $A$ is the $\RealUp$ sequence source row whose inspected terms are offered only through displayed real-name seals.
\item $I$ is the $\CompactIntervalUp$ bracket row naming the interval boundary in which the sequence is read.
\item $O$ is the finite monotone/order window. It records the inspected order comparisons and adjacent bracket witnesses visible inside the current window.
\item $R$ is the $\RegSeqRatUp$ readback row for the sequence terms that appear in the order window.
\item $W$ is the $\StreamNameUp$ schedule row selecting the finite indices and readback windows being inspected.
\item $D$ is the $\DyadicRatCoreUp$ tolerance row used to compare the displayed rational readbacks inside the compact interval bracket.
\item $H$ records componentwise $\hsame$ transport for the source sequence, interval bracket, order window, readback, schedule, tolerance, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from an order-window request through $A,I,O,R,W,D,H$ before any compactness-facing consumer reads the packet.
\item $P$ is the $\Pkg$ provenance over $\SequentialOrderCompactnessUp$, $\SequentialCompactUp$, $\CompactIntervalUp$, $\RealUp$, $\RegSeqRatUp$, $\StreamNameUp$, $\DyadicRatCoreUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
