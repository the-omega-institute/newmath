\begin{theorem}[Measure value route for probability and integral consumers]
\label{thm:measure-probability-integral-value-route}
Every accepted $\MeasureUp$ value row is read through the $\RealUp$ value surface of \autoref{ch:concrete-instances-real-namecert} before probability normalization through \autoref{ch:concrete-instances-probspace-namecert} or integration through \autoref{ch:concrete-instances-integral-namecert} can consume it. The probability and integral consumers therefore share the same finite event-value row, $\BHist$ ledger, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local $\NameCert_{\MeasureUp}$ row; neither consumer receives a detached host-valued measure function.
\end{theorem}
\begin{proof}
Project the accepted $\MeasureUp$ carrier through the value rows named in \autoref{thm:measure-dependency-lattice}. The value object is first a $\RealUp$-facing row, so event comparisons and normalization reads use the same displayed real-name surface.

The probability consumer reads that row as its normalization input, while the integral consumer reads it as the value input for integration. Both reads remain downstream of the same finite event-value boundary.

The structural rows transport, replay, source, and name that shared boundary. Since no carrier coordinate supplies a second host-valued measure function, probability and integration cannot detach their value reads from the displayed $\MeasureUp$ packet.
\end{proof}
