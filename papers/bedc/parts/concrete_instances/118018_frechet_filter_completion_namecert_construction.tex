\label{def:frechet-filter-completion-carrier}

$$

\item $Q$ is the $\CauchyFilterCompletionUp$ completion-facing row that receives the displayed filter route.
\item $S$ is the $\MetricSequentialCompletionUp$ handoff row by which sequential completion consumers read the same cofinite-tail route.

\begin{theorem}[Frechet filter completion NameCert obligations]
\label{thm:frechet-filter-completion-namecert-obligations}

$$

the local $\NameCert_{\FrechetFilterCompletionUp}$ surface consists exactly of carrier admission for the displayed Frechet filter row, Cauchy-filter completion row, metric sequential-completion handoff, StreamName window schedule, RegSeqRat readback, Real seal, componentwise transport, displayed replay, provenance, and local naming row. Every completion-facing obligation is read through those rows and no obligation is stored in quotient filter equality, selected limits, countable choice, host equality, or ambient completeness.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:frechet-filter-completion-carrier}. The tuple displays the Frechet filter source, the Cauchy-filter completion consumer, the sequential-completion handoff, the window schedule, the regular rational readback, the terminal real seal, and the structural rows.

The filter side is exhausted by $F$ and $Q$. The Frechet row exposes only cofinite-tail threshold and finite-complement data, and the Cauchy-filter completion row receives that displayed route without adding a quotient filter or selected completion point.

The sequential and real-name side is exhausted by $S,W,R,E$. The sequential handoff reads the same cofinite-tail route, the finite windows in $W$ schedule the requested observations, the regular rational row $R$ is read from those windows, and the real seal $E$ appears only after the readback row has been displayed.

Finally $H,C,P,N$ transport, replay, source, and name the same finite packet. Since no other coordinate is present, the excluded quotient, selector, choice, host-equality, and ambient-completeness data cannot become NameCert obligations.
\end{proof}
