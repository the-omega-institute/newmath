\begin{theorem}[MetaCIC candidate normalization residual-join scope]\label{thm:metacic-candidate-normalization-residual-join-scope}
An accepted $\MetacicCandidateNormalizationConfluenceHandoffUp$ candidate-normalization handoff may expose residual joins only after it has read the candidate diamond budget, the cut-height budget, the frontier dependency route, and the residual diamond bridge route. The resulting scope is the finite route through MetaCIC candidate rows, residual windows, candidate joins, $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$; it is not an unscoped global confluence claim.
\end{theorem}
\begin{proof}
Project the parent carrier of \autoref{def:metacic-candidate-normalization-confluence-handoff-carrier}. Its visible rows already separate candidate evidence, bounded endpoint data, residual confluence routing, decidable-boundary routing, blocked-edge retention, transport, replay, provenance, and local naming.

Read the budget rows next. The candidate diamond route of \autoref{thm:metacic-candidate-normalization-diamond-budget-route} fixes the bounded peak and join-budget surface, while the cut-height route of \autoref{thm:metacic-candidate-normalization-confluence-handoff-cut-height-budget} fixes the height boundary before a residual endpoint can be consumed.

Finally read the frontier and residual-diamond routes. The residual-frontier dependency and the bridge route of \autoref{ch:concrete-instances-metacic-parallel-diamond-frontier-namecert} keep residual windows and candidate joins attached to the displayed $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$ rows. Since no carrier coordinate stores global confluence, quotient syntax equality, evaluator equality, or kernel consistency, the handoff exposes only the scoped residual-join route stated above.
\end{proof}
