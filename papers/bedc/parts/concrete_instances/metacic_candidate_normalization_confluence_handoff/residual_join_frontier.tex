\begin{theorem}[MetaCIC candidate-normalization residual-join frontier]
\label{thm:metacic-candidate-normalization-confluence-residual-join-frontier}
An accepted $\MetacicCandidateNormalizationConfluenceHandoffUp$ handoff may consume a residual-join frontier only after the candidate set, normalization window, residual-substitution row, join-locality row, and strong-normalization handoff have all been displayed. The frontier read remains a finite route through the candidate-normalization carrier, residual-substitution boundary, local join ledger, bounded normal-form endpoint, $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$; it is not global Church--Rosser, unrestricted subject reduction, quotient syntax equality, evaluator soundness, or kernel consistency.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:metacic-candidate-normalization-confluence-handoff-carrier}. Its candidate evidence, bounded endpoint, residual envelope, decidable-boundary route, blocked-edge row, transport, replay, provenance, and local naming rows are visible before any frontier read is public.

Read the candidate and window rows first. The candidate set supplies the finite normalization candidates, and the normalization window fixes the bounded endpoint at which a residual join can be inspected.

Next consume the residual-substitution and join-locality rows. The residual-substitution boundary keeps substitutions attached to the displayed residual envelope, while the local join ledger keeps the join inside the candidate window rather than a host equality space.

Finally attach the strong-normalization handoff. It makes the bounded normal endpoint available to the confluence-facing consumer without erasing the candidate, window, substitution, and locality rows. Since the carrier has no coordinate for global Church--Rosser, subject reduction, quotient syntax equality, evaluator soundness, or kernel consistency, the frontier read is exactly the finite route stated above.
\end{proof}
