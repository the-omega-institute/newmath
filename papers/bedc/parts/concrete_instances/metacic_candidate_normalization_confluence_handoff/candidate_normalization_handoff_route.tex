\begin{theorem}[MetaCIC candidate normalization handoff route]
\label{thm:metacic-candidate-normalization-handoff-route}
Every accepted $\MetacicCandidateNormalizationConfluenceHandoffUp$ packet that exports a confluence handoff must first expose the $\MetaCICCriticalPathUp$ source row, the $\MetaCICParallelDiamondFrontierUp$ frontier row, residual join scope, candidate normalization budget, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local $\NameCert$ rows. In carrier notation the route reads the displayed packet rows $A,K,N,F,C,D,B,T,R,P,L$ before any consumer treats the bounded endpoint row $N$ as confluence-facing data.

The exported handoff is therefore a finite candidate-mediated route through the critical path, parallel-diamond frontier, residual envelope, decidable boundary, blocked-edge budget, transport, replay, provenance, and local naming surface. It is not global strong normalization, full Church--Rosser, unrestricted subject reduction, quotient syntax equality, evaluator equality, global conversion decidability, or closed consistency.
\end{theorem}
\begin{proof}
Start with the carrier of \autoref{def:metacic-candidate-normalization-confluence-handoff-carrier}. The rows $A,K,N,F,C,D,B,T,R,P,L$ display the audit anchor, candidate evidence, bounded endpoint, normalization frontier, residual confluence envelope, decidable boundary, blocked edge, transport, replay, provenance, and local naming.

Next read the sibling routes. The $\MetaCICCriticalPathUp$ row supplies the public critical-path source, while the $\MetaCICParallelDiamondFrontierUp$ row supplies the retained frontier that keeps residual join scope visible before any endpoint is consumed.

Now apply the existing premise-exposure and local-join routes of \autoref{thm:metacic-candidate-normalization-confluence-handoff-premise-exposure} and \autoref{thm:metacic-candidate-handoff-local-join-budget}. They force candidate evidence, residual envelope data, decidable-boundary data, and blocked-edge data to remain attached to the same handoff packet.

Finally pass through $T,R,P,L$. Componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local $\NameCert$ rows preserve the finite packet and add no coordinate for the refused global MetaCIC endpoints. Hence the confluence handoff can be exported only as the stated candidate-normalization route.
\end{proof}
