\label{thm:metacic-candidate-normalization-confluence-orphan-route}

Start with the handoff boundary surface. Next apply the forward-link route of \autoref{thm:metacic-candidate-normalization-confluence-handoff-forward-link}. It sends the retained residual data to the parallel-diamond frontier rather than to a detached confluence oracle.

Finally read the frontier consumer at \autoref{ch:concrete-instances-metacic-parallel-diamond-frontier-namecert}. The transport, replay, provenance, and local naming rows remain attached to the same finite handoff, so the orphan-facing read is a sibling dependency on $\MetaCICParallelDiamondFrontierUp$ and not an export of any excluded host theorem.
\end{proof}
