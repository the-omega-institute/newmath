\begin{theorem}[MetaCIC candidate handoff seed obligations]
\label{thm:metacic-candidate-normalization-confluence-handoff-seed-obligations}
Every seed-obligation read of an accepted $\MetacicCandidateNormalizationConfluenceHandoffUp$ packet exposes candidate evidence $K$, normalization frontier $F$, residual envelope $C$, decidable boundary $D$, blocked edge $B$, componentwise transport $T$, displayed replay $R$, provenance $P$, and local $\NameCert$ row $L$ before bounded endpoint consumption. The read remains a finite handoff boundary and does not assert unconditional strong normalization, full Church--Rosser, unrestricted subject reduction, global conversion decidability, quotient syntax equality, host evaluator soundness, or closed consistency.
\end{theorem}
\begin{proof}
Start with the handoff boundary of \autoref{thm:metacic-candidate-normalization-confluence-handoff-boundary}. It exposes candidate evidence and frontier data before endpoint consumption, keeps the residual and blocked-edge rows visible, and routes bounded comparison through the decidable-boundary row.

Use seed closure and premise exposure from \autoref{thm:metacic-candidate-normalization-confluence-handoff-seed-closure} and \autoref{thm:metacic-candidate-normalization-confluence-handoff-premise-exposure}. These theorems force $K,F,C,D,B$ to remain displayed before a confluence-facing or decidability-facing consumer reaches $N$.

Finally apply decider-row exhaustion from \autoref{thm:metacic-candidate-normalization-confluence-handoff-decider-row-exhaustion}. The structural rows $T,R,P,L$ preserve the same finite packet, so the bounded endpoint is consumed only after the seed-obligation rows have been exposed.
\end{proof}
