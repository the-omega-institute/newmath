\begin{theorem}[Candidate normalization retained frontier route]
\label{thm:metacic-candidate-normalization-confluence-handoff-parallel-frontier-candidate-route}
Every candidate-normalization confluence handoff that consumes a bounded local diamond must first read the retained-premise frontier of \autoref{ch:concrete-instances-metacic-parallel-diamond-frontier-namecert}. In carrier notation the consumer reaches the handoff rows $K,F,C,D,B,T,R,P,L$ only after the sibling frontier has exposed the retained premise row, candidate-join row, residual-frontier row, bounded-check row, obstruction row, transport row, replay row, provenance row, and local $\NameCert$ row.

The route is a finite candidate-normalization dependency. It does not supply residual-substitution discharge, subject reduction, full Church--Rosser, evaluator equality, quotient term equality, global normalization, or kernel consistency.
\end{theorem}
\begin{proof}
Start with the local handoff carrier of \autoref{def:metacic-candidate-normalization-confluence-handoff-carrier}. Its rows $K,F,C,D,B,T,R,P,L$ expose candidate evidence, bounded endpoint data, residual-envelope visibility, decidable-boundary routing, blocked-edge retention, transport, replay, provenance, and local naming.

Next read the sibling frontier. The parallel-diamond frontier chapter supplies the retained-premise and candidate-join route consumed by this handoff, so the local diamond budget cannot be inspected until those frontier rows are visible.

Finally apply the existing parallel-diamond frontier route of \autoref{thm:metacic-candidate-normalization-confluence-handoff-parallel-diamond-frontier-route}. It keeps the residual-substitution premise, bounded-check row, obstruction row, transport, replay, provenance, and local naming attached to the candidate-normalization handoff. Therefore the new route is a child dependency through $\MetaCICParallelDiamondFrontierUp$, not an independent confluence or kernel endpoint.
\end{proof}
