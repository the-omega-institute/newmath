\begin{theorem}[Dini uniform-monotone sibling lattice route]
\label{thm:dini-uniform-monotone-sibling-lattice-route}
Every accepted $\DiniUniformMonotoneUp$ consumer reads the $\DiniTheoremUp$, $\DiniUniformLimitModulusUp$, $\CompactModulusMonotoneConvergenceUp$, $\LowerSemicontinuousUp$, $\UpperSemicontinuousUp$, $\LocatedMonotoneConvergenceUp$, $\StreamNameUp$, $\RegSeqRatUp$, and $\RealUp$ rows in the same finite sibling lattice before a uniform-modulus read reaches the Real seal.
\end{theorem}
\begin{proof}
Start with an accepted consumer of \autoref{def:dini-uniform-monotone-carrier}. The carrier exposes the Dini finite-window row, the uniform-limit modulus row, the compact-modulus monotone-convergence row of \autoref{ch:concrete-instances-compact-modulus-monotone-convergence-namecert}, the lower and upper semicontinuity rows, the located monotone-convergence row, the stream-window row, the regular-rational row, and the terminal real row as displayed coordinates of one finite packet.

Apply \autoref{thm:dini-uniform-monotone-namecert-obligations}. Its carrier-admission, monotone-window, compact finite-modulus, semicontinuity, located-routing, transport, replay, provenance, and local naming clauses require these rows to be read through the same local NameCert surface.

Finally use \autoref{thm:dini-uniform-monotone-finite-modulus-route}. A uniform-modulus read reaches the terminal $\RealUp$ seal only after the displayed Dini, compact-modulus monotone-convergence, uniform-limit modulus, semicontinuity, located-monotone, stream, and regular-rational rows have been traversed, so the sibling lattice is fixed before the Real seal is consumed.
\end{proof}
