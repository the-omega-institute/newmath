\begin{proposition}[Window-six private/shared decoration defect forward route]
\label{thm:window-six-private-shared-decoration-defect-forward-route}
The private/shared row-set ledger exported by $\WindowSixPrivateSharedDecorationUp$ is an allowed child route for \autoref{ch:concrete-instances-window-six-decoration-defect-namecert}. Its rows $B,S,T,E,D,H,C,P,N$ supply the private block, shared row set, trigger coverage, enumeration, defect ledger, transport, replay, provenance, and local naming data used by the downstream defect-refined decoration polynomial route.
\end{proposition}
\begin{proof}
Read the exported packet through \autoref{def:window-six-private-shared-decoration-carrier}. The private/shared ledger already separates private blocks from shared row sets and records the defect ledger as a displayed row.

The downstream chapter \autoref{ch:concrete-instances-window-six-decoration-defect-namecert} consumes exactly that displayed ledger when it forms its defect-refined decoration polynomial route. Because the route is through the named child rows rather than through the hub file, it preserves the hub-only layout and records a genuine forward dependency between the two finite packets.
\end{proof}
