\begin{definition}[Constructive Banach fixed point carrier]
\label{def:banach-fixed-point-constructive-carrier}

\begin{theorem}[Constructive Banach fixed point NameCert obligations]
\label{thm:banach-fixed-point-constructive-namecert-obligations}

\end{theorem}
\begin{proof}

Finally $H,Q,P,N$ transport, replay, source, and name this packet. Since the carrier has no excluded coordinate, the listed rows exhaust the local NameCert obligations.
