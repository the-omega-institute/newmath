\begin{theorem}[Freedman inequality NameCert obligations]
\label{thm:freedman-inequality-namecert-obligations}

\begin{proof}
Carrier admission is projection from \autoref{def:freedman-inequality-carrier}. The accepted packet displays exactly the rows $\Omega,X,M,T,O,U,B,V,H,C,P,N$, so every local obligation is attached to one of those coordinates.

The martingale-difference obligations are the rows $X,M$. The $\RandomVarUp$ endpoint family supplies finite random-variable reads, while the $\MartingaleUp$ row supplies adaptedness and conditional-expectation faces inside the inspected window.

The bounded stopped-window obligations are $T,O,U$. The bounded stopping row determines which finite indices may be read, the optional-stopping row exposes stopped values only through those indices, and the upcrossing row keeps the same martingale window visible to crossing-control consumers.

The concentration-specific obligations are $B,V$. The bounded-step row records the displayed step bound, and the variance-budget row records the predictable quadratic-variation budget before a tail estimate can be named.

Finally $H,C,P,N$ transport, replay, source, and name the same finite route. Since the carrier has no coordinate for completed sigma-algebras, host measurable functions, almost-sure quotient equality, selected exponential limits, unbounded stopping choices, countable choice, or ambient measure completion, no NameCert obligation can export them.
