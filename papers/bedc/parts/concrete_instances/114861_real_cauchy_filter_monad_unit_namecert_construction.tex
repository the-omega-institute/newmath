\begin{theorem}[Real Cauchy-filter monad-unit obligations]
\label{thm:real-cauchy-filter-monad-unit-obligations}
For every accepted $\RealCauchyFilterMonadUnitUp$ carrier
$$
U=(A,F,B,M,E,R,S,H,C,P,N),
$$
the local $\NameCert_{\RealCauchyFilterMonadUnitUp}$ surface consists exactly of the following finite obligation rows:
\begin{enumerate}
\item carrier admission for the displayed Real source, Cauchy-filter row, filter-base row, completion handoff, universal-property row, rational readback, stream schedule, transport, replay, provenance, and local naming;
\item principal-filter exposure, requiring the Cauchy-filter row $F$ to be read only through the finite filter-base row $B$ generated from the real point $A$;
\item completion compatibility, requiring the metric-completion row $M$ and universal-property row $E$ to consume the same displayed Cauchy-filter route;
\item readback stability, requiring the $\RegSeqRatUp$ row $R$ and $\StreamNameUp$ row $S$ to remain attached to the source $\RealUp$ row before the filter row is exposed;
\item structural preservation by $H,C,P,N$;
\item nonescape for quotient representatives, selected limits, host filter equality, countable choice, ambient $\RealUp$ completeness, Lean theorem verification, and bridge checking.
\end{enumerate}
No local obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:real-cauchy-filter-monad-unit-carrier}. The Real source is $A$, the filter-facing rows are $F,B$, the completion-facing rows are $M,E$, and the finite readback rows are $R,S$.

The principal-filter obligation is forced because the carrier has no second filter generator. A consumer reaches $F$ only after the filter-base row $B$ has displayed the finite neighbourhood observations generated from $A$.

Completion compatibility is rowwise. The metric-completion handoff $M$ and the universal-property row $E$ both consume the same $F,B$ route, so neither can introduce a quotient representative or a selected completion point.

Finally $H,C,P,N$ transport, replay, source, and name the same packet. Since the excluded objects have no carrier coordinate, they cannot become NameCert obligations.
\end{proof}
