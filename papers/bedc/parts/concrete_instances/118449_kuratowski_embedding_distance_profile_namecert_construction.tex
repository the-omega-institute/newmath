Following Kuratowski's metric embedding of a metric space into distance functions, the $\KuratowskiEmbeddingDistanceProfileUp$ packet records the finite BEDC row that turns a source point or compact-source query into a displayed distance-profile classifier. It sits between the embedding carrier of \autoref{ch:concrete-instances-kuratowski-embedding-namecert}, the finite compact-subset comparison of \autoref{ch:concrete-instances-hausdorff-metric-namecert}, the compact-metric source of \autoref{ch:concrete-instances-compactmetric-namecert}, and the metric-distance surface of \autoref{ch:concrete-instances-metric-namecert}. The packet names the distance-profile classifier consumed by hyperspace and Hausdorff-facing chapters; it is not a host function space, quotient subset equality, selected completion representative, ambient supremum construction, or open-cover compactness theorem.

\begin{definition}[Kuratowski embedding distance-profile packet]
\label{def:kuratowski-embedding-distance-profile-packet}
A $\KuratowskiEmbeddingDistanceProfileUp$ packet is a finite $\BHist$ carrier
$$
P=(M,K,E,H,D,R,S,C,Q,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $M$ is the source $\MetricUp$ row carrying the visible point names, source-distance witnesses, and tolerance requests for the profile read.
\item $K$ is the optional $\CompactMetricUp$ support row used when the profile is read against compact finite-net data.
\item $E$ is the accepted $\KuratowskiEmbeddingUp$ row that converts the metric source into displayed distance-function observations.
\item $H$ is the $\HausdorffMetricUp$ comparison row available only when two compact-supported profile reads are compared.
\item $D$ is the distance-profile classifier row, listing the finite family of displayed distance observations and the tolerance window used by the consumer.
\item $R$ is the readback row that routes each displayed distance observation to the same metric and compact-support data named by $M,K,E,H$.
\item $S$ records componentwise $\hsame$ transport for the metric, compact-support, embedding, Hausdorff, profile, readback, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay along the route
$$
M,K,E,H \longmapsto D \longmapsto R .
$$
\item $Q$ is the $\Pkg$ provenance over $\KuratowskiEmbeddingDistanceProfileUp$, $\KuratowskiEmbeddingUp$, $\HausdorffMetricUp$, $\CompactMetricUp$, $\MetricUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\KuratowskiEmbeddingDistanceProfileUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through these ten rows. It has no coordinate for host real-valued function extensionality, quotient compact-set equality, selected completion representatives, ambient suprema, open-cover compactness, or a detached hyperspace object.
\end{definition}

\begin{theorem}[Kuratowski embedding distance-profile NameCert obligations]
\label{thm:kuratowski-embedding-distance-profile-namecert-obligations}
For every accepted $\KuratowskiEmbeddingDistanceProfileUp$ packet $P=(M,K,E,H,D,R,S,C,Q,N)$, the local $\NameCert_{\KuratowskiEmbeddingDistanceProfileUp}$ surface consists exactly of the following finite obligation rows:
\begin{enumerate}
\item carrier admission for the displayed metric, compact-support, Kuratowski embedding, Hausdorff comparison, distance-profile, readback, transport, replay, provenance, and local naming rows;
\item source exposure, requiring every distance-profile observation in $D$ to be read through the same $\MetricUp$ row $M$ and, when compact support is present, through the same $\CompactMetricUp$ row $K$;
\item embedding-profile coherence, requiring the profile row $D$ to be downstream of the $\KuratowskiEmbeddingUp$ row $E$ rather than a detached host function;
\item Hausdorff compatibility, requiring any compact-supported comparison to read the $\HausdorffMetricUp$ row $H$ before comparing two profile windows;
\item readback and transport, requiring $R,S,C$ to replay and transport only the displayed finite route;
\item provenance exhaustion, requiring $Q,N$ to name only the cited BEDC rows and to export no host function extensionality, quotient compact-set equality, selected completion representative, ambient supremum, open-cover compactness, or detached hyperspace object.
\end{enumerate}
No distance-profile obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Carrier admission is projection from \autoref{def:kuratowski-embedding-distance-profile-packet}. The accepted packet displays exactly the metric source, compact support, Kuratowski embedding row, Hausdorff comparison row, profile row, readback row, and structural rows.

Source exposure follows by reading $M$ first and $K$ when the profile is compact-supported. The profile row $D$ has no independent source coordinate, so every visible distance observation is tied to the same metric and compact-support data.

Embedding-profile coherence is the projection to $E,D$. The row $E$ is the only embedding row in the carrier, and $D$ is read after it, so the profile is a displayed Kuratowski distance-function read rather than a host function-space object.

For compact-supported comparison, the row $H$ supplies the Hausdorff finite-net comparison before any two profile windows are compared. The readback and transport rows $R,S,C$ preserve and replay that same finite route.

Finally, $Q,N$ exhaust provenance and local naming. Since the carrier has no coordinate for host function extensionality, quotient compact-set equality, selected completion representatives, ambient suprema, open-cover compactness, or detached hyperspace objects, none of these can be exported by the NameCert surface.
\end{proof}

\begin{theorem}[Kuratowski embedding distance-profile handoff]
\label{thm:kuratowski-embedding-distance-profile-handoff}
Every hyperspace-facing, Hausdorff-facing, or compact-metric-facing consumer of an accepted $\KuratowskiEmbeddingDistanceProfileUp$ packet factors through
$$
M,K,E,H \longmapsto D \longmapsto R \longmapsto S,C,Q,N .
$$
Consequently the consumer receives only the displayed metric source, compact-support row, Kuratowski embedding row, Hausdorff comparison row, finite distance-profile classifier, readback, componentwise transport, replay, provenance, and local name. It cannot claim host real-valued function extensionality, quotient compact-set equality, a selected completion representative, an ambient supremum, open-cover compactness, or a detached hyperspace object from the packet.
\end{theorem}
\begin{proof}
Start with an accepted packet $P=(M,K,E,H,D,R,S,C,Q,N)$. A profile read must first expose the metric source $M$ and the compact-support row $K$ when the read is compact-supported.

The Kuratowski embedding row $E$ then supplies the displayed distance-function observations. If the consumer compares compact-supported profiles, it must also read the Hausdorff comparison row $H$ before the profile classifier $D$ is public.

The readback row $R$ ties each displayed profile coordinate to the same source route. Componentwise transport, replay, provenance, and local naming are then supplied by $S,C,Q,N$ without adding any new object coordinate.

Thus the consumer receives exactly the finite rows listed in the statement and none of the excluded host-level function, quotient, representative, supremum, compactness, or hyperspace data.
\end{proof}
