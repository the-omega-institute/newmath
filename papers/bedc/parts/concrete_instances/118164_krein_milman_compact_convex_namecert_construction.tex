\begin{definition}[Krein--Milman compact-convex carrier]
\label{def:krein-milman-compact-convex-carrier}

$$
K=(A,V,X,W,E,F,H,C,P,N)

\begin{enumerate}

\item $V$ is the $\LocallyConvexSpaceUp$ row carrying the ambient vector-space, seminorm-window, and weak-neighborhood data available to the packet.
\item $X$ is the $\ConvexSetUp$ row for the same subset, including displayed affine-combination and convex-membership reads.
\item $W$ is the weak-window row through which continuous linear observations and finite neighborhood tests are opened.

\begin{theorem}[Krein--Milman compact-convex NameCert obligations]
\label{thm:krein-milman-compact-convex-namecert-obligations}

\begin{proof}

Open the weak and scalar windows next. The row $W$ records only finite weak-neighborhood and functional-observation tests, while $F$ records finite face, hull, and scalar-comparison data whose scalar reads pass through the $\RealUp$ seal of \autoref{ch:concrete-instances-real-namecert}.

Finally $H,C,P,N$ transport, replay, source, and name the same displayed route. Since the carrier has no row for unrestricted separation, quotient convex-body equality, countable choice, host compact-convex hull equality, or ambient real completeness, the listed rows exhaust the NameCert obligations.
\end{proof}
