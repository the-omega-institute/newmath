\begin{theorem}[Compact-metric sequential-complete obligations]
\label{thm:compact-metric-sequential-complete-obligations}

$$

\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:compact-metric-sequential-complete-carrier}. The accepted packet exposes exactly the compact metric, finite-net, complete-service, sequential-window, readback, seal, transport, replay, provenance, and local naming rows.

Read the compact metric side first. The source row $K$ supplies only the compact-metric interface, while $T$ supplies the finite-net schedule and coverage rows used to force Cauchy windows at displayed tolerances.

Next read the sequential side. The row $W$ records the finite tail windows and Cauchy-readiness evidence consumed by $R$; it does not store a selected infinite subsequence or a quotient stream equality.

Finally use $R,L,E,H,C,P,N$. Rational readback is passed to the complete-metric service row before the terminal Real seal is available, and transport and replay preserve the same displayed route.
