\begin{definition}[ConstructiveRealNormalization carrier]
\label{def:constructive-real-normalization-carrier}

$$

$$

\begin{enumerate}
\item $Q$ is the raw Cauchy source row, exposing the finite source requests and their Cauchy-window evidence.
\item $B$ is the $\BishopRealRegularizationUp$ row that regularizes the raw source before any public real-line consumer can read it.
\item $W$ is the finite $\StreamNameUp$ window row shared by the source, regularized output, and public interface read.
\item $R$ is the $\RegSeqRatUp$ readback row for the regular rational name delivered by the regularization route.
\item $D$ is the $\DyadicRatCoreUp$ tolerance ledger recording source budgets, regularization budgets, readback budgets, and Real-facing output budgets.

\item $E$ is the terminal $\RealUp$ seal, available only after $Q,B,W,R,D,L$ have been displayed.

\end{definition}

\begin{theorem}[ConstructiveRealNormalization window determinacy]
\label{thm:constructive-real-normalization-window}
Let $Z=(Q,B,W,R,D,L,E,H,C,P,N)$ be an accepted $\ConstructiveRealNormalizationUp$ packet. Every public $\ConstructiveRealLineUp$ or $\RealUp$ read of $E$ determines the same finite normalization window
$$
W_{\mathrm{norm}}(Z)=(Q,B,W,R,D,L)
$$
through the raw Cauchy source, Bishop regularization row, StreamName windows, RegSeqRat readback, DyadicRatCore tolerance ledger, and constructive real-line interface row. No second source window, quotient stream, selected limit, countable-choice schedule, trichotomy branch, host real equality, or ambient completeness principle can supply an alternate public read of the same seal.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:constructive-real-normalization-carrier}. The only analytic rows before the seal are $Q,B,W,R,D,L$, so every public read starts with the raw source, regularization packet, finite windows, readback row, tolerance ledger, and real-line interface.

Read \autoref{ch:concrete-instances-bishop-real-regularization-namecert}. Its regularization handoff forces the raw source through the displayed Bishop row before the terminal real-name seal can be inspected.

Read \autoref{ch:concrete-instances-constructive-real-line-namecert} next. The public interface row consumes the same StreamName, RegSeqRat, and DyadicRatCore route before exposing a $\RealUp$ consumer surface.

The structural rows $H,C,P,N$ transport, replay, source, and name that same finite route. Since the carrier has no coordinate for quotient streams, selected limits, countable choice, trichotomy, host equality, or ambient completeness, none of those objects can determine a second window for the seal.
\end{proof}
