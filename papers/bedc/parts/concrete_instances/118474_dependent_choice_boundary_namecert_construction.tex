\begin{theorem}[Dependent-choice boundary finite-prefix nonescape]
\label{thm:dependent-choice-boundary-finite-prefix-nonescape}
Every accepted $\DependentChoiceBoundaryUp$ carrier exposes its diagonal data through the finite route
$$
\CountableChoiceBoundaryUp,\quad
\LLPOBoundaryUp,\quad
\RegularCauchyDiagonalizationUp,\quad
\RegSeqRatUp,\quad
\RealUp .
$$
Any consumer that asks for an infinite dependent-choice chain, a hidden global selector, quotient stream equality, a selected real limit, or ambient completion must stop at the nonescape ledger $F$.
\end{theorem}
\begin{proof}
Project the carrier $D=(Q,L,G,W,R,E,F,H,C,P,N)$. The rows $Q$ and $L$ place the request behind the countable-choice and LLPO refusal boundaries before the diagonal source row is read.

Read the finite prefix data next. The diagonal source $G$ supplies only the inspected regular-Cauchy family, while $W$ records the finite dependency window and $R$ reads back the regular rational data visible in that window.

The terminal real-name row $E$ is therefore downstream of finite prefix evidence. The nonescape row $F$ has no field for a dependent-choice chain, a global branch selector, quotient stream equality, selected limits, or ambient completion, and the structural rows $H,C,P,N$ preserve this same finite route.
\end{proof}

\begin{theorem}[Dependent-choice boundary Real-completion refusal]
\label{thm:dependent-choice-boundary-real-completion-refusal}

The consumer may use those rows as a finite diagonal selection certificate, but it receives no dependent-choice assumption and no completed Real object beyond the displayed $\RealUp$ seal route.
\end{theorem}
\begin{proof}
Start from the displayed carrier. The Real-facing consumer reaches $\RealUp$ only through $G,W,R,E$: the diagonal row gives the source family, the prefix window lists the finite dependencies, the regular-rational row reads the inspected data, and the real seal records the terminal boundary.

\end{proof}
