\begin{theorem}[Regular Cauchy sandwich cofinal tail-mesh dependency]
\label{thm:regular-cauchy-sandwich-cofinal-tail-mesh-dependency-route}
Every accepted $\RegularCauchySandwichUp$ packet whose common tail row is presented cofinally must read the $\CofinalTailMeshUp$ route of \autoref{ch:concrete-instances-cofinal-tail-mesh-namecert} before the lower and upper $\RegSeqRatUp$ readbacks and the terminal $\RealUp$ seal are consumed. The dependency is the displayed route through the sandwich carrier, the window bracketing theorem, and the sibling dependency route; it is not an appeal to quotient streams, selected limits, trichotomy, choice, host real equality, or ambient completeness.
\end{theorem}
\begin{proof}
Read the carrier rows in \autoref{def:regular-cauchy-sandwich-carrier}. The common tail coordinate $T$ is displayed before the lower and upper StreamName windows, the lower and upper RegSeqRat readbacks, and the Real seal row.

When $T$ is presented cofinally, consume the CofinalTailMesh route of \autoref{ch:concrete-instances-cofinal-tail-mesh-namecert}. That route supplies the shared finite tail-window mesh before any Real or completion-facing seal is read.

Apply the window bracketing theorem \autoref{thm:regular-cauchy-sandwich-window-bracketing}. It keeps the lower and upper readbacks downstream of the common tail row and the shared dyadic ledger.

Finally use the sibling dependency route \autoref{thm:regular-cauchy-sandwich-sibling-dependency-route}. It already requires the StreamName and RegSeqRat siblings before the Real seal, so adding the cofinal tail-mesh read fixes the horizontal dependency without adding any external analytic coordinate.
\end{proof}
