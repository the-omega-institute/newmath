\label{def:compact-uniform-graph-modulus-carrier}

\item $M$ is the $\MetricUp$ source-and-target distance row used to compare source points, selected centers, and target values.
\item $F$ is the $\ContinuousMapUp$ graph-evaluation row, recording the finite pointwise graph windows opened at the centers of $K$.
\item $P$ is the pointwise-modulus row attached to the same graph windows.
\item $U$ is the $\UniformModulusUp$ handoff row obtained by folding the compact-net and pointwise-modulus data into a single tolerance budget.
\item $S$ is the $\StreamNameUp$ finite-window row for graph values and tolerance reads.
\item $R$ is the $\RegSeqRatUp$ readback row attached to the displayed stream windows.

\begin{theorem}[Compact uniform graph-modulus NameCert obligations]
\label{thm:compact-uniform-graph-modulus-namecert-obligations}
For every accepted $\CompactUniformGraphModulusUp$ carrier
$$
G=(K,M,F,P,U,S,R,E,H,C,Q,N),
$$
the local $\NameCert_{\CompactUniformGraphModulusUp}$ surface consists exactly of the following obligation rows:
\begin{enumerate}
\item carrier admission for compact finite-net, metric, continuous graph, pointwise-modulus, uniform-modulus, stream-window, regular readback, Real seal, transport, replay, provenance, and local naming rows;
\item graph-window adequacy, requiring each graph value used by $F$ and $P$ to be exposed through the displayed finite window $S$ and read back through $R$;
\item compact fold exactness, requiring the uniform-modulus row $U$ to be obtained only from the compact finite-net row $K$, metric row $M$, graph row $F$, and pointwise-modulus row $P$;
\item Real seal nonescape, requiring the terminal row $E$ to be consumed only after $K,M,F,P,U,S,R$ have all been displayed and replayed through $H,C,Q,N$;
\item exclusion of host graph subsets, open-cover compactness, global center choice, quotient map equality, selected external moduli, and ambient $\RealUp$ completeness.
\end{enumerate}
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:compact-uniform-graph-modulus-carrier}. The analytic rows are precisely $K,M,F,P,U,S,R,E$, and the structural rows $H,C,Q,N$ preserve and replay the same route.

The graph-window adequacy clause forces pointwise graph reads through $S$ and $R$. Thus a continuous-map value is consumed as finite StreamName and RegSeqRat data, not as a host graph element.

The compact fold exactness clause then makes $U$ downstream from the compact finite net $K$, metric comparisons $M$, graph values $F$, and pointwise moduli $P$. This is the finite graph-modulus route used by the compact-uniform-continuity construction.

Finally, $E$ is terminal and only Real-facing. Since no row stores open-cover compactness, a host graph subset, a global choice functional, quotient map equality, an external selected modulus, or ambient completeness, the local certificate cannot export those principles.
\end{proof}
