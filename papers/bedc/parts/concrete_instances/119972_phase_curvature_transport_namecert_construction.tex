\begin{definition}[Phase curvature transport carrier]
\label{def:phase-curvature-transport-carrier}
A $\PhaseCurvatureTransportUp$ carrier is a finite $\BHist$ packet
$$
C=(D,M,B,\Phi,K,R,H,T,P,N)
$$
with the following visible rows:
\begin{enumerate}
\item $D$ is the finite $\PoincareDiskMetricUp$ disk-window row, displaying the inspected disk probes and admissible boundary-facing routes.
\item $M$ is the $\HyperbolicMetricUp$ readback row consumed by the packet before any phase transport is inspected.
\item $B$ is the boundary-refusal row, recording which far-end or boundary reads are preserved as boundary data and not collapsed into interior centers.
\item $\Phi$ is the phase-transport row, listing the finite phase windows, holonomy comparisons, and observer-expansion readbacks inspected by the packet.
\item $K$ is the curvature-budget handoff row, reusing the budget discipline of \autoref{ch:concrete-instances-hyperbolic-phase-curvature-budget-namecert} for the displayed phase transport.
\item $R$ is the $\RealUp$ seal for metric, phase, and curvature-budget readbacks reached only after $D,M,B,\Phi,K$ have been displayed.
\item $H$ records componentwise $\hsame$ transport for disk, metric, boundary, phase, curvature-budget, real-seal, replay, provenance, and local-name rows.
\item $T$ records displayed $\Cont$ replay from disk windows through metric readback, boundary refusal, phase transport, curvature-budget handoff, and real sealing.
\item $P$ is the $\Pkg$ provenance over $\PhaseCurvatureTransportUp$, $\PoincareDiskMetricUp$, $\HyperbolicMetricUp$, $\HyperbolicPhaseCurvatureBudgetUp$, $\HyperbolicPhaseHolonomyIndexUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\PhaseCurvatureTransportUp}$ row.
\end{enumerate}
The classifier accepts a packet only when disk reads pass through $D$, metric reads pass through $M$, boundary refusal is read from $B$, phase transport is displayed in $\Phi$, curvature-budget constraints are carried by $K$, and all Real-facing outputs preserve $R,H,T,P,N$. It has no coordinate for a global connection form, chosen geodesic representative, quotient boundary equality, hidden smooth curvature tensor, or an identification of the boundary refusal with an interior phase center.
\end{definition}

\begin{theorem}[Phase curvature transport NameCert obligations]
\label{thm:phase-curvature-transport-namecert-obligations}
For every accepted $\PhaseCurvatureTransportUp$ carrier $C=(D,M,B,\Phi,K,R,H,T,P,N)$, the local $\NameCert_{\PhaseCurvatureTransportUp}$ obligations are exactly carrier admission for the disk-window row, hyperbolic metric readback, boundary-refusal row, phase-transport row, curvature-budget handoff, real-name seal, componentwise transport, continuation replay, provenance, and local naming; metric exactness requiring all phase windows to read the same displayed disk and metric rows; boundary-refusal exactness requiring transport to preserve the boundary row before phase readback is sealed; curvature-budget exactness requiring $K$ to be consumed before any Real-facing phase output; and non-escape from global connection forms, chosen geodesic representatives, quotient boundary equality, hidden smooth curvature tensors, and interior-center collapse.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:phase-curvature-transport-carrier}. The finite disk row $D$, metric row $M$, boundary-refusal row $B$, phase-transport row $\Phi$, curvature-budget row $K$, and Real seal $R$ are the only geometric rows available to the classifier.

Metric exactness is read first. A phase window cannot be consumed until the displayed disk probes have passed through $D$ and their hyperbolic metric readback has passed through $M$.

Boundary and curvature data are then checked in order. The row $B$ keeps the far-end refusal as boundary data, while $K$ supplies the finite curvature-budget handoff for the phase transport in $\Phi$ before any Real-facing output is sealed by $R$.

Finally, $H,T,P,N$ transport, replay, source, and name the same route. Because the carrier has no row for global connection forms, chosen geodesic representatives, quotient boundary equality, hidden smooth curvature tensors, or interior-center collapse, the listed rows exhaust the local NameCert surface.
\end{proof}
