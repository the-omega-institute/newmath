\begin{theorem}[Cauchy condensation finite-window NameCert obligations]
\label{thm:cauchy-condensation-finite-window-namecert-obligations}

\begin{proof}

The readback rows are downstream of that window. The row $R$ repacks only the displayed finite data as $\RegSeqRatUp$ readback, and the seal row $E$ is reachable only through $R$.

The structural rows $H,C,P,N$ preserve, replay, source, and name the same route. Since the carrier has no additional analytic coordinate, the listed rows exhaust the local NameCert obligations.
\end{proof}
