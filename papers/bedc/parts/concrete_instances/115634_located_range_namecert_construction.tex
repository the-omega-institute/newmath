\chapter{A Concrete Naming Certificate for $\LocatedRangeUp$}
\label{ch:concrete-instances-located-range-namecert}

Following Bishop and Bridges on located subsets and compact metric images, the $\LocatedRangeUp$ packet records the finite data by which the range of a displayed compact-continuous map is read as located range data. It sits after the compact source of \autoref{ch:concrete-instances-compactmetric-namecert}, the graph and pointwise route of \autoref{ch:concrete-instances-continuousmap-namecert}, the tolerance handoff of \autoref{ch:concrete-instances-uniformmodulus-namecert}, the finite observation windows of \autoref{ch:concrete-instances-streamname-namecert}, the regular rational readback of \autoref{ch:concrete-instances-regseqrat-namecert}, and the terminal real seal of \autoref{ch:concrete-instances-real-namecert}. The carrier names compact-continuous range reads through displayed finite rows; it does not import open-cover compactness, selected image points, quotient function equality, countable choice, or ambient $\RealUp$ completeness.

\begin{definition}[LocatedRange carrier]
\label{def:located-range-carrier}
A $\LocatedRangeUp$ carrier is a finite $\BHist$ packet
$$
K=(K_0,F,U,W,R,E,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $K_0$ is the $\CompactMetricUp$ source row, exposing the compact domain only through displayed finite-net and coverage data.
\item $F$ is the $\ContinuousMapUp$ graph row, recording the finite graph and pointwise-continuity history available to range consumers.
\item $U$ is the $\UniformModulusUp$ row that binds compact-source requests to one tolerance route before image windows are read.
\item $W$ is the finite $\StreamNameUp$ image-window row, listing only the displayed windows inspected by downstream range queries.
\item $R$ is the $\RegSeqRatUp$ readback row attached to the same image windows and tolerance requests.
\item $E$ is the $\RealUp$ seal row reached only after $W$ and $R$ have both been displayed.
\item $H$ records componentwise $\hsame$ transport for the compact source, graph, modulus, windows, readback, seal, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a located-range request through $K_0,F,U,W,R,E,H,P,N$.
\item $P$ is the $\Pkg$ provenance over $\LocatedRangeUp$, $\CompactMetricUp$, $\ContinuousMapUp$, $\UniformModulusUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\LocatedRangeUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $K_0,F,U,W,R,E,H,C,P,N$. It has no coordinate for open-cover compactness, a choice-selected image point, quotient equality of maps, a countable-choice schedule, host real equality, or ambient $\RealUp$ completeness.
\end{definition}

\begin{theorem}[LocatedRange NameCert obligations]
\label{thm:located-range-namecert-obligations}
For an accepted carrier $K=(K_0,F,U,W,R,E,H,C,P,N)$, the local $\NameCert_{\LocatedRangeUp}$ surface consists exactly of five rows:
\begin{enumerate}
\item carrier admission for the finite packet $K$;
\item classifier locality for the $\CompactMetricUp$ source, $\ContinuousMapUp$ graph, $\UniformModulusUp$ tolerance route, finite $\StreamNameUp$ windows, $\RegSeqRatUp$ readback, and $\RealUp$ seal;
\item stability through componentwise $\hsame$ transport $H$ and displayed $\Cont$ replay $C$;
\item exactness through the ordered compact-source, continuous-graph, uniform-modulus, window, readback, and seal route $K_0,F,U,W,R,E$;
\item ledger control through $\Pkg$ provenance $P$ and the local naming row $N$.
\end{enumerate}
No obligation may replace these rows by open-cover compactness, selected image points, quotient function equality, countable choice, host real equality, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:located-range-carrier}. The compact source, graph, modulus, window, readback, seal, transport, replay, provenance, and naming rows are exactly $K_0,F,U,W,R,E,H,C,P,N$.

Classifier locality is read through the same finite rows. The compact-source row supplies only displayed compact metric data, the graph row supplies only the continuous-map history, and the modulus row supplies only the tolerance route that is visible before windows are inspected.

Exactness then follows from the ordered route $K_0,F,U,W,R,E$. The image windows are admitted through $W$, the regular rational readback is downstream of those windows through $R$, and the real seal $E$ is reached only after the readback row is displayed.

Finally $H,C,P,N$ transport, replay, source, and name the same route. Since no carrier row stores open-cover compactness, selected image points, quotient function equality, countable choice, host real equality, or ambient completeness, the five listed rows exhaust the local NameCert surface.
\end{proof}

\begin{theorem}[LocatedRange compact-continuous handoff]
\label{thm:located-range-compact-continuous-handoff}
Every range read from an accepted $\LocatedRangeUp$ carrier factors through the finite compact-continuous route
$$
\CompactMetricUp,\ \ContinuousMapUp,\ \UniformModulusUp,\ \StreamNameUp,\ \RegSeqRatUp,\ \RealUp .
$$
In particular, a consumer may reach the range seal only after reading the compact source $K_0$, the continuous graph $F$, the uniform modulus $U$, the finite image windows $W$, the regular rational readback $R$, and the terminal real seal $E$ in that order, with $H,C,P,N$ preserving the same route.
\end{theorem}
\begin{proof}
Start with the compact source row $K_0$ and continuous graph row $F$. They expose the domain and image graph as displayed NameCert data, not as an open-cover compactness theorem or a host function object.

Read the uniform-modulus row $U$ before any image window is consumed. This keeps every range query behind the compact-continuous tolerance route supplied by the source and graph rows.

The finite image windows $W$ are then the only stream route available to the consumer. The readback row $R$ attaches the same windows to the regular rational surface, and the seal row $E$ is downstream of that readback.

The structural rows $H,C,P,N$ preserve this order under transport, replay, provenance, and local naming. Hence no range read can fork into selected image points, quotient function equality, countable-choice schedules, host real equality, open-cover compactness, or ambient $\RealUp$ completeness.
\end{proof}
