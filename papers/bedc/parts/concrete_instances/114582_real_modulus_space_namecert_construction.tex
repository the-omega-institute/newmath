\label{thm:real-modulus-space-namecert-obligations}

\end{theorem}
\begin{proof}

The finite index row $I$ is read before any tolerance request reaches a stream

Finally $H,C,P,N$ transport, replay, source, and name the same packet. Since no
excluded host object appears as a carrier coordinate, the listed rows exhaust
