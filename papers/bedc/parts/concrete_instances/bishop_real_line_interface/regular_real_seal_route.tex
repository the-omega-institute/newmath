\begin{theorem}[Bishop real-line interface regular-real seal route]
\label{thm:bishop-real-line-interface-regular-seal}
Every terminal $\RealUp$ seal read from an accepted $\BishopRealLineInterfaceUp$ carrier must pass through the displayed $\RegSeqRatUp$ readback row, the $\CauchyEquivalenceSetoidUp$ classifier comparison row, the $\DyadicRatCoreUp$ endpoint and tolerance rows, and the terminal $\RealUp$ seal row before any public real-line consumer reads it. Equivalently, a public interface read follows
$$
\DyadicRatCoreUp,\ \StreamNameUp,\ \RegSeqRatUp,\ \CauchyEquivalenceSetoidUp,\ \RealUp
\longmapsto H,C,P,N
$$
through the carrier rows $D,W,R,Q,E,H,C,P,N$.

The route exports no host real equality, quotient stream equality, selected representative, selected limit, trichotomy, countable-choice schedule, metric completeness, open-cover compactness, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Project the carrier $I=(D,W,R,E,Q,H,C,P,N)$ from \autoref{def:bishop-real-line-interface-carrier}. The dyadic ledger $D$ is the first value-facing row, and the finite stream window $W$ is the only stream observation row available before readback.

Apply the regular-completion dependency route of \autoref{thm:bishop-real-line-interface-regular-completion-dependency-route}. It places completion-facing reads behind the regular Cauchy completion packet, whose public surface reaches the interface through dyadic tolerances, finite stream windows, regular readback, common-tail comparison, and the terminal Real seal.

Apply the ordered Cauchy-group forward route of \autoref{thm:bishop-real-line-interface-ordered-cauchy-group-forward-route}. That theorem keeps order-compatible consumers behind the same dyadic, stream, RegSeqRat, Real, and Cauchy-equivalence rows rather than behind a host completed object.

Now use the local four-object route and nonescape theorems of \autoref{thm:bishop-real-line-interface-four-object-route} and \autoref{thm:bishop-real-line-interface-nonescape}. The comparison row $Q$ can classify only displayed regular-Cauchy data before the seal is read, and $H,C,P,N$ preserve the same route. Therefore every public real-line read reaches the terminal seal only after the RegSeqRat readback, CauchyEquivalenceSetoid comparison, DyadicRatCore tolerance rows, and Real seal have been displayed.
\end{proof}
