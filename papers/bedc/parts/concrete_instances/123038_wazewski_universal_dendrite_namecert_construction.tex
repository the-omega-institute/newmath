\chapter{A Concrete Naming Certificate for $\WazewskiUniversalDendriteUp$}

Following Wazewski and Nadler on universal dendrites and continuum theory, the $\WazewskiUniversalDendriteUp$ packet records the finite BEDC surface for the universal dendrite with dense branch points and finite subtree universality. It refines the dendrite carrier of \autoref{ch:concrete-instances-dendrite-namecert}, the Peano-continuum boundary of \autoref{ch:concrete-instances-peano-continuum-namecert}, the local connectedness surface of \autoref{ch:concrete-instances-locally-connected-namecert}, the compact-metric source of \autoref{ch:concrete-instances-compactmetric-namecert}, and the tree certificate of \autoref{ch:concrete-instances-tree-namecert}. The packet names branch-point density, finite subtree embedding, and universality handoff rows; it is not a host continuum, not a choice-selected embedding family, not an arbitrary inverse limit, and not a quotient presentation of arcs.

\begin{definition}[Wazewski universal dendrite carrier]
\label{def:wazewski-universal-dendrite-carrier}
A $\WazewskiUniversalDendriteUp$ carrier is a finite $\BHist$ packet
$$
W=(D,P,L,K,T,B,E,U,H,C,Q,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $D$ is the consumed $\DendriteUp$ row, exposing the endpoint, unique-arc, and cutpoint-separation ledgers already named by the dendrite packet.
\item $P$ is the consumed $\PeanoContinuumUp$ row, binding the compact connected metric continuum surface before any universal-dendrite read is exported.
\item $L$ is the consumed $\LocallyConnectedUp$ row, recording the local connectedness refinements through which branch neighbourhoods are inspected.
\item $K$ is the consumed $\CompactMetricUp$ row, exposing finite metric windows, compact finite-net rows, and rational tolerance comparisons.
\item $T$ is the consumed $\TreeUp$ row, recording the finite tree-like separation surface used by the finite subtree requests.
\item $B$ is the branch-point density row, asserting that every displayed nondegenerate open arc window contains a displayed branch-point witness.
\item $E$ is the finite subtree embedding row, asserting that each displayed finite tree request is represented by a finite subtree window inside the dendrite carrier.
\item $U$ is the universality handoff row, routing finite tree and dendrite consumers through $B$ and $E$ before they read the universal object.
\item $H$ records componentwise $\hsame$ transport for the dendrite, Peano-continuum, locally connected, compact-metric, tree, branch-density, embedding, universality, replay, provenance, and naming rows.
\item $C$ records displayed $\Cont$ replay from $D,P,L,K,T$ through branch-point density, finite subtree embedding, and the universality handoff.
\item $Q$ is the $\Pkg$ provenance over $\WazewskiUniversalDendriteUp$, $\DendriteUp$, $\PeanoContinuumUp$, $\LocallyConnectedUp$, $\CompactMetricUp$, $\TreeUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\WazewskiUniversalDendriteUp}$ row.
\end{enumerate}
The carrier predicate is exactly the assertion that these twelve rows form one finite universal-dendrite naming packet. It contains no coordinate for host continua, arbitrary path spaces, choice-selected embedding families, inverse-limit presentations, quotient equality of arcs, or open-cover compactness.
\end{definition}

\begin{theorem}[Wazewski universal dendrite NameCert obligations]
\label{thm:wazewski-universal-dendrite-namecert-obligations}
For every accepted $\WazewskiUniversalDendriteUp$ carrier $W=(D,P,L,K,T,B,E,U,H,C,Q,N)$, the local $\NameCert_{\WazewskiUniversalDendriteUp}$ surface consists exactly of the following finite obligation rows:
\begin{enumerate}
\item carrier admission for the displayed dendrite, Peano-continuum, locally connected, compact-metric, tree, branch-density, finite-subtree-embedding, universality, transport, replay, provenance, and local naming rows;
\item branch-point density, requiring each nondegenerate arc-window request to expose the displayed branch-point row $B$ before the universal object is read;
\item finite subtree embedding, requiring each finite tree request to pass through $T$ and then through the embedding row $E$;
\item universality handoff, requiring every downstream universal-dendrite consumer to replay $D,P,L,K,T,B,E,U$ before it receives the local name;
\item transport and replay, requiring $H$ and $C$ to preserve exactly the displayed rows under accepted source transport;
\item provenance and non-escape, requiring $Q$ and $N$ to cite only the listed sibling packets and to exclude host continua, choice-selected embedding families, inverse-limit presentations, quotient arc equality, and open-cover compactness.
\end{enumerate}
No NameCert obligation is stored outside those rows.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:wazewski-universal-dendrite-carrier}. The projection exposes exactly the consumed dendrite, Peano-continuum, locally connected, compact-metric, tree, branch-density, finite-subtree-embedding, universality, transport, replay, provenance, and local naming rows.

The branch-point density obligation is the row $B$ downstream of $D,P,L,K$. Since $B$ is the only branch-density coordinate, an arc-window consumer cannot obtain dense branching without first reading the dendrite and compact-continuum rows.

The finite subtree embedding obligation is the row $E$ downstream of $T$. A finite tree request is therefore interpreted as a displayed subtree window inside the same dendrite carrier, not as a host embedding theorem.

The universality handoff is ordered by $U$ and replayed by $C$. Transport through $H$ moves only the displayed coordinates, while $Q$ and $N$ package the same route as local provenance and local naming.

The exclusions follow from the carrier inventory. There is no row for a host continuum, arbitrary path space, choice-selected embedding family, inverse-limit presentation, quotient equality of arcs, or open-cover compactness, so such data cannot be part of the local NameCert surface.
\end{proof}

\begin{theorem}[Wazewski universal dendrite branch universality handoff]
\label{thm:wazewski-universal-dendrite-branch-universality-handoff}
Every downstream consumer of an accepted $\WazewskiUniversalDendriteUp$ packet reads the universal dendrite only through the finite route
$$
\DendriteUp,\ \PeanoContinuumUp,\ \LocallyConnectedUp,\ \CompactMetricUp,\ \TreeUp
\longmapsto B \longmapsto E \longmapsto U \longmapsto H,C,Q,N .
$$
Thus branch-point density and finite subtree universality are exposed as displayed BEDC rows over the dendrite and compact-continuum sources, not as a host universal-continuum theorem or as a selected infinite embedding family.
\end{theorem}
\begin{proof}
Let $W=(D,P,L,K,T,B,E,U,H,C,Q,N)$ be accepted. The only continuum source available to the consumer is the displayed dendrite row $D$, read with the Peano-continuum, local-connectedness, compact-metric, and tree rows $P,L,K,T$.

Branch-point density is then read through $B$. The row is downstream of the finite arc and local connectedness windows, so the consumer sees a displayed branch witness rather than a host density theorem.

Finite subtree universality is read through $E$. The tree row $T$ supplies the finite request, and $E$ embeds that request into the same displayed dendrite packet before the universality handoff row $U$ is available.

Finally $H,C,Q,N$ transport, replay, source, and name this route. Since every downstream read must pass through the displayed sequence, the packet exports no host continuum, arbitrary path space, choice-selected embedding family, inverse-limit presentation, quotient equality of arcs, or open-cover compactness.
\end{proof}
