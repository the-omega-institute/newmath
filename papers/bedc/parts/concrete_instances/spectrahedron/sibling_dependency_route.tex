\begin{theorem}[Spectrahedron sibling dependency route]
\label{thm:spectrahedron-sibling-dependency-route}
Every accepted $\SpectrahedronUp$ carrier reads the matrix carrier of \autoref{ch:concrete-instances-matrix-namecert} as offset rows, the affine pencil rows of \autoref{ch:concrete-instances-linearmap-namecert}, vector-space parameter rows from \autoref{ch:concrete-instances-vecspace-namecert}, semidefinite cone membership rows from \autoref{ch:concrete-instances-semidefinitecone-namecert}, and convex-set provenance rows from \autoref{ch:concrete-instances-convexset-namecert} before exposing the local spectrahedron $\NameCert$.
\end{theorem}
\begin{proof}
Project the accepted carrier. Its affine-semidefinite feasibility surface contains a matrix offset row, a linear pencil row, parameter-coordinate rows, positive semidefinite membership, convex provenance, and the local naming row.

The sibling references above exhaust those coordinates. Thus the spectrahedron packet reads the sibling rows as finite provenance before the local $\NameCert$ is admitted, rather than importing a host feasible set.
\end{proof}
