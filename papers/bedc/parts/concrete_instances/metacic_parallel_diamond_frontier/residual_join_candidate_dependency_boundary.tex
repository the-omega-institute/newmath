\begin{theorem}[Residual-join candidate dependency boundary]
\label{thm:metacic-parallel-diamond-frontier-residual-join-candidate-dependency-boundary}
Every residual-join candidate read from an accepted $\MetaCICParallelDiamondFrontierUp$ packet must expose the critical-pair envelope, residual-substitution dependency route, candidate-normalization scope, finite residual witness consumption, and retained-premise boundary before it can be consumed as a local diamond frontier. In carrier form the read remains inside
$$
P,K,J,R,S,C,B,O,H,T,G,N ,
$$
where $K$ displays the critical-pair envelope, $P$ retains the residual-substitution dependency, $J$ records the candidate-normalization row, $R,S,C,B,O$ keep the residual frontier, typed window, witness, bounded checker, and obstruction rows visible, and $H,T,G,N$ provide transport, replay, provenance, and local naming. The boundary exports only this local residual-join candidate surface; it explicitly refuses subject reduction, unrestricted confluence, evaluator equality, quotient term equality, global normalization, and kernel consistency.
\end{theorem}
\begin{proof}
Start with the critical-pair envelope of \autoref{thm:metacic-parallel-diamond-frontier-critical-pair-envelope}. It exposes the bounded overlap rows before a residual-join candidate can be read by a frontier consumer.

Next read the residual-substitution dependency route of \autoref{thm:metacic-parallel-diamond-frontier-residual-substitution-dependency-route}. This keeps the retained premise row $P$ visible while the candidate, residual, checker, and obstruction rows are opened.

Now apply candidate-normalization scope through \autoref{thm:metacic-parallel-diamond-frontier-candidate-normalization-scope}. The candidate row $J$ remains part of the displayed frontier packet rather than a detached normalization theorem.

Consume the finite residual witness with \autoref{thm:metacic-parallel-diamond-frontier-finite-residual-witness-consumption}. The residual rows $R,S,C,B,O$ remain tied to the same finite witness route and cannot be reread as a global local-confluence theorem.

Finally use the retained-premise boundary of \autoref{thm:metacic-parallel-diamond-retained-premise-boundary}. It keeps $P,K,J,R,S,C,B,O,H,T,G,N$ visible before any local diamond frontier consumes the candidate, so the refused endpoints remain outside the packet.
\end{proof}
