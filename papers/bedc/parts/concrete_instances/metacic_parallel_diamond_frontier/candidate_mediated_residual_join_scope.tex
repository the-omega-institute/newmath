\begin{theorem}[MetaCIC candidate-mediated residual-join scope]
\label{thm:metacic-parallel-diamond-candidate-mediated-residual-join-scope}
Every candidate-mediated residual join read from an accepted $\MetaCICParallelDiamondFrontierUp$ packet must expose the critical-pair envelope, candidate-normalization scope, residual-substitution dependency route, finite residual witness consumption, and residual join locality rows before it can be read as a parallel-diamond frontier packet. In carrier form the read remains on the displayed route
$$
P,K,J,R,S,C,B,O,H,T,G,N ,
$$
where $P$ retains the residual-substitution premise, $K$ exposes the critical-pair envelope, $J$ records the candidate-normalization row, $R,S,C,B,O$ keep the residual frontier, seed, witness, bounded checker, and obstruction rows visible, and $H,T,G,N$ provide transport, replay, provenance, and local naming. The scope exports only this finite candidate-mediated handoff, not global confluence, strong normalization, subject reduction, evaluator equality, quotient term equality, premise-free residual substitution, or kernel consistency.
\end{theorem}
\begin{proof}
Start with the critical-pair envelope of \autoref{thm:metacic-parallel-diamond-frontier-critical-pair-envelope}. It exposes the bounded overlap rows before any residual join is available to a frontier consumer.

Next read candidate-normalization scope through \autoref{thm:metacic-parallel-diamond-frontier-candidate-normalization-scope}. The candidate row $J$ is therefore part of the displayed packet rather than an external normalization theorem.

Now use the residual-substitution dependency route of \autoref{thm:metacic-parallel-diamond-frontier-residual-substitution-dependency-route}. It keeps the retained premise row $P$ load-bearing while the residual rows $R,S,C,B,O$ are opened.

Finally consume finite residual witness data and residual join locality via \autoref{thm:metacic-parallel-diamond-frontier-finite-residual-witness-consumption} and \autoref{thm:metacic-parallel-diamond-frontier-residual-join-locality}. These rows keep the local join inside $P,K,J,R,S,C,B,O,H,T,G,N$, so the resulting frontier packet provides only the stated candidate-mediated residual-join scope and none of the refused global endpoints.
\end{proof}

\begin{theorem}[MetaCIC candidate-mediated residual window]
\label{thm:metacic-parallel-diamond-frontier-candidate-mediated-residual-window}
Every accepted residual join read from a $\MetaCICParallelDiamondFrontierUp$ packet must keep the retained premise row $P$, candidate-normalization row $J$, residual-substitution route, finite residual witness rows, and residual-join locality rows inside the same bounded window before any parallel-diamond conclusion is visible. In carrier form the window is the displayed route
$$

$$
where $P$ remains the retained residual-substitution premise, $J$ remains the candidate-normalization row, $R,S,C,B,O$ carry the residual frontier, typed window, finite witness, bounded checker, and obstruction data, and $H,T,G,N$ transport, replay, source, and name the same packet. The read is therefore premise-bearing local residual evidence, not a premise-free parallel-diamond conclusion, unrestricted confluence theorem, subject-reduction theorem, evaluator equality, quotient term equality, or kernel-consistency certificate.
\end{theorem}
\begin{proof}
Start with the candidate-mediated residual-join scope of \autoref{thm:metacic-parallel-diamond-candidate-mediated-residual-join-scope}. It already requires the critical-pair envelope, candidate-normalization scope, residual-substitution dependency route, finite residual witness consumption, and residual-join locality rows to be displayed before a frontier consumer reads the handoff.

Next apply the residual-substitution dependency route of \autoref{thm:metacic-parallel-diamond-frontier-residual-substitution-dependency-route}. This keeps $P$ load-bearing while the residual rows are opened, so the bounded window cannot be reread as a premise-free substitution result.

Finally combine finite residual witness consumption with residual-join locality, using \autoref{thm:metacic-parallel-diamond-frontier-finite-residual-witness-consumption} and \autoref{thm:metacic-parallel-diamond-frontier-residual-join-locality}. These rows keep $R,S,C,B,O$ attached to the same candidate-normalization route through $J$ and the same structural rows $H,T,G,N$. Thus any visible parallel-diamond conclusion remains inside the retained bounded window named in the statement.
\end{proof}
