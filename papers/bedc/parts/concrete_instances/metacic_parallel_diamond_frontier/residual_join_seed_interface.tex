\begin{theorem}[MetaCIC residual-join seed interface]
\label{thm:metacic-parallel-diamond-frontier-residual-join-seed-interface}
Every seed-level diamond frontier consumer of an accepted $\MetaCICParallelDiamondFrontierUp$ packet that reads residual joins must first display the critical-pair envelope, candidate-normalization scope, residual-substitution dependency route, finite residual witness, and candidate strong-normalization handoff. Concretely, the read must pass through \autoref{thm:metacic-parallel-diamond-frontier-critical-pair-envelope}, \autoref{thm:metacic-parallel-diamond-frontier-candidate-normalization-scope}, \autoref{thm:metacic-parallel-diamond-frontier-residual-substitution-dependency-route}, \autoref{thm:metacic-parallel-diamond-frontier-finite-residual-witness-consumption}, and \autoref{thm:metacic-parallel-diamond-frontier-candidate-sn-handoff} before the packet is available as a seed interface. The exported seed read is therefore a displayed residual-join interface over the finite frontier spine, not a premise-free confluence theorem, global normalization theorem, subject-reduction theorem, host reduction equality, or kernel-consistency certificate.
\end{theorem}
\begin{proof}
Start with the critical-pair envelope. The envelope theorem keeps the rows $P,K,J,R,S,C,B,O,H,T,G,N$ visible before a parallel-diamond request can be read, so the seed consumer receives a bounded frontier packet rather than an unrestricted confluence surface.

Next read the candidate-normalization and residual-substitution routes. The candidate-normalization scope keeps $J$ inside the conditional spine, while the residual-substitution dependency route keeps the retained premise and residual windows attached to the same packet.

Now expose the finite residual witness and the candidate strong-normalization handoff. The finite witness theorem supplies the bounded residual rows consumed by the frontier, and the candidate handoff states the normalization-facing read available from those same rows.

Thus any seed-level residual-join consumer has displayed the five interface faces before reading the packet. Since none of those faces exports premise-free confluence, global normalization, subject reduction, host reduction equality, or kernel consistency, the seed interface remains exactly the finite residual-join route stated above.
\end{proof}
