\begin{theorem}[MetaCIC parallel diamond critical-pair envelope]
\label{thm:metacic-parallel-diamond-critical-pair-envelope}
Every accepted $\MetaCICParallelDiamondFrontierUp$ packet exposes a critical-pair envelope only after reading a residual substitution row, a local confluence overlap row, a closed-term substitution row, and a binder-budget row. In carrier terms, the envelope is the finite BEDC route through
$$
P,K,J,R,S,C,B,O,H,T,G,N
$$
with the residual-substitution and confluence audit-map rows still visible. The conclusion is a concrete frontier envelope for bounded MetaCIC confluence audit; it is not a general strong-normalization theorem, unrestricted confluence theorem, unrestricted beta-reduction theorem, or host equality principle.
\end{theorem}
\begin{proof}
Project the accepted frontier carrier. The residual-substitution premise row $P$, critical-pair row $K$, candidate-join row $J$, residual-frontier row $R$, closed-checker row $S$, closed-normal fragment row $C$, bounded-check row $B$, obstruction row $O$, and structural rows $H,T,G,N$ are the only rows exposed by the packet.

Read the residual-substitution route first. The row $P$ supplies the retained premise, while the residual-frontier row $R$ records branch-local substitution windows and binder exposure; neither row discharges compatibility.

Next read the confluence audit-map route. The critical-pair and candidate-join rows $K,J$ supply local overlap data, while $S,C,B$ keep the closed-term substitution and bounded checker information attached to the same finite packet.

The obstruction and structural rows close the envelope. Since $O,H,T,G,N$ preserve the retained premise, bounded replay, provenance, and local name, the packet cannot escape to unrestricted beta reduction, host equality, strong normalization, or a general confluence theorem.
\end{proof}

\begin{theorem}[MetaCIC parallel diamond frontier critical-pair envelope]
\label{thm:metacic-parallel-diamond-frontier-critical-pair-envelope}
Every accepted $\MetaCICParallelDiamondFrontierUp$ packet exposes critical-pair requests only through the finite frontier route
$$
P,K,J,R,S,C,B,O,H,T,G,N .
$$
The candidate term rows $K,J$, residual-substitution rows $P,R$, finite observation confluence rows $S,C,B$, normalization-frontier row $O$, componentwise $\hsame$ transport $H$, $\Cont$ replay $T$, $\Pkg$ provenance $G$, and local $\NameCert$ row $N$ remain displayed before any consumer can read a parallel-diamond request. The route does not assert unrestricted confluence, host reduction equality, unbounded critical-pair search, or a global normalization theorem.
\end{theorem}
\begin{proof}
Project the carrier and the existing critical-pair envelope. The projection exposes $P,K,J,R,S,C,B,O,H,T,G,N$ as the only rows available to a frontier request.

Read the candidate and residual rows first. The candidate term rows $K,J$ store the finite overlap and join candidates, while $P,R$ keep substitution and residual windows attached to the same bounded branch data.

Next read the finite observation confluence rows $S,C,B$ and the normalization-frontier row $O$. These rows certify only the displayed closed-term checks, bounded normal fragments, checker budget, and obstruction boundary.

Finally replay through $H,T,G,N$. Since transport, replay, provenance, and local naming preserve the same finite packet, the accepted critical-pair request cannot be replaced by unrestricted confluence, host reduction equality, unbounded search, or global normalization.
\end{proof}
