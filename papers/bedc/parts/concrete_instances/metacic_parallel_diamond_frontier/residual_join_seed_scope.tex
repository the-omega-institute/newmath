\begin{theorem}[MetaCIC residual-join seed scope]
\label{thm:metacic-parallel-diamond-residual-join-seed-scope}
Every residual-join seed read of an accepted $\MetaCICParallelDiamondFrontierUp$ packet factors through residual-substitution premise rows, critical-pair rows, candidate-join rows, residual-frontier rows, closed-checker rows, obstruction rows, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local $\NameCert$ rows. The seed read is therefore a finite residual-join scope for the parallel-diamond frontier, not a subject-reduction theorem, arbitrary Church--Rosser theorem, quotient term equality, or evaluator equality row.
\end{theorem}
\begin{proof}
Start with the residual-substitution dependency route and the critical-pair envelope. The dependency route keeps the retained substitution premise visible, while \autoref{thm:metacic-parallel-diamond-frontier-critical-pair-envelope} exposes the critical-pair rows before any diamond request is read.

Next read the candidate diamond budget route. It displays the candidate-join rows and keeps them tied to the same finite frontier rather than to an unrestricted Church--Rosser surface.

Now use the finite residual witness consumption route. The residual-frontier and closed-checker rows are consumed only after the finite witness rows have been displayed, so the obstruction rows remain part of the same seed scope.

The structural rows supply componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming. Since the cited routes contain no subject-reduction, arbitrary Church--Rosser, quotient term equality, or evaluator equality coordinate, the residual-join seed read exports none of those endpoints.
\end{proof}
