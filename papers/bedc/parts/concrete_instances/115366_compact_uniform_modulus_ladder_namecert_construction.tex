\begin{theorem}[CompactUniformModulusLadder certificate]
\label{thm:compact-uniform-modulus-ladder-certificate}
For every accepted $\CompactUniformModulusLadderUp$ carrier $L=(K,M,B,R,U,H,C,P,N)$, a tolerance-only uniform-modulus read must factor through the compact source row $K$, the metric row $M$, the finite $\ProbeBundle$ cover row $B$, and the pointwise-radius row $R$ before the $\UniformModulusUp$ row $U$ is exposed. \end{theorem}
\begin{proof}
Project the carrier of \autoref{def:compact-uniform-modulus-ladder-carrier}. The compact source, metric row, finite bundle, pointwise-radius row, uniform-modulus row, transport, replay, provenance, and naming rows are the only coordinates available.

Read $K,M,B$ first. The compact input is visible only through the finite $\ProbeBundle$ cover row over the shared metric, so the ladder starts from displayed cover data rather than from a host open-cover principle or an externally selected subcover.

Next read $R$. Each displayed center carries pointwise-radius evidence through $\ContinuousUp$, and the lower-bound fold uses only the finitely many rows already listed in $B$ and $R$.

Finally expose $U$ through $H,C,P,N$. The replay route sends a tolerance request to the same finite cover, pointwise rows, and fold before the uniform-modulus row is consumed. Since no excluded object is a coordinate of $L$, none can be exported from the accepted certificate.
\end{proof}
