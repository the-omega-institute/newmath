\begin{theorem}[RealSeparability countable dense window budget]
\label{thm:real-separability-countable-dense-window-budget}
Every accepted $\RealSeparabilityUp$ dense-window read that is consumed as countable dense data factors through the same finite L10 source route:
$$
\DyadicRatCoreUp \longmapsto \StreamNameUp \longmapsto \RegSeqRatUp \longmapsto \RealUp \longmapsto \BHist,\hsame,\Cont,\Pkg,\NameCert .
$$
Concretely, the read must display the $\DyadicRatCoreUp$ rational-density row, the $\StreamNameUp$ finite request schedule, the $\RegSeqRatUp$ regular readback, the terminal $\RealUp$ seal, the $\BHist$ transport ledger, the displayed $\Cont$ replay route, the $\Pkg$ provenance row, and the local $\NameCert_{\RealSeparabilityUp}$ row before any countable-dense consumer can use the window.

The theorem does not assert full $\RealUp$ completeness, a choice-selected enumeration of reals, a host dense subset, quotient real equality, or a selected nearest rational for each real name.
\end{theorem}
\begin{proof}
Start with the countable dense route of \autoref{lem:real-separability-countable-dense-route}. It already orders every exported dense surface through the countable dense subset boundary, dyadic-density witness surface, rational-density witness surface, finite $\StreamNameUp$ window, $\RegSeqRatUp$ readback, and terminal $\RealUp$ seal.

Use the dyadic-density dependency and RegSeqRat schedule rows in this hub. They force each dense-window request to carry a displayed dyadic tolerance row and a finite stream request schedule before the regular rational readback is available.

Now route the read through the Real seal route. The $\RealUp$ seal is downstream of the same dyadic, stream, and regular-rational rows, and the structural $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$ rows retain that dependency for the countable-dense consumer.

Thus the window budget is exactly the displayed L10 source route. Since none of those rows stores real completeness, a choice-selected enumeration, a host dense subset, quotient real equality, or nearest-rational selection, the exported countable dense read cannot claim any of those principles.
\end{proof}
