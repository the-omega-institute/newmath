\begin{theorem}[Real cofinal window transport]
\label{thm:real-cofinal-window-transport}
Suppose two terminal $\RealUp$ seal reads display cofinal $\StreamNameUp$ windows and their $\RegSeqRatUp$ readbacks agree under the $\DyadicRatCoreUp$ tolerance classifier. Then the terminal $\RealUp$ seal exposes the same public name for both reads. The comparison is made through the displayed finite windows, regular rational readbacks, dyadic tolerance rows, componentwise $\hsame$ transport, $\Cont$ replay, $\Pkg$ provenance, and the local $\NameCert_{\RealUp}$ seal row; it introduces no selected limit, quotient representative, host real equality, countable choice, ambient completeness, or bridge row.
\end{theorem}
\begin{proof}
Begin with the two displayed $\StreamNameUp$ windows. Cofinality says that every finite request used by either terminal read is eventually represented in the other visible window schedule, so the comparison remains inside finite stream data.

Read the $\RegSeqRatUp$ rows attached to those windows. Agreement under the $\DyadicRatCoreUp$ tolerance classifier identifies the regular rational readbacks only through displayed dyadic endpoint, radius, and tolerance rows, not through a hidden limit object.

Apply the existing Real hub routes through \autoref{ch:concrete-instances-streamname-namecert}, \autoref{ch:concrete-instances-regseqrat-namecert}, and \autoref{ch:concrete-instances-dyadicratcore-namecert}. These routes force the terminal Real-facing read to pass through the same finite-window, regular-readback, and dyadic-tolerance faces before the seal is exposed.

Finally use the terminal seal surface of \autoref{ch:concrete-instances-real-namecert}. Since the support rows transport and replay the same finite comparison and the local seal row has no coordinate for selected limits, quotient representatives, host real equality, countable choice, ambient completeness, or bridges, the public $\RealUp$ name exposed by the terminal seal is the same for the two cofinal reads.
\end{proof}

\begin{theorem}[Real cofinal window symmetry]
\label{thm:real-cofinal-window-symmetry}
Suppose two terminal $\RealUp$ seal reads display cofinal $\StreamNameUp$ windows and their $\RegSeqRatUp$ readbacks agree under the $\DyadicRatCoreUp$ tolerance classifier. If the first read exposes the public $\RealUp$ name of the second through the displayed finite $\StreamNameUp$, $\RegSeqRatUp$, $\DyadicRatCoreUp$, $\hsame$, $\Cont$, $\Pkg$, and local $\NameCert_{\RealUp}$ rows, then the swapped read exposes the same public $\RealUp$ name through the same rows.

The symmetry statement does not add a selected limit, quotient representative, host real equality, countable-choice schedule, ambient completeness coordinate, or bridge row.
\end{theorem}
\begin{proof}
Swap the two terminal seal reads. Cofinality of the displayed $\StreamNameUp$ windows is symmetric: every finite request visible from either side is still eventually represented in the other side's finite window schedule after the swap.

The $\DyadicRatCoreUp$ tolerance classifier is also read symmetrically on the displayed $\RegSeqRatUp$ readbacks. The comparison still uses the same dyadic endpoint, radius, and tolerance rows, transported by the same componentwise $\hsame$ data and replayed by the same $\Cont$ row.

Apply \autoref{thm:real-cofinal-window-transport} to the swapped pair. Its hypotheses are exactly the cofinal window and classifier-agreement rows just identified, with the $\Pkg$ provenance and local $\NameCert_{\RealUp}$ seal row unchanged.

Thus the swapped terminal read exposes the same public $\RealUp$ name. Since the cited transport theorem has no coordinate for selected limits, quotient representatives, host real equality, countable choice, ambient completeness, or bridge rows, the symmetric route has none.
\end{proof}
