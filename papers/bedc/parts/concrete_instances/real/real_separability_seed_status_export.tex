\begin{theorem}[Real separability seed status export]
\label{thm:real-separability-seed-status-export}
The hub-level $\RealSeparabilityUp$ seed and scoped markers read the rational-density route through $\CauchyEquivalenceSetoidUp$, $\DyadicRatCoreUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\RealUp$, and $\RegularCauchyDenseEmbeddingUp$ rows. \end{theorem}
\begin{proof}
Start with the hub registration \autoref{thm:real-separability-seed-status}. It records the status markers as a child-route read rather than as theorem content stored on the hub.

Read the Cauchy-equivalence and dyadic routes through the existing child files. They expose the $\CauchyEquivalenceSetoidUp$ classifier, $\DyadicRatCoreUp$ tolerance ledger, $\StreamNameUp$ finite windows, and $\RegSeqRatUp$ readback before the terminal $\RealUp$ seal is visible.

Finally use the dense-embedding route. The $\RegularCauchyDenseEmbeddingUp$ handoff exports the rational-density surface from those same rows, so the seed and scoped hub markers have a local readback path and still export no selected dense enumeration, quotient Real equality, countable choice, or ambient $\RealUp$ completeness.
\end{proof}
