\begin{theorem}[Real separability dyadic density induction]
\label{thm:real-separability-dyadic-density-induction}
Every $\RealSeparabilityUp$ rational-density read used by a completion-facing consumer factors through a finite induction on dyadic windows before reaching $\StreamNameUp$, $\RegSeqRatUp$, and $\RealUp$. At each induction stage the consumer reads the displayed dyadic tolerance row, the finite stream window, the regular rational readback, and the terminal real-name seal already carried by the RealSeparability route; it receives no classical countable choice, no selected dense subsequence, no quotient equality of Real names, and no ambient $\RealUp$ completeness theorem.
\end{theorem}
\begin{proof}
Start with \autoref{thm:real-separability-dyadic-density-dependency}. It places every density request behind the dyadic tolerance surface and the finite regular-rational window before the terminal real-name seal can be read.

Use induction over the displayed dyadic window length. The base window is the empty or initial tolerance request already visible in the $\DyadicRatCoreUp$ row, so no density witness can be consumed before the dyadic scale is named.

For the extension step, append one displayed dyadic refinement window and replay the existing RegSeqRat and StreamName dependencies. The dependency route keeps the new rational candidate inside the same finite window ledger rather than selecting a point from an ambient dense subset.

Finally compose with \autoref{thm:real-separability-regseqrat-dependency} and \autoref{thm:real-separability-dyadic-lattice-forward-route}. These routes pass the finite dyadic-window induction through $\StreamNameUp$, $\RegSeqRatUp$, and the terminal $\RealUp$ seal, while excluding countable choice, selected dense subsequences, quotient Real equality, and ambient completeness.
\end{proof}
