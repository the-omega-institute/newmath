\chapter{A Concrete Naming Certificate for $\ObservableOpenFilterUp$}
\label{ch:concrete-instances-observable-open-filter-namecert}
\origin{human}

Following Sierpinski, Kelley, and Bourbaki on observable opens and filters, the $\ObservableOpenFilterUp$ packet records the open-membership data needed by compact-uniform-continuity cover reads as a finite NameCert surface. It consumes the Sierpinski classifier of \autoref{ch:concrete-instances-sierpinski-space-namecert}, the topology source row of \autoref{ch:concrete-instances-topology-namecert}, the finite StreamName windows of \autoref{ch:concrete-instances-streamname-namecert}, and the uniform-modulus consumer boundary of \autoref{ch:concrete-instances-uniformmodulus-namecert}. The packet keeps open membership as displayed observable truth rather than as a host proposition.

\begin{definition}[Observable open-filter carrier]
\label{def:observable-open-filter-carrier}
An $\ObservableOpenFilterUp$ carrier is a finite $\BHist$ packet
$$
F=(S,T,O,W,U,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $S$ is the $\SierpinskiSpaceUp$ classifier row, exposing observable truth marks for open-membership reads.
\item $T$ is the $\TopologyUp$ source row whose indexed opens are filtered by the packet.
\item $O$ is the observable-open filter row. It records the directed finite family of open-index requests, refinement witnesses, and compatibility with the Sierpinski truth row.
\item $W$ is the $\StreamNameUp$ finite window row, listing the observed open-membership requests available to compact cover readers.
\item $U$ is the $\UniformModulusUp$ cover-read handoff row, recording the tolerance-facing consumer that reads the finite open filter before it consumes a compact-uniform modulus route.
\item $H$ stores componentwise $\hsame$ transport for the Sierpinski classifier, topology source, observable-open filter, finite windows, uniform-modulus handoff, replay, provenance, and local naming rows.
\item $C$ stores displayed $\Cont$ replay from an open-filter request through $S,T,O,W,U,H$.
\item $P$ is the $\Pkg$ provenance over $\ObservableOpenFilterUp$, $\SierpinskiSpaceUp$, $\TopologyUp$, $\StreamNameUp$, $\UniformModulusUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$ rows.
\item $N$ is the local $\NameCert_{\ObservableOpenFilterUp}$ row.
\end{enumerate}
The carrier has no coordinate for host open-membership propositions, excluded middle, selected neighbourhood filters, arbitrary powerset opens, quotient open equality, countable-choice schedules, or bridge credentials.
\end{definition}

\begin{theorem}[Observable open-filter NameCert obligations]
\label{thm:observable-open-filter-namecert-obligations}
For every accepted $\ObservableOpenFilterUp$ carrier $F=(S,T,O,W,U,H,C,P,N)$, the local $\NameCert_{\ObservableOpenFilterUp}$ surface consists exactly of Sierpinski classifier admission, Topology source admission, observable-open filter display, StreamName finite windows, UniformModulus cover-read handoff, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming. Every compact-uniform cover consumer must read $S,T,O,W,U$ before it consumes $H,C,P,N$.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:observable-open-filter-carrier}. Rows $S$ and $T$ supply the only observable-open classifier and topology source visible to the packet.

The filter data are finite and displayed. Row $O$ names the directed open-index requests and refinement witnesses, while $W$ records the finite StreamName windows through which compact cover readers observe those requests.

The uniform-modulus handoff $U$ is downstream of those observable-open rows. The structural rows $H,C,P,N$ then transport, replay, source, and name the same packet. Since no field stores host propositions, selected neighbourhood filters, powerset opens, quotient open equality, countable choice, or a bridge credential, the listed rows exhaust the local NameCert obligations.
\end{proof}

\begin{theorem}[Observable open-filter Sierpinski handoff]
\label{thm:observable-open-filter-sierpinski-handoff}
Every open-membership read exported by an accepted $\ObservableOpenFilterUp$ packet factors through the displayed route
$$
\SierpinskiSpaceUp \longrightarrow \TopologyUp \longrightarrow \StreamNameUp \longrightarrow \UniformModulusUp .
$$
Thus compact-uniform cover reads receive observable Sierpinski classifier data and finite open windows, not host propositions or selected neighbourhood filters.
\end{theorem}
\begin{proof}
Read the accepted packet $F=(S,T,O,W,U,H,C,P,N)$. The Sierpinski row $S$ classifies each open-membership request before the topology row $T$ is consumed, so the route begins with observable truth data.

The filter row $O$ and finite window row $W$ then display which open-index requests are available to a cover reader. The handoff row $U$ records the uniform-modulus consumer only after those finite observable-open rows have been inspected.

Transport, replay, provenance, and naming through $H,C,P,N$ preserve this dependency order. Therefore no compact-uniform cover read can bypass the Sierpinski classifier by importing host propositions, selected neighbourhood filters, powerset opens, quotient open equality, countable choice, or a bridge credential.
\end{proof}

\begin{theorem}[Observable open-filter rounded Cauchy consumption]
\label{thm:observable-open-filter-rounded-cauchy-consumption}
Any completion-facing consumer that reads an accepted $\ObservableOpenFilterUp$ packet before a $\RoundedCauchyFilterUp$ or $\CauchyFilterCompletionUp$ route must expose the $\SierpinskiSpaceUp$, $\TopologyUp$, $\StreamNameUp$, and $\UniformModulusUp$ rows first. The handoff into the rounded filter base is allowed only through the displayed open-membership windows of that packet. It cannot import host open predicates, selected neighbourhood filters, quotient filter equality, countable choice, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Project the carrier in \autoref{def:observable-open-filter-carrier}. The only rows available before the structural transport, replay, provenance, and local naming coordinates are the Sierpinski classifier $S$, topology source $T$, observable-open filter row $O$, StreamName windows $W$, and UniformModulus handoff $U$.

Apply \autoref{thm:observable-open-filter-namecert-obligations}. It forces every compact-uniform cover consumer to read $S,T,O,W,U$ before it can consume $H,C,P,N$. Apply \autoref{thm:observable-open-filter-sierpinski-handoff} to identify the observable route as the displayed Sierpinski-to-uniform-modulus chain.

The downstream completion route is the rounded Cauchy filter packet of \autoref{ch:concrete-instances-rounded-cauchy-filter-namecert}. By \autoref{thm:rounded-cauchy-filter-regular-sequence-handoff}, its completion-facing read consumes only the displayed rounded-base, stream-window, regular-readback, dyadic-ledger, completion-handoff, and real-seal rows. Therefore an $\ObservableOpenFilterUp$ consumer can feed that route only through displayed open-membership windows, not through host open predicates, selected neighbourhood filters, quotient filter equality, countable choice, or ambient $\RealUp$ completeness.
\end{proof}
