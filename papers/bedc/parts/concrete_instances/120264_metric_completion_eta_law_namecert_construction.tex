\begin{theorem}[Metric completion eta-law NameCert obligations]
\label{thm:metric-completion-eta-law-namecert-obligations}

\end{theorem}
\begin{proof}

Next read the comparison and endpoint rows $S,R,Q$. Separation is supplied by $S$, finite regular-rational agreement by $R$, and terminal real-name exposure by $Q$; none of these rows contains quotient equality or a selected representative.

\label{thm:metric-completion-eta-law-unit-handoff}

Read the separated comparison row $S$ and regular-rational row $R$. These rows keep the direct endpoint and the unit-applied endpoint inside the same finite comparison surface before the seal $Q$ can be consumed.
