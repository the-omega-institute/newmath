\begin{definition}[Doob-Meyer decomposition carrier]
\label{def:doob-meyer-decomposition-carrier}
A $\DoobMeyerDecompositionUp$ carrier is a finite $\BHist$ packet
$$
D=(S,M,A,E,O,U,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $S$ is the accepted $\SubmartingaleUp$ source row whose finite one-sided conditional-expectation comparisons are to be split.
\item $M$ is the $\MartingaleUp$ row carrying the equality-direction adapted sequence read from the same displayed finite window.
\item $A$ is the compensator ledger, a finite increasing row whose successor gaps record the displayed difference between the $\SubmartingaleUp$ inequality and the $\MartingaleUp$ equality row.
\item $E$ is the family of $\CondExpUp$ faces that reads the successor endpoint before the compensator step row is exposed.
\item $O$ is the bounded $\OptionalStoppingUp$ window used to compare stopped reads of $S$, $M$, and $A$.
\item $U$ is the $\UpcrossingUp$ ledger that keeps the same finite lower-to-upper crossing window visible to decomposition consumers.
\item $H$ records componentwise $\hsame$ transport for the submartingale, martingale, conditional-expectation, stopped-window, upcrossing, and compensator rows.
\item $C$ records displayed $\Cont$ replay from a decomposition request through $S,M,A,E,O,U$.
\item $P$ is the $\Pkg$ provenance over $\SubmartingaleUp$, $\MartingaleUp$, $\CondExpUp$, $\OptionalStoppingUp$, $\UpcrossingUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\DoobMeyerDecompositionUp}$ row.
\end{enumerate}
The carrier compares accepted packets only through these ten rows. It has no coordinate for measure completion, optional projection, a predictable host $\sigma$-algebra, selected almost-sure versions, quotient equality of stochastic processes, or an external decomposition theorem.
\end{definition}

\begin{theorem}[Doob-Meyer decomposition NameCert obligations]
\label{thm:doob-meyer-decomposition-namecert-obligations}

$$
\SubmartingaleUp,\ \MartingaleUp,\ \CondExpUp,\ \OptionalStoppingUp,\ \UpcrossingUp,\ \BHist,\ \hsame,\ \Cont,\ \Pkg,\ \NameCert

\end{theorem}
\begin{proof}
Project the accepted carrier of \autoref{def:doob-meyer-decomposition-carrier}. The analytic rows are $S,M,A,E,O,U$, and the structural rows are $H,C,P,N$.

The source row $S$ supplies the one-sided $\SubmartingaleUp$ inequality, while $M$ supplies the equality-direction $\MartingaleUp$ read on the same finite window. The conditional-expectation faces $E$ expose the successor comparisons before any compensator step row in $A$ can be inspected.

The bounded stopping and upcrossing rows $O,U$ keep the finite window stable for downstream consumers. Transport, replay, provenance, and local naming preserve the same route, so no consumer can bypass the displayed packet to obtain a host optional projection or a completed ambient decomposition theorem.
\end{proof}

\begin{theorem}[Doob-Meyer compensator handoff]
\label{thm:doob-meyer-decomposition-compensator-handoff}

$$

$$
The row $A$ is visible only as the finite ledger that records the gap between the $\SubmartingaleUp$ source comparisons and the $\MartingaleUp$ equality-direction row. A downstream martingale or upcrossing consumer receives that ledger together with the bounded $\OptionalStoppingUp$ and $\UpcrossingUp$ windows; it does not receive a host predictable projection, measure completion, selected almost-sure version, quotient process equality, or external compensator existence proof.
\end{theorem}
\begin{proof}

The compensator row is therefore not an independent host process. It is read only after the $\CondExpUp$ faces expose the one-step gap between the source $\SubmartingaleUp$ inequality and the $\MartingaleUp$ equality row.

\end{proof}
