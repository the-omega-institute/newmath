\begin{definition}[Omega generation body carrier]
\label{def:omega-generation-body-carrier}

$$

$$
with the following displayed rows:
\begin{enumerate}
\item $D$ is the licensed diagram body row. It records the finite coordinate list for the $\Omega$ generation diagram, the accepted object interfaces, and the readback arrows between coordinate rows.
\item $L$ is the legal stream display row, read through $\StreamNameUp$, exposing the public stream window used to display a body without replacing the body by a raw code string.
\item $K$ is the code/readback row. It records a faithful readable code morphism together with the displayed decode witness that returns each public stream row to the body row it names.
\item $J$ is the pairing involution row. It records the licensed endomorphism on each layer that claims paired behavior, its double-application classifier law, and the fixed-row or apart-pair branch.
\item $O$ is the generation-order row. It records the finite forward route generated by displayed history extension and continuation rows before any body read may be consumed.
\item $H$ records componentwise $\hsame$ transport for $D,L,K,J,O$ and the structural rows.
\item $C$ records displayed $\Cont$ replay for every consumer route through the diagram body, stream display, code/readback, pairing, and generation-order rows.
\item $P$ is the $\Pkg$ provenance over $\OmegaGenerationBodyUp$, the licensed interface rows of \autoref{ch:visions-omega-generation-structure-interface}, $\StreamNameUp$, $\ProdUp$, $\NameCertUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\OmegaGenerationBodyUp}$ row.

\begin{theorem}[Omega generation body display NameCert obligations]
\label{thm:omega-generation-body-display-namecert-obligations}
For every accepted $\OmegaGenerationBodyUp$ carrier
$$
G=(D,L,K,J,O,H,C,P,N),
$$
every body read consumed through the local $\NameCert_{\OmegaGenerationBodyUp}$ must first expose the licensed diagram body row $D$, the legal stream display row $L$, the code/readback row $K$, the pairing involution row $J$, the generation-order route $O$, componentwise $\hsame$ transport $H$, displayed $\Cont$ replay $C$, $\Pkg$ provenance $P$, and the local naming row $N$. Thus the body interface is consumed only as the finite row sequence
$$
D,L,K,J,O \longmapsto H,C,P,N,
$$
with no hidden body coordinate outside the accepted carrier.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:omega-generation-body-carrier}. The rows $D,L,K,J,O$ are the only interface-facing data: $D$ supplies the licensed generation diagram body, $L$ supplies the public stream display, $K$ supplies faithful readable code and decode witnesses, $J$ supplies typed pairing by involution, and $O$ supplies the finite generation-order route.

The display cannot be read as a raw external encoding. The stream row is licensed through $\StreamNameUp$, the code/readback row carries its own decode witness, and the product-shaped body data remains tied to the coordinate rows named by \autoref{ch:concrete-instances-prod-namecert}.

The pairing and order rows remain separate. The row $J$ authorizes paired behavior only where a licensed involution is present, while $O$ records the forward generation route through history extension and continuation replay. Neither row supplies a global inverse time map or an untyped pairing principle.

Finally replay $H,C,P,N$. Componentwise transport, displayed continuation replay, provenance, and local naming preserve exactly the same finite route. Since the carrier contains no unlicensed tower coordinate, raw code row, unsupported pairing, quotient body equality, choice schedule, or ambient completion row, every body read must expose the listed NameCert rows before it can be consumed.
\end{proof}
