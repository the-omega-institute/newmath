\begin{definition}[Riemann removable-discontinuity carrier]
\label{def:riemann-removable-discontinuity-carrier}
A $\RiemannRemovableDiscontinuityUp$ carrier is a finite $\BHist$ packet
$$
M=(D,F,A,W,R,E,J,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $D$ is the finite defect row, naming the single point or finite displayed defect window at which the source function is not read through the ordinary continuous-map route.
\item $F$ is the $\ContinuousMapUp$ off-defect row, exposing the continuous-map evidence on the displayed punctured window or finite complement route.
\item $A$ is the approach ledger, recording the visible two-sided or one-sided approximation windows by which the repaired value is compared with nearby off-defect reads.
\item $W$ is the $\StreamNameUp$ finite-window row, listing exactly the samples, punctured-neighbourhood observations, and requested precisions inspected before the repaired value is sealed.
\item $R$ is the $\RegSeqRatUp$ readback row attached to those windows, so every numeric comparison has a regular rational source before the terminal real-name seal is read.
\item $E$ is the $\RealUp$ seal row for the displayed replacement value and the repaired function values visible to downstream consumers.
\item $J$ is the integration and completion handoff row, allowing $\RiemannIntegrableUp$ and $\RiemannIntegrationCompletionUp$ consumers to read the repaired packet only after $D,F,A,W,R,E$ have been displayed.
\item $H$ records componentwise $\hsame$ transport for the defect, off-defect continuity, approach ledger, finite windows, regular readback, Real seal, handoff, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a repair request through $D,F,A,W,R,E,J,H,P,N$.
\item $P$ is the $\Pkg$ provenance over $\RiemannRemovableDiscontinuityUp$, $\ContinuousMapUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\RealUp$, $\RiemannIntegrableUp$, $\RiemannIntegrationCompletionUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\RiemannRemovableDiscontinuityUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $D,F,A,W,R,E,J,H,C,P,N$. It has no coordinate for ambient $\RealUp$ completeness, selected limits, quotient function equality, real trichotomy, countable choice, a host integration functional, or a full Riemann integration theorem.
\end{definition}

\begin{theorem}[Riemann removable-discontinuity NameCert obligations]
\label{thm:riemann-removable-discontinuity-namecert-obligations}
For every accepted $\RiemannRemovableDiscontinuityUp$ carrier
$$
M=(D,F,A,W,R,E,J,H,C,P,N),
$$
the local $\NameCert_{\RiemannRemovableDiscontinuityUp}$ surface consists exactly of carrier admission for the displayed defect row, off-defect continuous-map row, approach ledger, finite StreamName windows, RegSeqRat readback, terminal Real seal, integration and completion handoff, componentwise transport, displayed replay, provenance, and local naming rows.

The obligation surface requires the defect to be named before the off-defect continuity row is consumed, the approach ledger to expose only finite comparison windows, the $\StreamNameUp$ and $\RegSeqRatUp$ rows to precede any terminal $\RealUp$ seal, and the handoff row $J$ to export only the repaired finite route to $\RiemannIntegrableUp$ or $\RiemannIntegrationCompletionUp$ consumers.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:riemann-removable-discontinuity-carrier}. The analytic rows are $D,F,A,W,R,E,J$, and the structural rows are $H,C,P,N$.

The defect row $D$ fixes the only place where the ordinary continuous-map route is not read directly. The off-defect row $F$ supplies the continuous-map evidence away from that displayed window, while the approach ledger $A$ records the finite comparisons used to justify the replacement value.

The numeric readback is $W,R,E$. The stream row $W$ lists the inspected windows, the regular rational row $R$ supplies the readback for those windows, and the Real row $E$ seals the displayed replacement value only after those rows are present.

Finally $J,H,C,P,N$ preserve the same finite route for integration and completion consumers. Since no excluded principle is a carrier coordinate, none is a local NameCert obligation of the packet.
\end{proof}

\begin{theorem}[Riemann removable-discontinuity completion handoff]
\label{thm:riemann-removable-discontinuity-completion-handoff}
Every $\RiemannIntegrableUp$ or $\RiemannIntegrationCompletionUp$ consumer of an accepted $\RiemannRemovableDiscontinuityUp$ carrier must first read the finite route
$$
D,F,A \longmapsto W,R,E \longmapsto J \longmapsto H,C,P,N.

It receives no ambient $\RealUp$ completeness theorem, no selected limiting value, no quotient equality of functions, no real trichotomy, no countable-choice schedule, and no full integration theorem.
\end{theorem}
\begin{proof}
Use \autoref{thm:riemann-removable-discontinuity-namecert-obligations}. It places the defect row, off-defect continuity row, and approach ledger before any consumer-facing handoff.

The completion-facing readback is forced through $W,R,E$. Thus a requested repaired value is seen through finite StreamName observations and RegSeqRat data before the Real seal is public.

The handoff row $J$ can then be read by $\RiemannIntegrableUp$ or $\RiemannIntegrationCompletionUp$ consumers, but only as a boundary row attached to the already displayed repair packet. It does not supply a separate proof of integrability, a Cauchy-sum convergence theorem, or a host integral.

The rows $H,C,P,N$ transport, replay, source, and name the same packet. Since the carrier contains no coordinate for the excluded principles, the completion handoff cannot export them.
\end{proof}
