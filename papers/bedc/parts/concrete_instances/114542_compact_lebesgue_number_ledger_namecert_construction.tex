\begin{theorem}[Compact finite-cover radius fold]
\label{thm:compact-lebesgue-number-ledger-finite-radius-fold}
Every accepted $\CompactLebesgueNumberLedgerUp$ packet turns compact finite-cover data into a tolerance-facing $\UniformModulusUp$ row by reading the finite route
$$
\CompactMetricUp \longmapsto \ContinuousMapUp \longmapsto \MetricUp \longmapsto \DyadicRatCoreUp,\RegSeqRatUp,\RealUp \longmapsto \UniformModulusUp .
$$
The finite minimum fold uses only the displayed cover row $K$, pointwise radius row $F$, metric ledger $M$, cover-refinement row $C$, radius family $R$, dyadic ledger $D$, and numerical seal row $Q$ before exporting the handoff $U$.
\end{theorem}
\begin{proof}
Project an accepted carrier $L=(K,F,M,C,R,D,Q,U,H,T,P,N)$. The compact source and finite cover data are exactly $K$, while pointwise local radii are supplied by $F$.

The cover-refinement and metric rows bind those local radii to the same compact source. The row $C$ records which displayed cover member protects each inspected witness, and $M$ records the triangle and distance comparisons consumed by the fold.

The positive-radius family and dyadic ledger then perform the finite minimum step. The rows $R,D$ expose positivity, halving, and lower-bound comparisons, and $Q$ seals only the numerical reads already present in those rows.

Finally $U,H,T,P,N$ export, transport, replay, source, and name the tolerance-only uniform-modulus handoff. No excluded compactness, selected subcover, hidden radius choice, quotient real equality, or host map equality has a carrier coordinate.
\end{proof}

\begin{proof}
