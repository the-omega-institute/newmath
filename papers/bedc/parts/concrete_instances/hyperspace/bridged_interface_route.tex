\begin{theorem}[Hyperspace bridged interface route]
\label{thm:hyperspace-bridged-interface-route}
The public $\HyperspaceUp$ certificate of \autoref{thm:hyperspace-public-certificate} is bridged by the displayed compact-metric finite-net rows, Hausdorff metric rows, Vietoris handoff rows, and completion-facing dependency routes already present in the hyperspace packet. More precisely, every bridged reader must pass through the compact-source route of \autoref{ch:concrete-instances-compactmetric-namecert}, the Hausdorff comparison route of \autoref{ch:concrete-instances-hausdorff-metric-namecert}, the Vietoris handoff of \autoref{thm:hyperspace-vietoris-handoff}, the scoped lattice of \autoref{thm:hyperspace-scoped-closure-route}, and the completion-facing handoff of \autoref{thm:hyperspace-root-complete-totallybounded-handoff} before consuming the public interface. The bridge exports no host powerset, quotient compactum, selected limit, open-cover compactness proof, selected nearest point, or ambient complete-hyperspace object.
\end{theorem}
\begin{proof}
Start with the public certificate route. It exposes only the compact-metric source rows, finite compact-subset schedules, directed Hausdorff ledgers, Vietoris handoff rows, structural transport, replay, provenance, and local naming rows.

The compact-metric and Hausdorff rows are then read through the sibling dependency files and the scoped closure route. These force finite-net schedules, bidirectional Hausdorff windows, and metric witnesses to remain visible before any public hyperspace reader can inspect compact-subset data.

For topology and completion-facing consumers, apply the Vietoris handoff and the root complete--totally-bounded handoff. Both routes reuse the same displayed compact source, finite net rows, directed Hausdorff ledgers, completion boundary, transport, replay, provenance, and naming rows. Hence the public certificate has a bridged interface using only the rows already present in the chapter.
\end{proof}
