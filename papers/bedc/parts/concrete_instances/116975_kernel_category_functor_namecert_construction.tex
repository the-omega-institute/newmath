\label{def:kernel-category-functor-carrier}

$$
F=(S,T,O,M,I,Q,H,C,P,N)

\begin{enumerate}

\item $T$ is the target $\KernelCategoryUp$ row with the same displayed row discipline.
\item $O$ is the object-row transport ledger, assigning each visible source object row to a visible target object row.
\item $M$ is the morphism-row transport ledger, assigning each visible source continuation-ledger hom row to a visible target continuation-ledger hom row.

\item $H$ records componentwise $\hsame$ transport for the source, target, object transport, morphism transport, identity, composition, replay, provenance, and local naming rows.

\item $N$ is the local $\NameCert_{\KernelCategoryFunctorUp}$ row.

The classifier compares accepted packets only through $S,T,O,M,I,Q,H,C,P,N$. It has no coordinate for host function equality, quotient morphism equality, external category objects, semantic functor laws outside the displayed rows, or imported category-library data.

\begin{theorem}[KernelCategoryFunctor transport obligations]
\label{thm:kernel-category-functor-transport-obligations}
For every accepted $\KernelCategoryFunctorUp$ carrier $F=(S,T,O,M,I,Q,H,C,P,N)$, the local $\NameCert_{\KernelCategoryFunctorUp}$ surface consists exactly of carrier admission, source kernel-category exposure, target kernel-category exposure, object-row transport, morphism-row transport, identity preservation, composition preservation, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming.
\end{theorem}
\begin{proof}
Project the carrier rows. The source and target packets are the only category-shaped inputs, and the object and morphism transport ledgers are exactly $O$ and $M$.

Identity preservation is read from $I$. Since source identities are empty continuation rows and target identities are empty continuation rows, the preservation claim is a displayed row comparison rather than a host identity-function assertion.

Composition preservation is read from $Q$. Each preserved composite cites the source composite row, the two transported morphism rows, and the target composite row before any functor-facing consumer can use the transported hom.

Rows $H,C,P,N$ then transport, replay, source, and name the same packet. Because the carrier contains no host function equality, quotient morphism equality, external category object, or imported category-library coordinate, the listed rows exhaust the finite certificate surface.
\end{proof}

\end{theorem}
\begin{proof}

Use \autoref{thm:kernel-category-functor-transport-obligations}. It places identity and composition preservation on the displayed rows $I$ and $Q$, downstream of the source and target kernel-category packets.

The continuation handoff is then $C$ together with provenance and naming through $P,N$. Componentwise transport through $H$ preserves the same finite route.

Thus a $\FunctorUp$ consumer receives functorial transport only as a finite BEDC packet over $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$, with no additional host categorical coordinate.
