\begin{theorem}[Crandall--Liggett semigroup NameCert obligations]
\label{thm:crandall-liggett-semigroup-namecert-obligations}

No obligation may replace those rows by a host semigroup, selected limit curve, quotient trajectory equality, unlogged domain closure, countable-choice schedule, or external PDE/ODE well-posedness theorem.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:crandall-liggett-semigroup-carrier}. The analytic rows are $X,M,A,R,E,S,Q,T$: complete-metric and metric state data, operator graph data, admissible rational step sizes, resolvent reads, finite Euler products, stream windows, regular rational readback, and the terminal real seal.

Read the resolvent data before the Euler product. The row $R$ supplies only displayed resolvent graph windows for the step sizes in $A$, and the row $E$ records finite products of those displayed rows. Thus the packet does not introduce a host inverse operator or a selected infinite product.

The ODE/PDE-facing read is downstream of the finite windows. The $\StreamNameUp$ row $S$ fixes inspected times and state probes, the $\RegSeqRatUp$ row $Q$ records the rational readback, and the $\RealUp$ row $T$ seals only the displayed read.

Finally $H,C,P,N$ transport, replay, source, and name the same finite route. Since the carrier has no coordinate for a host semigroup, selected trajectory, quotient curve equality, unlogged domain completion, choice schedule, or ambient completeness, the listed rows exhaust the local NameCert obligations.
\end{proof}
