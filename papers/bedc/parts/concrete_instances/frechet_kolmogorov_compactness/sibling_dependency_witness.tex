\begin{theorem}[Frechet--Kolmogorov sibling dependency witness]
\label{thm:frechet-kolmogorov-sibling-dependency-witness}
Every accepted $\FrechetKolmogorovCompactnessUp$ carrier witnesses a substantive dependency on the compact metric, total-bounded, and Arzela--Ascoli finite-modulus sibling chapters. The compactness criterion may be consumed only after the compact source of \autoref{ch:concrete-instances-compactmetric-namecert}, the finite-net surface of \autoref{ch:concrete-instances-totallybounded-namecert}, and the Arzela--Ascoli finite-modulus route of \autoref{ch:concrete-instances-arzela-ascoli-finite-modulus-namecert} have all been displayed together with the local carrier rows of \autoref{def:frechet-kolmogorov-compactness-carrier}.
\end{theorem}
\begin{proof}
Read the compact source first. The row $M$ in \autoref{def:frechet-kolmogorov-compactness-carrier} is a $\CompactMetricUp$ source row, so the criterion has no compactness-facing read until the displayed compact metric packet is available.

Read the total-bounded surface next. The row $T$ supplies the finite-net budget consumed by the criterion, and the theorem \autoref{thm:frechet-kolmogorov-compactness-total-bounded-handoff} forces that budget to pass through the same compact metric source before any readback rows are inspected.

Read the Arzela--Ascoli finite-modulus route as the equicontinuity-facing control. The sibling route of \autoref{thm:frechet-kolmogorov-compactness-sibling-route} binds the Arzela--Ascoli finite-modulus chapter to the same finite compactness route, so the equicontinuity row cannot be replaced by an ambient function-space compactness theorem.

Finally the local transport, replay, provenance, and naming rows $H,A,P,N$ keep those sibling dependencies on the same packet. Thus the Frechet--Kolmogorov chapter records a dependency lattice over compact metric, total boundedness, and Arzela--Ascoli finite modulus rather than a kernel-only compactness assertion.
\end{proof}

\begin{theorem}[Frechet--Kolmogorov orphan compact metric lattice]
\label{thm:frechet-kolmogorov-orphan-compact-metric-lattice}
The compactness-facing export of an accepted $\FrechetKolmogorovCompactnessUp$ packet is not a kernel-only assertion. Before it exposes the local compactness criterion, the consumer must read the $\CompactMetricUp$ source row, the $\TotallyBoundedUp$ finite-net row, the $\UniformEquicontinuityModulusUp$ control row, the Arzela--Ascoli finite-modulus route, the $\RegSeqRatUp$ readback row, and the terminal $\RealUp$ seal row as sibling dependencies of the same carrier.
\end{theorem}
\begin{proof}
Start with the dependency witness of \autoref{thm:frechet-kolmogorov-sibling-dependency-witness}. It already forces the compact metric, total-bounded, and Arzela--Ascoli finite-modulus rows to be displayed with the local carrier rows.

Now read the sibling route of \autoref{thm:frechet-kolmogorov-compactness-sibling-route}. That route places the uniform-equicontinuity, $\RegSeqRatUp$, and $\RealUp$ rows in the same finite lattice rather than letting the criterion stand as an isolated kernel compactness claim.

Finally apply the total-bounded handoff of \autoref{thm:frechet-kolmogorov-compactness-total-bounded-handoff}. The finite-net budget must pass through the compact metric source before readback rows are inspected, so the local compactness criterion is exposed only after the compact-metric dependency lattice is visible.
\end{proof}
