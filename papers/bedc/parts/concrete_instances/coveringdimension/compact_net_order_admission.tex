\begin{definition}[CoveringDimension compact net order carrier]
\label{def:coveringdimension-compact-net-order-carrier}
For an accepted $\CoveringDimensionUp$ packet, the compact-net order carrier is
the finite subpacket
$$
O_{\mathrm{net}}=(K,M,E,U,R,Q,S,A,H,T,P,N)
$$
where $K$ is the $\CompactMetricUp$ source row, $M$ is the $\MetricUp$
distance-read ledger, $E$ is the finite compact-net cover support, $U$ is the
uniform radius table, $R$ is the $\RegSeqRatUp$ comparison row, $Q$ is the
terminal $\RealUp$ seal row, $S$ is the finite nerve row, and $A$ is the order
table counting displayed overlap rows. The structural rows $H,T,P,N$ are the
componentwise $\hsame$ transport, $\Cont$ replay, $\Pkg$ provenance, and local
NameCert rows.

The carrier has no coordinate for arbitrary open-cover compactness, ambient
dimension theory, choice-selected subcovers, or host topological refinement.
\end{definition}

\begin{theorem}[CoveringDimension compact net order admission]
\label{thm:coveringdimension-compact-net-order-admission}
Every compact-net order read admitted by
$O_{\mathrm{net}}=(K,M,E,U,R,Q,S,A,H,T,P,N)$ must be generated from the
displayed $\CompactMetricUp$ row $K$, the $\MetricUp$ distance ledger $M$, the
finite net support $E$, and the uniform radius table $U$. The exported order
count is then replayed through $R,Q,S,A,H,T,P,N$ and cannot be replaced by an
arbitrary compactness theorem or a choice-selected refinement.
\end{theorem}
\leanchecked{BEDC.Derived.CoveringdimensionUp.CoveringDimensionCompactNetOrderAdmission}
\begin{proof}
Project the read to the compact metric row $K$ and the metric ledger $M$. These
rows are the only sources from which distances and bounded cover tests can be
read.

Next consume the finite net support $E$ and uniform radius table $U$. The
regular rational and Real seal rows $R,Q$ compare the displayed radii and
distances without selecting a new cover.

Finally replay nerve incidence through $S$ and consult the order table $A$.
The transport, replay, provenance, and naming rows $H,T,P,N$ preserve that same
finite route, so the admitted order count remains compact-net data.
\end{proof}

\begin{theorem}[CoveringDimension RealSeparability cover pullback]
\label{thm:coveringdimension-real-separability-cover-pullback}
Any $\RealSeparabilityUp$ cover pullback used by the compact-net order carrier
must pass through the $\RegSeqRatUp$ comparison row $R$ and the $\RealUp$ source
seal row $Q$ before it reads the finite net support $E$, the uniform radius
table $U$, the nerve row $S$, and the order table $A$. The pullback therefore
records a displayed cover schedule, not a countable-choice enumeration,
quotient stream equality, or ambient separability theorem.
\end{theorem}
\leanchecked{BEDC.Derived.CoveringdimensionUp.CoveringDimensionRealSeparabilityCoverPullback}
\begin{proof}
Begin with the Real-facing comparison rows $R,Q$. They provide only regular
rational comparisons and terminal Real seal checks for the finite cover tests.

The cover itself is then pulled back to the compact-net rows $E,U$ over the
compact metric and metric ledgers $K,M$. This pins each cover member to a
displayed radius and a displayed source row.

Use the nerve and order rows $S,A$ to replay the overlap count. Since the
carrier lacks coordinates for countable choice, quotient stream equality, and
ambient separability, the RealSeparability consumer receives only the finite
cover schedule carried by $O_{\mathrm{net}}$.
\end{proof}

\begin{theorem}[CoveringDimension compact net order scope]
\label{thm:covering-dimension-compact-net-order-scope}
For an accepted compact-net order carrier
$$
O_{\mathrm{net}}=(K,M,E,U,R,Q,S,A,H,T,P,N),
$$
any order count read from $O_{\mathrm{net}}$ is scoped by the displayed $\CompactMetricUp$ row $K$, the $\MetricUp$ distance ledger $M$, the finite net support $E$, the uniform radius table $U$, the $\RegSeqRatUp$ comparison row $R$, the terminal $\RealUp$ seal $Q$, the finite nerve row $S$, and the order table $A$. The structural rows $H,T,P,N$ may transport, replay, source, and name that finite route, but they do not promote the count to arbitrary open-cover dimension theory.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:coveringdimension-compact-net-order-carrier}. The compact metric, metric, finite-net, uniform-radius, regular rational, Real, nerve, and order rows are all displayed entries of $O_{\mathrm{net}}$.

Apply \autoref{thm:coveringdimension-compact-net-order-admission}. It forces the order read to be generated from $K,M,E,U$ before the replay rows $R,Q,S,A,H,T,P,N$ expose the count.

Finally use \autoref{thm:coveringdimension-real-separability-cover-pullback}. The Real-facing comparison remains on the finite route through $R,Q,E,U,S,A$, so the carrier supplies a compact-net order count rather than an ambient open-cover dimension theorem.
\end{proof}
