\label{thm:coveringdimension-finite-cover-carrier-obligation}

In particular, the consumer must first see the compact finite-net row, the metric distance ledger, the finite $\BHist$ cover row, the refinement membership row, and the local $\NameCert$ row carried by the existing compactmetric route.
\end{theorem}
\begin{proof}

These place the compact metric source, finite-net row, metric distance ledger, finite cover row, refinement row, and order ledger in the displayed carrier before any dimension-facing consumer reads a bound.

The structural rows then preserve the same route. Componentwise $\hsame$ transport keeps the compact and metric witnesses attached to the finite cover rows, displayed $\Cont$ replay fixes the order of the read, and the local $\NameCert$ row names only that finite surface.
\end{proof}
