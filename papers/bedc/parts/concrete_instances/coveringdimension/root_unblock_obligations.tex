\begin{theorem}[CoveringDimension finite cover carrier obligation]
\label{thm:coveringdimension-finite-cover-carrier-obligation}
Every root $\CoveringDimensionUp$ carrier exposes finite cover rows over the displayed $\CompactMetricUp$ and $\MetricUp$ witnesses before any dimension read may inspect an order or refinement conclusion. In particular, the consumer must first see the compact finite-net row, the metric distance ledger, the finite $\BHist$ cover row, the refinement membership row, and the local $\NameCert$ row carried by the existing compactmetric route.
\end{theorem}
\begin{proof}
Read the hub route through \autoref{thm:coveringdimension-finite-cover-admission} and \autoref{thm:coveringdimension-compact-net-dependency-route}. These place the compact metric source, finite-net row, metric distance ledger, finite cover row, refinement row, and order ledger in the displayed carrier before any dimension-facing consumer reads a bound.

The structural rows then preserve the same route. Componentwise $\hsame$ transport keeps the compact and metric witnesses attached to the finite cover rows, displayed $\Cont$ replay fixes the order of the read, and the local $\NameCert$ row names only that finite surface.
\end{proof}

\begin{theorem}[CoveringDimension Real separability scale obligation]
\label{thm:coveringdimension-real-separability-scale-obligation}
Every scale-refinement read in a $\CoveringDimensionUp$ packet that touches Real-facing data must pass through the displayed $\RealSeparabilityUp$, $\RegSeqRatUp$, and $\DyadicRatCoreUp$ tolerance rows before the finite cover order is consumed. The scale row may refine cover radii and rational dense windows, but it may not replace the finite cover carrier by a host separability theorem or an ambient Real completeness principle.
\end{theorem}
\begin{proof}
Use the Real-separability route of \autoref{thm:coveringdimension-real-separability-refinement-bound} together with the metric-completion cover route of \autoref{thm:coveringdimension-real-separability-metric-completion-cover-route}. These routes display rational dense windows, dyadic tolerance comparisons, and regular-rational seal rows before cover refinement and order-bound rows are read.

The same finite carrier is preserved by the $\BHist$ and $\Cont$ rows. Since the scale rows are downstream of the metric ledger and upstream of the finite order read, they cannot introduce a separate separability oracle, selected dense subfamily, or ambient Real completeness export.
\end{proof}

\begin{theorem}[CoveringDimension compactmetric non-escape obligation]
\label{thm:coveringdimension-compactmetric-nonescape-obligation}
The $\CoveringDimensionUp$ packet does not export open-cover compactness, choice-selected refinements, or host topological dimension. Its compactmetric-facing export is limited to displayed compact finite-net rows, metric distance ledgers, finite $\BHist$ cover entries, refinement memberships, order rows, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local $\NameCert$ data.
\end{theorem}
\begin{proof}
Inspect the compactmetric and metric routes already named by the hub. The finite cover admission, compact-net dependency, and finite-cover order non-escape results keep compactness, refinement, and order data inside the displayed carrier rows.

No row in that carrier names arbitrary open-cover compactness, a selected refinement outside the finite $\BHist$ cover, or a host topological-dimension theorem. The structural rows transport and replay only the finite packet, so every downstream read remains inside the CoveringDimension NameCert surface.
\end{proof}
