\begin{theorem}[CoveringDimension root metric-real window]
\label{thm:coveringdimension-root-metric-real-window}
For every accepted $\CoveringDimensionUp$ carrier, any root cover read that touches a metric-real window must expose finite $\BHist$ cover rows, the displayed $\MetricUp$ distance ledger, the $\CompactMetricUp$ cover window, the $\RealSeparabilityUp$ finite density row, and the $\SimplicialComplexUp$ nerve row before a dimension-order conclusion is consumed. The route may refine a finite cover by rational or dyadic scale windows, but it may not replace the displayed carrier by open-cover compactness, an arbitrary dense subset, a selected refinement, or an ambient topological-dimension theorem.
\end{theorem}
\begin{proof}
Start with the finite-refinement carrier of \autoref{def:covering-dimension-finite-refinement-carrier}. It displays the compactmetric source, metric ledger, finite cover row, refinement membership row, order row, simplicial handoff row, and Real-facing scale windows in one packet.

Apply the root obligation surface of \autoref{thm:covering-dimension-root-obligation-surface}. That theorem forces the compactmetric, metric, finite cover, Real-separability, rational, dyadic, and simplicial rows to remain visible before a root consumer reads the order bound.

The structural rows then preserve the same finite window. Componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming do not add an open-cover compactness oracle, selected dense subset, selected refinement, or host dimension predicate.
\end{proof}
\leanchecked{BEDC.Derived.CoveringdimensionUp.CoveringDimensionRootMetricRealWindow}

\label{thm:coveringdimension-root-simplicial-cover-handoff}
Every $\CoveringDimensionUp$ root handoff from a finite cover window to $\SimplicialComplexUp$ must pass through the finite $\BHist$ cover row, refinement-membership row, order-bound row, $\CompactMetricUp$ cover window, $\MetricUp$ distance ledger, $\RealSeparabilityUp$ finite density row, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and the local $\NameCert_{\CoveringDimensionUp}$ row. The $\SimplicialComplexUp$ nerve row receives only finite cover incidence and order data; it does not receive host realization data, selected vertices outside the carrier, arbitrary compactness, or ambient dimension information.
\end{theorem}
\begin{proof}
First read the simplicial nerve handoff of \autoref{thm:covering-dimension-simplicial-nerve-handoff}. It identifies the finite cover incidences and order ledger as the only data exported to the simplicial consumer.

Next use \autoref{thm:coveringdimension-root-metric-real-window}. The metric and Real-separability windows are already attached to the finite cover packet before the nerve row is read, so the handoff does not create a second cover carrier.

Finally repack the handoff through the structural rows $H,T,P,N$ named in the root packet. Since the packet contains no coordinate for selected vertices, host realization, arbitrary compactness, or ambient dimension, the simplicial consumer receives exactly the finite cover handoff stated above.
\end{proof}
