\begin{definition}[Constructive ODE flow-box carrier]
\label{def:constructive-ode-flow-box-carrier}
A $\ConstructiveOdeFlowBoxUp$ carrier is a finite $\BHist$ packet
$$
F=(O,I,L,P,G,R,E,H,C,Q,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $O$ is the $\OdeUp$ source row, carrying the local time-state window and vector-field read.
\item $I$ is the $\InitialValueProblemUp$ row naming the base point and initial-time boundary.
\item $L$ is the local nonstationary and coordinate-window row, storing the rational box, transverse coordinate, and time strip on which the flow-box read is admitted.
\item $P$ is the $\PicardLindelofUp$ local handoff row for the displayed initial-value data and box.
\item $G$ is the $\GronwallInequalityUp$ stability row used to compare nearby Picard windows inside the same strip.
\item $R$ is the $\RegSeqRatUp$ readback row for the local coordinate and flow-window approximants, and $E$ is the terminal $\RealUp$ seal reached only after $R$ is displayed.
\item $H$ records componentwise $\hsame$ transport for the ODE source, initial-value row, local coordinate window, Picard handoff, Gronwall stability row, regular readback, Real seal, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay through
$$

\item $Q$ is the $\Pkg$ provenance over $\ConstructiveOdeFlowBoxUp$, $\OdeUp$, $\InitialValueProblemUp$, $\PicardLindelofUp$, $\GronwallInequalityUp$, $\RegSeqRatUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\ConstructiveOdeFlowBoxUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $O,I,L,P,G,R,E,H,C,Q,N$. It has no coordinate for a selected host solution, maximal continuation interval, quotient path equality, trichotomy on real values, countable choice, or ambient $\RealUp$ completeness.
\end{definition}

\begin{theorem}[Constructive ODE flow-box obligations]
\label{thm:constructive-ode-flow-box-namecert-obligations}
For every accepted $\ConstructiveOdeFlowBoxUp$ carrier $F=(O,I,L,P,G,R,E,H,C,Q,N)$, the local $\NameCert_{\ConstructiveOdeFlowBoxUp}$ surface consists exactly of carrier admission for the displayed ODE source, initial-value row, local coordinate window, Picard--Lindelof handoff, Gronwall stability row, regular rational readback, Real seal, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:constructive-ode-flow-box-carrier}. The ODE source and initial-value boundary are the rows $O$ and $I$, so every local flow-box read is tied to a displayed time-state window and base point.

Read the local coordinate row $L$. It stores the finite box, transverse coordinate, and time strip on which the nonstationary hypothesis is visible to the packet, rather than as an external differentiable-chart theorem.

The analytic handoff rows are $P,G,R,E$. The Picard row supplies the local solution-window handoff, the Gronwall row supplies stability inside the strip, the regular rational row records the finite approximants, and the Real seal is downstream of that readback.

Finally $H,C,Q,N$ transport, replay, source, and name the same finite route. Since no carrier coordinate stores a selected host solution, maximal interval, quotient path equality, trichotomy, countable-choice schedule, or ambient completeness witness, those objects cannot enter the local NameCert surface.
\end{proof}

\begin{theorem}[Constructive ODE flow-box Picard local handoff]
\label{thm:constructive-ode-flow-box-picard-local-handoff}

The local coordinate row $L$ must be displayed before the Picard handoff $P$ is consumed, and the Gronwall row $G$ must be displayed before any Real-facing seal $E$ is read. The route exports no selected solution curve, host flow map, quotient path equality, global existence theorem, countable choice, or ambient real completeness.

\begin{proof}
