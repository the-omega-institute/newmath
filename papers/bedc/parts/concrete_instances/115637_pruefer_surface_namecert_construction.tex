\begin{definition}[Pruefer surface carrier]
\label{def:pruefer-surface-carrier}

$$

\begin{enumerate}
\item $R$ is the real-coordinate chart row, exposing each local coordinate only through $\RealUp$ and the paired-coordinate readback supplied by $\ProductTopologyUp$.
\item $Q$ is the chart-index row, listing the visible ordinary coordinate charts and the boundary-indexed fan charts without importing an external atlas.
\item $F$ is the boundary fan row, recording for each displayed boundary index the finite neighbourhood rows that approach that boundary coordinate from the corresponding side.
\item $B$ is the boundary-neighbourhood exactness row, identifying which fan rows meet the boundary line and which ordinary rows remain in the interior chart region.
\item $O$ is the chart-overlap row, recording the finite overlap incidences and transition-read requests between displayed chart rows.
\item $T$ is the $\TopologyUp$ handoff row generated from the ordinary chart rows, boundary fan rows, and displayed overlap incidences.
\item $M$ is the $\ManifoldUp$ chart-read row available only after $R,Q,F,B,O,T$ have been displayed.

\end{definition}

\label{thm:pruefer-surface-namecert-obligations}

\end{theorem}

Next inspect the overlap row $O$. Chart compatibility is therefore a displayed finite incidence condition between the rows already named by $R,Q,F,B$, not an equality of host charts or a quotient atlas.

Finally pass through $T,M,H,C,P,N$. These rows turn the displayed chart and boundary data into topology and manifold-facing reads while preserving the same finite route.
