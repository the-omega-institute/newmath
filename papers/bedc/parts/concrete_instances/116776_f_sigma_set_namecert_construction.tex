Following descriptive set theory and classical topology, the $\FSigmaSetUp$ packet records the traditional countable-union-of-closed-sets interface as finite BEDC NameCert data. It sits after the generated-set boundary of \autoref{ch:concrete-instances-borel-set-namecert}, the zero-locus surface of \autoref{ch:concrete-instances-zero-set-namecert}, the dual open-schedule route of \autoref{ch:concrete-instances-g-delta-set-namecert}, and the indexed open and closed-row discipline of \autoref{ch:concrete-instances-topology-namecert}. The packet names the finite surface that Borel hierarchy consumers need before they read a displayed closed-row schedule; it does not import host subsets, quotient set equality, a selected countable enumeration, ambient countable choice, or a classical descriptive-set theorem.

\begin{definition}[F-sigma set carrier]
\label{def:f-sigma-set-carrier}
An $\FSigmaSetUp$ carrier is a finite $\BHist$ packet
$$
F=(T,B,Z,G,S,W,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $T$ is the $\TopologyUp$ source row, carrying the named open and closed-row vocabulary visible to the current consumer.
\item $B$ is the $\BorelSetUp$ generated-set row that receives the handoff after the displayed closed schedule has been inspected.
\item $Z$ is the $\ZeroSetUp$ closed-locus row used when a closed component is supplied as the zero set of a displayed continuous $\RealUp$-valued map.
\item $G$ is the $\GDeltaSetUp$ sibling row used only as a dual-route comparison for open schedules and Borel handoff discipline.
\item $S$ is the countable closed-row schedule. Each visible prefix names the closed components, the schedule position, and the topology row over which that component is read.
\item $W$ is the finite $\StreamNameUp$ window row recording exactly the schedule positions, component indices, and finite membership queries visible before the Borel handoff.
\item $H$ records componentwise $\hsame$ transport for the topology source, Borel row, zero-set row, GDeltaSet sibling row, schedule, windows, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a topology or Borel query through $T,S,W$ before the generated-set row $B$ is consumed.
\item $P$ is the $\Pkg$ provenance over $\FSigmaSetUp$, $\TopologyUp$, $\BorelSetUp$, $\ZeroSetUp$, $\GDeltaSetUp$, $\StreamNameUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\FSigmaSetUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $T,B,Z,G,S,W,H,C,P,N$. It has no coordinate for host powersets, quotient equality of subsets, selected countable enumerations, countable choice, or ambient Borel hierarchy completeness.
\end{definition}

\begin{theorem}[F-sigma set NameCert obligations]
\label{thm:f-sigma-set-namecert-obligations}
For every accepted $\FSigmaSetUp$ carrier $F=(T,B,Z,G,S,W,H,C,P,N)$, the local $\NameCert_{\FSigmaSetUp}$ surface consists exactly of the following finite obligation rows:
\begin{enumerate}
\item carrier admission for the topology source, Borel row, zero-set row, GDeltaSet sibling row, closed-row schedule, finite windows, transport, replay, provenance, and local naming;
\item closed-schedule exposure, requiring every inspected union stage to appear as a displayed finite prefix of $S$ before it reaches $B$;
\item finite-window stability, requiring each schedule position, component index, and membership query to be read through $W$;
\item closed-component readback, requiring every scheduled component to pass through the topology source $T$ and, when supplied by a zero-locus presentation, through the $\ZeroSetUp$ row $Z$;
\item Borel handoff, requiring the generated-set row $B$ to consume only the displayed route through $T,S,W$ and the closed-component readback;
\item sibling compatibility, requiring the $\GDeltaSetUp$ row $G$ to serve only as the dual open-schedule comparison surface and not as a complement-selection principle;
\item componentwise transport, continuation replay, package provenance, and local naming through $H,C,P,N$;
\item ledger refusal, excluding host powersets, selected enumerations, countable choice, quotient set equality, classical complement selection, and ambient descriptive-set theorems.
\end{enumerate}
No $\FSigmaSetUp$ NameCert obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:f-sigma-set-carrier}. The tuple displays exactly the topology source, Borel row, zero-set row, GDeltaSet sibling row, countable closed-row schedule, finite windows, transport, replay, provenance, and local naming.

The schedule and window obligations are read through $S$ and $W$. A consumer sees only a finite prefix of the countable closed schedule, and every component index and membership query is inspected through the same displayed finite window.

Closed-component readback is forced by $T$ and $Z$. The topology source supplies the closed-row vocabulary, and the zero-set row supplies the zero-locus presentation when the component is offered in that form.

Finally $H,C,P,N$ transport, replay, source, and name the same route. Since no listed row stores a host powerset, selected enumeration, countable-choice selector, quotient set equality, classical complement selector, or ambient descriptive-set theorem, the enumerated obligations exhaust the local NameCert surface.
\end{proof}

\begin{theorem}[F-sigma set Borel handoff]
\label{thm:f-sigma-set-borel-handoff}
Every Borel consumer of an accepted $\FSigmaSetUp$ packet factors through the displayed route
$$
\TopologyUp,\ \ZeroSetUp,\ \StreamNameUp
\longmapsto
\BorelSetUp .
$$
More precisely, the consumer first reads the topology source row $T$, then the closed-row schedule and finite windows $S,W$, then the zero-set row $Z$ when a scheduled component is presented as a zero locus, and only then the generated-set row $B$. The exported object is a finite NameCert packet for the displayed countable closed-row route; it is not a host subset, a chosen enumeration, a complement-selected $\GDeltaSetUp$ packet, an ambient descriptive-set theorem, or a quotient set equality.
\end{theorem}
\begin{proof}
Begin with a Borel consumer of the accepted packet. Carrier admission exposes the topology source row $T$, but the generated-set row $B$ is not available until the closed schedule and finite windows have been displayed.

Replay the continuation row $C$. The read moves through $S$ and $W$, so every countable-union stage is consumed only as a finite visible prefix with finite component and query observations.

When a closed component is presented by a zero locus, the read passes through $Z$ and therefore through the zero-set discipline of \autoref{ch:concrete-instances-zero-set-namecert}. The sibling $\GDeltaSetUp$ row $G$ supplies only a comparison route for the dual schedule shape; it does not choose complements.

The remaining rows $H,P,N$ preserve, source, and name the same route. Therefore every Borel consumer factors through the displayed topology, zero-set, schedule, and window route, with no host subset, selected enumeration, complement-selected GDeltaSet packet, ambient descriptive-set theorem, or quotient set equality exported by the packet.
\end{proof}
