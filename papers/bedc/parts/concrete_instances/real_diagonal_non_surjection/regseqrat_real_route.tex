\begin{theorem}[Real diagonal non-surjection RegSeqRat--Real route]
\label{thm:real-diagonal-non-surjection-regseqrat-route}
Every accepted $\RealDiagonalNonSurjectionUp$ read that exposes a diagonal non-surjection packet must consume the $\RegSeqRatUp$ regular readback row of \autoref{ch:concrete-instances-regseqrat-namecert}, the finite $\StreamNameUp$ windows of \autoref{ch:concrete-instances-streamname-namecert}, the terminal $\RealUp$ seal rows of \autoref{ch:concrete-instances-real-namecert}, and the Cantor-style diagonal sibling rows of \autoref{thm:real-diagonal-non-surjection-cantor-sibling-route} before the non-surjection surface is available.

In carrier coordinates this route reads $E,W,B,F,R,S,H,C,P,N$ from \autoref{def:real-diagonal-non-surjection-carrier}: the enumeration slice and window schedule are exposed first, the flipped dyadic bit is repacked through $R$ as regular rational data, the terminal seal $S$ presents the Real-facing row, and the Cantor sibling consumes the same displayed disagreement ledger. No host stream equality, selected inverse, quotient real equality, completed powerset, or ambient Real-completeness row is introduced by the route.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:real-diagonal-non-surjection-carrier}. The rows $E$ and $W$ expose only the inspected finite enumeration slice and diagonal windows, so the non-surjection read begins as $\StreamNameUp$ window data.

Apply \autoref{thm:real-diagonal-non-surjection-regseqrat-dependency-route}. The bit observation and flipped bit are read through $B$ and $F$, then the row $R$ repacks the disagreement as regular rational data before a Real-facing endpoint is visible.

Next apply \autoref{thm:real-diagonal-non-surjection-real-seal-dependency}. The seal row $S$ is the only $\RealUp$ endpoint available to the diagonal witness, and it is exposed only after the regular readback has been displayed.

Finally use \autoref{thm:real-diagonal-non-surjection-cantor-sibling-route}. The Cantor-style sibling consumes the same finite disagreement ledger after the StreamName, RegSeqRat, and Real seal rows are visible. The structural rows $H,C,P,N$ transport, replay, source, and name that route, so no excluded host object can enter the non-surjection packet.
\end{proof}
