Following Bishop-style compact metric analysis, the continuous image of compact metric data is compact only after two finite rows are visible: total bounded image nets and completeness for the target image route. The $\CompactMetricContinuousImageCompactUp$ packet records that theorem-facing route as finite BEDC data. It consumes the compact metric source of \autoref{ch:concrete-instances-compactmetric-namecert}, the continuous-map graph of \autoref{ch:concrete-instances-continuousmap-namecert}, the tolerance routing of \autoref{ch:concrete-instances-uniformmodulus-namecert}, the finite image-net packet of \autoref{ch:concrete-instances-compact-metric-continuous-image-namecert}, the total-bounded image carrier of \autoref{ch:concrete-instances-compact-continuous-image-total-bounded-namecert}, and the complete-metric handoff of \autoref{ch:concrete-instances-completemetric-namecert}. The packet names a compact-metric image row; it does not assert open-cover compactness, selected inverse images, quotient equality of target names, or ambient $\RealUp$ completeness.

\begin{definition}[Compact metric continuous-image compact carrier]
\label{def:compact-metric-continuous-image-compact-carrier}
A $\CompactMetricContinuousImageCompactUp$ carrier is a finite $\BHist$ packet
$$
J=(K,F,U,I,T,E,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $K$ is the $\CompactMetricUp$ source row, exposing finite source-net and compact-metric provenance.
\item $F$ is the $\ContinuousMapUp$ graph row from the source carrier to the target metric carrier.
\item $U$ is the $\UniformModulusUp$ tolerance route used by the same displayed map row.
\item $I$ is the $\CompactMetricContinuousImageUp$ finite image-net route from source nets to target image centers.
\item $T$ is the $\CompactContinuousImageTotalBoundedUp$ row that packages those image centers as total-bounded target-image data.
\item $E$ is the $\CompleteMetricUp$ row available for the displayed target-image route.
\item $H$ records componentwise $\hsame$ transport for the compact source, map row, modulus row, finite image-net row, total-bounded row, complete-metric row, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a compact-image request through $K,F,U,I,T,E,H,P,N$.
\item $P$ is the $\Pkg$ provenance over $\CompactMetricContinuousImageCompactUp$, $\CompactMetricUp$, $\ContinuousMapUp$, $\UniformModulusUp$, $\CompactMetricContinuousImageUp$, $\CompactContinuousImageTotalBoundedUp$, $\CompleteMetricUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\CompactMetricContinuousImageCompactUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $K,F,U,I,T,E,H,C,P,N$. It has no coordinate for open-cover compactness, a host image subset, selected preimages, quotient equality of target names, choice-selected target centers, or ambient real completeness.
\end{definition}

\begin{theorem}[Compact metric continuous-image compact obligations]
\label{thm:compact-metric-continuous-image-compact-namecert-obligations}
For every accepted $\CompactMetricContinuousImageCompactUp$ carrier $J=(K,F,U,I,T,E,H,C,P,N)$, the local $\NameCert_{\CompactMetricContinuousImageCompactUp}$ surface consists exactly of carrier admission, compact source-net accountability, continuous-map graph routing, uniform-modulus compatibility, finite image-net exactness, image total-bounded export, complete-metric handoff, componentwise transport, displayed replay, provenance, and local naming.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:compact-metric-continuous-image-compact-carrier}. The source, map, and tolerance rows are $K,F,U$, while the image-facing compactness route is $I,T,E$.

The finite image-net row $I$ may be read only after the source compact metric row and the displayed modulus row have routed a target tolerance to a source-net request. The total-bounded row $T$ repackages those image centers without adding a host image set.

The complete-metric row $E$ is read after the total-bounded image row. Transport, replay, provenance, and local naming are supplied by $H,C,P,N$, so the compact-metric image row is assembled from displayed finite data.

Since the carrier has no open-cover, selected-preimage, quotient-equality, choice, or ambient-completeness coordinate, the local NameCert surface cannot export those principles.
\end{proof}

\begin{theorem}[Compact metric continuous-image compact route]
\label{thm:compact-metric-continuous-image-compact-route}
Every compact-image consumer of an accepted $\CompactMetricContinuousImageCompactUp$ packet receives only the finite BEDC route
$$
\CompactMetricUp,\quad
\ContinuousMapUp,\quad
\UniformModulusUp,\quad
\CompactMetricContinuousImageUp,\quad
\CompactContinuousImageTotalBoundedUp,\quad
\CompleteMetricUp .
$$
The exported compactness row is a $\CompactMetricUp$-style row for the displayed image route, assembled from image nets plus completeness, not an open-cover compactness theorem, not a selected inverse-image construction, not quotient target equality, and not ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Begin with a compact-image request. The request first reads the compact source row $K$, the continuous-map graph row $F$, and the uniform-modulus row $U$.

Next apply the finite image-net route $I$. It reads source nets and displayed graph values to produce target image centers. Apply the total-bounded image row $T$ to expose those centers as total-bounded target-image data.

Finally read the complete-metric row $E$ for the same displayed target-image route. The structural rows $H,C,P,N$ transport, replay, source, and name this route componentwise.

The construction is exhausted by $K,F,U,I,T,E,H,C,P,N$. Therefore a consumer receives compact-metric image data from finite image nets plus completeness, with none of the excluded open-cover, selected-preimage, quotient, choice, or ambient-completeness objects.
\end{proof}
