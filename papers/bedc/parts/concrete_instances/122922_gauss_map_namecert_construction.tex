\begin{theorem}[Gauss map NameCert obligations]
\label{thm:gauss-map-namecert-obligations}

\end{theorem}
\begin{proof}

Read the arithmetic route next. The floor row $F$ and fractional residual row $Q$ are tied to the same reciprocal row, and the continued-fraction prefix row $A$ records only the finite partial-quotient handoff visible from that route.
