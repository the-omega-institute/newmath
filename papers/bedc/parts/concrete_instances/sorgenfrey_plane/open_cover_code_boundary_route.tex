\begin{theorem}[Sorgenfrey plane coded-cover boundary route]
\label{thm:sorgenfrey-plane-open-cover-code-boundary-route}
Every coded-cover consumer of an accepted $\SorgenfreyPlaneUp$ packet must read the lower-limit component rows, product topology row, rectangle ledger, and observable-open row before it can pass a finite cover fragment to \autoref{ch:concrete-instances-open-cover-code-namecert}. In the carrier notation of \autoref{def:sorgenfrey-plane-carrier}, the route is
$$
L_X,L_Y,O_X,O_Y,Q,B,S,H,C,R,N .
$$
The handoff supplies only displayed lower-limit product data for an $\OpenCoverCodeUp$ boundary packet; it does not export ambient powerset covers, open-cover compactness, selected subcovers, metrizability, normality, or quotient equality on $\RealUp\times\RealUp$.
\end{theorem}
\begin{proof}
Project the Sorgenfrey plane carrier. The component lower-limit rows $L_X,L_Y$, component topology rows $O_X,O_Y$, product row $Q$, and rectangle ledger $B$ are visible before any cover-facing read is available.

Read the observable-open row $S$ next. It supplies finite truth data for displayed rectangle observations, which is the only cover-facing material the packet can hand to the coded-cover boundary.

The structural rows $H,C,R,N$ transport, replay, source, and name the same lower-limit product route. Since the carrier has no coordinate for powerset covers, selected subcovers, compactness, metrizability, normality, or quotient real-pair equality, the downstream $\OpenCoverCodeUp$ read remains a finite boundary handoff.
\end{proof}
