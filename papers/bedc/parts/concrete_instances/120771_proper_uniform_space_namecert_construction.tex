Following Bourbaki and Kelley on uniform spaces, the $\ProperUniformSpaceUp$ packet records the finite BEDC surface in which uniform entourages admit displayed controlled-neighbourhood windows whose completion-facing reads stay inside a properness boundary. It sits beside the uniform carrier of \autoref{ch:concrete-instances-uniformspace-namecert}, the proper-metric specializations of \autoref{ch:concrete-instances-propermetric-namecert} and \autoref{ch:concrete-instances-proper-metric-space-namecert}, the uniform and metric completion packets of \autoref{ch:concrete-instances-uniformcompletion-namecert} and \autoref{ch:concrete-instances-metriccompletion-namecert}, and the naming spine of \autoref{ch:concrete-instances-streamname-namecert}, \autoref{ch:concrete-instances-regseqrat-namecert}, and \autoref{ch:concrete-instances-real-namecert}. The carrier names properness as uniform finite data; it is not a selected compactification, a quotient-completion equality, a host-limit selector, or an ambient completeness principle.

\begin{definition}[Proper uniform space carrier]
\label{def:proper-uniform-space-carrier}
A $\ProperUniformSpaceUp$ carrier is a finite $\BHist$ packet
$$
P_{\mathrm{pus}}=(U,M,W,C,R,S,Q,H,T,K,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $U$ is the $\UniformSpaceUp$ entourage row, carrying finite entourage membership, inverse, refinement, and composition data.
\item $M$ is the $\ProperMetricUp$ or $\ProperMetricSpaceUp$ metric specialization row used when a consumer requests the metric properness face.
\item $W$ is the controlled-uniform-neighbourhood window row, recording the bounded entourage windows that replace host compact neighbourhoods.
\item $C$ is the completion-boundary row, exposing the $\UniformCompletionUp$ route before the $\MetricCompletionUp$ specialization can be read.
\item $R$ is the regular rational readback row through $\RegSeqRatUp$, tied to the same finite windows.
\item $S$ is the $\StreamNameUp$ schedule that names every inspected uniform and completion-facing request.
\item $Q$ is the terminal $\RealUp$ seal row reached only after $U,M,W,C,R,S$ have been displayed.
\item $H$ records componentwise $\hsame$ transport for the uniform source, metric specialization, window, completion, readback, stream, seal, replay, provenance, and local naming rows.
\item $T$ records displayed $\Cont$ replay from a proper-uniform request through the same rows.
\item $K$ is the $\Pkg$ provenance over $\ProperUniformSpaceUp$, $\UniformSpaceUp$, $\ProperMetricUp$, $\ProperMetricSpaceUp$, $\UniformCompletionUp$, $\MetricCompletionUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\ProperUniformSpaceUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through these eleven rows. It has no coordinate for host compact neighbourhoods, selected completions, quotient uniform equality, countable choice, host real equality, or ambient completeness.
\end{definition}

\begin{theorem}[Proper uniform space NameCert obligations]
\label{thm:proper-uniform-space-namecert-obligations}
For every accepted $\ProperUniformSpaceUp$ carrier $P_{\mathrm{pus}}=(U,M,W,C,R,S,Q,H,T,K,N)$, the local $\NameCert_{\ProperUniformSpaceUp}$ surface consists exactly of carrier admission for the displayed eleven-row packet; uniform-source exactness for $U$; metric-specialization compatibility through $M$; controlled-window properness through $W$; completion-boundary routing through $C$; regular rational and stream readback through $R,S$; Real seal non-escape through $Q$; and structural transport, replay, provenance, and local naming through $H,T,K,N$.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:proper-uniform-space-carrier}. The uniform row, metric specialization, controlled window, completion boundary, regular readback, stream schedule, Real seal, and structural rows are exactly the visible coordinates.

Uniform-source exactness is rowwise. The row $U$ supplies the entourage ledger, and every controlled neighbourhood request must pass through the displayed window row $W$ before any completion-facing consumer can read it.

The metric face is only a specialization. The row $M$ may expose $\ProperMetricUp$ or $\ProperMetricSpaceUp$ data, but it does so downstream of the same uniform windows, so it cannot replace the uniform carrier by an unrelated metric completion.

Finally the rows $C,R,S,Q,H,T,K,N$ preserve the displayed completion route. Since the carrier has no coordinate for selected completions, quotient equality, countable choice, host real equality, or ambient completeness, the listed obligations exhaust the local NameCert surface.
\end{proof}

\begin{theorem}[Proper uniform space completion route]
\label{thm:proper-uniform-space-completion-route}
Every completion-facing consumer of an accepted $\ProperUniformSpaceUp$ carrier factors through the displayed route
$$
\UniformSpaceUp \longmapsto W \longmapsto \UniformCompletionUp \longmapsto \MetricCompletionUp \longmapsto \RegSeqRatUp,\StreamNameUp \longmapsto \RealUp .
$$
The route may use the $\ProperMetricUp$ or $\ProperMetricSpaceUp$ face as a specialization, but it cannot bypass the uniform window row or replace the completion boundary by a selected host limit, quotient completion, countable-choice schedule, or ambient $\RealUp$ completeness theorem.
\end{theorem}
\begin{proof}
Start with a completion-facing consumer and project the accepted carrier. The only source row is the uniform entourage row $U$, and the only properness row available before completion is the controlled window row $W$ together with the metric specialization row $M$.

Read the completion boundary next. The row $C$ exposes the $\UniformCompletionUp$ route before any $\MetricCompletionUp$ specialization can be consumed, so a metric-completion read remains attached to the same uniform source and windows.

The naming spine is then forced by $R,S,Q$. Regular rational readback and stream scheduling are displayed before the terminal Real seal, while the transport, replay, provenance, and naming rows keep the consumer inside the same finite packet.

The excluded objects are absent from the carrier. Thus every completion-facing read follows the displayed route and cannot obtain a selected host limit, quotient completion, countable-choice schedule, or ambient completeness principle.
\end{proof}

\begin{theorem}[Proper uniform space L10 boundary]
\label{thm:proper-uniform-space-l10-boundary}
An accepted $\ProperUniformSpaceUp$ packet supplies an L10 source object for properness arguments that do not start from the metric specialization. Any downstream route to $\UniformCompletionUp$, $\MetricCompletionUp$, $\StreamNameUp$, $\RegSeqRatUp$, or $\RealUp$ must first expose the uniform entourage row $U$ and controlled window row $W$, then preserve the same packet through $H,T,K,N$.
\end{theorem}
\begin{proof}
Project the source rows of \autoref{def:proper-uniform-space-carrier}. The packet begins with $\UniformSpaceUp$ data and a controlled-window row, so the properness source is uniform before it is metric.

Use \autoref{thm:proper-uniform-space-completion-route}. It places $\UniformCompletionUp$ ahead of the metric-completion specialization and binds both completion reads to the same stream and regular-rational naming spine.

The structural rows $H,T,K,N$ preserve that source order under accepted comparison. Therefore the L10 boundary is a proper-uniform source object, while the metric face remains a downstream specialization rather than the only properness entry point.
\end{proof}
