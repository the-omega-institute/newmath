\begin{definition}[Regular Cauchy tail reparametrization carrier]
\label{def:regular-cauchy-tail-reparametrization-carrier}

$$

\begin{enumerate}

\item $W$ is the target tail-window row. It records the finite target tail budget and the source tail window to which the current request is sent.
\item $M$ is the monotone finite reparametrization ledger. It records the displayed order comparisons and target-to-source request map for the fixed window $W$.

\begin{theorem}[Regular Cauchy tail reparametrization NameCert obligations]
\label{thm:regular-cauchy-tail-reparametrization-namecert-obligations}
For every accepted $\RegularCauchyTailReparametrizationUp$ carrier
$$

$$
the local $\NameCert_{\RegularCauchyTailReparametrizationUp}$ surface consists exactly of carrier admission for the source $\StreamNameUp$ window, target tail-window, monotone finite reparametrization ledger, $\DyadicRatCoreUp$ tolerance row, $\RegSeqRatUp$ readback, $\RealUp$ seal, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming row. The obligations require every readback request to pass through the fixed target tail-window and its monotone finite ledger before any dyadic tolerance, regular rational value, or Real seal is consumed.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:regular-cauchy-tail-reparametrization-carrier}. The rows $S,W,M,D,R,E$ are the complete analytic route, while $H,C,P,N$ only transport, replay, source, and name that route.

The target tail-window $W$ is fixed before the reparametrization ledger is read. The row $M$ supplies the finite monotone target-to-source request map for that window, so the packet does not choose a subsequence or appeal to a global cofinal selector.

After $W$ and $M$ have fixed the inspected source window, the dyadic tolerance row $D$ supplies the precision budget for the regular rational readback $R$. The terminal seal $E$ is downstream of the same displayed data, so no quotient stream equality, selected subsequence choice, trichotomy, host equality, countable choice, or ambient $\RealUp$ completeness row can be exported.
\end{proof}
