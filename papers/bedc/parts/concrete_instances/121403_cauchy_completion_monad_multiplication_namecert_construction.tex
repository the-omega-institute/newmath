\begin{theorem}[Flattening scope]
\label{thm:cauchy-completion-monad-multiplication-flatten-scope}

\end{theorem}
\begin{proof}

The regular-Cauchy tail data are read next. The stream windows $S$, regular readback $R$, and dyadic tolerance ledger $D$ determine the finite tail-stability comparison used by the flattened classifier before the seal row $E$ can be consumed.

Finally $H,C,P,N$ transport, replay, source, and name the same displayed packet. Since none of the excluded principles has a carrier coordinate, the flattening map cannot depend on them.
