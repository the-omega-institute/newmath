\begin{definition}[RiemannSumMesh carrier]
\label{def:riemann-sum-mesh-carrier}
A $\RiemannSumMeshUp$ carrier is a finite $\BHist$ packet
$$
M=(I,C,W,T,S,V,R,H,K,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $I$ is the closed interval row, with dyadic endpoint names read through $\DyadicRatCoreUp$;
\item $C$ is the finite ordered cell row, listing adjacent subintervals whose endpoints cover $I$ without overlap;
\item $W$ is the dyadic mesh-width row, recording each cell width and the displayed maximum mesh bound;
\item $T$ is the tag-containment row, assigning one sample tag to each cell and witnessing that the tag lies inside that cell;
\item $S$ is the finite $\StreamNameUp$ window row for the sampled input names used by the tagged partition;
\item $V$ is the $\RegSeqRatUp$ sample-value row, giving rational approximants for the sampled function values at the displayed precision;
\item $R$ is the $\RealUp$ seal row, recording that real-name reads are only the finite seals needed for the sample values;
\item $H$ records componentwise $\hsame$ transport for $I,C,W,T,S,V,R,K,P,N$;

\item $N$ is the local $\NameCert_{\RiemannSumMeshUp}$ row.

The local classifier compares accepted packets only through $I,C,W,T,S,V,R,H,K,P,N$. It has no coordinate for a host integral, selected limiting process, quotient function equality, countable-choice sampling schedule, or ambient $\RealUp$ completeness.
\end{definition}

\begin{theorem}[RiemannSumMesh NameCert obligations]
\label{thm:riemann-sum-mesh-namecert-obligations}

$$
M=(I,C,W,T,S,V,R,H,K,P,N).
$$
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:riemann-sum-mesh-carrier}. The accepted packet displays the interval, cells, mesh widths, tags, sample windows, sample values, real seal, transport, replay, provenance, and naming rows as $I,C,W,T,S,V,R,H,K,P,N$.

The dyadic rows provide the finite arithmetic support. The interval row $I$, ordered cell row $C$, and mesh row $W$ are read through $\DyadicRatCoreUp$, so adjacency, coverage, widths, and the maximum mesh bound are finite rational data.

The real seal and structural rows close the packet. The row $R$ bars ambient completeness reads, while $H,K,P,N$ preserve the same finite route under transport, replay, package provenance, and local naming. Hence the listed rows exhaust the local NameCert obligations.
