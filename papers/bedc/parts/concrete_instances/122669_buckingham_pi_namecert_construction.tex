\begin{definition}[Buckingham Pi carrier]
\label{def:buckingham-pi-carrier}
A $\BuckinghamPiUp$ carrier is a finite $\BHist$ packet
$$
B=(U,M,K,T,E,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $U$ is the finite unit-exponent carrier, listing the base-unit coordinates of every inspected quantity.
\item $M$ is the $\MatrixUp$ row for the displayed dimension matrix over the same finite coordinate window.
\item $K$ is the dimensionless monomial classifier, exposing exactly the nullspace rows whose exponent vectors cancel all base-unit coordinates.
\item $T$ is the exponent-transport stability row, recording componentwise $\hsame$ transport for unit rows, exponent vectors, matrix reads, and monomial classifiers.
\item $E$ is the nullspace and exactness ledger, showing that each exported Pi row is read through $M$ and $K$ before any scalar readback is consumed.
\item $H$ records the no-host-units non-escape boundary: every accepted read remains inside the displayed unit-exponent packet.
\item $C$ is the displayed $\Cont$ replay row for finite unit windows, matrix rows, nullspace rows, and dimensionless monomial reads.
\item $P$ is the $\Pkg$ provenance over $\BuckinghamPiUp$, $\VecSpaceUp$, $\LinearMapUp$, $\MatrixUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$ rows.
\item $N$ is the local $\NameCert_{\BuckinghamPiUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through these nine rows. It has no coordinate for host units, quotient dimensions, selected physical constants, analytic regularity, or an ambient real-valued law outside the displayed finite packet.
\end{definition}

\begin{theorem}[Buckingham Pi NameCert surface]
\label{thm:buckingham-pi-namecert-surface}
For every accepted $\BuckinghamPiUp$ carrier $B=(U,M,K,T,E,H,C,P,N)$, the local $\NameCert_{\BuckinghamPiUp}$ surface consists exactly of carrier admission for the finite unit-exponent row, matrix readback for the dimension map, dimensionless monomial classification, exponent-transport stability, nullspace and exactness accounting, no-host-units non-escape, displayed replay, provenance, and local naming.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:buckingham-pi-carrier}. The rows $U$ and $M$ display the finite unit coordinates and the dimension matrix before any monomial read is available.

Read the classifier row $K$ through the nullspace ledger $E$. A dimensionless monomial is therefore a finite exponent vector whose matrix read is zero in the displayed unit window, not an equality of host physical quantities.

Transport and replay through $T$ and $C$. These rows preserve the same unit-exponent coordinates and the same classifier row, while $H$ prevents escape to unlisted host units.

Finally package the route through $P$ and $N$. Since the carrier has no coordinate for host units, quotient dimensions, selected physical constants, or analytic regularity, the listed rows exhaust the NameCert surface.
\end{proof}

\begin{theorem}[Buckingham Pi non-escape]
\label{thm:buckingham-pi-no-host-units-nonescape}

$$

\end{theorem}
\begin{proof}
Begin with the requested Pi coordinate. The finite unit-exponent row $U$ fixes the displayed basis of dimensions, and the matrix row $M$ records the corresponding dimension map.

Use the classifier $K$ and exactness ledger $E$ to read only exponent vectors annihilated by that displayed map. The read is stable under $T$ because transport acts componentwise on the same exponent and unit rows.

The no-host-units row $H$ then blocks any appeal to unlisted dimensions or ambient physical quantities. Replay, provenance, and naming through $C,P,N$ preserve the finite route, so no excluded host object is exported.
\end{proof}
