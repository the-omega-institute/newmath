$$

\item $B$ is the cofinal-base row, recording which displayed filter base refines the regular common-tail window.
\item $T$ is the $\RegSeqRatUp$ tail-window row exposed by the refined base.
\item $S$ is the $\StreamNameUp$ finite-observation row read on that tail window.
\item $D$ is the $\DyadicRatCoreUp$ tolerance row shared by the filter request and the regular-sequence readback.
\item $R$ is the terminal $\RealUp$ seal handoff, available only after $F,B,T,S,D$ have been displayed.
\item $H$ records componentwise $\hsame$ transport for the filter, refinement, tail-window, observation, tolerance, seal, replay, provenance, and local naming rows.

The classifier compares accepted packets only through $F,B,T,S,D,R,H,C,P,N$. No coordinate stores quotient-filter equality, selected limits, countable-choice schedules, host equality of Real names, or ambient $\RealUp$ completeness.

\begin{theorem}[Regular Cauchy filter sequential handoff]
\label{thm:regular-cauchy-filter-comparison-sequential-handoff}
Every accepted $\RegularCauchyFilterComparisonUp$ packet that receives a $\CauchyFilterUp$ basis whose displayed base refines the packet's common-tail window hands the completion read to a $\RegSeqRatUp$ tail window with the same $\DyadicRatCoreUp$ tolerance ledger, $\StreamNameUp$ finite observations, $\hsame$ transport, $\Cont$ replay, $\Pkg$ provenance, and local $\NameCert$ row. The terminal $\RealUp$ seal is read only after that regular tail route has been displayed.
\end{theorem}
\leanchecked{BEDC.Derived.RegularCauchyFilterComparisonUp.RegularCauchyFilterComparisonSequentialHandoff}
\begin{proof}
Project the carrier of \autoref{def:regular-cauchy-filter-comparison-carrier}. The incoming filter row is $F$, and the cofinal-base row $B$ is the only place where a filter refinement may be read.

Use $B$ to expose the finite regular tail window $T$. The stream observations $S$ and dyadic tolerance ledger $D$ are then read on the same displayed window, so the comparison has a sequence-facing route before any Real seal is consumed.

The structural rows preserve that route. Componentwise $\hsame$ transport in $H$ and displayed $\Cont$ replay in $C$ carry the same finite rows through provenance $P$ and local naming $N$.

Finally read the terminal $\RealUp$ seal $R$. Since the carrier has no quotient-filter, selected-limit, choice, host-equality, or Real-completeness coordinate, the handoff is exactly the displayed finite sequential route.
\end{proof}

\begin{theorem}[Regular Cauchy filter comparison NameCert obligations]
\label{thm:regular-cauchy-filter-comparison-namecert-obligations}
For every accepted $\RegularCauchyFilterComparisonUp$ carrier $K=(F,B,T,S,D,R,H,C,P,N)$, the local $\NameCert_{\RegularCauchyFilterComparisonUp}$ surface consists exactly of:
\begin{enumerate}
\item carrier admission for the CauchyFilter base, cofinal-base refinement, RegSeqRat tail window, StreamName observations, DyadicRatCore tolerance ledger, Real seal, transport, replay, provenance, and local naming rows;
\item sequential handoff, requiring the refined filter base to expose $T,S,D$ before $R$ is available;
\item classifier stability, requiring componentwise $\hsame$ transport and displayed $\Cont$ replay to preserve the route $F,B,T,S,D,R$;
\item ledger non-escape, requiring $P$ and $N$ to export no quotient filters, selected limits, countable choice, host Real equality, or ambient $\RealUp$ completeness.
\end{enumerate}
No NameCert obligation is stored outside these rows.
\end{theorem}
\begin{proof}

Sequential handoff is supplied by \autoref{thm:regular-cauchy-filter-comparison-sequential-handoff}. The filter request is first refined by $B$, then read as the regular tail window $T$ with observations $S$ and tolerance ledger $D$ before the terminal Real seal $R$ is exposed.

Classifier stability is rowwise. The $\hsame$ row transports displayed coordinates, and the $\Cont$ row replays the same finite route without changing the classifier surface.

The ledger boundary follows from absence. Since no excluded object is a coordinate of the carrier, provenance and local naming cannot export quotient filters, selected limits, countable choice, host Real equality, or ambient Real completeness.
\end{proof}
