\label{thm:dedekind-cut-stream-regseqrat-forward-route}

$$

\longrightarrow
\StreamNameUp
\longrightarrow

\longrightarrow

inside the same $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and local $\NameCert_{\DedekindCutStreamUp}$ surface. It exports no quotient cut, quotient stream equality, trichotomy branch, selected supremum, selected limit, ambient real completeness, or host comparison outside the displayed route.

Start with the carrier of \autoref{def:dedekind-cut-stream-carrier}. A Real-facing comparison can read endpoint budgets only through the $\DyadicRatCoreUp$ row $D$, and it can inspect cut observations only through the finite $\StreamNameUp$ window row $W$.

Finally pass through the terminal $\RealUp$ seal while preserving the transport, replay, provenance, and local naming rows $H,C,P,N$. Since the packet has no coordinate for quotient cuts, selected suprema, selected limits, trichotomy, ambient completeness, or host comparison, the exported comparison route is exactly the displayed forward dependency chain.
\end{proof}
