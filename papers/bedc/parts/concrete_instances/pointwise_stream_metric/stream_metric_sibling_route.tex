\begin{theorem}[Pointwise stream metric stream-metric sibling route]
\label{thm:pointwise-stream-metric-stream-metric-sibling-route}
Every $\PointwiseStreamMetricUp$ consumer first reads the certified $\StreamNameUp$ finite windows of \autoref{ch:concrete-instances-streamname-namecert} and the displayed $\MetricSpaceUp$ distance rows of \autoref{ch:concrete-instances-metric-namecert}. \end{theorem}
\begin{proof}
Project the carrier of \autoref{def:pointwise-stream-metric-carrier}. Its stream source row $S$, finite window row $W$, dyadic ledger $D$, regular readback row $R$, Real seal $E$, and metric row $M$ are the only analytic rows available before transport, replay, provenance, and local naming.

Apply \autoref{thm:pointwise-stream-metric-pointwise-classifier}. It forces the pointwise distance read to pass through $S,W,D,R,E$ before the metric row $M$ can be inspected.

Finally use \autoref{thm:pointwise-stream-metric-real-completion-anchor}. Any completion-facing or convergence-facing consumer receives the same finite route before reaching $\MetricCompletionUp$ or $\RealModulusOfConvergenceUp$. Since no carrier coordinate stores host stream equality, selected representatives, countable-choice schedules, or ambient completeness, the sibling route is exhausted by the displayed stream and metric surfaces.
\end{proof}
