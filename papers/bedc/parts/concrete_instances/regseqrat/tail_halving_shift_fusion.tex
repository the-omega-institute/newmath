\begin{theorem}[RegSeqRat tail-halving shift fusion]
\label{thm:regseqrat-tail-halving-shift-fusion}
Let $P$ be an accepted $\RegSeqRatUp$ packet. Suppose a displayed tail-shift row over the $\StreamNameUp$ schedule and a displayed tail-halving row over the $\DyadicRatCoreUp$ tolerance ledger are both available for $P$. Then the two rows compose to a common finite tail window whose StreamName schedule, DyadicRatCore tolerance ledger, RegSeqRat readback, and downstream $\RealUp$ seal are the same public read.

The fused window is a finite L10 four-object route through $\StreamNameUp$, $\DyadicRatCoreUp$, $\RegSeqRatUp$, and $\RealUp$. It exports no quotient stream equality, selected limit, host real equality, metric-completeness datum, completion point, countable-choice schedule, or ambient $\RealUp$ completeness coordinate.
\end{theorem}
\begin{proof}
Project the existing tail-shift route of \autoref{thm:regseqrat-tail-shift-stability}. The shifted window exposes only the transported StreamName schedule, DyadicRatCore endpoint and radius rows, regularity ledgers, classifier support, componentwise $\hsame$, displayed $\Cont$, $\Pkg$, and local $\NameCert$ rows.

Apply the tail-halving closure route of \autoref{thm:regseqrat-tail-halving-closure} to that shifted window. The halved successor refines the displayed dyadic tolerance ledger while keeping the same finite StreamName source and the same regular-rational classifier surface.

Now take the common finite tail window given by the shifted window and its halved successor. On that window the StreamName schedule is already fixed by the tail-shift row, and the DyadicRatCore tolerance ledger is fixed by the halving row. The RegSeqRat classifier can therefore read only one finite source surface.

Finally read the downstream $\RealUp$ seal through the same four-object route. Since the carrier rows have been exhausted by $\StreamNameUp$, $\DyadicRatCoreUp$, $\RegSeqRatUp$, $\RealUp$, $\hsame$, $\Cont$, $\Pkg$, and local naming, no quotient stream equality, selected limit, host real equality, metric-completeness datum, completion point, countable-choice schedule, or ambient completeness coordinate remains available.
\end{proof}
