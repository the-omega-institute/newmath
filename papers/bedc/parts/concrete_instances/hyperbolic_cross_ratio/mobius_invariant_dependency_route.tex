\begin{theorem}[Hyperbolic cross-ratio Mobius-invariant sibling route]
\label{thm:hyperbolic-cross-ratio-mobius-sibling-route}
Every accepted $\HyperbolicCrossRatioUp$ four-boundary-point carrier consumes the $\MobiusTransformUp$ route of \autoref{ch:concrete-instances-mobius-transform-namecert} and the $\HyperbolicMobiusInvariantUp$ route of \autoref{ch:concrete-instances-hyperbolic-mobius-invariant-namecert} before any cross-ratio comparison is exported. In carrier notation $X=(D,M,B_0,B_1,B_2,B_3,T,Q,R,F,H,C,P,N)$, the accepted comparison row $Q$ is public only after the disk, metric, four boundary, boundary-fixed transport, refusal, provenance, replay, package, and naming rows have passed the sibling Mobius and invariant routes.
\end{theorem}
\begin{proof}
Apply \autoref{thm:hyperbolic-cross-ratio-nonescape}. Every public read of $Q$ already factors through the displayed disk, metric, four boundary rows, boundary-fixed transport, refusal, Schwarz--Pick provenance, transport, replay, provenance, and local naming rows.

Apply \autoref{thm:hyperbolic-cross-ratio-mobius-consumer-route}. A $\MobiusTransformUp$ consumer of that packet may claim preservation only through the same four-boundary carrier route, so the Mobius sibling is a prerequisite route rather than an external host symmetry.

The $\HyperbolicMobiusInvariantUp$ sibling then reads the same Mobius-facing route as invariant data. Since $X$ has no coordinate for an isolated cross-ratio scalar, quotient boundary equality, or unrecorded transformation invariant, any accepted cross-ratio comparison exported from $Q$ has already consumed both sibling routes.
\end{proof}
