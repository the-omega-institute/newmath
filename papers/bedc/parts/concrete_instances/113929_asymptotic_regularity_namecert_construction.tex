\begin{theorem}[Asymptotic regularity NameCert obligations]
\label{thm:asymptotic-regularity-namecert-obligations}
For every accepted $\AsymptoticRegularityUp$ carrier $A=(O,D,M,E,S,T,H,C,P,N)$, the local $\NameCert_{\AsymptoticRegularityUp}$ surface consists exactly of the following five obligation rows:
\begin{enumerate}
\item carrier admission through the displayed orbit window $O$, displacement-metric row $D$, Cauchy-modulus row $M$, terminal seal $E$, map-stability row $S$, transport row $T$, handoff row $H$, replay row $C$, provenance row $P$, and local naming row $N$;
\item metric displacement visibility, requiring every orbit-decay read to expose the $\MetricUp$ distance row $D$ before it can be consumed as a real-valued displacement claim;
\item Cauchy-modulus routing, requiring $M$ to give the finite tolerance window through which the displacement sequence is inspected before $E$ is opened;
\item map-stability preservation, requiring $S,T,C$ to keep the orbit entries and displacement rows inside the same displayed map and metric source;
\item seal non-escape, requiring $E,P,N$ to export no host fixed-point theorem, ambient completeness, quotient orbit equality, selected limit, countable choice, or bridge-checking evidence.
\end{enumerate}
No local NameCert obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:asymptotic-regularity-carrier}. Carrier admission lists every row available to a consumer, so the orbit window, metric displacement, modulus, seal, stability, transport, handoff, replay, provenance, and local naming rows are the complete packet surface.

The analytic read begins with $O$ and $D$. A displacement claim has no separate host metric coordinate; it is read only from the displayed $\MetricUp$ row attached to the finite orbit window.

The tolerance step is $M$. It supplies the finite Cauchy window before the terminal Real seal $E$ is opened, while $S,T,C$ preserve the same map and orbit rows under stability, transport, and replay.

Finally $P,N$ source and name only this route. Since the carrier contains no coordinate for a host fixed point, ambient completeness, quotient orbit equality, selected limit, choice principle, or bridge certificate, the five listed rows exhaust the obligation surface.
\end{proof}
