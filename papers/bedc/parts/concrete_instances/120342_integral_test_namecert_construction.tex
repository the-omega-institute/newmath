\begin{theorem}[IntegralTest NameCert obligations]
\label{thm:integral-test-namecert-obligations}

\end{theorem}
\begin{proof}
Project the accepted carrier. The rows of \autoref{def:integral-test-carrier} are precisely the series source, monotone comparison function, finite windows, dyadic tolerances, regular readback, terminal seal, transport, replay, provenance, and local naming rows.

The comparison part is finite: $S$ exposes only inspected series tails, $F$ exposes only the monotone comparison data, $W$ names the windows, and $D$ names the dyadic budgets. The readback row $Q$ is therefore downstream of displayed tail and integral-cell data.

The terminal row $E$ can then be read only after $Q$ has been exposed. The structural rows $H,C,P,N$ transport, replay, source, and name the same route, so the local certificate contains exactly the listed obligations and no host summation or ambient completeness row.
\end{proof}
