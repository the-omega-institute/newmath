\begin{theorem}[CauchyContinuousMap bridge scope]
\label{thm:cauchy-continuous-map-bridge-scope}
Every public bridge-scope read of an accepted $\CauchyContinuousMapUp$ carrier $M=(W,R,D,E,H,C,P,N)$ factors through the finite Cauchy-name transformer boundary of \autoref{thm:cauchy-continuous-map-continuousmap-boundary}. \end{theorem}
\begin{proof}
Start with the carrier of \autoref{def:cauchy-continuous-map-carrier}. It exposes only the rows $W,R,D,E,H,C,P,N$, so any bridge-scope consumer has to use the same finite Cauchy-name transformer surface as the rest of the chapter.

Apply the continuous-map boundary theorem, \autoref{thm:cauchy-continuous-map-continuousmap-boundary}. It identifies the $\ContinuousMapUp$ side as a boundary row for the displayed Cauchy-name transformer, not as a host function or a full metric-continuity theorem.

The bridge scope therefore records exactly which rows face the standard boundary. Since the carrier has no coordinate for bridge checking, host functions, all-points metric continuity, detached moduli, quotient streams, selected limits, or ambient completeness, none of those claims is exported by this child route.
\end{proof}
