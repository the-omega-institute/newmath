\begin{definition}[Porous set carrier]
\label{def:porous-set-carrier}
A $\PorousSetUp$ carrier is a finite $\BHist$ packet
$$
P=(M,L,R,E,H,W,D,S,T,C,Q,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $M$ is the ambient $\MetricUp$ row, carrying the point classifier, distance classifier, and metric-distance ledger used by every hole request.
\item $L$ is the $\LocatedSetUp$ row naming the admitted subset and its distance-to-set readback surface.
\item $R$ is the terminal $\RealUp$ seal for distances, radii, and scale comparisons visible to the porous-set consumer.
\item $E$ is the $\FiniteEpsilonNetUp$ comparison row used only to expose finite center and tolerance windows around the inspected scale.
\item $H$ is the hole-schedule row. Each visible entry records a base point, an outer scale, a candidate hole center, an inner radius, and the finite witness that the named inner ball is disjoint from the located subset at the inspected tolerance.
\item $W$ is the finite window row for the base point, center point, outer-radius request, inner-radius request, and distance comparisons currently read by the consumer.
\item $D$ records the dyadic or rational comparison cells that witness the positive scale relation between the outer request and the inner hole.
\item $S$ records componentwise $\hsame$ transport for the metric source, located-set row, Real seal, finite-net comparison row, hole schedule, finite windows, comparison cells, replay, provenance, and local naming rows.
\item $T$ records displayed $\Cont$ replay from a porous-set query through $M,L,R,E,H,W,D,S,C,Q,N$.
\item $C$ is the $\Pkg$ provenance over $\PorousSetUp$, $\MetricUp$, $\LocatedSetUp$, $\RealUp$, $\FiniteEpsilonNetUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $Q$ is the local refusal ledger for measure, category, open-cover, selected-hole, and ambient-completion claims.
\item $N$ is the local $\NameCert_{\PorousSetUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $M,L,R,E,H,W,D,S,T,C,Q,N$. It has no coordinate for a measure-null theorem, Baire-category theorem, open-cover compactness proof, global hole selector, quotient subset equality, or ambient completeness of $\RealUp$.
\end{definition}

\begin{theorem}[Porous set NameCert obligations]
\label{thm:porous-set-namecert-obligations}
For every accepted $\PorousSetUp$ carrier $P=(M,L,R,E,H,W,D,S,T,C,Q,N)$, the local $\NameCert_{\PorousSetUp}$ surface consists exactly of ambient metric admission, located-set admission, Real distance seal handoff, finite epsilon-net comparison exposure, hole-schedule exposure, finite-window inspection, positive-scale comparison, componentwise transport, displayed replay, provenance, refusal-ledger recording, and local naming for the same finite packet.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:porous-set-carrier}. The analytic source rows are the ambient metric row $M$, the located-set row $L$, the Real seal $R$, and the finite epsilon-net comparison row $E$.

The hole data are finite. The schedule row $H$ names only the currently inspected base point, scale, hole center, inner radius, and disjointness witness, while $W$ restricts each read to the displayed finite window.

The comparison and structural rows then fix the same route. The row $D$ records the positive relation between outer scale and inner hole, and $S,T,C,N$ transport, replay, source, and name the packet.

Finally $Q$ records the refused exits. Since no carrier coordinate stores measure-nullness, Baire meagreness, open-cover compactness, a global selector for holes, quotient subset equality, or ambient Real completeness, the listed rows exhaust the local NameCert obligations.
\end{proof}

\begin{theorem}[Porous set metric hole route]
\label{thm:porous-set-metric-hole-route}
Every metric or located-set consumer of an accepted $\PorousSetUp$ packet reads porous-set hole data through the finite route
$$
\MetricUp,\ \LocatedSetUp,\ \RealUp,\ \FiniteEpsilonNetUp
\longmapsto

$$
Thus the consumer must first read the ambient metric row, located-set distance surface, Real distance seal, and finite epsilon-net comparison row before it can inspect a displayed hole schedule, finite window, and positive-scale comparison.
\end{theorem}
\begin{proof}
Start from a porous-set query. The ambient metric row $M$ supplies the point and distance observations, and the located-set row $L$ supplies the admitted subset boundary through the distance interface of \autoref{ch:concrete-instances-locatedset-namecert}.

The query next reaches the Real and finite-net rows. The seal $R$ carries the distance and radius readbacks, while $E$ exposes only the finite center and tolerance windows relevant to the inspected scale.

Only after those rows are displayed can the hole schedule be read. The rows $H,W,D$ name the base point, candidate center, inner radius, finite disjointness witness, finite observation window, and positive-scale comparison.

The structural rows $S,T,C,Q,N$ preserve the same route and record the refused exits. Therefore the exported hole datum is a finite metric route, not a measure theorem, category theorem, open-cover compactness proof, choice-selected family of holes, or ambient completeness principle.
\end{proof}
