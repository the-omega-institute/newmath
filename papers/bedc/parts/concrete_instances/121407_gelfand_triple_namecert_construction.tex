\begin{definition}[Gelfand triple carrier]
\label{def:gelfand-triple-carrier}
A $\GelfandTripleUp$ carrier is a finite $\BHist$ packet
$$

$$
with the following displayed rows:
\begin{enumerate}
\item $\Phi$ is the test carrier row. It records the finite test-function or finite-energy windows read from sibling packets such as $\SchwartzSpaceUp$ and $\SobolevSpaceUp$.
\item $H$ is the Hilbert carrier row. It records the inner-product and norm-facing readback surface through which $\Phi$ is interpreted as a dense Hilbert-facing test domain.
\item $D$ is the dual carrier row. It records the displayed $\DualSpaceUp$ or $\TemperedDistributionUp$ action rows that consume test windows from $\Phi$.
\item $I$ is the dense inclusion row $\Phi \to H$. It records that every Hilbert-facing read of the test carrier must pass through the displayed inclusion and its finite density ledger.
\item $J$ is the dual inclusion and pairing row $H \to D$. It records the pairing of a Hilbert row against a dual row only after the test row, Hilbert row, and dense inclusion row have been displayed.
\item $P$ is the $\Pkg$ provenance over $\GelfandTripleUp$, $\SobolevSpaceUp$, $\SchwartzSpaceUp$, $\TemperedDistributionUp$, $\DualSpaceUp$, $\HilbertUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\GelfandTripleUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $\Phi,H,D,I,J,P,N$. It has no coordinate for a host locally convex topology, unrestricted continuous dual, selected representative, spectral basis, countable-choice schedule, or ambient Hilbert-space completeness theorem.

\label{thm:gelfand-triple-namecert-obligations}

\begin{theorem}[Gelfand triple density sandwich]
\label{thm:gelfand-triple-density-sandwich}
Every Hilbert-facing consumer of an accepted $\GelfandTripleUp$ carrier must read the test row $\Phi$, the dense inclusion row $I$, and the Hilbert row $H$ before consuming any dual-facing row. Thus the packet exposes a finite density sandwich
$$
\Phi \longmapsto H \longmapsto D
$$

\end{theorem}
\begin{proof}
Project the accepted carrier. The only test row is $\Phi$, the only Hilbert row is $H$, and the only row connecting them is $I$.

Apply the NameCert obligations of \autoref{thm:gelfand-triple-namecert-obligations}. They place dense inclusion exposure before any dual-pairing exposure, so a Hilbert-facing read cannot skip directly to $D$.

The structural rows $P,N$ source and name the same ordered route. Therefore the public analytic shape available from the packet is the displayed density sandwich, not a host completion or quotient construction.
\end{proof}
