\begin{definition}[RegSeqRat functorial-map carrier]
\label{def:regseqrat-functorial-map-carrier}
A $\RegSeqRatFunctorialMapUp$ carrier is a finite $\BHist$ packet
$$
F=(M,S,Q,D,R,W,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $M$ is the $\ContinuousMapUp$ modulus-controlled map row, including the displayed input tolerance and output tolerance schedule.
\item $S$ is the source $\StreamNameUp$ finite-window row whose observations feed the map.
\item $Q$ is the source $\RegSeqRatUp$ regular-rational name row read through $S$.
\item $D$ is the $\DyadicRatCoreUp$ ledger recording the dyadic input and output budgets used by $M$.
\item $R$ is the terminal $\RealUp$ seal reached only after $M,S,Q,D$ have been displayed.
\item $W$ is the transported finite-window row listing the output observations certified by the modulus schedule.
\item $H$ records componentwise $\hsame$ transport for the map, source windows, source regular name, dyadic ledger, terminal seal, transported windows, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a regular Cauchy rational-name read through the modulus-controlled map and the transported output windows.
\item $P$ is the $\Pkg$ provenance over $\RegSeqRatFunctorialMapUp$, $\ContinuousMapUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\DyadicRatCoreUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\RegSeqRatFunctorialMapUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $M,S,Q,D,R,W,H,C,P,N$. It has no coordinate for quotient-stream equality, a selected representative, countable choice over moduli, host real equality, function extensionality, or ambient $\RealUp$ completeness.
\end{definition}

\begin{theorem}[RegSeqRat functorial-map NameCert obligations]
\label{thm:regseqrat-functorial-map-namecert-obligations}
For every accepted $\RegSeqRatFunctorialMapUp$ carrier $F=(M,S,Q,D,R,W,H,C,P,N)$, the local $\NameCert_{\RegSeqRatFunctorialMapUp}$ surface consists exactly of modulus-controlled map exposure, source $\StreamNameUp$ finite-window scheduling, source $\RegSeqRatUp$ regularity readback, $\DyadicRatCoreUp$ tolerance accounting, terminal $\RealUp$ sealing, transported output-window admission, componentwise transport, displayed continuation replay, package provenance, local naming, and ledger refusal for quotient streams, selected limits, countable choice over moduli, host real equality, function extensionality, and ambient completeness.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:regseqrat-functorial-map-carrier}. The accepted packet displays exactly the map row $M$, the source window row $S$, the source regular-rational row $Q$, the dyadic ledger $D$, the terminal seal $R$, and the transported output windows $W$.

The structural rows $H,C,P,N$ transport, replay, source, and name only those displayed rows. Thus every local certificate obligation is read through $M,S,Q,D,R,W,H,C,P,N$.

The refusal clauses are coordinate exclusions. Quotient streams, selected representatives, countable choice over moduli, host real equality, function extensionality, and ambient completeness are not rows of $F$, so the local NameCert cannot export them.
\end{proof}

\begin{theorem}[RegSeqRat functorial-map regularity preservation]
\label{thm:regseqrat-functorial-map-regularity-preservation}
Every Real-facing consumer of an accepted $\RegSeqRatFunctorialMapUp$ carrier receives the transported regular Cauchy rational name only through the finite route
$$
M,S,Q,D,W \longmapsto R,H,C,P,N .
$$
In particular, the output windows preserve the displayed regularity budget supplied by the $\ContinuousMapUp$ modulus and the $\DyadicRatCoreUp$ ledger before the terminal $\RealUp$ seal is read.
\end{theorem}
\begin{proof}
Start with the output-window row $W$. By the carrier definition, $W$ is admitted only after the modulus-controlled map $M$, the source windows $S$, the source regular-rational row $Q$, and the dyadic tolerance ledger $D$ have been displayed.

Read the continuation row $C$. It replays a regular Cauchy rational-name request through the same modulus schedule and dyadic budgets before the terminal seal $R$ is exposed.

Componentwise transport through $H$ preserves the displayed rows, and $P,N$ source and name only that packet. Hence the consumer obtains regularity preservation along the stated finite route, without quotienting names, selecting a limit, invoking choice over moduli, or importing ambient completeness.
\end{proof}
