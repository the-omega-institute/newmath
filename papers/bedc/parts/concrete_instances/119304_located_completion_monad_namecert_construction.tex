\begin{definition}[Located completion monad carrier]
\label{def:located-completion-monad-carrier}
A $\LocatedCompletionMonadUp$ carrier is a finite $\BHist$ packet
$$
Q=(L,M,U,J,S,R,D,E,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $L$ is the $\LocatedCompletionUp$ source row, including the displayed located-completion route consumed before any monad operation is public.
\item $M$ is the $\CauchyCompletionMonadUp$ row naming the finite completion transformer and its schedule discipline.
\item $U$ is the unit row, sending source located data to the completion-facing packet through displayed windows and regular rational readback.
\item $J$ is the join row, flattening a completion-of-completion read by replaying the same located completion and Cauchy-completion schedules.
\item $S$ is the $\StreamNameUp$ finite-window row used by both unit and join reads.
\item $R$ is the $\RegSeqRatUp$ readback row attached to the displayed stream windows.
\item $D$ is the $\DyadicRatCoreUp$ tolerance ledger controlling requested precision, located comparison, and replay.
\item $E$ is the terminal $\RealUp$ seal reached only after $L,M,U,J,S,R,D$ have been displayed.
\item $H$ records componentwise $\hsame$ transport for the located completion, monad, unit, join, stream, readback, dyadic, Real-seal, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ routes from a completion request through the same ordered rows.
\item $P$ is the $\Pkg$ provenance over $\LocatedCompletionMonadUp$, $\LocatedCompletionUp$, $\CauchyCompletionMonadUp$, $\CauchyCompletionMonadLawUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\DyadicRatCoreUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\LocatedCompletionMonadUp}$ row.
\end{enumerate}
The classifier compares accepted carriers only through $L,M,U,J,S,R,D,E,H,C,P,N$. It has no coordinate for quotient completion equality, selected limits, host equality of completed points, countable choice, or ambient $\RealUp$ completeness.
\end{definition}

\begin{theorem}[Located completion monad NameCert obligations]
\label{thm:located-completion-monad-namecert-obligations}
For every accepted $\LocatedCompletionMonadUp$ carrier $Q=(L,M,U,J,S,R,D,E,H,C,P,N)$, the local $\NameCert_{\LocatedCompletionMonadUp}$ surface consists exactly of carrier admission for the twelve displayed rows, located-source visibility through $L$, completion-monad visibility through $M$, unit visibility through $U$, join visibility through $J$, $\StreamNameUp$ window preservation through $S$, $\RegSeqRatUp$ readback preservation through $R$, $\DyadicRatCoreUp$ tolerance preservation through $D$, $\RealUp$ seal preservation through $E$, componentwise transport through $H$, displayed replay through $C$, provenance through $P$, and local naming through $N$. The carrier exports no quotient completion, selected limit, countable-choice schedule, host equality of completed points, or ambient $\RealUp$ completeness row.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:located-completion-monad-carrier}. The analytic rows are the located completion source $L$, the Cauchy completion monad row $M$, the unit and join rows $U,J$, the finite stream windows $S$, the regular rational readback $R$, the dyadic tolerance ledger $D$, and the Real seal $E$.

Read the unit route first. A source located-completion request must display $L$ and $M$, then pass through the same $S,R,D$ readback discipline before the terminal seal $E$ is visible.

Read the join route next. A completion-of-completion request is flattened only by replaying the displayed unit and monad schedules through $J$, with the StreamName windows, regular readback, dyadic tolerances, and Real seal preserved as the same finite rows.

Finally attach $H,C,P,N$. These rows transport, replay, source, and name the displayed packet, and none supplies quotient completion equality, selected limits, countable choice, host equality, or ambient Real completeness. Hence the listed rows exhaust the local NameCert obligations.
\end{proof}

\begin{theorem}[Located completion monad unit exactness]
\label{thm:located-completion-monad-unit-exactness}
For every accepted $\LocatedCompletionMonadUp$ carrier
$Q=(L,M,U,J,S,R,D,E,H,C,P,N)$, every unit read through $U$ exposes the located
completion source row $L$, the Cauchy completion monad row $M$, the shared
finite-window row $S$, the regular rational readback row $R$, the DyadicRatCore
tolerance row $D$, and the Real seal row $E$ before the local
$\NameCert_{\LocatedCompletionMonadUp}$ row is read. In particular, the unit
route is the displayed finite route
$$
L,M \longmapsto U \longmapsto S,R,D \longmapsto E,H,C,P,N ,
$$
not a selected limit, quotient completion equality, countable-choice schedule,
or ambient completeness premise.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:located-completion-monad-carrier}. The
unit row $U$ is not independent data; it is listed between the source rows
$L,M$ and the finite readback rows $S,R,D,E$.

A unit request therefore first displays the located completion source and the
completion-monad row. It can then read $U$ only as the route that sends those
source rows into the shared StreamName, RegSeqRat, and DyadicRatCore corridor.

The Real seal and local certificate are terminal for the unit route. The rows
$E,H,C,P,N$ preserve, replay, source, and name the same displayed packet, and
none supplies a quotient, selected limit, choice schedule, host equality, or
ambient completeness coordinate.
\end{proof}

$$

\begin{proof}

Finally the structural rows close the route without adding new analytic data.

selector, choice schedule, host equality, or ambient completeness premise is
