\begin{theorem}[LowerSemicontinuous epigraph public export]
\label{thm:lowersemicontinuous-epigraph-public-export}
Every public lower-semicontinuity read from an accepted $\LowerSemicontinuousUp$ packet is exported through the finite route
$$
X,F,W,R,E,O,H,C,P,N .
$$
The export combines the root epigraph basis, located readback route, transport replay, and terminal $\RealUp$ seal boundary. It is a public BEDC NameCert route over displayed $\BHist$, $\StreamNameUp$, $\RegSeqRatUp$, $\LowerRealUp$, $\LocatedRealUp$, $\hsame$, $\Cont$, $\Pkg$, and local $\NameCert$ rows, not a semantic topology theorem, host liminf operator, quotient-real equality, countable-choice schedule, compactness principle, or ambient completeness assertion.
\end{theorem}
\begin{proof}
Start with the root epigraph basis of \autoref{thm:lowersemicontinuous-root-epigraph-basis}. It identifies the consumer-visible lower-real basis as the finite source, graph, schedule, readback, epigraph, comparison, transport, replay, provenance, and naming route.

Apply located readback and transport compatibility, using \autoref{thm:lowersemicontinuous-root-located-readback} together with \autoref{thm:lowersemicontinuous-located-epigraph-transport-induction}. These results keep each lower-bound read on the same $W,R,E,O,H,C,P,N$ path when it is transported or replayed.

Finally use the Real-seal exhaustion results, \autoref{thm:lowersemicontinuous-real-seal-window-exhaustion} and \autoref{thm:lowersemicontinuous-root-nonescape}. They force the public endpoint through the terminal $\RealUp$ seal boundary while excluding host topology, semantic liminf data, quotient real equality, countable choice, compactness, and ambient completeness. The exported statement is therefore the finite NameCert route above.
\end{proof}

\begin{theorem}[LowerSemicontinuous finite threshold epigraph route]
\label{thm:lower-semicontinuous-epigraph-finite-threshold-route}
Every lower-bound threshold consumed by the public epigraph route of an accepted $\LowerSemicontinuousUp$ packet must pass through the displayed
$$
X,F,W,R,E,O,H,C,P,N
$$
packet before any lower-semicontinuity consumer may read it. The route exposes the $\StreamNameUp$ window row $W$, the $\RegSeqRatUp$ readback row $R$, the $\LowerRealUp$ and $\LocatedRealUp$ comparison rows $E,O$, and the terminal $\RealUp$ seal row before the threshold becomes consumer-visible. The consumer receives a finite epigraph threshold route, not a host liminf operator, quotient-real equality, countable-choice schedule, compactness principle, or ambient completeness assertion.
\end{theorem}
\begin{proof}
Start with \autoref{thm:lowersemicontinuous-root-epigraph-basis}. It fixes the public threshold as a row of the same source, graph, schedule, readback, epigraph, comparison, transport, replay, provenance, and naming packet.

Use \autoref{thm:lowersemicontinuous-root-located-readback} to make the threshold readable only through the displayed $\StreamNameUp$ window and $\RegSeqRatUp$ readback rows. Then apply \autoref{thm:lowersemicontinuous-located-epigraph-transport-induction}; transport keeps the $\LowerRealUp$ and $\LocatedRealUp$ comparison rows on the same $X,F,W,R,E,O,H,C,P,N$ route.

Finally apply \autoref{thm:lowersemicontinuous-real-seal-window-exhaustion}. Coordinate exhaustion leaves only the displayed window, readback, comparison, terminal seal, transport, replay, provenance, and naming rows, so a consumer cannot recover host liminf data, quotient-real equality, countable choice, compactness, or ambient completeness.
\end{proof}
