\begin{theorem}[Hankel operator NameCert obligations]
\label{thm:hankel-operator-namecert-obligations}
For every accepted $\HankelOperatorUp$ carrier $K=(M,I,A,S,B,H,C,P,N)$, the local $\NameCert_{\HankelOperatorUp}$ surface consists exactly of these finite obligations:
\begin{enumerate}
\item carrier admission for the moment rows, finite index window, anti-diagonal matrix row, shift row, boundedness ledger, transport, replay, provenance, and local name;
\item moment-window exactness, requiring every entry of $A$ to be read from $M$ using an index named by $I$;
\item anti-diagonal exactness, requiring the displayed $\MatrixUp$ row to depend only on the visible sum index $i+j$;
\item shift-moment stability, requiring the row $S$ to transport moment-window reads without adding an unlisted source or target index;
\item boundedness nonescape, requiring $B$ to expose only finite inner-product, norm, or tolerance rows and no ambient bounded-operator theorem;
\item componentwise transport, displayed replay, package provenance, and local naming through $H,C,P,N$.
\end{enumerate}
No Hankel obligation is stored outside this finite packet.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:hankel-operator-carrier}. The visible rows are exactly $M,I,A,S,B,H,C,P,N$.

Moment-window exactness and anti-diagonal exactness read $M,I,A$ together. The matrix row is admitted only when each displayed entry uses a visible moment row at the displayed sum index.

Shift-moment stability is the row $S$. It reuses the same finite index and moment data under the displayed source-target shift, while $H$ and $C$ transport and replay only those rows.

The boundedness and nonescape clauses follow from $B,P,N$. The provenance row names the moment, collision-kernel, matrix, inner-product, and real scalar sources, and the local naming row contains no coordinate for an infinite operator, spectral object, representing measure, selected completion, or host Hilbert-space equality.
\end{proof}
