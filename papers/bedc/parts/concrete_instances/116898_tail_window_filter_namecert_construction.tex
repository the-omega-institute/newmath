\label{thm:tail-window-filter-cofinality}

\begin{proof}

The comparison that the window lies beyond the request is recorded in $D$. The stream source $S$ names the finite observations used by that comparison, and $R$ is read only after those rows have been displayed.

Transport through $H$ moves the request, window, dyadic comparison, stream row, and readback row componentwise. Replay through $C$ follows the same displayed route, so cofinality remains a finite tail-window property.
