\label{thm:polyhedral-cone-namecert-obligations}

Finally inspect the refused coordinates. No row contains Hahn--Banach extension, strong separation, selected optimizers, quotient dual spaces, topological closure, ambient bidual identification, or choice, so the local NameCert cannot project any such object.
