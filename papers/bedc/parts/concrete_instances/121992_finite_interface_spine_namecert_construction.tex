\begin{definition}[Finite interface spine carrier]
\label{def:finite-interface-spine-carrier}
A $\FiniteInterfaceSpineUp$ carrier is a finite $\BHist$ packet
$$
F=(B,O,S,P,L,H,C,Q,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $B$ is the $\BoolUp$ endpoint row, naming the two visible truth tags.
\item $O$ is the $\OptionUp$ nullable row, naming absence and displayed presence over the admitted carrier.
\item $S$ is the $\SumUp$ branch row, naming left and right injections with their branch tags.
\item $P$ is the $\ProdUp$ pair row, naming first and second projections as displayed components.
\item $L$ is the $\ListUp$ finite sequence row, naming nil, cons, length, and component readback ledgers.
\item $H$ records componentwise $\hsame$ transport for all five finite-data rows and the structural rows.
\item $C$ records displayed $\Cont$ replay from finite-data requests through $B,O,S,P,L$.
\item $Q$ is the $\Pkg$ provenance over $\FiniteInterfaceSpineUp$, $\BoolUp$, $\OptionUp$, $\SumUp$, $\ProdUp$, $\ListUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\FiniteInterfaceSpineUp}$ row.
\end{enumerate}
The carrier is an interface spine only. It has no coordinate for a host finite-type universe, an external eliminator, quotient equality of displayed finite objects, or a new BEDC kernel constructor.
\end{definition}

\begin{theorem}[Finite interface spine NameCert obligations]
\label{thm:finite-interface-spine-namecert-obligations}
For every accepted $\FiniteInterfaceSpineUp$ carrier $F=(B,O,S,P,L,H,C,Q,N)$, the local $\NameCert_{\FiniteInterfaceSpineUp}$ surface consists exactly of carrier admission for the displayed five finite-data rows, constructor exposure for the Boolean, option, sum, product, and list interfaces, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:finite-interface-spine-carrier}. The rows $B,O,S,P,L$ are the only finite-data rows available to an accepted packet.

Each constructor surface is inherited from its displayed sibling row. Boolean reads use the endpoint row $B$; option reads use the absent-or-present row $O$; sum reads use the branch row $S$; product reads use the projection row $P$; and list reads use the nil, cons, length, and component ledgers in $L$.

The structural rows $H,C,Q,N$ transport, replay, source, and name only those displayed rows. Since the carrier has no host finite-type universe, external eliminator, quotient equality, or kernel constructor coordinate, the listed rows exhaust the local NameCert obligations.
\end{proof}
