\begin{definition}[Arzela--Ascoli finite-net carrier]
\label{def:arzela-ascoli-finite-net-carrier}
An $\ArzelaAscoliFiniteNetUp$ carrier is a finite $\BHist$ packet
$$
A=(K,M,C,T,E,R,W,H,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $K$ is the compact source row, read through the $\CompactUp$ and $\CompactMetricUp$ certificates.
\item $M$ is the $\MetricUp$ distance row used by finite-net comparisons on the source.
\item $C$ is the finite $\ContinuousUp$ or $\ContinuousMapUp$ family row whose values are inspected only through displayed pointwise windows.
\item $T$ is the $\TotallyBoundedUp$ finite-net ledger of centers, membership rows, distance witnesses, and refinement data.
\item $E$ is the $\EquicontinuityUp$ shared tolerance-radius row for the same family and source.
\item $R$ is the $\RealUp$ value-readback row used for displayed pointwise distances and oscillation bounds.
\item $W$ is the finite extraction window row, recording which center values and tolerance budgets are exposed to a completion or compactness-facing consumer.
\item $H$ records componentwise $\hsame$ transport for the compact, metric, continuity, total-bounded, equicontinuity, Real, window, provenance, and local naming rows.
\item $P$ is the $\Pkg$ provenance over $\ArzelaAscoliFiniteNetUp$, $\CompactUp$, $\MetricUp$, $\ContinuousUp$, $\TotallyBoundedUp$, $\RealUp$, $\EquicontinuityUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$ rows.
\item $N$ is the local $\NameCert_{\ArzelaAscoliFiniteNetUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $K,M,C,T,E,R,W,H,P,N$. It has no coordinate for open-cover compactness, host function-space topology, quotient equality of maps, selected subsequences, countable choice, or ambient Real completeness.
\end{definition}

\begin{theorem}[Arzela--Ascoli finite-net NameCert obligations]
\label{thm:arzela-ascoli-finite-net-obligations}
For every accepted $\ArzelaAscoliFiniteNetUp$ carrier $A=(K,M,C,T,E,R,W,H,P,N)$, the local $\NameCert_{\ArzelaAscoliFiniteNetUp}$ surface consists exactly of carrier admission for the displayed compact source, metric row, continuous-family row, total-bounded finite-net ledger, equicontinuity modulus row, Real value-readback row, extraction window, componentwise transport, provenance, and local naming; finite-net compatibility requiring $T$ to be read before $W$; equicontinuity compatibility requiring $E$ to be read before the extracted window is consumed; Real readback exactness requiring $R$ to remain attached to the displayed pointwise values; and nonescape excluding open-cover compactness, selected subsequences, quotient function equality, countable choice, and ambient completeness.
\end{theorem}
\begin{proof}
Carrier admission is projection from \autoref{def:arzela-ascoli-finite-net-carrier}. The accepted packet displays exactly $K,M,C,T,E,R,W,H,P,N$, so every local obligation must be read from those rows.

The finite-net compatibility row is $T$. It supplies centers, membership rows, distance witnesses, and refinement data before the extraction window $W$ can expose any finite sample of the family.

The equicontinuity compatibility row is $E$. Its shared tolerance-radius handoff is read after the continuous-family row $C$ and before $W$, so the extracted window is controlled by the same family modulus rather than by memberwise radius choices.

Real readback exactness is the role of $R$. The value comparisons consumed by $W$ remain terminal real-name reads for displayed pointwise data, not quotient equality of functions or a host supremum.

Finally $H,P,N$ transport, source, and name only the displayed rows. Since no row stores open-cover compactness, selected subsequences, quotient function equality, countable choice, or ambient completeness, the listed obligations exhaust the local NameCert surface.
\end{proof}
