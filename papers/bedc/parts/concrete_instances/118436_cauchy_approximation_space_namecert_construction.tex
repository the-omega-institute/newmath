\begin{proof}

Read the RegSeqRat row through that shared window. Since $R$ is a carrier coordinate and not a hidden tail selector, the readback available to a retained request is the same regular rational source row on both carriers.

Finally replay the support rows. The $\hsame$ row identifies the displayed coordinates, $\Cont$ repeats the same route, and $P,N$ package and name that route without adding quotient stream equality, a selected limit, host real equality, or an ambient completeness principle.
