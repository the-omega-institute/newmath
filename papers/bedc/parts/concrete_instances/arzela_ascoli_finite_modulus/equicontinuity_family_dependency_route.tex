\begin{theorem}[Arzela--Ascoli EquicontinuityFamily dependency route]
\label{thm:arzela-ascoli-equicontinuity-family-dependency-route}
Every finite-modulus extraction read from an accepted $\ArzelaAscoliFiniteModulusUp$ carrier consumes the family-level ledger of \autoref{ch:concrete-instances-equicontinuityfamily-namecert} before any selector row is exported. The route then passes through the $\CompactUniformContinuityUp$ finite-modulus handoff, the compact metric source row, the continuous-map family row, the finite $\StreamNameUp$ window row, the $\RegSeqRatUp$ readback row, the $\DyadicRatCoreUp$ tolerance ledger, and the terminal $\RealUp$ seal. It exports no selected subsequence, host function-space compactness, quotient equality of real names, ambient $\RealUp$ completeness, or selector row detached from the family ledger.
\end{theorem}
\begin{proof}
Project the accepted carrier $A=(K,F,M,W,R,E,H,C,P,N)$. The continuous-map family row $F$ is not a bare list of maps: it is read as the family surface whose shared modulus and common finite-window obligations are supplied by $\EquicontinuityFamilyUp$.

Apply \autoref{thm:arzela-ascoli-finite-modulus-equicontinuity-dependency-route}. It already forces the finite-modulus extraction through the equicontinuity ledger, compact-uniform-continuity handoff, compact source, continuous-map rows, windows, readback, and terminal Real seal before selector output becomes public.

It remains to name the family-level source. The sibling \autoref{ch:concrete-instances-equicontinuityfamily-namecert} supplies the displayed family ledger consumed by $F$ and $M$, while \autoref{ch:concrete-instances-compactuniformcontinuity-namecert} supplies the finite-modulus handoff consumed after that ledger is visible.

Therefore a selector-facing consumer cannot bypass $\EquicontinuityFamilyUp$. The rows $H,C,P,N$ preserve only the same displayed carrier, so no selected subsequence, host function-space compactness, quotient real equality, ambient completeness, or detached selector coordinate is exported.
\end{proof}
