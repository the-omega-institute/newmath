\begin{theorem}[Arzela--Ascoli finite-modulus equicontinuity dependency route]
\label{thm:arzela-ascoli-finite-modulus-equicontinuity-dependency-route}
Every finite-modulus extraction read from an accepted $\ArzelaAscoliFiniteModulusUp$ carrier factors through the $\EquicontinuityFamilyUp$ ledger, the $\CompactUniformContinuityUp$ finite-modulus handoff, the $\CompactMetricUp$ source row, the $\ContinuousMapUp$ family row, the $\StreamNameUp$ window row, the $\RegSeqRatUp$ readback row, and the terminal $\RealUp$ seal before any selector output is public. The route exports no selected subsequence, host function-space compactness, quotient real equality, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Project the accepted carrier $A=(K,F,M,W,R,E,H,C,P,N)$. The compact metric row $K$, continuous-map family row $F$, finite modulus row $M$, window row $W$, regular-rational readback row $R$, and seal row $E$ are the whole analytic surface available before a selector can read output.

Apply \autoref{thm:arzela-ascoli-finite-modulus-forward-lattice}. It places every downstream selector read through the compact metric, continuous-map, finite common modulus, window, readback, Real seal, and dyadic tolerance rows.

Use the sibling routes of \autoref{ch:concrete-instances-equicontinuity-namecert} and \autoref{ch:concrete-instances-compactuniformcontinuity-namecert}. The equicontinuity family supplies the shared finite family ledger, while compact uniform continuity supplies the finite-modulus handoff consumed by the selector surface.

Finally use \autoref{thm:arzela-ascoli-finite-modulus-compact-uniform-repair}. It identifies the compact-uniform-continuity consumer as the same finite selector route, so selector output cannot become public before the listed dependency rows are displayed.
\end{proof}
