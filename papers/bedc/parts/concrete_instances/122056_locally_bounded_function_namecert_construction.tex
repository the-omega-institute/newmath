\begin{definition}[Locally bounded function carrier]
\label{def:locally-bounded-function-carrier}
A $\LocallyBoundedFunctionUp$ carrier is a finite $\BHist$ packet
$$
L=(K,F,V,B,W,R,D,A,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $K$ is the local source-window row, naming the finite neighborhood or bounded source portion on which the read is inspected.
\item $F$ is the $\ContinuousMapUp$ row whose graph or evaluation interface supplies the function read on $K$.
\item $V$ is the $\RealUp$ value-read row exposed by the function on the displayed source window.
\item $B$ is the finite bound row, recording the displayed local upper budget against which the value read is compared.
\item $W$ is the $\StreamNameUp$ window row opened for the source inspection, value read, and bound request.
\item $R$ is the $\RegSeqRatUp$ readback row for the rational observations used by $V$ and $B$.
\item $D$ is the $\DyadicRatCoreUp$ tolerance row, carrying the dyadic scale, slack, and comparison budget for the local bound.
\item $A$ is the terminal $\RealUp$ seal reached only after $K,F,V,B,W,R,D$ have been displayed.
\item $H$ records componentwise $\hsame$ transport for the local source window, continuous-map read, value row, finite bound, StreamName, RegSeqRat, DyadicRatCore, Real seal, replay, provenance, and naming rows.
\item $C$ records displayed $\Cont$ replay through
$$
K\longrightarrow F\longrightarrow V\longrightarrow B\longrightarrow W\longrightarrow R\longrightarrow D\longrightarrow A .
$$
\item $P$ is the $\Pkg$ provenance over $\LocallyBoundedFunctionUp$, $\ContinuousMapUp$, $\RealUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\DyadicRatCoreUp$, $\BoundedFunctionFamilyUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\LocallyBoundedFunctionUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $K,F,V,B,W,R,D,A,H,C,P,N$. It has no coordinate for an ambient function space, a selected global bound, quotient equality of functions, countable choice, ambient $\RealUp$ completeness, or bridge checking.
\end{definition}

\begin{theorem}[Locally bounded function NameCert obligations]
\label{thm:locally-bounded-function-namecert-obligations}

The value-bound obligation is supplied by $V,B,R,D$. The Real value and finite bound are exposed through regular rational readback and dyadic tolerance comparison before the terminal Real seal can be reached.

Finally, $H,C,P,N$ transport, replay, source, and name the same route. Since the carrier has no rows for ambient completeness, host function-space equality, selected global bounds, quotient equality, countable choice, or bridge checking, the listed obligations exhaust the local NameCert surface.
