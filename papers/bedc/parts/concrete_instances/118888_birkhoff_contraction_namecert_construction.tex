\begin{theorem}[Birkhoff contraction NameCert obligations]
\label{thm:birkhoff-contraction-namecert-obligations}
For every accepted $\BirkhoffContractionUp$ carrier $B=(V,K,M,\Delta,T,\tau,R,E,H,C,P,N)$, the local $\NameCert_{\BirkhoffContractionUp}$ surface consists exactly of these finite obligation rows:
\begin{enumerate}
\item carrier admission for the vector source, positive cone, Hilbert projective metric row, finite image-diameter ledger, positive operator row, contraction-budget row, rational readback, terminal real seal, transport, replay, provenance, and local naming row;
\item common-cone discipline, requiring $K,M,\Delta,T,\tau$ to be read over the same displayed positive cone and vector-space source;
\item budget exactness, requiring the contraction estimate to pass through the diameter ledger $\Delta$, the budget row $\tau$, the regular readback $R$, and the real seal $E$;
\item replay stability, requiring transport and continuation rows $H,C$ to preserve the same budget route before $P,N$ name the packet;
\item ledger refusal, excluding selected fixed points, eigenvectors, projective quotient representatives, host compactness, completed cones, and Perron--Frobenius conclusions.
\end{enumerate}
No local NameCert obligation is stored outside those rows.
\end{theorem}
\begin{proof}

Since the carrier has no coordinate for a selected eigenvector, projective quotient representative, host fixed point, compactness theorem, completed cone, or Perron--Frobenius conclusion, the listed rows exhaust the local NameCert surface.
\end{proof}
