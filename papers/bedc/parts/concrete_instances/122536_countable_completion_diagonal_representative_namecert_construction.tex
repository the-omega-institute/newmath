Finally $H,C,P,N$ transport, replay, source, and name the same rows. Since the carrier has no coordinate for quotient stream equality, selected completed limits, countable choice, host real equality, ambient completeness, or bridge checking, the five rows exhaust the local NameCert surface.
\end{proof}
