\begin{definition}[Schwartz distribution carrier]\label{def:schwartz-distribution-carrier}
A $\SchwartzDistributionUp$ carrier is a finite $\BHist$ packet
$$
D=(S,T,A,W,Q,E,L,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $S$ is the $\SchwartzFunctionUp$ test-window row. It records the rapidly decreasing smooth windows, derivative orders, polynomial-weight labels, and finite observation domains visible to the packet.
\item $T$ is the $\TestFunctionUp$ compact-support row. It records the compact test windows through which local reads may be compared with the Schwartz-function row.
\item $A$ is the response-ledger row. It lists the finite action values assigned to the displayed test windows and records which response belongs to which test-window request.
\item $W$ is the test-window coverage row. It records that every public action read names a test window in $S$ or $T$ before any scalar response in $A$ is exposed.
\item $Q$ is the $\RegSeqRatUp$ readback row for rational approximations to the finite response ledger.
\item $E$ is the $\RealUp$ scalar seal row reached only after the corresponding rational readback in $Q$ has been displayed.
\item $L$ is the local classifier row. It admits two packets together exactly when their Schwartz windows, compact-support windows, response ledger, coverage row, rational readback, and Real seal match componentwise.
\item $H$ records componentwise $\hsame$ transport for $S,T,A,W,Q,E,L$.
\item $C$ records displayed $\Cont$ replay from a distribution-action request through $S,T,W,A,Q,E,L,H$ in that order.
\item $P$ is the $\Pkg$ provenance over $\SchwartzDistributionUp$, $\SchwartzFunctionUp$, $\TestFunctionUp$, $\TemperedDistributionUp$, $\DistributionDerivativeUp$, $\RegSeqRatUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\SchwartzDistributionUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through these eleven rows. It has no coordinate for the full locally convex dual, measure completion, quotient distribution equality, Fourier transform completeness, selected representatives, countable choice, or ambient $\RealUp$ completeness.
\end{definition}

\begin{theorem}[Schwartz distribution NameCert obligations]\label{thm:schwartz-distribution-namecert-obligations}
For every accepted $\SchwartzDistributionUp$ carrier $D=(S,T,A,W,Q,E,L,H,C,P,N)$, the local $\NameCert_{\SchwartzDistributionUp}$ surface consists exactly of carrier admission for the displayed test-window rows, response-ledger rows, test-window coverage, rational readback, Real scalar sealing, local classification, componentwise $\hsame$ transport, displayed $\Cont$ replay, package provenance, and local naming.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:schwartz-distribution-carrier}. The rows $S,T,A,W,Q,E,L,H,C,P,N$ are the whole visible packet, so every local obligation starts from one of those displayed rows.

The test-window obligations are the rows $S,T,W$. The row $S$ exposes Schwartz-function windows, $T$ exposes compact-support test windows, and $W$ records that a public action read first names one of those windows.

The response obligations are the rows $A,Q,E$. The response ledger $A$ stores only finite action values for displayed windows, $Q$ gives their regular-rational readback, and $E$ supplies the terminal Real scalar seal after the readback has been opened.

Finally, $L,H,C,P,N$ compare, transport, replay, source, and name the same finite distribution-action surface. Since the carrier has no row for a full locally convex dual, measure completion, Fourier transform completeness, quotient distribution equality, selected representatives, or countable choice, none of those objects belongs to the local NameCert surface.
\end{proof}

\begin{theorem}[Schwartz distribution test-window nonescape]\label{thm:schwartz-distribution-test-window-nonescape}
Every $\TemperedDistributionUp$, $\DistributionDerivativeUp$, or $\RealUp$ consumer of an accepted $\SchwartzDistributionUp$ packet receives a scalar action only through the finite route
$$
S,T\longmapsto W\longmapsto A\longmapsto Q\longmapsto E\longmapsto L,H,C,P,N .
$$
Thus no consumer can extract a response without first displaying a Schwartz or compact-support test window, and no consumer can extract the full locally convex dual, measure-theoretic distribution data, Fourier transform completeness, quotient distribution equality, selected representatives, or ambient $\RealUp$ completeness from the packet.
\end{theorem}
\begin{proof}
Start with an accepted carrier and apply \autoref{thm:schwartz-distribution-namecert-obligations}. The theorem identifies the visible rows and in particular forces every response read to pass through the coverage row $W$.

The route to a scalar response is then fixed. A consumer reads either the Schwartz-function window $S$ or the compact-support test row $T$, checks the coverage row $W$, and only then reads the response ledger $A$.

The numeric endpoint remains downstream of $A$. The regular-rational readback $Q$ and Real seal $E$ expose scalar names for the displayed response, while $L,H,C,P,N$ only compare, transport, replay, source, and name the same route.

Because the carrier inventory contains no dual-space coordinate, no measure-completion coordinate, no Fourier-completeness coordinate, no quotient-distribution equality, and no selected representative, the finite route cannot export those principles to tempered-distribution, derivative, or Real-facing consumers.
\end{proof}
