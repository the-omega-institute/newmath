\begin{definition}[CotransitiveApartness carrier]
\label{def:cotransitive-apartness-carrier}

$$

$$
with the following displayed rows:
\begin{enumerate}
\item $A$ is the $\MetricApartnessUp$ source row, exposing the positive-distance apartness read already certified by the metric apartness sibling.
\item $O$ is the $\RealApartnessOrderBridgeUp$ order-facing handoff row, used only to read the finite positive-radius comparison cell exported by the real apartness bridge.
\item $L$ is the $\LocatedMetricSpaceUp$ located-distance row that supplies the dyadic tolerance windows through which intermediate point requests are inspected.
\item $M$ is the $\MetricUp$ metric-source row shared by the endpoint and intermediate-point observations.
\item $R$ is the $\RealUp$ real-seal row reached by the displayed positive-radius and located-distance reads.
\item $W$ is the finite cotransitivity witness row. For an accepted apartness read between displayed endpoints and a displayed intermediate point request, it stores the finite branch data saying that the request is routed to the left endpoint or to the right endpoint through the rows above.
\item $H$ records componentwise $\hsame$ transport for the apartness source, real-order bridge, located metric-space row, metric source, real seal, cotransitivity witness, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from an apartness request through $A,O,L,M,R,W,H,P,N$.
\item $P$ is the $\Pkg$ provenance over $\CotransitiveApartnessUp$, $\MetricApartnessUp$, $\RealApartnessOrderBridgeUp$, $\LocatedMetricSpaceUp$, $\MetricUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.

The carrier has no coordinate for real trichotomy, quotient apartness, host inequality, selected representatives, or completeness.
\end{definition}

\begin{proof}

The intermediate request is inspected through the located metric-space row $L$ and the shared metric source $M$. These rows provide finite tolerance windows and metric observations before the branch row can be read.
