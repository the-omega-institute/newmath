\begin{definition}[Endpoint bisection certificate carrier]
\label{def:endpoint-bisection-certificate-carrier}
An $\EndpointBisectionCertificateUp$ carrier is a finite $\BHist$ packet
$$
B=(I,\beta,R,S,L,H,K,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $I$ is the RHRoute endpoint-interval row, carrying an endpoint dyadic interval and its finite diameter data.
\item $\beta$ is the branch-choice row, listing the finite lower/upper decisions used by endpoint replay.
\item $R$ is the replay row, computing the endpoint interval reached by the displayed branch list.
\item $S$ is the preservation row, recording the depth, width, and endpoint-location invariants kept by replay.
\item $L$ is the local half-split handoff row, available only after $I,\beta,R,S$ have been displayed.
\item $H$ stores componentwise $\hsame$ transport for the endpoint interval, branch list, preservation row, local half-split row, provenance, and local name.
\item $K$ stores displayed $\Cont$ replay from endpoint reads through the branch and preservation rows before any RHRoute conclusion is consumed.
\item $P$ records $\Pkg$ provenance over $\EndpointBisectionCertificateUp$, RHRoute endpoint intervals, branch choices, preservation rows, $\LocalHalfSplitCertificateUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\EndpointBisectionCertificateUp}$ row.
\end{enumerate}
The carrier has no coordinate for a global RH conclusion, a selected zero, a quotient over endpoint models, parity tower equality, oriented triadic equivalence, or zero-recursor cover boundary replacement.
\end{definition}

\begin{theorem}[Endpoint bisection certificate NameCert surface]
\label{thm:endpoint-bisection-certificate-namecert-surface}
For every accepted $\EndpointBisectionCertificateUp$ carrier $B=(I,\beta,R,S,L,H,K,P,N)$, the local $\NameCert_{\EndpointBisectionCertificateUp}$ surface consists exactly of endpoint interval admission, branch-choice admission, replay determinacy, preservation visibility, local half-split handoff, componentwise transport, displayed continuation replay, provenance, and local naming. Any endpoint-bisection read that omits one of $I,\beta,R,S,L,H,K,P,N$ is outside the carrier surface.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:endpoint-bisection-certificate-carrier}. The analytic rows are the endpoint interval $I$, branch list $\beta$, replay row $R$, preservation row $S$, and local half-split handoff $L$.

Read the rows in dependency order. Replay depends on the displayed branch list, preservation is recorded only for the replayed interval, and the local half-split handoff is available only after replay and preservation have both been displayed.

The structural rows $H,K,P,N$ transport, replay, source, and name the same packet. Since no coordinate carries a global RH conclusion, selected zero, quotient endpoint model, parity tower equality, oriented triadic equivalence, or zero-recursor cover boundary replacement, the listed rows exhaust the local NameCert surface.
\end{proof}

The carrier omits global RH conclusions, zero selectors, quotient endpoint models, parity tower equality, oriented triadic equivalence, and zero-recursor cover replacement. Therefore every accepted RHRoute handoff remains the displayed finite endpoint-bisection route.
\end{proof}
