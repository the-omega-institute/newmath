\begin{theorem}[Metric completion existence Real-consumer route]
\label{thm:metric-completion-existence-orphan-real-route}
Every $\RealUp$ or completion-facing consumer of an accepted $\MetricCompletionExistenceUp$ carrier must read the $\MetricSpaceUp$ source row, $\CauchyUp$ schedule row, $\StreamNameUp$ finite-window row, $\RegSeqRatUp$ readback row, $\DyadicRatCoreUp$ tolerance ledger, $\RealUp$ distance seal, $\MetricCompletionUp$ completion row, and $\CompleteMetricUp$ consumer row before using the completion seal. The route is a finite L10 dependency route through the displayed completion-existence packet, not a quotient completion, selected representative, countable-choice schedule, host equality oracle, trichotomy row, open-cover compactness row, or ambient $\RealUp$ completeness theorem.
\end{theorem}
\begin{proof}
Start with the carrier of \autoref{def:metric-completion-existence-carrier}. Its only completion seal is the row $U$, and the route to $U$ first displays the metric source $M$, Cauchy schedule $S$, dense embedding $D$, finite windows $W$, regular rational readback $R$, and dyadic tolerance ledger $Y$.

Apply the NameCert obligation theorem \autoref{thm:metric-completion-existence-namecert-obligations}. It keeps $\MetricSpaceUp$, $\CauchyUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\DyadicRatCoreUp$, $\RealUp$, $\MetricCompletionUp$, and $\CompleteMetricUp$ as separate source and consumer rows before the completion seal is exposed.

The sibling routes then keep the same boundary for downstream consumers. The complete-metric forward route and the completion uniqueness reflective route preserve the completion seal as packet data, while the Cauchy completion monad-law forward link reads the same finite source rows before any algebraic consumer uses the seal.

Since none of these rows contains quotient completion, selected representatives, countable choice, host equality, trichotomy, open-cover compactness, or ambient $\RealUp$ completeness, every Real/completion consumer remains on the displayed L10 route.
\end{proof}
