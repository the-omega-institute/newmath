\begin{theorem}[MetricCompletionExistence pointwise-stream lattice route]
\label{thm:metric-completion-existence-pointwise-stream-metric-lattice-route}
Any $\MetricCompletionExistenceUp$ read consumed by $\PointwiseStreamMetricUp$ or by a regular Cauchy completion consumer first exposes the finite lattice
$$
\StreamNameUp,\RegSeqRatUp,\RealUp,\MetricSpaceUp,\PointwiseStreamMetricUp
$$
before it reaches the completion-existence boundary. Thus the read travels through displayed stream windows, regular rational readback, terminal real-name sealing, the metric carrier, and the pointwise stream metric row; it is not a quotient completion, a selected limit, an ambient completeness theorem, or a host equality of real streams.
\end{theorem}
\begin{proof}
Read the pointwise-stream metric consumer first. Its distance observations are stream-indexed, so the consumer must display the $\StreamNameUp$ row and the $\PointwiseStreamMetricUp$ row before any completion-existence seal can be used.

For a regular Cauchy completion consumer, the same route exposes the $\RegSeqRatUp$ readback and the terminal $\RealUp$ seal on top of the ambient $\MetricSpaceUp$ row. These rows are the finite completion-facing lattice visible to the consumer.

The $\MetricCompletionExistenceUp$ boundary is therefore reached only after the displayed lattice has been opened. Since none of those rows carries quotient completion, selected limits, ambient completeness, or host stream equality, the handoff cannot export those conclusions.
\end{proof}

\begin{theorem}[MetricCompletionExistence pointwise-stream factorization]
\label{thm:metric-completion-existence-pointwise-stream-factorization}
Every completion-existence read consumed through $\PointwiseStreamMetricUp$ factors through the displayed order
$$
\StreamNameUp,\RegSeqRatUp,\RealUp,\MetricSpaceUp,\PointwiseStreamMetricUp
$$
before it reaches the $\MetricCompletionExistenceUp$ boundary. The factorization exposes finite stream windows, regular rational readback, the terminal Real seal, metric-space carrier rows, and the pointwise-stream distance row in that order; it exports no quotient completion, selected limit, ambient completeness theorem, or host equality of streams.
\end{theorem}
\begin{proof}
Project the lattice route of \autoref{thm:metric-completion-existence-pointwise-stream-metric-lattice-route}. It already displays the only rows available to a pointwise-stream metric consumer before the completion-existence boundary.

The first factor is the finite stream read. A consumer sees $\StreamNameUp$ windows and then the $\RegSeqRatUp$ readback attached to those windows before any Real or metric row can be used.

The second factor is the completion-facing metric read. The terminal $\RealUp$ seal is exposed before the ambient $\MetricSpaceUp$ row, and the $\PointwiseStreamMetricUp$ distance row is downstream of both.

Since the route contains only these displayed rows, it has no coordinate for quotient completions, selected limits, ambient completeness, or host stream equality. The completion-existence handoff therefore consumes the pointwise-stream factorization rather than a hidden completion principle.
\end{proof}
