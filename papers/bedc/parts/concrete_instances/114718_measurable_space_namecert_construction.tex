\begin{definition}[MeasurableSpace carrier]
\label{def:measurable-space-carrier}
A $\MeasurableSpaceUp$ carrier is a finite $\BHist$ packet
$$
M=(X,A,B,E,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $X$ is the underlying point-carrier row whose events are being named.
\item $A$ is the $\SigmaAlgebraUp$ event-family row over $X$, including empty-event, complement, and countable-union closure readback.
\item $B$ is the optional $\BorelSetUp$ generated-event row used when the measurable space is read from a topological or real-facing source.
\item $E$ is the public event classifier, reading event membership and event comparison only through $A$ and, when present, $B$.
\item $H$ records componentwise $\hsame$ transport for the carrier, sigma-algebra, Borel, event-classifier, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a measurable-event request through $X,A,B,E$ and then to the structural rows.
\item $P$ is the $\Pkg$ provenance over $\MeasurableSpaceUp$, $\SigmaAlgebraUp$, $\BorelSetUp$, $\MeasureUp$, $\ProbSpaceUp$, $\MeasurableFunctionUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$.
\item $N$ is the local $\NameCert_{\MeasurableSpaceUp}$ row.
\end{enumerate}
The carrier has no coordinate for a host powerset, completed sigma-algebra, quotient event equality, countable-choice enumeration of events, ambient measure, or external measurable-space instance.
\end{definition}

\begin{theorem}[MeasurableSpace NameCert obligations]
\label{thm:measurable-space-namecert-obligations}
For every accepted $\MeasurableSpaceUp$ carrier $M=(X,A,B,E,H,C,P,N)$, the local $\NameCert_{\MeasurableSpaceUp}$ surface consists exactly of carrier admission for $X$, sigma-algebra admission for $A$, generated-event compatibility for $B$ when a Borel source is present, event-classifier visibility for $E$, componentwise $\hsame$ transport through $H$, displayed $\Cont$ replay through $C$, package provenance through $P$, and local naming through $N$.

Every obligation routes through the sibling rows of $\SigmaAlgebraUp$, $\BorelSetUp$, $\MeasureUp$, $\ProbSpaceUp$, and $\MeasurableFunctionUp$ before any downstream measurable-object read is public.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:measurable-space-carrier}. The point row $X$ supplies the underlying carrier, while $A$ supplies the sigma-algebra closure rows that make event reads measurable.

When the source is Borel-facing, read the generated-event row $B$ through \autoref{ch:concrete-instances-borel-set-namecert}. The event classifier $E$ is then constrained to the same displayed event family, so it cannot leave the packet for a host powerset or completed measurable universe.

The structural rows $H,C,P,N$ transport, replay, source, and name exactly this packet. Since no coordinate names quotient event equality, countable-choice enumeration, ambient measure data, or an external measurable-space instance, the listed rows exhaust the local NameCert obligations.
\end{proof}

\begin{theorem}[MeasurableSpace sigma-algebra handoff]
\label{thm:measurable-space-sigma-algebra-handoff}
Every $\MeasureUp$, $\ProbSpaceUp$, or $\MeasurableFunctionUp$ consumer that cites an accepted $\MeasurableSpaceUp$ carrier must first read the $\SigmaAlgebraUp$ row $A$, the generated $\BorelSetUp$ row $B$ when present, and the event classifier $E$ over the same point row $X$. Thus measures receive measurable events before assigning values, probability spaces receive the same event family before normalization, and measurable functions receive source and target event families before reading preimage ledgers.

The handoff exports no host powerset, completed sigma-algebra, quotient event algebra, countable-choice event selector, ambient measure completion, or hidden measurable-map carrier.
\end{theorem}
\begin{proof}
Start with the sigma-algebra row. By \autoref{ch:concrete-instances-sigma-algebra-namecert}, event admission, complement, and countable-union closure are displayed inside the $\SigmaAlgebraUp$ packet before measure-facing rows consume them.

Next route generated events through \autoref{ch:concrete-instances-borel-set-namecert} when the measurable space is Borel-sourced. The same event classifier $E$ is used by \autoref{ch:concrete-instances-measure-namecert} and \autoref{ch:concrete-instances-probspace-namecert}, so value and normalization rows cannot precede measurable-event exposure.

Finally apply the preimage discipline of \autoref{ch:concrete-instances-measurable-function-namecert}. A measurable-map consumer reads source and target event families before the preimage ledger, so the measurable-space handoff is a source interface for measurable functions rather than a hidden host function space or completed measure object.
\end{proof}
