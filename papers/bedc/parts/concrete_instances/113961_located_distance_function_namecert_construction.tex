\chapter{A Concrete Naming Certificate for $\LocatedDistanceFunctionUp$}
\label{ch:concrete-instances-located-distance-function-namecert}
\origin{human}

Following Bishop and Bridges on located subsets of metric spaces, the $\LocatedDistanceFunctionUp$ packet records the standard point-to-set distance function as a finite BEDC NameCert surface. It sits over the metric source of \autoref{ch:concrete-instances-metric-namecert}, the located-set row of \autoref{ch:concrete-instances-locatedset-namecert}, the point-to-set packet of \autoref{ch:concrete-instances-distance-to-set-namecert}, the lower-semicontinuity sibling of \autoref{ch:concrete-instances-lowersemicontinuous-namecert}, the located-real comparison surface of \autoref{ch:concrete-instances-locatedreal-namecert}, and the terminal real-name seal of \autoref{ch:concrete-instances-real-namecert}. The packet names a reusable real-valued function row for located subsets; it does not assert a host infimum, selected nearest point, quotient real equality, countable-choice selector, or ambient completeness principle.

\begin{definition}[Located distance function carrier]
\label{def:located-distance-function-carrier}
A $\LocatedDistanceFunctionUp$ carrier is a finite $\BHist$ packet
$$
L=(X,A,D,F,R,O,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $X$ is the $\MetricUp$ source row over which point and subset reads are interpreted.
\item $A$ is the $\LocatedSetUp$ source row naming the subset by located-radius observations.
\item $D$ is the $\DistanceToSetUp$ row that supplies the point-to-set distance read for each displayed point request.
\item $F$ is the function graph row, recording the finite route from a point row in $X$ through $A,D$ to the exported real-name value.
\item $R$ is the $\RealUp$ seal row for each displayed value of the function.
\item $O$ is the lower-semicontinuity and $\LocatedRealUp$ comparison ledger, recording lower-real threshold reads, located-real value comparison, and sibling handoff to $\LowerSemicontinuousUp$.
\item $H$ records componentwise $\hsame$ transport for the metric source, located-set source, distance-to-set row, graph row, Real seal, comparison ledger, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a point request through the metric and located-set rows, the distance-to-set row, the graph row, the Real seal, and the lower-semicontinuity ledger.
\item $P$ is the $\Pkg$ provenance over $\LocatedDistanceFunctionUp$, $\MetricUp$, $\LocatedSetUp$, $\DistanceToSetUp$, $\LowerSemicontinuousUp$, $\LocatedRealUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$ rows.
\item $N$ is the local $\NameCert_{\LocatedDistanceFunctionUp}$ row.
\end{enumerate}
The classifier accepts only packets whose graph values are read through $X,A,D,F,R,O,H,C,P,N$. It has no coordinate for a host function space, selected nearest point, ambient infimum, quotient real equality, or countable-choice schedule.
\end{definition}

\begin{theorem}[Located distance function NameCert obligations]
\label{thm:located-distance-function-namecert-obligations}
For every accepted $\LocatedDistanceFunctionUp$ carrier $L=(X,A,D,F,R,O,H,C,P,N)$, the local $\NameCert_{\LocatedDistanceFunctionUp}$ surface consists exactly of the following finite obligation rows:
\begin{enumerate}
\item carrier admission for the metric source, located-set source, distance-to-set row, function graph, Real seal, lower-semicontinuity and located-real comparison ledger, transport, replay, provenance, and local naming;
\item point-request routing, requiring every value read to start in $X$ and pass through the located subset row $A$;
\item distance-to-set handoff, requiring the value row to consume the $\DistanceToSetUp$ packet of \autoref{ch:concrete-instances-distance-to-set-namecert} before the graph row $F$ is public;
\item Real and located-real sealing, requiring $R$ and $O$ to record only displayed values and comparisons;
\item lower-semicontinuity exposure, requiring the lower-threshold route to pass through the sibling surface of \autoref{ch:concrete-instances-lowersemicontinuous-namecert};
\item componentwise transport, displayed replay, package provenance, and local naming for exactly the displayed packet.
\end{enumerate}
No local obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:located-distance-function-carrier}. The source row $X$ supplies points, the located-set row $A$ supplies located-radius observations, and the distance row $D$ supplies the point-to-set value route.

The graph row $F$ does not introduce a separate host function. It records the replay from point requests to the displayed distance row and then to the Real seal $R$.

The ledger $O$ records the lower-semicontinuity and located-real comparison data after the value row is sealed. Transport $H$, replay $C$, provenance $P$, and local naming $N$ preserve the same row family, so the listed obligations exhaust the certificate surface.
\end{proof}

\begin{theorem}[Located distance function lower semicontinuity]
\label{thm:located-distance-function-lower-semicontinuity}
Every accepted $\LocatedDistanceFunctionUp$ carrier $L=(X,A,D,F,R,O,H,C,P,N)$ exports lower-semicontinuity only through the displayed route
$$
X,A,D,F,R,O,H,C,P,N .
$$
The lower-threshold read consumes the $\DistanceToSetUp$ value row and the $\LocatedRealUp$ comparison ledger before it reaches the $\LowerSemicontinuousUp$ sibling surface. It cannot be replaced by a host liminf, selected nearest point, quotient real equality, countable-choice selector, or ambient completeness theorem.
\end{theorem}
\begin{proof}
Start with a lower-threshold request for the function value. By \autoref{thm:located-distance-function-namecert-obligations}, the request first reads the metric source, located subset, distance-to-set row, graph row, and Real seal.

The ledger $O$ then exposes the located-real comparison needed by the lower-semicontinuity sibling. Since $O$ is downstream of $D,F,R$, the lower-threshold route remains tied to the same displayed point-to-set distance value.

Finally $H,C,P,N$ transport, replay, source, and name that finite route. The carrier has no coordinate for a host limiting theorem or chosen nearest point, so the exported lower-semicontinuity surface is exactly the displayed BEDC handoff.
\end{proof}
