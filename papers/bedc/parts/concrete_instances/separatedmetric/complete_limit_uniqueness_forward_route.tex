\begin{theorem}[SeparatedMetric complete-limit uniqueness forward route]
\label{thm:separated-metric-complete-limit-route}
Every $\CompleteMetricLimitUniquenessUp$ consumer that takes a $\SeparatedMetricUp$ packet as its separation witness must first expose the displayed $\MetricUp$ distance row, the $\RealUp$ zero-distance row, the $\CompleteMetricUp$ limit rows, the $\CauchySequenceEquivalenceUp$ comparison row, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and the local $\NameCert$ row before the uniqueness handoff. The consumer route is therefore the finite row chain already named by \autoref{ch:concrete-instances-complete-metric-limit-uniqueness-namecert}, \autoref{thm:separatedmetric-completion-limit-uniqueness-route}, \autoref{thm:separatedmetric-completion-uniqueness-consumer-obligation}, and \autoref{thm:separatedmetric-root-finite-completion-readiness}.

This route is read as a child of \autoref{ch:concrete-instances-separatedmetric-namecert} and consumes the displayed root obligation package before $\CompleteMetricLimitUniquenessUp$ can read the separated zero-distance classifier.

It exports completion-limit uniqueness only as a separated zero-distance classifier consequence of the displayed rows. It does not export quotient completion equality, selected host limits, countable choice, host equality, trichotomy, compactness, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Begin with the $\CompleteMetricLimitUniquenessUp$ request. The consumer may compare the two completion-limit rows only after the $\CompleteMetricUp$ entries have been displayed and tied to the same finite-window route by the $\CauchySequenceEquivalenceUp$ row, as in \autoref{thm:separatedmetric-completion-limit-uniqueness-route}.

Next apply the completion-uniqueness consumer obligation of \autoref{thm:separatedmetric-completion-uniqueness-consumer-obligation}. It sends the comparison through the $\MetricUp$ distance row and the $\RealUp$ zero-distance seal before the separated classifier row may be consumed.

Finally use the root finite completion-readiness package of \autoref{thm:separatedmetric-root-finite-completion-readiness}. The structural rows $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$ transport, replay, source, and name the same finite chain for the downstream consumer, so no quotient completion equality, selected limit, host equality, choice, trichotomy, compactness, or ambient completeness row can replace the displayed handoff.
\end{proof}
