\label{thm:complete-metric-limit-uniqueness-cauchy-sequence-space-forward-link}

Now apply the CompleteMetricLimitUniqueness separated route already exposed by this chapter. The separated-limit row can be consumed only after the metric-completion and Real-seal rows have been displayed along the same finite comparison route.

Thus the forward link is a dependency edge from the paired CauchySequenceSpace or RegularCauchySequenceSpace windows into the CompleteMetricLimitUniqueness separated-limit row. The packet has no coordinate for selected limits, quotient stream equality, or ambient $\RealUp$ completeness.
\end{proof}
