\begin{theorem}[CompleteMetricLimitUniqueness separated consumer route]
\label{thm:complete-metric-limit-uniqueness-separated-consumer-route}
Every separated consumer read of an accepted $\CompleteMetricLimitUniquenessUp$ packet must consume the $\SeparatedMetricReflectionUp$ classifier and the $\MetricCompletionUniquenessUp$ completion-uniqueness row before exporting uniqueness. The public route is the finite packet
$$
\CompleteMetricLimitUniquenessUp\longmapsto \MetricCompletionUniquenessUp\longmapsto \SeparatedMetricReflectionUp .
$$
It exports only uniqueness after the separated reflection and metric-completion uniqueness rows have been displayed; it does not assert choice of limits, selected completion representatives, quotient-limit equality, ambient $\RealUp$ completeness, or a host equality of metric points.
\end{theorem}
\begin{proof}
Start from the carrier and sibling routes of the parent chapter. A public uniqueness read already exposes the paired complete-metric limit rows, the distance witness, the zero-distance Real row, and the separated classifier before uniqueness is available.

Read the metric-completion uniqueness dependency next. The $\MetricCompletionUniquenessUp$ row supplies the completion-facing uniqueness boundary as a displayed sibling, not as a choice of a limit or a selected completion representative.

Finally apply the separated reflection route. The $\SeparatedMetricReflectionUp$ classifier is the point where zero-distance data can be exported as public uniqueness. Since neither the parent carrier nor this route contains a selected limit, quotient equality, ambient Real-completeness row, or host equality coordinate, the consumer receives only the displayed separated completion route.
\end{proof}
