\begin{theorem}[Complete metric limit uniqueness RegSeqRat--Real separated dependency route]
\label{thm:complete-metric-limit-uniqueness-regseqrat-real-separated-dependency-route}
Every public $\CompleteMetricLimitUniquenessUp$ handoff must first expose the $\RegSeqRatUp$ readback of \autoref{ch:concrete-instances-regseqrat-namecert}, the $\StreamNameUp$ finite-window rows, the $\DyadicRatCoreUp$ tolerance ledger, the $\RealUp$ zero-distance seal, the $\CompleteMetricUp$ completion boundary, and the $\SeparatedMetricReflectionUp$ classifier route of \autoref{thm:complete-metric-limit-uniqueness-separated-reflection-route}. \end{theorem}
\begin{proof}
Project the carrier of \autoref{def:complete-metric-limit-uniqueness-carrier}. The shared source row, two limit rows, metric witness, zero-distance row, separated row, transport, replay, provenance, and local name give the whole public uniqueness packet.

Use the RegSeqRat forward route \autoref{thm:complete-metric-limit-uniqueness-regseqrat-forward-route}. It forces the regular-rational readback, StreamName window, dyadic tolerance ledger, and Real zero-distance seal to be displayed before the separated classifier can be consumed.

Now apply the separated reflection route \autoref{thm:complete-metric-limit-uniqueness-separated-reflection-route}. The $\SeparatedMetricReflectionUp$ read is public only after the metric distance witness and $\RealUp$ zero-distance row have been exposed, so the uniqueness handoff cannot bypass the $\CompleteMetricUp$ and Real-facing dependencies.

The structural rows transport, replay, source, and name that same route. Since the carrier has no selected-limit coordinate, quotient point-equality coordinate, host-equality coordinate, or ambient-completeness coordinate, the public handoff remains the listed finite dependency route.
\end{proof}
