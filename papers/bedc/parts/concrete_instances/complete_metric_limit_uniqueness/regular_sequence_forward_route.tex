\begin{theorem}[Complete metric limit uniqueness regular-sequence forward route]
\label{thm:complete-metric-limit-uniqueness-regular-sequence-forward-route}
Every $\CompleteMetricLimitUniquenessUp$ read consumed by a regular-sequence completion route must pass through the $\RegularSequenceSpaceUp$ source surface of \autoref{ch:concrete-instances-regular-sequence-space-namecert}, the $\RegSeqRatUp$ readback row, the $\StreamNameUp$ finite-window row, the $\DyadicRatCoreUp$ tolerance row, the terminal $\RealUp$ seal, the $\CompleteMetricUp$ limit rows, and the $\SeparatedMetricReflectionUp$ classifier before uniqueness is public. In carrier notation the route is still the displayed packet
$$
A,L_{0},L_{1},M,Z,S,H,C,P,N,
$$
with the regular-sequence data read before $Z$, the complete-metric rows read before the comparison, and the separated classifier read before the uniqueness handoff.
\end{theorem}
\begin{proof}
Start with the regular-Cauchy real route of \autoref{thm:complete-metric-limit-uniqueness-regular-route}. It already forces a regular consumer through $\RegSeqRatUp$, $\StreamNameUp$, $\DyadicRatCoreUp$, and $\RealUp$ before the zero-distance row can be consumed.

Next insert the $\RegularSequenceSpaceUp$ source row. The regular-sequence-space carrier supplies the common family and window surface before the same $\RegSeqRatUp$ readback, $\StreamNameUp$ windows, and $\DyadicRatCoreUp$ tolerance rows are visible to the uniqueness packet.

Now apply the sibling route and separated zero-distance route, \autoref{thm:complete-metric-limit-uniqueness-sibling-route} and \autoref{thm:complete-metric-limit-uniqueness-separated-zero-distance-route}. These rows place the $\CompleteMetricUp$ limit reads before the metric comparison and require the $\SeparatedMetricReflectionUp$ classifier after the $\RealUp$ zero-distance seal.

Finally carry the route through $H,C,P,N$. The structural rows transport, replay, source, and name the same finite packet, so regular-sequence completion consumers reach public uniqueness only through the displayed sequence, readback, tolerance, Real seal, complete-metric, and separated-reflection route.
\end{proof}
