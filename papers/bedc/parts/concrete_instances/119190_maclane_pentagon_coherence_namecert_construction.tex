\begin{theorem}[Mac Lane pentagon coherence NameCert obligations]
\label{thm:maclane-pentagon-coherence-namecert-obligations}
For every accepted $\MacLanePentagonCoherenceUp$ carrier
$$
P=(C,T,A,W,L,R,H,Q,K,N),
$$
the local $\NameCert_{\MacLanePentagonCoherenceUp}$ surface consists exactly of the following five obligation rows:
\begin{enumerate}
\item carrier admission for the displayed $\CategoryUp$ row $C$, tensor $\FunctorUp$ row $T$, associator $\NatTransUp$ row $A$, four-object word row $W$, and pentagon boundary rows $L,R$;
\item tensor typing, requiring every edge of the pentagon to read the same category and tensor rows before any reassociation is consumed;
\item associator exposure, requiring each pentagon edge to be one displayed component of the associator row $A$;
\item boundary comparison, requiring $L$ and $R$ to name the two Mac Lane pentagon composites over the same word row $W$;
\item ledger exhaustion through $H,Q,K,N$, excluding external category carriers, quotient parenthesization equality, hidden naturality squares, and host coherence imports.
\end{enumerate}
No local NameCert obligation is stored outside these rows.
\end{theorem}
\begin{proof}
Carrier admission is projection from \autoref{def:maclane-pentagon-coherence-carrier}. The packet exposes only the category row, tensor row, associator row, four-object word row, the two boundary composites, and the structural rows.

Tensor typing is read before any associator edge. Each edge of the pentagon is a tensor expression over the same displayed category carrier and the same tensor functor row, so no second monoidal carrier can enter the route.

Associator exposure is then read from $A$. The five pentagon edges are not arbitrary morphisms; each is the displayed associator component or tensoring of such a component required by the word row $W$.

The boundary comparison is local to $L$ and $R$. These rows name the two Mac Lane composites over the same four-object word, so the packet records coherence as a comparison of displayed histories rather than as an ambient theorem about all parenthesizations.

Finally, $H,Q,K,N$ transport, replay, source, and name the same finite packet. Since the carrier contains no quotient parenthesization equality, hidden naturality square, external category object, or host coherence import, the five rows exhaust the local NameCert surface.
\end{proof}
