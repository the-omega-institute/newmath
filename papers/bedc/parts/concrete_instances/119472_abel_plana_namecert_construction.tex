\begin{theorem}[Abel-Plana NameCert obligations]
\label{thm:abel-plana-namecert-obligations}

\end{theorem}
\begin{proof}

Read the tolerance and readback layer next. The dyadic row $D$ budgets the three analytic faces, and the regular rational row $R$ supplies the only completion-facing readback available before the seal.

Finally use the structural rows. The seal row $E$ is downstream of $S,I,V,B,D,R$, while $H,C,P,N$ only transport, replay, source, and name the same displayed route.
