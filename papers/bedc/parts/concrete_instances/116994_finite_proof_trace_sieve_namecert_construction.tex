\begin{definition}[Finite proof-trace sieve carrier]
\label{def:finite-proof-trace-sieve-carrier}
A $\FiniteProofTraceSieveUp$ carrier is a finite $\BHist$ packet
$$
S=(T,E,D,O,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $T$ is the finite candidate trace table, listing proof-search candidates, local rule tags, dependency windows, and the bounded endpoints to be checked.
\item $E$ is the bounded normal endpoint row, read through $\BoundedNormalEqualityCheckerUp$ and the MetaCIC normalization frontier, that records which displayed candidates have finished endpoint witnesses.
\item $D$ is the discharge-socket row, recording the subject-reduction, closedness, and proof-obligation sockets that a candidate must fill before it can be consumed.
\item $O$ is the obstruction row, naming the residual open frontier when a candidate endpoint, discharge socket, or closure-preservation trace is missing.
\item $H$ records componentwise $\hsame$ transport for trace rows, endpoint rows, discharge sockets, obstruction rows, replay rows, provenance, and local naming.
\item $C$ records displayed $\Cont$ replay from candidate enumeration through endpoint checking, discharge inspection, obstruction retention, transport, provenance, and local naming.
\item $P$ is the $\Pkg$ provenance over $\FiniteProofTraceSieveUp$, $\MetaCICCriticalPathUp$, $\BoundedNormalEqualityCheckerUp$, $\MetaCICNormalizationFrontierUp$, proof-trace audit witness rows, closure-preservation trace rows, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$ rows.
\item $N$ is the local $\NameCert_{\FiniteProofTraceSieveUp}$ row.
\end{enumerate}
The carrier has no coordinate for a complete proof-search procedure, global normalization, unrestricted confluence, closed subject reduction, quotient equality of proof traces, hidden oracle discharge, or host equality of MetaCIC terms.
\end{definition}

\begin{theorem}[Finite proof-trace sieve NameCert obligations]
\label{thm:finite-proof-trace-sieve-namecert-obligations}
For every accepted $\FiniteProofTraceSieveUp$ carrier
$$
S=(T,E,D,O,H,C,P,N),
$$
the local $\NameCert_{\FiniteProofTraceSieveUp}$ surface consists exactly of carrier admission for the finite candidate table, bounded normal endpoint row, discharge-socket row, obstruction row, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local naming. These obligations keep each proof-search candidate inside the displayed sieve and expose any missing endpoint, discharge, or closure-preservation witness as an obstruction rather than a hidden success.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:finite-proof-trace-sieve-carrier}. The packet exposes only $T,E,D,O,H,C,P,N$.

The finite candidate table $T$ supplies the traces that may be inspected. Endpoint checking is confined to $E$, so a consumer sees only bounded normal endpoint witnesses and cannot infer a global normalization theorem.

The discharge row $D$ records which subject-reduction, closedness, and proof-obligation sockets are filled. If any socket or endpoint is absent, the obstruction row $O$ is the exported frontier, not a replacement proof.

Finally $H,C,P,N$ transport, replay, source, and name the same finite sieve. Because the carrier contains no global confluence, subject-reduction, quotient trace equality, or oracle-discharge coordinate, the listed rows exhaust the local NameCert obligations.
\end{proof}

\begin{theorem}[Finite proof-trace sieve frontier handoff]
\label{thm:finite-proof-trace-sieve-frontier-handoff}
Every consumer read from an accepted $\FiniteProofTraceSieveUp$ packet factors through the route
$$
\MetaCICCriticalPathUp,\ \BoundedNormalEqualityCheckerUp,\ \MetaCICNormalizationFrontierUp,\ T,E,D,O,H,C,P,N.
$$
The route first enumerates finite proof-trace candidates, then checks bounded normal endpoints, then inspects discharge sockets and closure-preservation traces, and finally exports either a replayable candidate row or the displayed obstruction row. It does not export global normalization, unrestricted confluence, closed subject reduction, quotient equality of proof traces, hidden oracle discharge, or host equality of MetaCIC terms.
\end{theorem}
\begin{proof}
Begin with a consumer asking whether a proof-search candidate can be consumed. Carrier admission restricts the request to the finite table $T$, so only the listed trace candidates and dependency windows are visible.

Next the endpoint row $E$ is read through the bounded normal-equality checker and normalization frontier. This gives bounded endpoint evidence for displayed candidates only, not a normalization theorem for all closed terms.

The discharge row $D$ is then inspected together with the closure-preservation trace. A filled socket can be replayed as part of the finite candidate route; an unfilled socket is recorded by $O$ as the frontier handoff.

Transport, replay, provenance, and naming preserve this same sieve. Since the packet contains no global confluence, subject-reduction, quotient trace equality, oracle discharge, or host equality coordinate, every consumer receives either the finite replayable rows or the explicit obstruction row.
\end{proof}
