\begin{definition}[Sturm separation carrier]
\label{def:sturm-separation-carrier}
A $\SturmSeparationUp$ carrier is a finite $\BHist$ packet
$$

\begin{enumerate}
\item $O$ is the $\OdeUp$ source row for the scalar second-order equation and its local solution-window request.
\item $I$ is the $\IntervalUp$ row naming the inspected compact interval and its left, middle, and right subwindows.
\item $F$ and $G$ are two $\ContinuousMapUp$ solution-observation rows over the interval window.
\item $Z$ is the zero-window ledger, recording the displayed zeros of $F$ and the adjacent zero-search windows for $G$.
\item $A$ is the alternation ledger, recording which $G$ zero-window is read between adjacent $F$ zero-windows and which $F$ zero-window is read between adjacent $G$ zero-windows.
\item $B$ is the $\SturmComparisonUp$ coefficient and comparison handoff row.
\item $D$ is the $\DyadicRatCoreUp$ endpoint and tolerance ledger for the zero windows and comparison inequalities.

The classifier compares accepted carriers only through these rows. It has no coordinate for global ODE completeness, host solution equality, excluded-middle sign trichotomy, quotient real equality, or a selected classical solution curve.

\begin{theorem}[Sturm separation NameCert obligations]
\label{thm:sturm-separation-namecert-obligations}

$$

$$
the local $\NameCert_{\SturmSeparationUp}$ surface consists exactly of carrier admission, ODE-source exposure, interval-window exposure, two continuous solution-observation rows, zero-window exposure, alternation-ledger exposure, Sturm comparison handoff, dyadic endpoint and tolerance accounting, regular rational readback, terminal Real sealing, componentwise transport, displayed replay, provenance, and local naming.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:sturm-separation-carrier}. The rows $O,I,F,G$ are the only displayed source rows, so a separation read cannot inspect a host solution space before the local ODE, interval, and continuous-map observations are opened.

Read the zero data through $Z$ and the alternation data through $A$. These rows record finite adjacent windows rather than an ambient zero set or a trichotomy oracle.

Use the Sturm comparison handoff row $B$ together with the dyadic and regular readback rows $D,R$. They place coefficient comparisons, endpoint tolerances, and solution observations on the same finite windows before the terminal seal $E$ is available.

Finally $H,C,P,N$ transport, replay, source, and name the same packet. Since no displayed coordinate names global completeness, host solution equality, quotient real equality, hidden choice, or selected classical curves, those objects are not local NameCert obligations.
\end{proof}
