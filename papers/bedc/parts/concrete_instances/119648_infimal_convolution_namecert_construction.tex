Following Rockafellar's convex analysis and the Boyd--Vandenberghe finite convex-optimization presentation, the $\InfimalConvolutionUp$ packet records the binary lower-envelope operation by displayed epigraph, value-window, and Fenchel handoff rows. It separates the lower-envelope certificate consumed by the Moreau envelope chapter \autoref{ch:concrete-instances-moreau-envelope-namecert} from the proximal smoothing packet itself, while staying anchored in the convex source of \autoref{ch:concrete-instances-convexset-namecert}, the convex-conjugate boundary of \autoref{ch:concrete-instances-convex-conjugate-namecert}, the Fenchel duality ledger of \autoref{ch:concrete-instances-fenchelduality-namecert}, the Fenchel--Young inequality surface of \autoref{ch:concrete-instances-fenchel-young-inequality-namecert}, and the terminal real-name seal of \autoref{ch:concrete-instances-real-namecert}. The carrier names finite candidate decompositions and lower-bound comparisons; it is not a host infimum operator, selected minimizer, quotient function space, or ambient lower-semicontinuity theorem.

\begin{definition}[Infimal convolution carrier]
\label{def:infimal-convolution-carrier}
An $\InfimalConvolutionUp$ carrier is a finite $\BHist$ packet
$$
I=(F,G,X,V,L,D,Y,E,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $F$ and $G$ are the two source function rows, each read through finite domain, value, and convexity observations.
\item $X$ is the split-variable window, listing the displayed decompositions $x=u+v$ that are available to the lower-envelope read.
\item $V$ is the value-sum ledger, recording the visible rows $F(u)$, $G(v)$, and $F(u)+G(v)$ for each displayed split.
\item $L$ is the lower-bound ledger, recording finite comparison rows that any proposed lower envelope must satisfy against the displayed value sums.
\item $D$ is the $\ConvexConjugateUp$ and $\FenchelDualityUp$ handoff row, exposing the conjugate and dual comparison data visible at the same split window.
\item $Y$ is the $\FenchelYoungInequalityUp$ row, recording the local inequality witnesses used when a downstream Fenchel consumer reads the lower-envelope packet.
\item $E$ is the terminal $\RealUp$ seal row for value readback, reachable only after $F,G,X,V,L,D,Y$ have been displayed.
\item $H$ records componentwise $\hsame$ transport for the source functions, split window, value ledger, lower-bound ledger, Fenchel handoff, inequality row, real seal, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from source-function admission through split inspection, value-sum comparison, lower-bound readback, Fenchel handoff, and real-seal export.
\item $P$ is the $\Pkg$ provenance over $\InfimalConvolutionUp$, $\MoreauEnvelopeUp$, $\ConvexSetUp$, $\ConvexConjugateUp$, $\FenchelDualityUp$, $\FenchelYoungInequalityUp$, $\RealUp$, $\BHist$, $\hsame$, $\Cont$, and $\NameCert$ rows.
\item $N$ is the local $\NameCert_{\InfimalConvolutionUp}$ row.
\end{enumerate}
The accepted carrier compares lower-envelope reads only through these rows. It has no coordinate for an arbitrary host infimum, a selected minimizing split, quotient equality of functions, global lower-semicontinuous hulls, or ambient convex completeness.
\end{definition}

\begin{theorem}[Infimal convolution NameCert obligations]
\label{thm:infimal-convolution-namecert-obligations}
For the carrier of \autoref{def:infimal-convolution-carrier}, the local $\NameCert_{\InfimalConvolutionUp}$ surface consists exactly of carrier admission for $I=(F,G,X,V,L,D,Y,E,H,C,P,N)$, source-function exposure, split-window exposure, value-sum ledger exactness, lower-bound comparison, Fenchel handoff visibility, Fenchel--Young inequality replay, $\RealUp$ seal nonescape, componentwise transport, displayed continuation replay, package provenance, and local naming. Every accepted lower-envelope read factors through
$$
F,G \longmapsto X \longmapsto V \longmapsto L \longmapsto E
$$
with $D,Y,H,C,P,N$ attached as Fenchel, inequality, transport, replay, provenance, and naming rows.
\end{theorem}
\begin{proof}
Project the accepted carrier. The source-function rows are $F$ and $G$, and the only displayed decompositions are those listed in the split window $X$.

The value-sum row $V$ is therefore the first lower-envelope ledger a consumer can inspect. The lower-bound row $L$ compares proposed envelope data only against the sums already displayed by $V$, and the real seal $E$ is downstream of those same rows.

The Fenchel-facing rows do not add an alternate envelope. The handoff $D$ and inequality row $Y$ replay conjugate and Fenchel--Young evidence at the same split window, while $H,C,P,N$ transport, replay, source, and name the same finite packet. Since no row stores a host infimum, selected minimizing split, quotient function equality, global lower-semicontinuous hull, or ambient convex-completeness object, the listed rows exhaust the local NameCert obligations.
\end{proof}

\begin{theorem}[Infimal convolution Fenchel handoff]
\label{thm:infimal-convolution-fenchel-handoff}
Every $\ConvexConjugateUp$, $\FenchelDualityUp$, $\FenchelYoungInequalityUp$, or $\MoreauEnvelopeUp$ consumer of an accepted $\InfimalConvolutionUp$ carrier must first read the source rows $F,G$, the split-variable window $X$, the value-sum ledger $V$, and the lower-bound ledger $L$ before it consumes the Fenchel handoff row $D$, inequality row $Y$, or terminal $\RealUp$ seal $E$. The handoff is a finite lower-envelope route, not a host optimization theorem or selected minimizing decomposition.
\end{theorem}
\begin{proof}
Start with the local obligations of \autoref{thm:infimal-convolution-namecert-obligations}. They force every lower-envelope read through the displayed source rows, split window, value-sum ledger, and lower-bound ledger.

Now read the Fenchel-facing side. The row $D$ exposes only conjugate and dual comparison data attached to the same split window, and the row $Y$ exposes only the corresponding Fenchel--Young witnesses. A $\MoreauEnvelopeUp$ consumer can cite this packet only after that lower-envelope route has been displayed, so smoothing data cannot replace the binary lower-envelope certificate.

Finally pass to the real seal. The seal $E$ is reached after $F,G,X,V,L,D,Y$, and the structural rows $H,C,P,N$ preserve that route under transport and replay. Hence the downstream Fenchel and Moreau consumers receive exactly the finite handoff displayed by the carrier and no host optimization, selected minimizer, quotient function equality, or ambient convex-completeness coordinate.
\end{proof}
