\chapter{CantorModulusContinuity name certificate construction}
\label{ch:concrete-instances-cantor-modulus-continuity-namecert}
\origin{human}

Following Brouwer and Bishop--Bridges, the $\CantorModulusContinuityUp$ packet records the constructive compact-prefix fact that a continuous map out of Cantor space is read through a finite inspected prefix before any modulus consumer acts. It sits beside the Cantor-space carrier of \autoref{ch:concrete-instances-cantorspace-namecert}, the stream naming surface of \autoref{ch:concrete-instances-streamname-namecert}, the continuous-map row of \autoref{ch:concrete-instances-continuousmap-namecert}, the uniform-modulus route of \autoref{ch:concrete-instances-uniformmodulus-namecert}, and the compact-metric source of \autoref{ch:concrete-instances-compactmetric-namecert}. The packet is a finite certificate for compact-prefix continuity; it does not assert open-cover compactness, choose a bar-recursion branch, import countable choice, or identify host quotient function spaces.

\begin{definition}[Cantor modulus-continuity carrier]
\label{def:cantor-modulus-continuity-carrier}
A $\CantorModulusContinuityUp$ carrier is a finite row
$$
K=(B,F,P,M,S,U,H,C,G,N),
$$
where $B$ is the accepted $\CantorSpaceUp$ source row, $F$ is a $\ContinuousMapUp$ row out of $B$, $P$ is the inspected prefix ledger, $M$ is the finite modulus bound, $S$ is the $\StreamNameUp$ readback row, $U$ is the $\UniformModulusUp$ consumer handoff, $H$ is componentwise $\hsame$ transport, $C$ is displayed $\Cont$ replay, $G$ is $\Pkg$ provenance, and $N$ is the local $\NameCert_{\CantorModulusContinuityUp}$ row.
\end{definition}

\begin{theorem}[Cantor modulus-continuity classifier]
\label{thm:cantor-modulus-continuity-classifier}
An accepted $\CantorModulusContinuityUp$ packet classifies exactly those finite routes in which the continuous-map read $F$ from the Cantor-space row $B$ is exhausted by the displayed prefix ledger $P$, and the resulting modulus bound $M$ is handed to the $\UniformModulusUp$ row $U$ through the same stream row $S$. It rejects any route that obtains uniformity from open-cover compactness, a selected infinite cover, a host fan theorem oracle, quotient equality of functions, or ambient real-completion data.
\end{theorem}
\begin{proof}
Read the source through \autoref{ch:concrete-instances-cantorspace-namecert}. The Cantor-space row supplies finite binary prefix windows, so a continuity read can be inspected as a finite prefix request rather than as a host compact space.

The continuous-map and stream rows then determine the route $F,P,S$. The prefix ledger records which finite windows were read, and the modulus row $M$ is the first carrier coordinate allowed to summarize those reads for downstream use.

Finally pass through $U,H,C,G,N$. The uniform-modulus handoff, transport, replay, provenance, and local name rows preserve the same finite packet, so no excluded compactness or choice source can be inserted without changing the carrier.
\end{proof}

\begin{theorem}[Cantor modulus-continuity NameCert obligations]
\label{thm:cantor-modulus-continuity-namecert-obligations}
For every accepted carrier $K=(B,F,P,M,S,U,H,C,G,N)$, the local $\NameCert_{\CantorModulusContinuityUp}$ row verifies the following five obligations:
\begin{enumerate}
\item the carrier binds one $\CantorSpaceUp$ source row $B$, one $\ContinuousMapUp$ row $F$, one prefix ledger $P$, one modulus row $M$, and one $\StreamNameUp$ row $S$;
\item the classifier accepts only routes where $P$ records finite prefix windows read from $B$ before $M$ is exported;
\item the exactness row sends the same modulus bound $M$ to the $\UniformModulusUp$ handoff $U$ and to no other modulus source;
\item the transport and replay rows $H,C$ preserve the prefix ledger, continuous-map read, and modulus handoff componentwise;
\item the provenance and local naming rows $G,N$ expose the route as finite BEDC NameCert data and not as open-cover compactness, countable choice, quotient function equality, or ambient completion.
\end{enumerate}
\end{theorem}
\begin{proof}
The carrier obligation is a projection from \autoref{def:cantor-modulus-continuity-carrier}. It lists the rows that may be read by a consumer and leaves no coordinate for a host compactness theorem.

For classifier and exactness, use \autoref{thm:cantor-modulus-continuity-classifier}. It fixes the order $B,F,P,M,S,U$ and makes $M$ the finite summary of prefix inspection before the uniform-modulus handoff.

The remaining obligations are structural. The rows $H,C,G,N$ transport, replay, source, and name the same finite route, so any attempted replacement by a selected cover, quotient equality, or external completion datum changes the packet rather than satisfying the local certificate.
\end{proof}

\begin{theorem}[Cantor modulus-continuity compact-prefix nonescape]
\label{thm:cantor-modulus-continuity-compact-prefix-nonescape}
Every accepted $\CantorModulusContinuityUp$ carrier $K=(B,F,P,M,S,U,H,C,G,N)$ exposes compact-prefix continuity only through the finite route $B,F,P,M,S,U,H,C,G,N$. A downstream $\UniformModulusUp$ consumer may read the modulus bound $M$ through $U$, but it cannot split the read into open-cover compactness, selected subcovers, countable choice, quotient equality of continuous functions, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Apply the NameCert obligations of \autoref{thm:cantor-modulus-continuity-namecert-obligations}. They bind $B,F,P,M,S,U$ as one finite prefix-to-modulus route.

The structural rows $H,C,G,N$ only preserve that route. Since the carrier has no coordinate for open-cover compactness, selected subcovers, quotient function equality, or ambient completion, a consumer that reads any such object has left the accepted packet.
\end{proof}
