\label{thm:setlike-kernel-membership-obligation}

The structural tail is then read by projection. The rows $H,C,P,N$ transport, replay, source, and locally name the same membership surface, so no host element relation, powerset row, or unrecorded classifier is introduced.
\end{proof}

\begin{definition}[SetLike root membership carrier]
\label{def:setlike-root-membership-carrier}
The root membership carrier of an accepted $\SetLikeUp$ packet $S=(M,Q,I,R,E,H,C,P,N)$ is the finite $\BHist$ route
$$
\begin{gathered}
M \longrightarrow Q \longrightarrow I \longrightarrow R \longrightarrow E,\\
H \longrightarrow C \longrightarrow P \longrightarrow N .
\end{gathered}
$$

\end{definition}
