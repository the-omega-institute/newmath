\begin{theorem}[Asymptotic density NameCert obligations]
\label{thm:asymptotic-density-namecert-obligations}

$$

\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:asymptotic-density-carrier}. The rows $U,I,C,D,Q,T,R,E,H,K,P,N$ are the whole public surface, so carrier admission is exactly admission of those rows as one finite packet.

The counting part is forced by the prefix rows. The membership observations in $U$ are read only for the prefixes named in $I$, and the ledger $C$ stores exactly the corresponding finite counts. The denominator row $D$ names the same prefix lengths, so the quotient row $Q$ can form only the displayed prefix-density ratios.

The tail comparison is then read through $T$. This row imports the finite-tail discipline of \autoref{ch:concrete-instances-finite-tail-filter-namecert} without adding a second selector for later prefixes or a completed limit coordinate.

Finally $R$ and $E$ are downstream of the displayed quotient and tail rows. The structural rows $H,K,P,N$ transport, replay, source, and name the same route, so none of the excluded host objects can appear as an additional NameCert obligation.
\end{proof}

\label{thm:asymptotic-density-finite-prefix-stability}

The stability is a finite-tail comparison inside the packet, not an appeal to host set equality modulo finite difference or to an ambient limit theorem.
\end{theorem}
\begin{proof}
Read the affected prefix rows first. A finite change in $U$ can alter only the counting ledger entries $C$ attached to the finitely many prefixes of $I$ that inspect those cells.

Move to the tail row $T$. Once the displayed finite-tail filter has passed beyond those prefixes, later density comparisons use the same membership windows, quotient budgets, and prefix denominators as before.

The conclusion is therefore internal to the finite carrier. No host equality modulo finite sets, selected limiting subsequence, quotient predicate equality, trichotomy, countable-choice row, or ambient completeness theorem is introduced.
\end{proof}
