\label{def:located-number-carrier}

\end{theorem}
\begin{proof}
Project the accepted packet. The analytic rows are precisely the scale row $N$, rational bracket row $Q$, dyadic tolerance row $D$, finite window row $S$, regular readback row $R$, Archimedean compatibility row $A$, and terminal seal row $E$.

Read the sibling obligations in their displayed order.
