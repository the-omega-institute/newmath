\begin{proposition}[ParallelDiamondResidual MetaCIC frontier sibling route]
\label{thm:parallel-diamond-residual-sibling-route}
Every $\ParallelDiamondResidualUp$ residual-join consumer reads the local residual row through \autoref{ch:concrete-instances-metacic-parallel-diamond-frontier-namecert} and the residual-normalization route before exporting confluence data. The consumer must keep the residual-substitution boundary, local-join ledger, bounded checker, compatibility handoff, obstruction row, transport, replay, provenance, and local $\NameCert$ rows visible while the MetaCIC frontier is read.
\end{proposition}
\begin{proof}
Start with the local carrier of \autoref{def:parallel-diamond-residual-carrier}. It displays the residual frontier, substitution boundary, local-join ledger, bounded checker, compatibility handoff, obstruction row, and structural certificate rows.

Read the sibling frontier through \autoref{ch:concrete-instances-metacic-parallel-diamond-frontier-namecert}. That frontier supplies the confluence-facing residual-substitution and critical-pair context, but it does not discharge the local residual rows carried here.

Finally apply the residual-normalization route already recorded by the hub siblings. The residual row can be exported as confluence data only with the MetaCIC frontier and the local residual-normalization rows simultaneously displayed.
\end{proof}
