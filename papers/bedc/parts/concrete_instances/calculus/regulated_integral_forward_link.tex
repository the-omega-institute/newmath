\begin{theorem}[Calculus regulated-integral forward link]
\label{thm:calculus-regulated-integral-forward-link}
Every $\CalculusUp$ integration-facing consumer that reads a regulated integral first exposes the regulated-integral finite step route of \autoref{ch:concrete-instances-regulatedintegral-namecert} before it may use $\RealUp$ endpoint seals. In the root package of \autoref{def:calculus-root-public-package}, the integral branch reads the calculus finite-sum row, then the $\RegulatedIntegralUp$ interval, regulated-function, step approximation, finite step-sum, Darboux/Riemann compatibility, error, transport, replay, provenance, and local NameCert rows, and only then consumes the Real-facing endpoint.

The forward link is therefore a sibling dependency from the accepted $\CalculusUp$ root package to the $\RegulatedIntegralUp$ route. It does not supply a host integral functional, selected antiderivative, quotient equality of functions, measure completion, or ambient $\RealUp$ completeness principle.
\end{theorem}
\leanchecked{BEDC.Derived.CalculusUp.CalculusRegulatedIntegralForwardLink}
\begin{proof}
Start from the $\CalculusUp$ root public package of \autoref{def:calculus-root-public-package}. Its integration-facing branch contains the finite-sum row and the structural rows that transport, replay, source, and locally name the accepted calculus read.

Route that branch through \autoref{ch:concrete-instances-regulatedintegral-namecert}. The regulated-integral packet exposes its interval, regulated-function, dyadic step approximation, finite step-sum, Darboux/Riemann compatibility, error, transport, replay, provenance, and local NameCert rows before a Real-facing handoff is public.

The terminal endpoint seal is then read through $\RealUp$ and the existing calculus Real-completion sibling route. Since neither the calculus root package nor the regulated-integral sibling carries a coordinate for host integration, selected antiderivatives, quotient function equality, measure completion, or ambient completeness, the forward link remains the displayed finite route.
\end{proof}
