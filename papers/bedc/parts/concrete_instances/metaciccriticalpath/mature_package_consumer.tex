\begin{theorem}[MetaCIC critical-path mature package consumer]
\label{thm:metacic-critical-path-mature-package-consumer}
Every mature-package consumer of an accepted $\MetaCICCriticalPathUp$ packet reads the cited L10 source ledger only through $\DyadicRatCoreUp$, $\StreamNameUp$, $\RegSeqRatUp$, and $\RealUp$ before it consumes residual substitution, local diamond, bounded checker, candidate frontier, obstruction, discharge socket, transport, replay, provenance, and local naming rows. In carrier notation the consumer remains on the displayed packet route
$$
K=(S,N,O,U,D,H,C,P,L),
$$
together with the four L10 source faces named by the mature package of \autoref{thm:metacic-critical-path-mature-package}. The route exports no quotient stream, selected limit, ambient $\RealUp$ completeness, global confluence theorem, global beta-conversion decision procedure, closed subject-reduction theorem, or hidden fifth source face.
\end{theorem}
\begin{proof}
Start with the mature L10 source package. Theorem~\ref{thm:metacic-critical-path-mature-package} requires every residual, confluence, and candidate-mediated strong-normalization consumer to keep $\DyadicRatCoreUp$, $\StreamNameUp$, $\RegSeqRatUp$, and $\RealUp$ visible as the only L10 source faces.

Next use the L10 source candidate frontier and mature source socket separation. Theorems~\ref{thm:metacic-critical-path-l10-source-candidate-frontier} and~\ref{thm:metacic-critical-path-mature-l10-source-socket-separation} keep residual substitution, local diamond data, bounded checker rows, obstruction rows, and discharge sockets attached to the same displayed packet rather than to a quotient stream or selected limit.

Finally apply the mature consumer synthesis of \autoref{thm:metaciccriticalpath-mature-consumer-synthesis}. It packages the confluence frontier, normalization frontier, substitution boundary, typed-example row, bounded checker route, and the four L10 faces as one consumer surface. Since none of those cited rows contains a quotient stream, selected limit, ambient completeness theorem, global confluence theorem, global beta-conversion decider, closed subject-reduction theorem, or fifth source face, the mature consumer receives only the displayed finite route.
\end{proof}
