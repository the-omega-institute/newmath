\begin{theorem}[MetaCIC candidate residual budget interface]
\label{thm:metacic-critical-path-candidate-residual-budget-interface}
For every accepted $\MetaCICCriticalPathUp$ packet
$$
K=(S,N,O,U,D,H,C,P,L),
$$
any candidate-mediated residual substitution, bounded confluence, or decidability read that reaches the critical-path normal-form endpoint must first expose the four L10 source rows
$$
\DyadicRatCoreUp,\qquad
\StreamNameUp,\qquad
\RegSeqRatUp,\qquad
\RealUp
$$
through the open-phase source ledger of \autoref{def:metacic-critical-path-open-phase-source-ledger}. The candidate rows, residual substitution rows, SN confluence-decidability budget, residual-budget socket, componentwise $\hsame$ transport, displayed $\Cont$ replay, $\Pkg$ provenance, and local $\NameCert$ row remain visible before any critical-path consumer reads the endpoint $N$. The interface exports no closed subject reduction, global confluence, beta-conversion decidability, full consistency, quotient term equality, selected limits, host equality, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Begin with the open-phase source ledger. Definition~\ref{def:metacic-critical-path-open-phase-source-ledger} lists the packet rows $S,N,O,U,D,H,C,P,L$ together with the four L10 source rows $\DyadicRatCoreUp$, $\StreamNameUp$, $\RegSeqRatUp$, and $\RealUp$.

Attach the candidate residual stability surface, \autoref{thm:metacic-critical-path-candidate-residual-stability}. It keeps candidate-mediated residual substitution attached to the same four source faces and prevents the residual handoff from becoming a global confluence or decidability theorem.

Use the residual-confluence budget bridge, \autoref{thm:metacic-critical-path-residual-confluence-budget-bridge}, together with the SN confluence-decidability budget of \autoref{thm:metacic-critical-path-sn-confluence-budget}. These routes force residual substitution, bounded confluence, and decidability consumers through one finite ledger before any normal-form endpoint read is exported.

Finally apply the frontier nonescape route, \autoref{thm:metacic-critical-path-frontier-nonescape}. It leaves only the displayed candidate rows, residual rows, socket budget, L10 source faces, transport, replay, provenance, and local naming. Since none of those rows carries the excluded metatheoretic or real-completion principles, the budget interface exposes exactly the stated source rows before $N$ can be read.
\end{proof}
