\begin{theorem}[MetaCICCriticalPath mature closure witness]
\label{thm:metacic-criticalpath-mature-closure-witness}
Let
$$
K=(S,N,O,U,D,H,C,P,L)
$$
be an accepted $\MetaCICCriticalPathUp$ packet. The mature packet is a paper-side package witness: it is exactly the candidate-mediated strong-normalization, residual-substitution, confluence and decidability, and four-object L10 source package exposed by the existing child routes. A mature consumer must read the candidate schedule, residual-budget discharge, parallel-diamond frontier, and $\DyadicRatCoreUp$, $\StreamNameUp$, $\RegSeqRatUp$, $\RealUp$ source rows before it treats $K$ as a mature critical-path packet.

The mature paper closure exports no subject-reduction theorem, global Church--Rosser theorem, quotient term equality, selected limit, ambient $\RealUp$ completeness, or Lean formal verification of those external principles.
\end{theorem}
\begin{proof}
Start with the mature L10 source package of \autoref{thm:metacic-critical-path-mature-package}. It fixes the four source faces $\DyadicRatCoreUp$, $\StreamNameUp$, $\RegSeqRatUp$, and $\RealUp$ and keeps residual, confluence, decidability, and candidate-mediated strong-normalization data attached to the same packet rows.

Next apply the parallel-diamond frontier handoff of \autoref{thm:metacic-critical-path-parallel-diamond-frontier-handoff}. It forces any confluence-facing or normalization-facing discharge request through the displayed candidate frontier, residual substitution budget, local diamond witness, and L10 source ledger before the request reaches a public endpoint.

Finally apply the candidate schedule mature package of \autoref{thm:metaciccriticalpath-candidate-schedule-mature-package}. The schedule route combines the candidate schedule discharge, residual-budget frontier, and mature L10 source package on the same carrier $K$, with $H,C,P,L$ preserving transport, replay, provenance, and naming.

These three routes exhaust the mature packet advertised by the hub marker as a paper-side package witness. None of the cited routes contains a row for subject reduction, global Church--Rosser, quotient term equality, selected limits, ambient $\RealUp$ completeness, or Lean formal verification of those external principles, so the mature closure witness exports exactly the displayed package and none of the excluded principles.
\end{proof}
