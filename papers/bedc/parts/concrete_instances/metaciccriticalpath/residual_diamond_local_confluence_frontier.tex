\begin{theorem}[MetaCIC residual-diamond local-confluence frontier]\label{thm:metacic-critical-path-residual-diamond-local-confluence-frontier}
Let
$$
K=(S,N,O,U,D,H,C,P,L)
$$
be an accepted $\MetaCICCriticalPathUp$ packet. Any local-confluence read for $K$ must expose the residual-substitution frontier, candidate-mediated strong-normalization frontier, residual-budget socket, bounded confluence checker, and the four L10 source faces $\DyadicRatCoreUp$, $\StreamNameUp$, $\RegSeqRatUp$, and $\RealUp$ before it reads $U$. The read is therefore a finite residual-diamond frontier over the displayed packet rows, not a global confluence theorem, beta-conversion decidability result, quotient equality of terms, selected limit, or ambient $\RealUp$ completeness principle.
\end{theorem}
\begin{proof}
Start with \autoref{thm:metacic-critical-path-residual-substitution-diamond-budget}. It already binds residual substitution, candidate-mediated normalization, residual budget, bounded checker data, and L10 source rows to the same accepted packet route before any confluence-facing consumer can use the handoff.

Use residual diamond source totality, \autoref{thm:metacic-critical-path-residual-diamond-source-totality}. The local-confluence read may inspect $U$ only after the closed-substitution boundary, residual-budget socket, candidate-mediated frontier, and source rows are all displayed on $S,N,O,U,D,H,C,P,L$.

Finally apply the L10 source separation theorem, \autoref{thm:metacic-critical-path-residual-diamond-l10-source-separation}. The four source faces remain distinct rows throughout the residual-diamond route, so a checker that merges them, reconstructs them after reading $U$, or detaches the residual proof from the bounded budget leaves the accepted $\MetaCICCriticalPathUp$ packet.
\end{proof}

\begin{theorem}[MetaCIC candidate-SN confluence handoff]
\label{thm:metacic-critical-path-candidate-sn-confluence-handoff}
Let
$$
K=(S,N,O,U,D,H,C,P,L)
$$
be an accepted $\MetaCICCriticalPathUp$ packet. Any local-confluence read that consumes both the residual-diamond frontier and the candidate-mediated strong-normalization frontier must expose $S,N,O,U,D,H,C,P,L$ and the four L10 source faces $\DyadicRatCoreUp$, $\StreamNameUp$, $\RegSeqRatUp$, and $\RealUp$ before $U$ is consumed. The handoff remains a finite candidate-mediated boundary; it does not close subject reduction, arbitrary strong normalization, global confluence, beta-decidability, quotient term equality, selected limits, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Begin with the residual-diamond local-confluence frontier, \autoref{thm:metacic-critical-path-residual-diamond-local-confluence-frontier}. It requires the residual-substitution frontier, residual-budget socket, bounded checker data, and L10 source faces to remain visible before a local-confluence consumer reads $U$.

Next use the candidate-mediated strong-normalization frontier, \autoref{thm:metacic-critical-path-candidate-mediated-sn-frontier}. Candidate evidence is read only as packet data on the displayed rows together with the same four L10 source faces, not as a closed normalization theorem.

Finally apply the L10 source separation theorem, \autoref{thm:metacic-critical-path-residual-diamond-l10-source-separation}. Since the four source faces stay distinct and the residual and candidate rows remain attached to $S,N,O,U,D,H,C,P,L$, the handoff cannot export any of the excluded global metatheoretic, quotient, selected-limit, or Real-completeness principles.
\end{proof}
