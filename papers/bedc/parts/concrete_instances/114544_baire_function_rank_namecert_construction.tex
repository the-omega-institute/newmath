Following Hausdorff, Kuratowski, and Kechris in classical descriptive set theory, the $\BaireFunctionRankUp$ packet records the finite BEDC route by which a real-valued function on a Polish source exposes a displayed Baire-class rank to downstream consumers. It sits over the complete separable source of \autoref{ch:concrete-instances-polishspace-namecert}, the displayed rank schedule of \autoref{ch:concrete-instances-borel-hierarchy-namecert}, the Borel-function row of \autoref{ch:concrete-instances-borel-function-namecert}, the finite observation windows of \autoref{ch:concrete-instances-streamname-namecert}, the regular rational readback of \autoref{ch:concrete-instances-regseqrat-namecert}, and the real seal of \autoref{ch:concrete-instances-real-namecert}. The packet names a rank-read route only; it does not assert Baire hierarchy completeness, selected codes, quotient equality of functions, countable choice, measure completion, or ambient $\RealUp$ completeness.

\begin{definition}[Baire-function rank carrier]
\label{def:baire-function-rank-carrier}
A $\BaireFunctionRankUp$ carrier is a finite $\BHist$ packet
$$
R=(P,B,F,S,Q,E,H,C,G,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $P$ is the $\PolishSpaceUp$ source row for the domain of the real-valued function.
\item $B$ is the $\BorelHierarchyUp$ rank schedule row, including the visible predecessor, successor, and limit-stage windows used by the current rank read.
\item $F$ is the $\BorelFunctionUp$ row that hands the source-side function query to the displayed Borel schedule.
\item $S$ is the $\StreamNameUp$ window row for finite observation of source names, rank positions, and real-facing output windows.
\item $Q$ is the $\RegSeqRatUp$ readback row used before the rank read reaches the real seal.
\item $E$ is the $\RealUp$ seal row for the real-valued output readback.
\item $H$ records componentwise $\hsame$ transport for the Polish source, rank schedule, Borel-function row, stream windows, regular-rational readback, real seal, replay, provenance, and local naming rows.
\item $C$ records displayed $\Cont$ replay from a source query through the rank schedule, Borel-function handoff, readback, and real seal.
\item $G$ is the $\Pkg$ provenance over the sibling surfaces named above.
\item $N$ is the local $\NameCert_{\BaireFunctionRankUp}$ row.
\end{enumerate}
The classifier compares accepted packets only through $P,B,F,S,Q,E,H,C,G,N$. It has no coordinate for a host-space function, a chosen Baire code, quotient equality of functions, countable-choice selection, completed measure structure, or ambient real-completion principle.
\end{definition}

\begin{theorem}[Baire-function rank NameCert obligations]
\label{thm:baire-function-rank-namecert-obligations}
For every accepted $\BaireFunctionRankUp$ carrier
$$
R=(P,B,F,S,Q,E,H,C,G,N),
$$
the local $\NameCert_{\BaireFunctionRankUp}$ surface consists exactly of the following obligations:
\begin{enumerate}
\item carrier admission for the displayed ten-row packet;
\item Polish source exposure, requiring the domain read to pass through $P$ before any rank-facing row is consumed;
\item Borel rank schedule exposure, requiring every inspected predecessor, successor, or limit-stage window to be displayed in $B$;
\item Borel-function handoff, requiring the function row $F$ to connect the source query to the rank schedule before the real readback is used;
\item Real readback nonescape, requiring the route through $S,Q,E$ before any real-facing consumer receives a rank value;
\item transport, requiring $H$ to preserve $P,B,F,S,Q,E,C,G,N$ componentwise;
\item continuation replay, requiring $C$ to replay the same ordered route for each accepted consumer;
\item provenance, requiring $G$ to cite only the displayed PolishSpace, BorelHierarchy, BorelFunction, StreamName, RegSeqRat, and Real sibling surfaces;
\item local naming, requiring $N$ to certify exactly the rows $P,B,F,S,Q,E,H,C,G$.
\end{enumerate}
No $\BaireFunctionRankUp$ obligation stores a selected code, host function quotient, countable-choice selector, measure-completion datum, or ambient $\RealUp$ completeness theorem.
\end{theorem}
\begin{proof}
Project the carrier of \autoref{def:baire-function-rank-carrier}. The tuple displays the Polish source, Borel rank schedule, Borel-function handoff, stream windows, regular rational readback, real seal, transport, replay, provenance, and local naming rows.

The rank-facing read starts at $P,B,F$. The Polish source is exposed first, the Borel hierarchy row supplies only visible rank windows, and the Borel-function row is the single handoff from the source query to that schedule.

The real-facing part is downstream of $S,Q,E$. Stream windows and regular rational readback are consumed before the real seal, so no consumer can replace the route by host equality, selected limits, or ambient real completeness.

Finally $H,C,G,N$ transport, replay, source, and name the same finite packet. Since no row contains a selected Baire code, quotient function equality, countable-choice selector, or measure-completion object, the enumerated obligations exhaust the local certificate surface.
\end{proof}

\begin{theorem}[Baire-function rank Borel handoff]
\label{thm:baire-function-rank-borel-handoff}
Every rank read of an accepted $\BaireFunctionRankUp$ carrier
$$
R=(P,B,F,S,Q,E,H,C,G,N)
$$
passes through
$$
P \longmapsto B \longmapsto F \longmapsto S \longmapsto Q \longmapsto E
$$
before any real-facing consumer may use it. The structural rows $H,C,G,N$ only transport, replay, source, and name that route; they do not add a selected Baire code, quotient equality of functions, countable-choice schedule, measure completion, or ambient $\RealUp$ completeness.
\end{theorem}
\begin{proof}
Use \autoref{thm:baire-function-rank-namecert-obligations}. The Polish source exposure, Borel rank schedule exposure, and Borel-function handoff obligations force the route through $P,B,F$ before a rank value is read.

Apply the Real readback nonescape obligation. It places every real-facing rank use behind the finite stream window $S$, regular rational readback $Q$, and real seal $E$.

The rows $H,C,G,N$ cannot create a second path. They preserve, replay, cite, and name the displayed packet, so the handoff remains the ordered route through the six source and readback rows.
\end{proof}
