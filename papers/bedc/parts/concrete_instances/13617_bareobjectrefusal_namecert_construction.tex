\chapter{A Concrete Naming Certificate for $\BareObjectRefusalUp$}
\label{ch:concrete-instances-bareobjectrefusal-namecert}
\origin{ai}

The $\BareObjectRefusalUp$ packet realizes the bare-object refusal direction of \autoref{sec:visions-philosophy-object-knowledge-namecert} as finite NameCert data. It sits beside the licensed object-knowledge packet of \autoref{ch:concrete-instances-objectknowledgecertificate-namecert}, the description-expansion boundary of \autoref{ch:concrete-instances-definite-description-boundary-namecert}, the apophatic refusal boundary of \autoref{ch:concrete-instances-negativecertificateboundary-namecert}, and the classifier boundary of \autoref{ch:concrete-instances-classifierboundary-namecert}. Those siblings license object names, regulate descriptions, record apophatic refusal rows, and expose classifier-boundary rows; this packet records the failed five-field object license itself.

The packet is composite over \autoref{ch:concrete-instances-objectknowledgecertificate-namecert}, \autoref{ch:concrete-instances-definite-description-boundary-namecert}, \autoref{ch:concrete-instances-negativecertificateboundary-namecert}, and \autoref{ch:concrete-instances-classifierboundary-namecert}; it bundles their boundary rows into one failed-license certificate.

\begin{definition}[Bare-object refusal carrier]
\label{def:bare-object-refusal-carrier}
A $\BareObjectRefusalUp$ carrier is a finite $\BHist$ packet
$$
B=(O,M,R,W,L,H,C,P,N)
$$
with the following displayed rows:
\begin{enumerate}
\item $O$ is the requested object-name row whose proposed use is tested against the object-knowledge certificate discipline.
\item $M$ is the missing-field row, recording which of source, pattern, classifier, stability, and ledger is absent or refused for the requested object license.
\item $R$ is the refusal row that prevents the requested name from being exported as an object-layer license while $M$ is nonempty.
\item $W$ is the witness-audit row recording that no auditable witness row has been supplied for the requested object read.
\item $L$ is the anti-primitive ledger row recording that the refusal cannot be bypassed by treating the name as a bare object primitive.
\item $H$ records componentwise $\hsame$ transport for the requested name, missing-field row, refusal row, witness audit, ledger row, continuation row, package row, and local naming row.
\item $C$ records the displayed $\Cont$ routes by which consumers read the missing fields, refusal, witness audit, and ledger nonescape rows.
\item $P$ is the $\Pkg$ provenance over $\ObjectKnowledgeCertificateUp$, $\DefiniteDescriptionBoundaryUp$, $\NegativeCertificateBoundaryUp$, $\ClassifierBoundaryUp$, $\BHist$, $\hsame$, $\Cont$, $\Pkg$, and $\NameCert$ rows.
\item $N$ is the local $\NameCert_{\BareObjectRefusalUp}$ row.
\end{enumerate}
The carrier has no coordinate for a licensed object name, witness-free knowledge export, primitive object token, host ontology, or object-layer license detached from the displayed five-field certificate check.
\end{definition}

\begin{theorem}[Bare-object refusal NameCert obligations]
\label{thm:bare-object-refusal-namecert-obligations}
For the carrier of \autoref{def:bare-object-refusal-carrier}, the local $\NameCert_{\BareObjectRefusalUp}$ surface consists of five obligation rows:
\begin{enumerate}
\item source refusal records the requested object-name row $O$ and the absence of an accepted source field in $M$;
\item pattern refusal records that no displayed pattern row licenses $O$ as an object read;
\item classifier refusal records that no accepted classifier row turns $O$ into an object-identity surface;
\item stability refusal records that no componentwise transport may convert the missing fields into a stable object license;
\item ledger refusal records the anti-primitive row $L$, witness-audit row $W$, refusal row $R$, routes $C$, provenance $P$, and local naming row $N$ as the only public export.
\end{enumerate}
Consequently a public consumer of an accepted $\BareObjectRefusalUp$ packet receives a refusal certificate for the failed object license, not a weak object license.
\end{theorem}
\leanchecked{BEDC.Derived.BareObjectRefusalUp.BareObjectRefusalCarrier\_namecert\_obligations}
\begin{proof}
Carrier admission is projection from the displayed tuple $B=(O,M,R,W,L,H,C,P,N)$. The missing-field row $M$ is the only place where the five object-knowledge fields are named, and it records absence or refusal rather than a licensed object packet.

The first four obligation rows inspect the failed source, pattern, classifier, and stability fields. They show that the requested name has not met the object-knowledge discipline of \autoref{ch:concrete-instances-objectknowledgecertificate-namecert}; description expansion, negative-certificate refusal, and classifier-boundary rows remain sibling surfaces rather than substitutes for the missing object license.

The ledger obligation then closes the export. The witness-audit row $W$, refusal row $R$, anti-primitive ledger $L$, transports $H$, routes $C$, provenance $P$, and local naming row $N$ expose only the failed-license packet. Since no carrier coordinate contains a licensed object name or witness row, the consumer cannot repack the refusal as object knowledge.
\end{proof}

\begin{theorem}[Bare-object refusal obligation carrier]
\label{thm:bare-object-refusal-obligation-carrier}
Every accepted $\BareObjectRefusalUp$ packet must expose the rows
$$
O,M,R,W,L,H,C,P,N
$$
before any consumer reads the requested name as an object-layer license. In particular, source, missing-field, refusal, witness-audit, anti-primitive ledger, transport, replay, provenance, and local naming data are public parts of the same finite carrier.
\end{theorem}
\begin{proof}
Project the carrier tuple of \autoref{def:bare-object-refusal-carrier}. Its coordinates are exactly $O,M,R,W,L,H,C,P,N$, and no coordinate stores a licensed object name detached from the missing-field row.

The object-knowledge sibling of \autoref{ch:concrete-instances-objectknowledgecertificate-namecert} supplies a positive route only when source, pattern, classifier, stability, ledger, object-name, and witness rows are displayed. The description, apophatic, and classifier siblings of \autoref{ch:concrete-instances-definite-description-boundary-namecert}, \autoref{ch:concrete-instances-negativecertificateboundary-namecert}, and \autoref{ch:concrete-instances-classifierboundary-namecert} regulate boundary rows without replacing the missing object-license carrier.

Thus any read of $O$ as an object license must first pass through the exposed refusal tuple, and the $\BareObjectRefusalUp$ packet exports the requested name only as part of that finite failed-license carrier.
\end{proof}

\begin{theorem}[Bare-object refusal classifier preservation]
\label{thm:bare-object-refusal-obligation-classifier}
Same-packet comparison for $\BareObjectRefusalUp$ preserves the missing-field row $M$ and the refusal row $R$. It cannot turn an absent classifier field into object identity by using $\hsame$ transport, continuation replay, package provenance, local naming, or any sibling boundary packet.
\end{theorem}
\begin{proof}
Compare two accepted reads of the same carrier $B=(O,M,R,W,L,H,C,P,N)$. Componentwise $\hsame$ transport in $H$ preserves the displayed coordinates; it does not create a new classifier coordinate.

The classifier boundary sibling of \autoref{ch:concrete-instances-classifierboundary-namecert} exposes classifier-boundary rows only as displayed boundary data. The object-knowledge sibling of \autoref{ch:concrete-instances-objectknowledgecertificate-namecert} requires an accepted classifier field for object identity, while the description and negative-certificate siblings of \autoref{ch:concrete-instances-definite-description-boundary-namecert} and \autoref{ch:concrete-instances-negativecertificateboundary-namecert} do not synthesize that missing field.

Therefore same-packet comparison can preserve the refusal surface, but it cannot convert the absent classifier entry recorded in $M$ into a licensed object-identity row.
\end{proof}

\begin{theorem}[Bare-object refusal ledger export]
\label{thm:bare-object-refusal-obligation-ledger}
The only public export of an accepted $\BareObjectRefusalUp$ packet is the anti-primitive ledger row $L$ together with the witness-audit row $W$ and their displayed refusal routes, unless a separate $\ObjectKnowledgeCertificateUp$ route is displayed.
\end{theorem}
\begin{proof}
Read the ledger part of the carrier. Rows $W,L$ record that no auditable witness has been supplied and that the requested name cannot be treated as a primitive object token; rows $R,C,P,N$ expose the refusal, replay, provenance, and local naming around that ledger.

The positive export route belongs to \autoref{ch:concrete-instances-objectknowledgecertificate-namecert}. The sibling boundaries of \autoref{ch:concrete-instances-definite-description-boundary-namecert}, \autoref{ch:concrete-instances-negativecertificateboundary-namecert}, and \autoref{ch:concrete-instances-classifierboundary-namecert} can route or refuse descriptions and classifiers, but they do not provide the source-pattern-classifier-stability-ledger package required for object knowledge.

Hence the public packet exported by $\BareObjectRefusalUp$ remains the anti-primitive and witness-audit refusal surface, except when an independent $\ObjectKnowledgeCertificateUp$ certificate supplies the missing positive route.
\end{proof}

\begin{theorem}[Bare-object refusal object-license nonescape]
\label{thm:bare-object-refusal-object-license-nonescape}
Every accepted $\BareObjectRefusalUp$ packet exports only the requested-name, missing-field, refusal, witness-audit, anti-primitive ledger, transport, route, provenance, and local naming rows
$$
O,M,R,W,L,H,C,P,N.
$$
It cannot export an object-layer license unless the read factors through an existing $\ObjectKnowledgeCertificateUp$ packet with displayed source, pattern, classifier, stability, ledger, object-name, and witness rows.
\end{theorem}
\leanchecked{BEDC.Derived.BareObjectRefusalUp.BareObjectRefusalCarrier\_object\_license\_nonescape}
\begin{proof}
Start with the NameCert obligations above. They make the missing source, pattern, classifier, stability, and ledger fields part of the refusal surface, so the local packet records a failed object license rather than a partial one.

Use the object-knowledge sibling. \autoref{ch:concrete-instances-objectknowledgecertificate-namecert} exposes licensed object knowledge only through its object-name, witness, five-field certificate, audit-route, transport, and local naming rows. None of those licensed rows is present in the $\BareObjectRefusalUp$ carrier except as refused or missing data.

Finally apply the anti-primitive ledger row. The ledger $L$ records that a consumer cannot treat $O$ as a primitive object token after the five-field certificate check has failed. Thus any accepted object-layer license must come from the sibling $\ObjectKnowledgeCertificateUp$ route, while this packet exports only the refusal rows listed above.
\end{proof}
